    // why get listed

    Best of AI tracks {{ partial "count.html" (len $models) }} models across {{ partial "count.html" (len $types) }} model types, alongside the tools that use them. The full dataset is open at /index.json, so other projects pull from it too.

    Listings are free, permanent, and not ranked by payment — only by community-assessed quality.

    // what happens next
    Issue posted

    Goes into the GitHub submissions queue. You can track it and answer follow-up questions from maintainers.

    Maintainers review

    Checked in batches, usually within a few days — verifying the model is real, type fits, and description is accurate.

    Added to the directory

    Accepted models get a Markdown file and appear after the next deploy. The issue closes with a link to the new listing.

    // what gets accepted

    There's no strict bar to clear, but a few things affect how quickly a submission gets merged. The model should be publicly released or documented in a paper, not vaporware or a rumor. The description should say what the model actually does rather than repeating marketing copy.

    Duplicate entries and submissions without enough information to verify the model are the most common reasons for rejection. When in doubt, submit anyway — the issue will get a note if something's missing.

    // common questions
    Is there a fee to get listed?

    No. Best of AI is a free, open source directory. Listing a model costs nothing and there are no paid placements or promoted spots.

    How long does review take?

    Most submissions get reviewed within a few days. Maintainers work through the queue in batches. If yours has been open for more than a week without a response, add a comment to bump it.

    What if the model already has a listing with wrong information?

    Open an issue to flag the correction, or submit a PR directly to the model's Markdown file in content/models/. The filename matches the model's slug.

    What if no model type fits?

    Pick the closest match and mention the gap in the issue. New types get added when enough models warrant one.

    Can I use the directory data in my own project?

    Yes. The full index is available at /index.json and the raw Markdown files are in the public GitHub repository. No API key or account needed.
