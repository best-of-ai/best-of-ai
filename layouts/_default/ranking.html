// how ranking works

Usage matters, but the leaderboard isn't a straight popularity ranking. A good tool with a small audience can belong. A viral one that doesn't work probably shouldn't. We make the call based on whether the tool does what it says for the people who use it.

// what happens next
Suggestion posted

Goes into the GitHub issues queue. You can track it and add more context there.

Maintainers review

Checked in batches, usually within a few days. If they need more information, they'll comment on the issue.

Change goes live

Accepted changes go live after the next deploy. The issue closes with a note on what changed.
