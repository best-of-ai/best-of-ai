## Resumo

A Best of AI é um diretório de ferramentas de IA que vale a pena usar. Uma pessoa verifica cada item antes de publicá-lo. Ninguém paga para entrar ou para subir no ranking.

## Por que existe

A maioria das “listas de ferramentas de IA” na internet copia as outras, está cheia de links quebrados e tem muitos itens que são apenas interfaces simples sobre a API de terceiros. A Best of AI é criada e mantida por [Dariush Abbasi](https://github.com/dariubs), que queria uma lista confiável, não uma feita para vender posições. O projeto segue os princípios do código aberto: os dados e o código são públicos, e qualquer pessoa pode revisar um item ou sugerir uma correção.

## O que você encontra aqui

- Ferramentas organizadas por categoria, de assistentes de escrita a geradores de imagens
- Páginas para profissões específicas, para que fotógrafos ou advogados vejam apenas o que é relevante
- Um [ranking](/leaderboard/) que classifica ferramentas pela utilidade real, não pelo orçamento de marketing
- Páginas de alternativas para comparar uma ferramenta com outras que fazem o mesmo trabalho
- Diretórios de empresas de IA, hardware e modelos para quem quer ir além de “este é um aplicativo”

## Para quem é

Para qualquer pessoa que queira encontrar uma ferramenta que resolva um problema real, sem ter que atravessar spam de afiliados para chegar até ela.
