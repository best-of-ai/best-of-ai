Este repositório reúne as seguintes skills:

- **Video to Super Prompt**: converte gravações de tela em prompts detalhados para geração de código.
- **HTML to Interaction Prompts**: extrai prompts reutilizáveis de páginas HTML existentes.
- **Build Isometric ARPG**: estrutura o desenvolvimento de jogos de RPG com Three.js.
- **Design Action Combat**: define e ajusta a arquitetura de sistemas de combate em jogos.
- **Test Playable Web Games**: oferece QA e validação para jogos jogáveis no navegador.
- **Landing Page**: fluxo de trabalho de design web e otimização de conversão.
- **Three.js**: gerenciamento de gráficos 3D e cenas WebGL.
- **Animation on Scroll**: padrões de animação acionada pela rolagem.
- **Shader Cursor Trail**: efeitos de interação do cursor com WebGL.
- **Glass Dark Mode UI**: sistema de design e linguagem visual.
