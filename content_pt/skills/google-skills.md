Este repositório reúne as seguintes skills:

- **google-ads-api-quickstart**: Orienta sobre credenciais, escolha entre seis bibliotecas cliente ou REST e primeira chamada à API.
- **google-ads-api-account-diagnostics**: Diagnostica problemas de conta, como conversões perdidas ou baixo volume de leads.
- **google-ads-api-mcp-setup**: Instala e configura o servidor MCP oficial e de código aberto do Google Ads.
- **data-manager-api-setup**: Configura bibliotecas cliente e autenticação para a Data Manager API.
- **data-manager-api-event-ingestion**: Implementa ingestão de eventos e conversões com a Data Manager API.
- **data-manager-api-audience-ingestion**: Adiciona, remove e limpa membros de públicos pela Data Manager API.
- **google-mobile-ads-banner**: Adiciona anúncios de banner do Google Mobile Ads a aplicativos Android e outros aplicativos móveis.
- **google-mobile-ads-android-migrate-to-next-gen**: Migra um aplicativo Android do SDK legado do Google Mobile Ads para a próxima geração.
