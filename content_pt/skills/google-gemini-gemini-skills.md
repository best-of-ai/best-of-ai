Este repositório reúne as seguintes skills:

- **gemini-api-dev**: Abrange geração de texto, conversas com várias interações e uso multimodal da API Gemini.
- **gemini-live-api-dev**: Abrange aplicativos de streaming bidirecional em tempo real com a Gemini Live API.
- **gemini-api-cli**: Chama a API Gemini pelo shell para gerar mídia e trabalhar com arquivos.
- **gemini-omni-flash-api**: Abrange geração e edição de vídeo com referências de texto, imagem e vídeo.
