Este repositório reúne as seguintes skills:

- **offensive-active-directory**: Abrange reconhecimento de Active Directory e metodologia de ataque em operações internas de red team.
- **offensive-netexec**: Abrange o uso do NetExec para enumeração de rede e pós-exploração.
- **offensive-api-security**: Metodologia para testar APIs REST, gRPC e WebSocket.
- **offensive-api-abuse**: Abrange abuso de lógica de negócios e padrões avançados de ataque a APIs.
- **offensive-jwt**: Abrange ataques a JWT, como confusão de algoritmo e secrets HMAC fracos.
- **offensive-cicd-pipeline**: Abrange vulnerabilidades em pipelines de CI/CD, incluindo injeção no GitHub Actions.
