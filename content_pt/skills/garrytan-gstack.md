Este repositório reúne as seguintes skills:

- **office-hours**: Faz perguntas diretas sobre uma ideia de produto antes de qualquer código ser escrito.
- **plan-ceo-review**: Revisa o escopo do projeto e reformula o problema subjacente.
- **plan-eng-review**: Revisa arquitetura, fluxo de dados e planos de teste.
- **review**: Executa uma revisão de código voltada à produção e aplica correções automaticamente.
- **qa**: Testa o aplicativo em um navegador ativo e gera testes de regressão.
- **ship**: Abre um pull request e configura uma estrutura de testes se estiver faltando.
- **design-consultation**: Gera um sistema de design completo para o projeto.
- **design-shotgun**: Produz vários mockups visuais para explorar direções de design.
- **cso**: Executa uma auditoria de segurança baseada em OWASP e STRIDE.
- **document-release**: Atualiza automaticamente a documentação do projeto.
