- **acquire-codebase-knowledge**: Ajuda um agente a entender uma base de código existente.

- **aws-cost-optimize**: Procura maneiras de reduzir os gastos com a nuvem AWS.
- **codeql**: Aplica análise estática de segurança baseada em CodeQL.
- **architecture-blueprint-generator**: Produz documentação da arquitetura do sistema.
- **conventional-commit**: Aplica o formato de mensagens Conventional Commits.
- **agent-owasp-compliance**: Verifica o comportamento do agente com base nas orientações de segurança OWASP.
- **copilot-pr-autopilot**: Automatiza partes do fluxo de trabalho de pull requests.
- **anti-ui-slop**: Sinaliza resultados de interface de baixa qualidade ou com aparência genérica.
