Este repositório reúne as seguintes skills:

- **grill-with-docs**: conduz uma sessão de planejamento que cria um modelo de domínio e atualiza a documentação do projeto.
- **triage**: move issues por um fluxo de trabalho com estados definidos.
- **improve-codebase-architecture**: examina uma base de código e aponta onde sua arquitetura poderia ser aprofundada.
- **to-spec**: transforma uma conversa em uma especificação escrita para um rastreador de issues.
- **to-tickets**: divide um plano em tickets pequenos e ordenados, registrando as dependências.
- **implement**: desenvolve um recurso a partir de uma especificação usando desenvolvimento orientado a testes.
- **wayfinder**: planeja trabalhos grandes como um conjunto de tickets de decisão interligados.
- **prototype**: cria um protótipo descartável para responder a uma questão de design.
- **diagnosing-bugs**: executa um ciclo estruturado para investigar bugs difíceis.
- **research**: investiga uma questão com base em fontes primárias.
- **domain-modeling**: cria e refina o modelo de domínio de um projeto.
- **code-review**: revisa o código conforme os padrões de programação e a especificação original.
