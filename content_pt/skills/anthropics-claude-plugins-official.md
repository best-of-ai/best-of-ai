Este repositório reúne as seguintes skills:

- **skill-creator**: Ferramentas para criar novas Agent Skills.
- **frontend-design**: Orientações para criar interfaces distintas e intencionais.
- **code-review**: Revisa diffs ou pull requests quanto à correção e qualidade.
- **code-simplifier**: Simplifica e limpa código existente.
- **claude-security**: Plugin com foco em segurança para o uso do Claude Code.
- **pr-review-toolkit**: Conjunto de ferramentas para revisar pull requests.
- **hookify**: Ajuda a configurar hooks do Claude Code.
- **mcp-server-dev**: Apoio ao desenvolvimento de servidores MCP.
- **agent-sdk-dev**: Apoio ao desenvolvimento com o Claude Agent SDK.
