Este repositório reúne as seguintes skills:

- **interview-me**: Extrai requisitos fazendo perguntas direcionadas.
- **spec-driven-development**: Escreve um PRD antes de qualquer código.
- **constraint-driven-development**: Define e aplica padrões de qualidade ao projeto.
- **planning-and-task-breakdown**: Divide uma especificação em tarefas verificáveis individualmente.
- **incremental-implementation**: Entrega o trabalho em etapas verticais pequenas e testadas.
- **test-driven-development**: Aplica o ciclo red-green-refactor.
- **context-engineering**: Gerencia quais informações chegam ao agente e quando.
- **doubt-driven-development**: Executa uma revisão de código adversarial.
- **frontend-ui-engineering**: Orienta decisões de design de componentes e interfaces.
- **api-and-interface-design**: Aplica design baseado em contratos a APIs e interfaces.
- **browser-testing-with-devtools**: Usa o Chrome DevTools para inspecionar um aplicativo em execução.
- **code-review-and-quality**: Revisa o código com cinco critérios de qualidade distintos.
- **security-and-hardening**: Verifica o código em relação ao OWASP Top 10.
- **git-workflow-and-versioning**: Aplica um fluxo Git baseado em trunk.
- **shipping-and-launch**: Executa uma implantação gradual ao lançar uma alteração.
