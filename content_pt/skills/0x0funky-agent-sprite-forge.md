description: O agente gera uma imagem principal e, em seguida, cria um clipe de imagem
  para vídeo para cada movimento. Ferramentas Python determinísticas validam, aplicam
  chroma key, registram, fazem loop, ajustam o tempo e empacotam cada movimento para
  Godot, Aseprite ou um jogo web. Os loops são escolhidos por medição, e animações
  de execução única têm o tempo ajustado à velocidade do jogo. Funciona como plugin
  do Claude Code e com Codex e Grok.
