Este repositório reúne as seguintes skills:

- **stitch::code-to-design**: Converte código existente em um design do Stitch.
- **stitch::generate-design**: Gera um novo design a partir de um prompt.
- **stitch::manage-design-system**: Gerencia o sistema de design de um projeto no Stitch.
- **stitch::react-components**: Gera componentes React a partir de um design do Stitch.
- **stitch::react-native**: Gera código React Native a partir de um design do Stitch.
- **remotion**: Gera código de vídeo Remotion a partir de um design do Stitch.
- **shadcn-ui**: Gera componentes baseados em shadcn/ui.
- **enhance-prompt**: Skill utilitária que aprimora um prompt de design antes da geração.
- **taste-design**: Skill utilitária para avaliar a qualidade do design.
