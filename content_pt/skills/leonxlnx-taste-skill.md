Este repositório reúne as seguintes skills:

- **design-taste-frontend**: Infere uma linguagem visual a partir do briefing e gera esqueletos de código GSAP.
- **gpt-taste**: Variante mais rigorosa ajustada para GPT e Codex, com maior variação de layout.
- **image-to-code**: Gera primeiro uma imagem de referência e depois cria o frontend para corresponder a ela.
- **redesign-existing-projects**: Audita uma interface existente e corrige layout e espaçamento.
- **high-end-visual-design**: Busca uma aparência mais serena, com contraste suave e fontes sofisticadas.
- **minimalist-ui**: Produz interfaces em estilo editorial com paleta de cores contida.
- **industrial-brutalist-ui**: Produz um estilo de alto contraste baseado na tipografia suíça.
- **imagegen-frontend-web**: Gera imagens de referência de sites com ênfase em tipografia e espaçamento.
- **imagegen-frontend-mobile**: Gera protótipos de telas móveis para iOS, Android e aplicativos multiplataforma.
- **brandkit**: Gera um painel de identidade de marca com logotipo, paleta de cores e escolhas tipográficas.
