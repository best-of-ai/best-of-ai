Este repositório reúne as seguintes skills:

- **camerax**: Orienta a criação de recursos de câmera com CameraX.
- **android-cli**: Explica como instalar e usar a ferramenta de linha de comando do Android.
- **appfunctions**: Encontra fluxos de aplicativos que podem ser expostos como AppFunctions, por exemplo, criar uma nota.
- **ml-kit-genai-prompt-api**: Adiciona a API ML Kit GenAI Prompt a uma base de código Android.
- **mlkit-agent-api**: Cria fluxos de agentes no dispositivo com a API ML Kit GenAI Agent.
- **restore-credentials**: Implementa a restauração de credenciais com a biblioteca Credential Manager.
- **verified-email**: Implementa a recuperação de e-mails verificados pelo Credential Manager.
- **android-for-cars-parked-apps**: Adapta aplicativos de vídeo, jogos e navegador para funcionar como aplicativos estacionados no Android Auto.
