Este repositório reúne as seguintes skills:

- **baseline-ui**: Corrige código de interface mal acabado, ajustando espaçamento, hierarquia e tipografia.
- **improve-ui**: Audita uma tela de produto com base nas próprias evidências de design e registra problemas verificados.
- **fixing-accessibility**: Audita e corrige rótulos ARIA, navegação por teclado, foco e contraste.
- **fixing-metadata**: Corrige títulos de página, metadescrições, URLs canônicas e tags Open Graph.
- **fixing-motion-performance**: Encontra atualizações repetidas de layout e outros problemas de desempenho de animação.
- **create-design-md**: Cria ou atualiza um DESIGN.md com base em um repositório ou site público existente.
- **component-canvas**: Cria um canvas com panorâmica e zoom para explorar componentes de interface e variantes.
