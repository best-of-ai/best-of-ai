O trabalho de IA do GitHub gira em torno do Copilot, que começou como preenchimento de código em linha e hoje inclui chat, revisão de código e um agente que recebe issues e abre pull requests. O Copilot é vendido como parte de uma assinatura do GitHub, com planos superiores para uso mais intenso.

O Agent HQ, anunciado no Universe em outubro de 2025 e lançado de forma mais ampla no início de 2026, muda a proposta. Em vez de oferecer apenas o próprio agente da Microsoft, o GitHub permite que assinantes deleguem tarefas a agentes de programação da Anthropic, OpenAI, Google, Cognition e xAI. Uma tela do Mission Control acompanha o trabalho de cada agente, e administradores escolhem quais agentes e modelos suas equipes podem usar. O Codex, da OpenAI, foi o primeiro agente externo a aparecer ali, seguido pelo Claude Code.

O Plan Mode, um painel de métricas e uma etapa de revisão integrada, que verifica o código do agente antes de mostrá-lo ao desenvolvedor, completam o conjunto de recursos. A aposta do GitHub é que não precisa criar o melhor agente se controlar o espaço onde todos eles trabalham.
