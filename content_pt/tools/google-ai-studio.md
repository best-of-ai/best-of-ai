Google AI Studio é o lugar onde desenvolvedores experimentam os modelos do Google sem precisar configurar nada. Você entra com uma conta Google, escolhe um modelo Gemini e começa a criar prompts em um playground que permite ajustar configurações como temperatura, adicionar instruções de sistema e anexar imagens, áudio, vídeo ou documentos. Quando um prompt funciona, um clique fornece o código para executá-lo pela API Gemini em Python, JavaScript e outras linguagens.

A ferramenta se expandiu para além de um playground. Um modo de criação pode gerar um pequeno aplicativo web funcional a partir de uma descrição, que você pode visualizar, editar e implantar. Live mode permite testar conversas de voz e vídeo em tempo real com um modelo, e outras ferramentas cobrem geração de imagens, geração de vídeos e saídas estruturadas. Também é onde se criam e gerenciam chaves da API Gemini e se consulta o uso.

O uso é gratuito dentro dos limites de frequência, o que torna a ferramenta popular para prototipagem e aprendizagem. Em produção, paga-se pelo uso da API Gemini ou migra-se para Vertex AI no Google Cloud, que acrescenta recursos empresariais como governança de dados e acordos de nível de serviço. No plano gratuito, o Google pode usar prompts para melhorar seus produtos, então não envie dados sensíveis. Entre as alternativas estão OpenAI Playground, Anthropic Console e o playground do AWS Bedrock.
