Mutable AI era uma startup que criava ferramentas de IA para programadores. Sua extensão para VS Code oferecia preenchimento de código, refatoração e chat capaz de responder a perguntas sobre um projeto, e o recurso AutoPilot buscava implementar uma funcionalidade descrita em uma base de código. Mais tarde, a equipe ficou conhecida por transformar repositórios em documentação legível no estilo wiki, ajudando desenvolvedores a entender código desconhecido.

A Google adquiriu a empresa, e o site original da Mutable AI não funciona mais. A ideia de gerar uma wiki atualizada para uma base de código continua nos próprios produtos do Google, que passaram a oferecer ferramentas de documentação baseadas nesse conceito. Usuários da extensão antiga precisaram migrar para outros assistentes, pois o serviço independente foi encerrado.

Hoje, há várias opções para funções semelhantes. GitHub Copilot, Cursor e Claude Code oferecem preenchimento, refatoração e alterações agênticas, enquanto ferramentas como DeepWiki e os recursos de documentação de código do Google geram explicações de repositórios. Sourcegraph e Greptile oferecem pesquisa e compreensão de código em projetos grandes. Esta página foi mantida como referência porque artigos e listas comparativas antigos ainda mencionam Mutable AI.
