Perspective usava aprendizado de máquina para ajudar a moderar conversas on-line. Um site enviava um comentário à API e recebia pontuações de características como toxicidade, insulto, palavrões e ameaça. Editoras e plataformas usavam os resultados para sinalizar comentários para revisão, alertar autores antes da publicação ou ordenar discussões. Organizações de notícias e fóruns a usavam para lidar com grandes volumes de comentários, e pesquisadores estudavam abusos on-line com a ferramenta.

O serviço também gerou debates. Estudos descobriram possíveis vieses, como pontuações mais altas de toxicidade para comentários que mencionavam certos termos de identidade; a API não substituía moderadores humanos. O Jigsaw reconheceu limitações e trabalhou para reduzir vieses, e o modelo foi amplamente usado como referência em pesquisas sobre toxicidade.

O Jigsaw deixou de aceitar novas solicitações e anunciou que encerrará o serviço. Operadores que dependem dele precisam migrar para outras ferramentas de moderação, como a API de moderação da OpenAI, Azure AI Content Safety, Hive, Sightengine ou modelos abertos de classificação de toxicidade, além de manter revisão humana. Esta página permanece para referência porque muitos guias de moderação e artigos de pesquisa mencionam Perspective.
