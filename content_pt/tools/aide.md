Aide era um editor de código com IA como prioridade, criado pela startup londrina CodeStory. Era uma bifurcação do VS Code, portanto tinha aparência familiar e aceitava extensões, mas adicionava uma camada de IA que entendia o projeto. Era possível conversar sobre a base de código, solicitar alterações em vários arquivos e receber sugestões de código com contexto mais amplo. O projeto foi lançado como código aberto sob a licença AGPL e despertou bastante interesse entre desenvolvedores que buscavam uma alternativa ao Cursor.

A CodeStory também pesquisava programação baseada em agentes, incluindo benchmarks que medem se um modelo consegue corrigir problemas reais em repositórios de código aberto. O editor fazia parte desse trabalho e permitia que as pessoas experimentassem programação agêntica em seus próprios projetos, com vários modelos à escolha.

O desenvolvimento foi interrompido, e o editor não recebe mais manutenção. O código continua disponível no GitHub para quem quiser criar uma bifurcação, mas novos usuários encontram opções melhores entre ferramentas atualizadas ativamente. Cursor, Windsurf, Cline e GitHub Copilot são as alternativas mais comuns; Void era outro editor de código aberto da mesma categoria. Esta página permanece como referência, pois artigos antigos e páginas comparativas ainda mencionam Aide.
