n8n permite criar automações conectando nós em uma tela, de forma semelhante ao Zapier ou Make, mas com mais espaço para código. Cada nó representa uma etapa: um gatilho, como webhook ou agendamento; uma ação em um aplicativo; ou um bloco que transforma dados com JavaScript ou Python. Centenas de integrações estão incluídas, e um nó HTTP genérico cobre os demais casos. Os fluxos podem ter ramificações, loops e chamadas a outros fluxos, atendendo desde notificações simples até pipelines de dados elaborados.

A IA agora ocupa parte importante do produto. n8n inclui nós para modelos de linguagem, ferramentas, memória e bancos vetoriais, permitindo criar agentes que leem e-mails, pesquisam documentos, chamam APIs e decidem o que fazer em seguida. É possível acompanhar cada execução passo a passo, exigir aprovação humana antes de ações sensíveis e trocar de provedor de modelos. Isso tornou a plataforma popular para prototipar e operar agentes de IA sem desenvolver um aplicativo completo.

O código está disponível no GitHub sob uma licença fair-code, e pode ser executado em um servidor próprio ou no Docker, mantendo os dados no ambiente da equipe. n8n Cloud é a opção hospedada, com planos que variam conforme as execuções; planos corporativos acrescentam login único, controles de acesso e registros de auditoria. A hospedagem própria custa pouco, mas exige cuidar de atualizações, segurança e disponibilidade. Zapier é mais simples para quem não é técnico, e Make é o concorrente visual mais próximo.
