GPT Engineer foi um dos primeiros projetos a mostrar que um modelo de linguagem poderia gerar um programa funcional completo a partir de um prompt. O usuário escrevia uma especificação, a ferramenta fazia perguntas para esclarecer requisitos e depois produzia arquivos e código. A versão de linha de comando de código aberto atraiu uma grande comunidade de desenvolvedores.

Os fundadores criaram um produto hospedado, gptengineer.app, que permitia a pessoas sem experiência em programação descrever um aplicativo web e vê-lo construído. Esse produto mudou de nome para Lovable, que se tornou um dos construtores de aplicativos com IA mais conhecidos. O repositório original de código aberto continua disponível para experimentar fluxos de prompt para código.

Para criar aplicativos atualmente, a ferramenta a considerar é Lovable. Outros construtores de aplicativos por prompt incluem Bolt, v0, Replit e Base44; para programação agêntica em repositórios, há Claude Code, Cursor e Codex. GPT Engineer é indicado para quem tem curiosidade sobre as origens das ferramentas de prompt para aplicativos.
