LiteLLM resolve o problema de integrar vários provedores de modelos. Desenvolvedores escrevem o código uma vez usando o formato da OpenAI, e LiteLLM traduz a chamada para o provedor escolhido. Para trocar de modelo, basta mudar um nome, sem reescrever o código.

O servidor proxy acrescenta recursos para equipes: um gateway com chaves virtuais, orçamentos e limites de requisições por equipe, registros, balanceamento de carga entre implantações e alternância automática para outro provedor quando ocorre uma falha. Equipes de plataforma o usam para oferecer aos usuários internos um acesso controlado aos modelos e acompanhar os custos.

LiteLLM é gratuito e de código aberto, com uma versão empresarial paga que adiciona recursos como logon único e registros de auditoria. Operar um gateway significa assumir sua operação e segurança. Entre as alternativas estão OpenRouter, Portkey, Cloudflare AI Gateway, Helicone e Kong AI Gateway. LiteLLM é indicado para desenvolvedores e equipes de plataforma que gerenciam vários provedores de modelos.
