Amazon Q Developer é o sucessor de CodeWhisperer e foi criado em torno do conhecimento da AWS. No VS Code, JetBrains e outras IDEs, oferece sugestões de código em linha e um painel de conversa que explica código, escreve testes e otimiza funções. No terminal, acrescenta preenchimento automático e um chat que traduz linguagem simples em comandos de shell. No console AWS e em plataformas de chat, como Slack, ajuda a solucionar problemas de serviços e explicar por que um recurso não está funcionando como esperado.

Os recursos de agente lidam com tarefas maiores. Um agente pode ler seu projeto, planejar o trabalho, editar vários arquivos e executar comandos para concluir um recurso, escrever documentação ou revisar código. Agentes especializados de transformação atualizam versões de Java e portam aplicativos .NET para execução no Linux, trabalho tedioso em grandes bases de código. Uma verificação integrada encontra problemas de segurança no código e sugere correções.

Um nível gratuito oferece uso mensal limitado, e o plano Pro pago aumenta os limites e acrescenta controles administrativos, incluindo o compromisso de não usar seu conteúdo para melhorar o serviço. A AWS vem direcionando seu trabalho mais recente com agentes para Kiro, sua própria IDE centrada em IA, então os plugins Q Developer são uma entre várias opções da AWS. O produto faz mais sentido para equipes que trabalham na AWS, enquanto GitHub Copilot e Cursor são concorrentes mais generalistas.
