Os modelos podem usar métodos de eventos discretos, baseados em agentes ou de dinâmica de sistemas, isoladamente ou combinados. Os usuários executam experimentos, visualizam animações e analisam resultados. Scripts em Java permitem criar lógica personalizada.

Há uma versão gratuita para aprendizado; as licenças profissionais são pagas.

Simul8 e Arena são alternativas. O AnyLogic é indicado para engenheiros industriais que realizam estudos de simulação.
