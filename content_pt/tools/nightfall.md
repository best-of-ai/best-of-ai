Nightfall protege os dados nas ferramentas usadas diariamente pelas empresas. Conecta-se a aplicativos como Slack, Google Drive, GitHub e Salesforce, examina conteúdos em busca de dados pessoais, informações de pagamento e chaves de API e emite alertas ou age quando os encontra. A detecção usa aprendizado de máquina, em vez de depender apenas da correspondência de padrões.

Os recursos de correção podem ocultar, colocar em quarentena ou excluir dados expostos e notificar usuários com orientações. A empresa acrescentou proteção para o uso de IA, examinando prompts e arquivos enviados a ferramentas de chat para evitar que funcionários compartilhem informações confidenciais com modelos.

Nightfall é vendida por assinatura a equipes de segurança. Soluções de prevenção contra perda de dados sempre precisam de ajustes para limitar falsos alarmes. Entre as alternativas estão Microsoft Purview, Cyberhaven, Netskope, Symantec DLP e Varonis. Nightfall atende equipes de segurança que protegem dados em SaaS.
