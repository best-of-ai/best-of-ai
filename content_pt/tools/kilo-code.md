O Kilo Code funciona como extensão do VS Code e do JetBrains, como ferramenta de linha de comando e como app de desktop. Ele tem agentes para programar, planejar, fazer perguntas e depurar, e você pode definir os seus. Os agentes podem passar trabalho a subagentes e rodar em paralelo, e os agentes na nuvem podem continuar trabalhando pelo navegador, pelo Slack ou por um app de celular. O código tem licença MIT, e a ferramenta de linha de comando é um fork do OpenCode.

Você escolhe como pagar pelos modelos. O Kilo Gateway direciona para mais de 500 modelos e repassa os preços dos provedores sem acréscimo, você pode trazer suas próprias chaves ou rodar modelos locais com Ollama ou LM Studio. Um Code Reviewer revisa pull requests automaticamente, e um marketplace lista agentes, skills e servidores MCP.

A extensão é gratuita. Os planos Teams custam 15 dólares por usuário por mês, e o processamento na nuvem é cobrado por hora além do uso dos modelos. A Anaconda anunciou em julho de 2026 que adquiriu o Kilo Code e não divulgou os termos. Agentes podem alterar muitos arquivos de uma vez, então revise os diffs antes de aceitá-los. Entre as alternativas estão Cline, OpenCode, Claude Code e Cursor. O Kilo Code serve para desenvolvedores que querem um agente de código aberto que funcione com qualquer modelo.
