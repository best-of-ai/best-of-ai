Visual Studio Code, normalmente chamado de VS Code, é o editor de código mais usado por desenvolvedores. É leve o bastante para abrir rapidamente e oferece o que a maioria precisa: realce de sintaxe, depurador, terminal integrado, suporte ao Git e um enorme marketplace de extensões que adiciona linguagens, linters, temas e ferramentas. O núcleo é de código aberto e funciona no Windows, macOS e Linux. Também há uma versão para navegador, e os recursos de desenvolvimento remoto permitem trabalhar dentro de contêineres, por SSH ou em ambientes na nuvem.

A IA agora faz parte do editor. GitHub Copilot oferece sugestões de código em linha enquanto você digita, um painel de chat que responde a perguntas sobre o projeto e um modo de agente que pode planejar uma tarefa, editar vários arquivos, executar comandos no terminal e corrigir erros encontrados. VS Code também oferece suporte ao Model Context Protocol, permitindo que agentes se conectem a ferramentas e fontes de dados externas; você também pode usar modelos de diferentes provedores. Muitas outras ferramentas de programação com IA, incluindo Cursor e Windsurf, começaram como bifurcações do VS Code, o que demonstra quanto do ecossistema se baseia nele.

O editor não custa nada. Copilot tem um nível gratuito com uso limitado e planos pagos para uso mais intenso e equipes. Os downloads oficiais da Microsoft incluem telemetria e alguns componentes proprietários; por isso, existem compilações da comunidade, como VSCodium, para quem quer um binário totalmente de código aberto. Em comparação com IDEs completas, como IntelliJ ou Visual Studio, o VS Code oferece menos recursos prontos e depende de extensões, o que pode exigir mais configuração, mas resulta em um editor mais rápido e flexível.
