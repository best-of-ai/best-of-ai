O Cline é um assistente autônomo de programação integrado ao seu editor. Você descreve uma tarefa, e ele a executa passo a passo: lê os arquivos relevantes, propõe alterações, executa comandos e verifica o resultado. Há um modo Plan, no qual ele explora o projeto e combina uma abordagem com você, e um modo Act, no qual executa o plano. Cada alteração de arquivo e comando de terminal é mostrado para aprovação, mantendo você no controle, embora seja possível ativar a aprovação automática para ações de menor risco.

Ele faz muito mais do que editar texto. Com uma ferramenta de navegador, pode abrir o aplicativo que está construindo, clicar nele e analisar capturas de tela para encontrar problemas. O suporte ao Model Context Protocol permite adicionar ferramentas como acesso a bancos de dados ou APIs personalizadas. Pontos de verificação permitem restaurar o projeto a um estado anterior se algo der errado. O Cline também está disponível como ferramenta de linha de comando e SDK.

A extensão é gratuita e de código aberto sob a licença Apache 2.0, e você fornece o modelo. Ela funciona com Anthropic, OpenAI, Google, AWS Bedrock, OpenRouter e modelos locais via Ollama ou LM Studio. O uso de tokens é cobrado pelo provedor, e sessões agênticas podem consumir muitos tokens, então os custos variam. Roo Code e Kilo Code são ramificações que desenvolvem a mesma ideia. Cursor e Claude Code são as alternativas comerciais mais próximas.
