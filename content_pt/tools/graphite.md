Graphite se baseia em um fluxo em que alterações grandes são divididas em pequenos pull requests dependentes. Essa abordagem de empilhamento, popular em grandes empresas de tecnologia, permite que engenheiros continuem trabalhando na próxima parte sem esperar que a anterior seja revisada e integrada. Graphite oferece uma ferramenta de linha de comando e uma interface web que simplificam o gerenciamento de pilhas, tarefa que o GitHub puro não facilita.

A plataforma acrescenta recursos de revisão. Uma fila de integração mantém o branch principal estável ao testar e integrar alterações em ordem, uma caixa de entrada ajuda revisores a ver o que exige atenção, e insights mostram a duração das revisões. Um revisor de IA comenta pull requests para identificar bugs e problemas de estilo, algo importante à medida que mais código é escrito por assistentes de IA.

A Cursor adquiriu Graphite para aproximar a revisão do editor, e o produto continua funcionando com repositórios GitHub. Há uma modalidade gratuita para indivíduos e planos pagos para equipes. Adotar pull requests empilhados muda hábitos e exige adesão da equipe. Entre as alternativas estão ferramentas nativas do GitHub, CodeRabbit, Greptile, Reviewable e fluxos no estilo Phabricator. Graphite é indicado para equipes que querem revisões de código mais rápidas e organizadas.
