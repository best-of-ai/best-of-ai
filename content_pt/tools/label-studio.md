Label Studio é uma plataforma flexível de anotação. Equipes a usam para rotular dados de aprendizado de máquina, por exemplo, desenhar caixas em imagens, marcar entidades em textos, transcrever áudio e avaliar respostas de modelos de linguagem. Seu sistema de configuração permite definir interfaces de rotulagem personalizadas com marcação simples, atendendo a vários tipos de projeto em uma única ferramenta; pode ser executada localmente ou em um servidor.

A rotulagem assistida por modelos acelera o trabalho. Um sistema de aprendizado de máquina pode pré-rotular dados para correção humana, e o aprendizado ativo ajuda a priorizar os exemplos mais informativos. A plataforma oferece suporte à avaliação de modelos de linguagem, com modelos para tarefas como classificar respostas e verificar erros factuais, uso que se tornou comum conforme equipes desenvolvem aplicações de IA. Uma API e SDK conectam a ferramenta a pipelines de treinamento.

A edição comunitária é gratuita e de código aberto, e a HumanSignal vende Label Studio Enterprise com recursos como controle de acesso por função, fluxos de trabalho, análises e segurança. Hospedar por conta própria exige algum trabalho técnico. Entre as alternativas estão CVAT para visão computacional, Labelbox, Scale AI e Encord como plataformas comerciais, Prodigy para texto e Argilla para dados de modelos de linguagem. Label Studio atende equipes que querem uma ferramenta flexível de anotação que possam hospedar por conta própria.
