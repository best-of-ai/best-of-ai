Catchlight é uma ferramenta de pontuação de leads para empresas de consultoria financeira. Ela enriquece o perfil de um cliente potencial com dados como renda estimada, ativos disponíveis para investimento, faixa etária e interesses e, em seguida, aplica um modelo treinado com conversões anteriores para gerar uma pontuação que indica a probabilidade de essa pessoa se tornar cliente.

Consultores usam a ferramenta para priorizar seu tempo. Em vez de telefonar para cada pessoa interessada, podem se concentrar nas mais adequadas e ver contexto para iniciar uma conversa. A plataforma se integra a CRMs usados por consultores, como Wealthbox, e aparece em plataformas que atendem empresas de gestão de patrimônio.

O uso de dados financeiros pessoais estimados levanta questões de privacidade e equidade, e consultores devem seguir as regulamentações sobre uso de dados e contato comercial. As estimativas podem estar incorretas, então servem como orientação para priorização, não como veredito. Entre as alternativas estão Salesforce Einstein, pontuação de leads do HubSpot, ZoomInfo e Zoe Financial para encontrar leads. Catchlight é indicado para empresas de consultoria que gerenciam leads recebidos.
