Gemini CLI leva o Gemini ao terminal como agente de programação e automação. Em uma pasta de projeto, descreva uma tarefa em linguagem natural, como explicar uma base de código, corrigir um teste que falha ou criar um recurso. O agente lê arquivos, propõe alterações, executa comandos de shell e repete o processo. Também pode pesquisar na web, usar um arquivo de contexto para aprender as convenções do projeto e trabalhar com contextos longos graças à grande janela de contexto do Gemini.

A ferramenta foi criada para ser ampliada. O suporte ao Model Context Protocol conecta ferramentas externas, extensões agrupam comandos e integrações personalizados, e as configurações permitem controlar permissões e isolamento. É de código aberto sob a licença Apache 2.0 e pode ser integrado a automações e à integração contínua. Também funciona no modo agente do Gemini Code Assist em editores.

A ferramenta é gratuita com uma conta pessoal do Google, dentro de limites de uso; planos pagos ou chaves de API aumentam esses limites. Como todo agente de programação, pode cometer erros, então revise as alterações e tenha cuidado com comandos que modifiquem ou excluam arquivos. Entre as alternativas estão Claude Code, OpenAI Codex CLI, Aider, Cline e a CLI do GitHub Copilot. Gemini CLI atende desenvolvedores que procuram um agente de terminal gratuito e de código aberto.
