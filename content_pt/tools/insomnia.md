Insomnia é um aplicativo para computador que permite enviar solicitações a APIs e inspecionar respostas. Você cria solicitações com cabeçalhos, autenticação e corpo, organiza-as em coleções e usa variáveis de ambiente para alternar entre desenvolvimento e produção. Oferece suporte a REST, GraphQL, gRPC, WebSocket e Server-Sent Events e pode importar definições de especificações OpenAPI.

Além dos testes manuais, oferece suporte a design e automação. Um editor de design de API ajuda a escrever especificações, suítes de teste executam coleções de solicitações com asserções, e ferramentas de linha de comando executam testes em CI. Plugins ampliam os recursos, sincronização com Git armazena coleções junto ao código, e recursos de IA ajudam a gerar solicitações, testes e documentação. Insomnia pode armazenar dados localmente ou na nuvem, uma escolha importante para equipes preocupadas com privacidade.

Insomnia é de código aberto, tem modalidade gratuita e planos pagos para colaboração de equipes e recursos empresariais. Compete em um espaço no qual usuários migraram entre ferramentas conforme fornecedores mudaram suas abordagens para contas na nuvem. Entre as alternativas estão Postman, líder de mercado, Bruno, cliente de código aberto e focado em uso off-line, Hoppscotch, Thunder Client para VS Code e curl. Insomnia é indicado para desenvolvedores que querem um cliente de API simples e amigável ao uso local.
