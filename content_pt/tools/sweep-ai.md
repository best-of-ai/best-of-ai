Sweep começou como um desenvolvedor júnior de IA no GitHub. O usuário descrevia uma tarefa em um issue, e o bot lia o código, planejava as alterações e abria um pull request. A equipe teve dificuldade para alcançar a confiabilidade desejada e percebeu que a maior parte da atenção em programação com IA estava voltada ao VS Code.

A empresa migrou para um plugin JetBrains para IntelliJ, PyCharm e outras IDEs, com chat contextual, aplicação de alterações em vários arquivos e revisão automática de código. O plugin pode ser executado em ambientes locais, o que atende a empresas com requisitos de segurança.

Sweep tem um plano gratuito e planos pagos. O fluxo original de issue para pull request continua no projeto de código aberto, cujo suporte é incerto. Entre as alternativas estão JetBrains AI Assistant, GitHub Copilot, Cline, Continue e Cursor. Sweep AI é indicado para desenvolvedores que usam ferramentas JetBrains.
