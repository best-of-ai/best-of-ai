Fluxos de trabalho são arquivos YAML que chamam ações reutilizáveis de um marketplace. Executores hospedados funcionam em Linux, Windows e macOS, ou as equipes podem usar os próprios. Segredos e ambientes controlam as implantações.

Repositórios públicos podem usar o serviço gratuitamente, e repositórios privados recebem uma franquia gratuita, com cobranças pelo uso adicional.

GitLab CI e CircleCI são alternativas. GitHub Actions atende engenheiros de DevOps que trabalham no GitHub.
