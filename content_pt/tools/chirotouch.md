Quiropráticos registram consultas usando modelos e realizam o faturamento de convênios no mesmo sistema. Lembretes e portais para pacientes reduzem faltas. Os relatórios mostram o número de consultas e os valores recebidos.

O software foi desenvolvido especificamente para quiropraxia, o que significa menos flexibilidade para outras clínicas.

Jane e ChiroSpring são alternativas. O ChiroTouch é indicado para quiropráticos.
