Usuários gratuitos consultam status e histórico de voos. Produtos empresariais incluem APIs de dados de voo e ferramentas para ajudar operadores com planejamento e alertas. Os dados combinam sinais de radar, satélites e receptores terrestres.

Equipes de operações o usam para monitorar atrasos e rastrear aeronaves. Como outros rastreadores públicos, oferece informações e não substitui os sistemas oficiais de tráfego aéreo.

Flightradar24 é a principal alternativa. FlightAware é indicado para despachantes, operadores e desenvolvedores que precisam de dados de voo.
