Zilliz Cloud oferece Milvus como serviço. As equipes não precisam operar os próprios clusters e recebem um banco de dados gerenciado para embeddings, com recursos como escalabilidade automática, backups e controles de segurança. A solução oferece suporte a buscas para recomendações, recuperação em aplicações de IA e similaridade de imagens ou áudio.

Zilliz criou o Milvus e contribui para o projeto de código aberto, permitindo que clientes alternem entre a hospedagem própria e o serviço gerenciado. Busca híbrida, filtragem e configurações para vários clientes atendem cargas de produção.

Zilliz tem um plano gratuito e planos cobrados conforme o uso. Entre as alternativas estão Pinecone, Qdrant, Weaviate, Chroma e turbopuffer. Zilliz é indicada para equipes que querem usar o Milvus de forma gerenciada.
