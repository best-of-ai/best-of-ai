Agentes literários o usam para ver quais editores compram determinados tipos de livro e para divulgar seus próprios negócios. Autores o usam para pesquisar agentes. Um boletim diário lista novos negócios de livros.

Os dados são relatados principalmente por membros, portanto não constituem um registro completo.

Query Tracker ajuda autores a acompanhar submissões. Publishers Marketplace é indicado para agentes literários.
