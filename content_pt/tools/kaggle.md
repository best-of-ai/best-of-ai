O Kaggle é um espaço onde muitos cientistas de dados aprendem e demonstram suas habilidades. Empresas e pesquisadores propõem competições com problemas reais, como prever resultados com base em dados ou classificar imagens, e participantes enviam modelos para um placar. Soluções vencedoras costumam ser publicadas, e os fóruns de discussão são uma rica fonte de técnicas. Classificações e medalhas ajudam a construir um histórico público de habilidades.

A plataforma oferece mais do que competições. Conjuntos de dados públicos cobrem temas que vão de saúde a esportes; notebooks gratuitos executam Python e R no navegador e, dentro de certos limites, dão acesso a GPUs e TPUs; e um hub de modelos compartilha modelos pré-treinados. O Kaggle Learn oferece cursos curtos e práticos de Python, pandas, aprendizado de máquina e outros assuntos. Também foram acrescentados benchmarks e desafios comunitários sobre modelos de linguagem grandes, e o site se integra ao Google Cloud.

O Kaggle é gratuito. A computação gratuita tem limites semanais, e a qualidade e as licenças dos conjuntos de dados variam; confira os termos antes de usá-los em trabalhos comerciais. Competições premiam o desempenho no placar, que é diferente de criar sistemas de produção fáceis de manter. Entre as alternativas estão Hugging Face para modelos e conjuntos de dados, Google Colab para notebooks, DrivenData e Zindi para competições e Papers with Code para pesquisa. O Kaggle é um ótimo lugar para praticar e encontrar conjuntos de dados para experimentação.
