MultiOn foi uma das primeiras empresas a criar agentes capazes de usar navegadores. O usuário fornece uma instrução em linguagem simples, e o agente navega por sites, clica, digita e conclui etapas, mantendo uma sessão entre páginas. Desenvolvedores podiam acessá-lo por API para criar seus próprios agentes.

A empresa mencionou uma transição para uma nova fase, e diretórios descrevem uma mudança de nome e foco, embora os relatos sejam diferentes. Vale consultar o site oficial para verificar o que está disponível atualmente antes de depender do serviço.

Agentes web enfrentam obstáculos comuns, incluindo sites que bloqueiam automação, segurança de login e pagamentos e erros em tarefas com várias etapas. Ações com consequências reais devem ser revisadas. Entre as alternativas estão Browserbase com frameworks de agentes, o modo de agente da OpenAI, o uso do computador da Anthropic, Perplexity Comet e Skyvern. MultiOn é indicada para desenvolvedores que experimentam com agentes de navegador.
