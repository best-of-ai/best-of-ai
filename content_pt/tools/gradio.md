Gradio facilita apresentar um modelo a outras pessoas. Com poucas linhas de Python, você envolve uma função — por exemplo, uma que recebe uma imagem e retorna uma legenda — e Gradio produz uma interface web com componentes de entrada e saída apropriados: caixas de texto, envio de imagens, gravadores de áudio, controles deslizantes e muito mais. Executar o script inicia um aplicativo web local, e uma opção de compartilhamento cria um link público temporário, útil para demonstrações e feedback.

A ferramenta cresceu para além de demonstrações simples. A API Blocks do Gradio permite criar interfaces mais complexas e com várias etapas, com layouts personalizados, e uma classe de interface de chat cria chatbots com pouco código. Cada aplicativo Gradio também expõe uma API e pode ser usado programaticamente por bibliotecas de cliente. Oferece suporte ao Model Context Protocol, então uma função Gradio pode ser disponibilizada como ferramenta para agentes de IA. Muitos artigos de aprendizado de máquina e modelos abertos incluem links para demonstrações Gradio.

Gradio é gratuito e de código aberto sob a licença Apache 2.0; hospedar no Hugging Face Spaces é gratuito para usos básicos, com hardware pago para demonstrações mais exigentes. A ferramenta foi projetada para demonstrações, ferramentas internas e protótipos, então aplicativos grandes de produção geralmente precisam de um framework web adequado. Streamlit é a alternativa mais próxima e popular em aplicativos de dados; Panel e Dash atendem a painéis, e Chainlit se concentra em aplicações de chat. Gradio é a opção padrão para demonstrações de modelos.
