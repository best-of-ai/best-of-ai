O dbt, abreviação de data build tool, tornou-se a forma padrão de transformar dados brutos em um data warehouse como Snowflake, BigQuery ou Databricks. Analistas escrevem instruções SQL SELECT, definem as dependências entre elas, e o dbt cria tabelas e visualizações na ordem correta, com controle de versão, testes e documentação. Isso leva práticas de engenharia de software, como revisão de código e integração contínua, ao trabalho analítico.

O dbt Cloud é o produto hospedado da dbt Labs. Ele oferece um ambiente de desenvolvimento integrado no navegador, agendamento de tarefas, integração contínua que testa alterações antes da produção, um catálogo de dados com linhagem e uma camada semântica que define métricas uma vez para uso em diferentes ferramentas de BI. Recursos de IA ajudam a gerar modelos, testes e documentação e a responder perguntas sobre o projeto, agilizando tarefas repetitivas.

O dbt Core, mecanismo de código aberto, é gratuito; o dbt Cloud oferece um plano gratuito para desenvolvedores e planos pagos para equipes e empresas. Executar o dbt por conta própria exige infraestrutura e orquestração, necessidades eliminadas pelo produto na nuvem. Entre as alternativas estão SQLMesh, Dataform no BigQuery, Coalesce e recursos nativos dos data warehouses. O dbt atende engenheiros analíticos que buscam uma camada de transformação estruturada e testável.
