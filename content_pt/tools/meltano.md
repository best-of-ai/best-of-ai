Meltano trata a integração de dados como desenvolvimento de software. Um projeto define extratores e carregadores em um arquivo de configuração, e Meltano os executa para transferir dados de fontes a um data warehouse. Como tudo é código, pipelines ficam no Git, são executados em integração contínua e podem ser revisados como outras alterações.

A ferramenta se baseia no padrão Singer, que tem centenas de conectores comunitários, e integra-se ao dbt para transformações e ao Airflow para orquestração. Equipes podem criar conectores personalizados com um kit de desenvolvimento de software, útil para fontes que ferramentas comerciais não atendem.

Meltano é gratuito e de código aberto. Exige conhecimento de engenharia e manutenção, e a qualidade dos conectores varia. Entre as alternativas estão Airbyte, Fivetran, dlt, Dagster com integrações e o próprio Singer. Meltano atende equipes de dados com perfil de engenharia.
