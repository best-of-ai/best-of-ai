Codiga oferecia análise de código em tempo real dentro do editor. Seus plugins para VS Code, IDEs JetBrains e outras ferramentas examinavam o código enquanto era escrito em busca de vulnerabilidades, bugs e violações de padrões de programação; um mecanismo de regras permitia que equipes criassem verificações próprias. A plataforma também fornecia um assistente de trechos de código e, mais tarde, sugestões baseadas em IA; integrava-se a plataformas Git para revisar pull requests automaticamente.

A Datadog adquiriu a empresa para incorporar análise de código à sua plataforma de observabilidade e segurança. Os produtos independentes da Codiga foram encerrados pouco depois, com reembolsos para assinantes pagos, e a equipe passou a fazer parte da Datadog. O mecanismo de análise estática e suas regras agora sustentam o Datadog Code Security, e o analisador está disponível como código aberto.

Para ferramentas semelhantes, SonarQube, Semgrep, Snyk Code e CodeQL oferecem análise estática, enquanto ferramentas de revisão com IA como CodeRabbit e Qodo cuidam de pull requests. Equipes que usam Datadog podem recorrer aos recursos integrados de segurança de código. Esta página permanece como referência porque listas de ferramentas e tutoriais antigos ainda mencionam Codiga.
