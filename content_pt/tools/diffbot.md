A Diffbot usa visão computacional e processamento de linguagem natural para ler páginas da web como uma pessoa faria. Em vez de escrever um extrator específico para cada site, desenvolvedores enviam uma URL às APIs e recebem dados estruturados sobre artigos, produtos ou pessoas, independentemente do layout da página.

A empresa também criou um grande grafo de conhecimento, uma base de entidades como organizações, pessoas e produtos, com relações coletadas em toda a web. Clientes consultam esse grafo para enriquecer registros, acompanhar notícias, encontrar empresas que correspondam a critérios ou fornecer fatos fundamentados a modelos de linguagem. As ferramentas de extração permitem rastrear a web em grande escala.

A Diffbot é paga, com planos por chamadas de API e período de teste. A coleta de dados da web deve respeitar os termos dos sites e as leis de privacidade. Entre as alternativas estão Apify, Bright Data, Firecrawl, Zyte e Crunchbase para dados de empresas. A Diffbot atende equipes que precisam de dados estruturados da web e de um grafo de entidades.
