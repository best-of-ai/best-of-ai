Copilot Workspace foi uma tentativa do GitHub Next de repensar como a IA poderia ajudar a resolver problemas. A partir de um issue do GitHub ou de uma instrução, primeiro escrevia uma especificação do comportamento atual e do desejado, depois um plano com os arquivos a alterar e, por fim, o código. Em cada etapa, era possível editar o texto e orientar o trabalho em linguagem simples antes de qualquer código aparecer. As alterações finalizadas podiam ser abertas como pull request ou executadas em um ambiente na nuvem.

Era uma prévia técnica, não um produto finalizado, e mostrava como o GitHub imaginava que agentes poderiam cuidar de tarefas rotineiras. A prévia terminou, e usuários não podem mais criar ou abrir workspaces. O GitHub indicou como substitutos mais próximos o modo agente do Copilot no VS Code e o agente de programação do Copilot, que recebe um issue atribuído e trabalha nele em segundo plano; porém, não são equivalentes diretos.

Para usar esse tipo de fluxo hoje, a opção mais próxima é o agente de programação do GitHub Copilot, além de ferramentas como Devin, OpenAI Codex, Google Jules e Claude Code. Elas executam tarefas de ponta a ponta e geralmente retornam um pull request para revisão. A etapa de especificação e planejamento que diferenciava Workspace agora aparece em modos de planejamento de outras ferramentas. Esta página permanece como referência porque links, artigos e páginas de alternativas ainda mencionam o produto.
