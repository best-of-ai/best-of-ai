Usuários inserem dados em tabelas, escolhem análises como testes t, ANOVA, curvas de sobrevivência ou regressão não linear e recebem gráficos prontos para publicação. O programa orienta pessoas sem formação em estatística com explicações dos resultados. Ajuste de curvas dose-resposta e cinética são usos comuns.

É uma licença paga, frequentemente disponibilizada por universidades. É menos flexível que R ou Python para trabalhos personalizados.

R, Python e JMP são alternativas. Prism é indicado para cientistas de laboratório que querem passar rapidamente dos dados a uma figura.
