Usuários pesquisam palavras e expressões, consultam colocações e comparam o uso em diferentes corpora. Um perfil lexical resume padrões gramaticais de uma palavra. Também é possível criar corpora a partir dos próprios textos.

É um serviço por assinatura, com acesso gratuito para alguns usuários acadêmicos.

AntConc é uma alternativa gratuita para desktop. Sketch Engine atende linguistas e terminólogos.
