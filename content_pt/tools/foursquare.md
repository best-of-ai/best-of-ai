A Foursquare começou como um aplicativo para fazer check-in em lugares e descobrir estabelecimentos, mas hoje seu principal negócio são dados de localização. A empresa mantém uma grande base de pontos de interesse, incluindo estabelecimentos comerciais, marcos e locais, com informações como categorias, horários e popularidade. Desenvolvedores usam a API Places para incluir busca, recomendações e informações sobre lugares em mapas e aplicativos, e marcas usam os dados para entender os destinos das pessoas.

Além dos dados de lugares, a Foursquare oferece ferramentas para analisar deslocamentos e comportamento de localização. Painéis de usuários que aceitaram participar permitem medir visitas a lojas, analisar públicos e atribuir resultados à publicidade; produtos de mapeamento e geoespaciais ajudam empresas a visualizar e processar dados de localização em grande escala. Aprendizado de máquina mantém as informações dos lugares atualizadas e ajuda a combinar registros de fontes diferentes.

A atuação voltada ao consumidor foi reduzida: o aplicativo Foursquare City Guide foi encerrado, e o produto para consumidores concentra-se no Swarm, que permite fazer check-ins e manter um histórico de lugares. Para desenvolvedores, a Foursquare oferece uma faixa gratuita para a API e planos pagos com maior volume e dados mais completos. Entre os concorrentes em dados de lugares estão Google Places, Mapbox, HERE, TomTom e Overture Maps, uma iniciativa de dados abertos. As regras de privacidade para dados de localização são rigorosas e variam por região, então as empresas devem confirmar como os dados são coletados.
