O OpenHands oferece uma alternativa aberta aos agentes comerciais de programação. O usuário atribui uma tarefa, e o agente trabalha em um ambiente isolado com terminal, editor e navegador, executando etapas para concluí-la e mostrando o que faz. Ele pode resolver problemas do GitHub e abrir pull requests.

O projeto começou como OpenDevin, uma resposta de código aberto à demonstração do Devin, e cresceu como uma plataforma comunitária mantida pela All Hands AI. É compatível com modelos de muitos provedores, oferece uma ferramenta de linha de comando e uma interface web e é usado em pesquisas e benchmarks de agentes de programação.

O OpenHands é gratuito e de código aberto, com opção de nuvem hospedada. Os resultados dos agentes variam e precisam ser revisados. Para executá-lo, são necessários Docker e uma chave de API. Entre as alternativas estão Devin, Claude Code, OpenAI Codex, SWE-agent e Cline. É indicado para desenvolvedores e pesquisadores que querem um agente de programação aberto.
