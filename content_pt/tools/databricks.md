O Databricks começou com o Apache Spark e se tornou uma plataforma unificada para trabalhar com dados. Empresas armazenam dados em formatos abertos na própria nuvem e usam o Databricks para pipelines, análises SQL, notebooks e aprendizado de máquina, com uma camada de governança chamada Unity Catalog que controla o acesso e acompanha a linhagem de dados.

A IA se tornou central para a proposta. A plataforma oferece suporte ao treinamento e ajuste fino de modelos, à execução por meio de endpoints, à busca vetorial para recuperação de informações e a uma estrutura para criar agentes baseados em dados corporativos. A empresa adquiriu a MosaicML para fortalecer o treinamento de modelos e oferece ferramentas para monitorar e avaliar sistemas de IA. Um assistente ajuda a escrever código e consultas.

O Databricks é cobrado por uso e funciona na AWS, Azure e Google Cloud. É poderoso, mas complexo, e os custos precisam ser monitorados. Entre as alternativas estão Snowflake, Google BigQuery, Microsoft Fabric, Amazon Redshift e Dataiku. O Databricks é indicado para equipes de dados e IA que trabalham com grandes volumes de informação.
