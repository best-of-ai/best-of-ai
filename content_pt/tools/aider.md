Aider é uma ferramenta de linha de comando para programação em pares com um modelo de linguagem. Você a inicia dentro de um repositório Git, adiciona os arquivos em que quer trabalhar e descreve o pedido em linguagem natural. A ferramenta edita os arquivos diretamente, mostra as diferenças e registra cada alteração em um commit com uma mensagem adequada, para que você possa revisar ou desfazer qualquer ação do modelo com comandos Git comuns. Essa integração estreita com Git torna seguro usá-la em um projeto real.

Para lidar com bases de código maiores, cria um mapa do repositório, ajudando o modelo a entender as relações entre arquivos sem carregar tudo em um único prompt. Pode executar linters e testes após cada alteração e tentar corrigir os problemas encontrados. Aider funciona com vários modelos, desde serviços hospedados como Claude, GPT e DeepSeek até modelos locais, e oferece entrada por voz e contexto de imagens ou páginas web quando necessário.

A ferramenta é gratuita e de código aberto; você paga apenas pelo uso da API do modelo conectado. Isso torna os custos transparentes, mas sessões intensas podem acumular despesas. Aider não tem interface gráfica, sendo adequado a desenvolvedores confortáveis com o terminal e que preferem permanecer no próprio editor. Cursor e Windsurf são alternativas integradas a editores; Claude Code e Codex CLI são seus concorrentes mais próximos no terminal.
