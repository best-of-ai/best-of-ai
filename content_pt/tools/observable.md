Os usuários escrevem código em notebooks, e os gráficos são atualizados conforme os dados mudam. Observable Plot oferece uma API concisa para gráficos, e Observable Framework cria aplicativos de dados estáticos. Equipes compartilham notebooks e painéis.

É necessário ter algum conhecimento de JavaScript, o que representa uma barreira para quem não programa.

Datawrapper e Flourish são alternativas sem código. O Observable é indicado para especialistas em visualização de dados que programam.
