Ragas ajuda equipes a medir o desempenho de sistemas RAG. Um desenvolvedor fornece perguntas, trechos recuperados e respostas geradas, e Ragas usa modelos de linguagem para pontuar aspectos como se a resposta é sustentada pelo contexto, se responde à pergunta e se o contexto recuperado era relevante.

Como não exige respostas rotuladas manualmente para cada caso, equipes podem avaliar rapidamente; a ferramenta também pode gerar conjuntos de teste sintéticos a partir de documentos. Integra-se a frameworks como LangChain e LlamaIndex e a ferramentas de observabilidade.

Ragas é gratuito e de código aberto. Usar um modelo de linguagem como avaliador traz inconsistências próprias, então é melhor usar pontuações para comparar versões, e não como verdade absoluta. Entre as alternativas estão TruLens, DeepEval, Arize Phoenix, Braintrust e Promptfoo. Ragas é indicado para desenvolvedores que ajustam pipelines RAG.
