Azure Government é uma região separada da nuvem, criada para órgãos federais, estaduais e locais dos Estados Unidos e seus parceiros. Funciona em centros de dados operados por funcionários norte-americanos previamente verificados e é isolada do Azure comercial, permitindo cumprir regimes de conformidade para dados governamentais sensíveis.

Órgãos públicos a usam para trabalhos comuns na nuvem, incluindo hospedagem de aplicações, análises e IA. Serviços como Azure OpenAI e Copilot foram disponibilizados em versões que atendem requisitos governamentais, permitindo o uso de IA generativa com proteção de dados.

Os preços seguem o modelo de pagamento conforme o uso do Azure, com ofertas específicas para governos. A disponibilidade de novos serviços em regiões governamentais costuma ficar atrás das regiões comerciais. Entre as alternativas estão AWS GovCloud, Google Public Sector, Oracle Government Cloud e ofertas governamentais da IBM. Microsoft Azure Government atende órgãos públicos e contratados que precisam de uma nuvem em conformidade.
