A Factory vende agentes de IA para equipes de engenharia. Os Droids recebem tarefas de tickets ou chats, exploram uma base de código, fazem alterações, executam testes e abrem solicitações de pull request para revisão. Droids especializados lidam com diferentes trabalhos, como revisão de código, resposta a incidentes ou migrações.

O produto funciona por meio de uma ferramenta de linha de comando, integrações com IDEs e uma interface web. Conecta-se ao GitHub, Jira, Slack e outras ferramentas para que os agentes se encaixem nos fluxos de trabalho existentes. Recursos empresariais atendem a necessidades de segurança, permissões e escolha de modelo, com suporte a vários provedores.

A Factory é paga, com planos baseados no uso, e voltada a equipes profissionais de engenharia. Os resultados dos agentes precisam ser revisados, e bons testes são importantes. Entre as alternativas estão Claude Code, OpenAI Codex, Devin, Cursor e o agente do GitHub Copilot. A Factory é indicada para organizações de engenharia que automatizam tarefas rotineiras de desenvolvimento.
