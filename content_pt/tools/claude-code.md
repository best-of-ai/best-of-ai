O Claude Code atua como agente no projeto real, em vez de apenas sugerir alterações em um editor. Você o inicia no repositório pelo terminal e descreve a tarefa, como corrigir um teste com falha, adicionar um endpoint ou atualizar uma dependência. Ele lê os arquivos relevantes, cria um plano, edita o código em várias partes do projeto, executa testes e outros comandos e ajusta o trabalho diante dos erros. Pede permissão para ações potencialmente arriscadas, e você pode revisar as alterações como diferenças de código ou pelo Git antes de confirmar as mudanças.

A ferramenta é altamente personalizável. Um arquivo CLAUDE.md no projeto contém instruções e convenções que o agente segue em cada execução, e as skills agrupam procedimentos reutilizáveis. Hooks executam seus próprios scripts em etapas do fluxo de trabalho, subagentes dividem tarefas entre contextos paralelos e o Model Context Protocol conecta a ferramenta a bancos de dados, rastreadores de issues e outros serviços. Ela também funciona em editores como VS Code e JetBrains, em um aplicativo para computador e no navegador, e pode ser executada em scripts e CI para tarefas automatizadas.

O Claude Code está incluído nos planos pagos do Claude e também pode ser usado com uma chave de API cobrada por uso, então o custo depende da intensidade de uso. Sessões autônomas longas podem consumir muitos tokens. As saídas ainda precisam ser revisadas, especialmente em código sensível à segurança. As principais alternativas são Codex da OpenAI, Gemini CLI do Google, Cursor, o agente do GitHub Copilot e Cline.
