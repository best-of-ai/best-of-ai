Metaflow permite que cientistas de dados escrevam fluxos de trabalho como classes Python comuns. Etapas são funções, e o framework acompanha código, dados e parâmetros de cada execução, permitindo reproduzir qualquer resultado. Um decorador escala etapas para recursos computacionais na nuvem sem exigir que o cientista aprenda infraestrutura.

A Netflix criou a ferramenta para permitir que cientistas de dados passassem de experimentos em laptops à produção por conta própria. Os recursos incluem artefatos versionados, agendamento por orquestradores como Argo Workflows e AWS Step Functions e uma interface para inspecionar execuções. Outerbounds, empresa fundada pelos criadores do Metaflow, oferece uma plataforma gerenciada.

Metaflow é gratuito e de código aberto. É voltado a fluxos de ML e dados, não à orquestração geral de aplicações. Entre as alternativas estão Kubeflow, Dagster, Prefect, Airflow e ZenML. Metaflow atende equipes de ciência de dados que querem fluxos de trabalho simples e reproduzíveis.
