O Cody surgiu da busca de código da Sourcegraph, que indexa repositórios inteiros e permite que desenvolvedores encontrem e entendam código em vários projetos. Esse contexto era sua principal vantagem: em vez de adivinhar com base no arquivo aberto, o Cody podia recorrer à base de código mais ampla para responder a perguntas, escrever código que seguisse padrões existentes e explicar como as partes de um sistema se encaixavam. Funcionava no VS Code, em IDEs JetBrains e na web, com chat, preenchimento automático e comandos para editar e testar código.

O produto mudou. A Sourcegraph encerrou os planos Free e Pro do Cody para indivíduos e também o removeu do plano Enterprise Starter. Cody Enterprise continua disponível para grandes organizações que usam a plataforma da Sourcegraph, onde sua compreensão da base de código é mais útil. Para programação mais recente no estilo agente, a Sourcegraph lançou Amp, uma ferramenta separada, criada para fluxos de trabalho com agentes.

Hoje, o Cody faz sentido principalmente para empresas que já usam Sourcegraph e precisam de inteligência de código em bases muito grandes com vários repositórios, com a opção de usar modelos de vários provedores. Implantações empresariais podem ser executadas no ambiente do cliente. Desenvolvedores individuais devem considerar GitHub Copilot, Cursor, Claude Code ou Amp. Avaliações antigas que mencionam um plano gratuito do Cody descrevem algo que não é mais oferecido.
