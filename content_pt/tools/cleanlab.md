O Cleanlab parte da ideia de que a qualidade do modelo depende da qualidade dos dados. Conjuntos de dados reais contêm erros: imagens com rótulos incorretos, exemplos duplicados e valores atípicos. A biblioteca de código aberto do Cleanlab usa métodos estatísticos e previsões de modelos para localizar os exemplos com maior probabilidade de estarem incorretos, permitindo que a equipe os corrija em vez de revisar tudo.

A plataforma comercial, Cleanlab Studio, amplia esses recursos com uma interface sem código para limpar e aprimorar conjuntos de dados e treinar modelos com os dados resultantes. A empresa também passou a trabalhar com a confiabilidade de IA generativa, oferecendo ferramentas para avaliar a confiabilidade das respostas de modelos de linguagem e detectar alucinações em sistemas de produção.

A biblioteca de código aberto é gratuita, e a plataforma oferece planos gratuitos e pagos. A limpeza de dados exige julgamento humano para determinar qual é o rótulo correto. Entre as alternativas estão Snorkel AI, Label Studio, Argilla, Encord e Labelbox. O Cleanlab é indicado para equipes de aprendizado de máquina que lidam com conjuntos de dados desorganizados.
