LangChain forneceu aos desenvolvedores um conjunto comum de ferramentas quando modelos de linguagem passaram a ser disponibilizados por APIs. Oferece blocos de construção para partes comuns de aplicações de IA: chamar modelos, formatar prompts, analisar resultados, conectar ferramentas e fontes de dados e manter a memória de uma conversa. Como oferece suporte a muitos provedores de modelos e bancos de dados vetoriais por interfaces consistentes, é possível trocar um pelo outro com poucas mudanças no código. Há versões para Python e JavaScript.

O ecossistema cresceu e se dividiu em várias partes. O próprio LangChain agora é uma forma rápida de criar agentes que usam ferramentas e modelos de qualquer provedor. LangGraph é um framework de nível mais baixo para agentes que precisam controlar etapas, ciclos, ramificações e aprovações humanas, sendo a ferramenta usada pela maioria das equipes em fluxos de agentes sérios. LangSmith é a plataforma comercial para rastrear execuções, avaliar qualidade, monitorar e implantar agentes, disponível como serviço hospedado, na nuvem do cliente ou auto-hospedada.

As bibliotecas de código aberto são gratuitas, e LangSmith oferece uma faixa gratuita e planos pagos para equipes. LangChain já foi criticado por abstrações que podem parecer pesadas ou mudar frequentemente, e alguns desenvolvedores preferem chamar APIs de modelos diretamente ou usar frameworks mais leves. Continua sendo uma das opções mais usadas, com grande comunidade e muitas integrações. LlamaIndex se concentra mais em dados e recuperação; Vercel AI SDK, CrewAI e OpenAI Agents SDK também cobrem agentes.
