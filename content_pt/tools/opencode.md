O OpenCode é um agente de programação que funciona no terminal do desenvolvedor. Ele lê um repositório, planeja alterações, edita arquivos e executa comandos por meio de uma interface de texto para conversas. O mesmo mecanismo também está por trás de um aplicativo para desktop, uma extensão de editor e um cliente web.

A liberdade de escolher provedores é seu principal atrativo. Os usuários conectam modelos da Anthropic, OpenAI, Google e outros, ou executam modelos abertos localmente, podendo alternar entre eles. Arquivos de configuração adicionam regras de projeto, agentes personalizados e ferramentas do Model Context Protocol; as sessões podem ser compartilhadas.

O OpenCode é gratuito e de código aberto; os usuários pagam pelo acesso aos modelos que utilizam, com opção de um serviço hospedado. A qualidade depende do modelo escolhido. Entre as alternativas estão Claude Code, OpenAI Codex, Gemini CLI, Aider e Kimi Code. É indicado para desenvolvedores que querem um agente aberto compatível com vários modelos.
