O Kimi Code é um agente de linha de comando da mesma família que Claude Code e Codex CLI. Você o inicia em uma pasta de projeto, descreve uma tarefa e ele lê arquivos, edita código, executa comandos e confere os resultados, decidindo os próximos passos com base no que acontece. As permissões permitem aprovar ações arriscadas.

Por padrão, usa os modelos Kimi da Moonshot AI, conhecidos pela capacidade de programação e pelo contexto longo, mas também pode se conectar a outros provedores compatíveis. Os recursos incluem subagentes integrados para programar, explorar e planejar; suporte ao Model Context Protocol para conectar ferramentas; hooks de ciclo de vida para automação e verificações de segurança; e modo ACP, que permite que editores como Zed e JetBrains controlem o agente.

A ferramenta é de código aberto sob a licença MIT. Para acessar os modelos, é necessária uma conta ou chave de API, e os planos têm limites. Vários projetos não oficiais usam o mesmo nome, então use o repositório oficial da Moonshot AI. Entre as alternativas estão Claude Code, OpenAI Codex CLI, Gemini CLI, OpenCode e Aider. O Kimi Code é indicado para desenvolvedores que querem um agente de terminal baseado nos modelos Kimi.
