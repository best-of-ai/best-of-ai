O Claude Docs leva a criação de documentos para o chat. Em vez de copiar uma resposta da conversa para outro aplicativo, você pede ao Claude que redija um relatório, memorando ou plano, e o texto aparece como um documento que pode ser editado ao lado da conversa. Você pode revisá-lo digitando alterações diretamente ou pedindo ao Claude para reescrever seções.

Os documentos ficam armazenados na guia Artifacts, facilitando encontrá-los e atualizá-los em outras sessões. Quando o rascunho estiver pronto, ele pode ser exportado para formatos comuns, como Word, PDF, Google Docs ou Markdown. A ferramenta trabalha com títulos, listas e tabelas, além de usar arquivos e contexto compartilhados na conversa.

O Claude Docs faz parte do Claude e está disponível nos planos pagos. O recurso vem sendo lançado em versão beta, então as funcionalidades podem mudar. Como em qualquer rascunho gerado por IA, fatos e números precisam ser conferidos antes do compartilhamento. Entre as alternativas estão Google Docs com Gemini, Microsoft Word com Copilot, Notion AI e o canvas do ChatGPT. O Claude Docs é indicado para quem redige no Claude e quer chegar a um documento finalizado.
