Os usuários importam modelos de robôs, criam cenários com física e sensores e executam testes. A ferramenta pode gerar imagens rotuladas para treinar modelos de visão. A integração com ROS permite que as equipes reutilizem código.

É necessário ter uma GPU NVIDIA RTX. A ferramenta é gratuita para desenvolvedores individuais, com licenciamento empresarial para empresas.

Gazebo e Webots são alternativas. O Isaac Sim é indicado para engenheiros de robótica que treinam e testam sistemas de percepção.
