Codex funciona como agente de engenharia de software. Um desenvolvedor descreve uma tarefa, como corrigir um bug ou adicionar um recurso, e Codex explora o código, elabora um plano, edita arquivos e executa testes ou linters para verificar o resultado. Depois, apresenta um resumo do que mudou e por quê.

Há várias formas de usá-lo. Uma ferramenta de linha de comando funciona na máquina do desenvolvedor; um aplicativo para computador gerencia várias tarefas; extensões integram a ferramenta a editores como VS Code; e uma versão na nuvem do ChatGPT executa tarefas em ambientes isolados, muitas vezes em paralelo, e pode propor pull requests no GitHub. Arquivos de configuração permitem que equipes forneçam instruções específicas do projeto ao agente.

Codex está incluído nos planos ChatGPT, com limites de uso que dependem do nível, e há acesso à API para desenvolvedores. Agentes cometem erros, então as alterações precisam de revisão e testes. Entre as alternativas estão Claude Code, Cursor, o agente do GitHub Copilot, Gemini CLI e Devin. Codex é indicado para desenvolvedores que querem o agente da OpenAI integrado ao fluxo de trabalho.
