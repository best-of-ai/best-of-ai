Firebase permite criar aplicativos sem manter servidores próprios. Seus serviços centrais incluem Cloud Firestore e Realtime Database para armazenar e sincronizar dados; Authentication para login por e-mail, telefone ou contas sociais; Cloud Storage para arquivos; Hosting para sites; e Cloud Functions para código no servidor. Analytics, Crashlytics e Cloud Messaging para notificações completam as ferramentas do ciclo de vida de aplicativos, e SDKs oferecem suporte a iOS, Android, web, Flutter e Unity.

A IA se tornou parte da plataforma. Gemini no Firebase ajuda desenvolvedores a escrever código, depurar e entender projetos, e Firebase AI Logic oferece aos aplicativos uma forma segura de chamar Gemini e outros modelos diretamente do cliente. Genkit é um framework de código aberto para criar recursos e agentes de IA, e Firebase Studio oferece um ambiente no navegador para prototipar aplicativos com assistência de IA.

Firebase tem um plano gratuito com cotas generosas para projetos pequenos e um plano de pagamento conforme o uso para produção. Os custos podem surpreender quando o uso cresce, especialmente com leituras de banco de dados, então é importante definir orçamentos e estruturar consultas cuidadosamente. A plataforma vincula você aos serviços do Google, e retirar dados exige trabalho. Supabase é uma alternativa de código aberto baseada em Postgres; AWS Amplify e Appwrite também concorrem, e Convex oferece outro tipo de back-end em tempo real. Firebase é uma escolha comum para aplicativos móveis e protótipos.
