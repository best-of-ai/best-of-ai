O Winnow se concentra em um custo específico de cozinhas profissionais: alimentos preparados que acabam no lixo. Seu produto Vision fica sobre uma lixeira e registra cada descarte. A câmera identifica o alimento, uma balança o pesa, e o sistema registra o horário e fotografa o evento, sem exigir que a equipe faça anotações manualmente.

Esses dados alimentam relatórios que mostram quais itens são desperdiçados, quando e por quê. Um produto de previsão, o Winnow Foresight, usa o histórico para sugerir quanto produzir em cada serviço. Os planos vão de uma opção simples de registro por tablet ao sistema Vision baseado em câmera.

Entre os clientes estão operadores de serviços de alimentação, hotéis, resorts, universidades e cruzeiros. O Winnow não divulga preços, mas oferece uma calculadora de retorno sobre o investimento para estimar a economia. Foi desenvolvido para cozinhas com volume suficiente para que o desperdício represente um custo significativo; é menos relevante para um café pequeno.
