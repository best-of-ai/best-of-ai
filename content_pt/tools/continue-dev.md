Continue foi desenvolvido em torno de escolha e controle. Em vez de prender usuários a um único provedor, permite conectar o modelo preferido, de APIs na nuvem a modelos executados localmente com Ollama, e configurar seu comportamento com regras, prompts e contexto da base de código e da documentação.

A extensão oferece preenchimento automático, chat que pode consultar arquivos e documentos e um modo de edição que reescreve o código selecionado. Equipes podem compartilhar configurações e usar o hub do Continue para compartilhar assistentes; o projeto também se expandiu para verificações automatizadas em pull requests. Como o código é aberto, empresas podem auditá-lo e adaptá-lo.

Continue é gratuito e de código aberto, com opções pagas para equipes. A configuração exige mais trabalho do que em produtos comerciais, e a qualidade depende dos modelos escolhidos. Entre as alternativas estão GitHub Copilot, Cursor, Cline, Roo Code e Sourcegraph Cody. Continue é indicado para desenvolvedores que querem um assistente aberto e personalizável.
