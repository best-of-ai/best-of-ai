Agent HQ é a forma do GitHub de tratar agentes de programação como uma equipe que você gerencia, em vez de um único assistente. Em vez de escolher um fornecedor de IA, um desenvolvedor pode atribuir tarefas a agentes de provedores diferentes, como Codex da OpenAI e Claude Code da Anthropic, no mesmo lugar em que código, issues e pull requests já estão. Cada agente trabalha na tarefa e retorna alterações para revisão no fluxo habitual de pull requests.

Mission Control oferece uma visão central do trabalho de cada agente para que o desenvolvedor veja quais tarefas estão em andamento, quais foram concluídas e quais exigem atenção. Plan Mode permite que um agente proponha as etapas antes de escrever código, possibilitando corrigir a abordagem desde o início. Como funciona no GitHub, na linha de comando e no VS Code, as mesmas tarefas podem ser iniciadas e acompanhadas na interface mais conveniente.

Organizações controlam quais agentes e modelos suas equipes podem usar, e um painel de métricas mostra uso e resultados. O acesso depende de um plano pago do Copilot, e alguns agentes podem cobrar solicitações premium. Executar vários agentes aumenta o volume de código a revisar, então práticas de revisão se tornam ainda mais importantes. Cursor e Devin oferecem suas próprias formas de gerenciar agentes; Claude Code e Codex também podem ser executados diretamente. Agent HQ interessa principalmente a equipes já centradas no GitHub.
