O Turso leva SQLite para a nuvem. libSQL acrescenta recursos ao SQLite, como acesso pela rede e replicação, e o Turso hospeda bancos de dados e os replica para regiões próximas aos usuários para permitir leituras rápidas. Também oferece réplicas incorporadas que ficam dentro de um aplicativo.

O modelo é adequado a produtos que usam um banco de dados por usuário ou inquilino, pois criar um novo banco custa pouco. O suporte a busca vetorial ajuda em recursos de IA, e agentes podem usar bancos de dados como armazenamento temporário.

O Turso oferece um nível gratuito e planos cobrados pelo uso. O design do SQLite limita algumas cargas de trabalho intensivas em gravação. Entre as alternativas estão Neon, PlanetScale, Cloudflare D1, Supabase e Fly.io LiteFS. O Turso é indicado para desenvolvedores que criam aplicativos de borda e multi-tenant.
