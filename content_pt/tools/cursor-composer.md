O Composer foi a resposta do Cursor a uma limitação básica das primeiras ferramentas de programação com IA, que sugeriam uma linha ou editavam um arquivo, mas tinham dificuldade com mudanças que afetavam vários arquivos. Você descreve uma funcionalidade ou refatoração, e o Composer identifica os arquivos que precisam mudar, escreve as alterações e as mostra como diferenças para você aceitar ou rejeitar. Ele cria arquivos, atualiza importações e mantém consistência entre trechos relacionados. O recurso evoluiu depois para o agente do Cursor, que também executa comandos e corrige os próprios erros.

Composer também é o nome que o Cursor deu a seus próprios modelos, treinados para programação agêntica rápida dentro do editor. Eles foram criados para ser rápidos o bastante para manter o desenvolvedor concentrado enquanto lidam com tarefas de várias etapas e são oferecidos junto com modelos de provedores como Anthropic, OpenAI e Google. Os detalhes dos modelos disponíveis e seus preços mudam com frequência.

O Composer faz parte do Cursor, então usá-lo significa trabalhar no editor Cursor, uma ramificação do VS Code, com um plano gratuito e planos pagos que incluem uma franquia de uso. Alterações grandes ainda exigem revisão cuidadosa, pois um modelo pode editar muitos arquivos de forma que compila, mas não atende à intenção. Entre as alternativas para edição de vários arquivos com IA estão Cascade do Windsurf, modo agente do GitHub Copilot, Cline e Claude Code.
