Usuários carregam gravações, visualizam espectrogramas, anotam segmentos e executam scripts para análise em lote. O software também dá suporte a experimentos de síntese de fala. A interface é antiquada, mas muito capaz.

É de código aberto e funciona em Windows, macOS e Linux.

ELAN é útil para anotar vídeos e áudios. O Praat é indicado para linguistas que estudam fonética.
