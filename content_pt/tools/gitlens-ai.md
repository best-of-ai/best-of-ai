GitLens enriquece o VS Code com o histórico do Git. Exibe anotações inline de blame indicando quem alterou uma linha por último, quando e em qual commit, e permite navegar pelo histórico de arquivos, linhas ou branches sem sair do editor. Os recursos incluem grafo de commits, comparações entre branches e um Launchpad que reúne pull requests e issues. É uma das extensões mais baixadas do VS Code.

Recursos de IA ajudam em tarefas comuns do Git. GitLens pode escrever mensagens de commit a partir de alterações preparadas, resumir em linguagem simples as mudanças de um commit ou branch e ajudar a redigir descrições de pull requests, poupando tempo de documentação. Oferece suporte a vários provedores e modelos de IA, com opções para controlar o envio de dados.

GitLens tem uma modalidade gratuita com muitos recursos e planos pagos para capacidades avançadas, como Launchpad e workspaces, dentro do ecossistema GitKraken. Resumos de IA devem ser conferidos com o diff real. Entre as alternativas estão recursos integrados do Git no VS Code, geração de mensagens de commit do GitHub Copilot, GitKraken Client, Sourcetree e Lazygit para terminal. GitLens é indicado para desenvolvedores que trabalham no VS Code e querem compreender melhor o histórico do código.
