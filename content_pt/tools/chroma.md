O Chroma é um banco de dados vetorial que prioriza a simplicidade para desenvolvedores. Ele armazena embeddings — representações numéricas de texto, imagens ou outros dados — junto com metadados e documentos originais. Aplicações fazem consultas para encontrar itens com significado semelhante ao de uma entrada, fundamento da busca semântica e da geração aumentada por recuperação.

É fácil começar: algumas linhas de Python ou JavaScript criam uma coleção, adicionam documentos e executam consultas. O Chroma pode funcionar na memória dentro de um programa, como servidor local ou em um serviço de nuvem hospedado. Ele se integra ao LangChain, LlamaIndex e outras estruturas, o que o tornou uma escolha comum para protótipos.

O Chroma é gratuito e de código aberto, e oferece o Chroma Cloud gerenciado para produção. Implantações em grande escala exigem atenção ao desempenho e à operação, e algumas equipes migram para outros bancos de dados para cargas de trabalho pesadas. Entre as alternativas estão Pinecone, Weaviate, Qdrant, Milvus e pgvector no Postgres. O Chroma é indicado para desenvolvedores que estão prototipando aplicações de recuperação de informações.
