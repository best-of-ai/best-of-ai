A Realtime API muda a forma como aplicativos de voz são criados. Sistemas antigos encadeavam reconhecimento de fala, modelo de linguagem e síntese de fala, acrescentando atraso em cada etapa. A Realtime API recebe e envia áudio diretamente em um único modelo, de modo que as respostas começam mais rápido e podem incluir entonação, pausas e interrupções naturais.

Desenvolvedores se conectam por WebRTC ou WebSockets para transmitir áudio e receber fala, texto e chamadas de ferramentas. A API oferece chamada de funções, permitindo que um agente de voz consulte dados ou realize ações, e pode ser usada em agentes telefônicos, assistentes dentro de aplicativos e prática de idiomas.

A API é cobrada conforme o uso e custa mais que chamadas somente de texto. Agentes de voz exigem atenção cuidadosa à latência, interrupções e segurança. Entre as alternativas estão Gemini Live API do Google, agentes conversacionais da ElevenLabs, Vapi, Retell AI e Twilio ConversationRelay. A OpenAI Realtime API é indicada para desenvolvedores que criam experiências de voz.
