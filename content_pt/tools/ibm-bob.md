Bob é o assistente agêntico da IBM para desenvolvimento de software. Em vez de apenas completar código, participa de todo o ciclo: compreende a base de código, planeja alterações, escreve e revisa código, gera testes e ajuda na implantação. Agentes diferentes assumem funções como arquiteto ou revisor e trabalham dentro do editor do desenvolvedor.

O foco é o uso empresarial. A IBM destaca segurança e governança, com proteção contra vazamentos de dados sensíveis, aplicação de políticas e testes para detectar vulnerabilidades na IA. A ferramenta distribui tarefas entre vários modelos de linguagem, incluindo a família Granite da IBM e modelos de outros provedores, e é voltada à modernização, como migração de aplicativos antigos em Java ou COBOL.

A IBM afirma que primeiro disponibilizou a ferramenta a dezenas de milhares de seus próprios funcionários antes do lançamento geral e declara grandes ganhos de produtividade, que são autorrelatados. Bob é um produto pago, com testes e licenciamento empresarial. Entre as alternativas estão GitHub Copilot, Cursor, Claude Code, Amazon Q Developer e Gemini Code Assist do Google. IBM Bob atende grandes organizações com ambientes regulamentados e código legado.
