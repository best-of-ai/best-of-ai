SonarQube analisa código-fonte sem executá-lo. Verifica erros, vulnerabilidades de segurança, segredos embutidos no código, problemas de qualidade, duplicação e cobertura de testes e apresenta os resultados em um painel e em pull requests. Equipes definem critérios de qualidade, como não permitir novos erros críticos, que podem bloquear uma mesclagem quando o código não atende ao padrão, detectando problemas cedo no desenvolvimento.

A ferramenta se integra a sistemas de CI/CD como GitHub Actions, GitLab, Jenkins e Azure DevOps e a IDEs pelo SonarLint, que destaca problemas durante a digitação. Os recursos de IA incluem CodeFix, que sugere alterações para problemas encontrados, e funções para verificar código gerado por IA, uma preocupação crescente com a produção de mais código por assistentes. Há suporte a muitas linguagens e frameworks.

SonarQube tem uma edição comunitária gratuita para hospedagem própria, edições pagas com mais linguagens e recursos e SonarQube Cloud como serviço hospedado. Análise estática pode gerar falsos positivos, portanto equipes precisam ajustar as regras. Entre os concorrentes estão Snyk, Checkmarx, Semgrep, Veracode e CodeQL no GitHub; Codacy e DeepSource são outras ferramentas de qualidade. SonarQube é uma escolha padrão para qualidade contínua de código.
