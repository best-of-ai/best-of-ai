O MAI Code 2 Flash é o irmão menor do MAI Code 2, anunciado em 17 de novembro de 2026 no Ignite. A Microsoft o criou para tarefas de grande volume, como explicações de código, edições pontuais e correções de rotina. Está no GitHub Copilot e em prévia de acesso limitado no Microsoft Foundry.

A Microsoft diz que sua média nos benchmarks é comparável à do GPT-6 Luna e do Claude Haiku 5.5 por uma fração do custo, e não informa preços por token. Um modelo derivado, o MAI Work Flash, é construído a partir do Code 2 Flash para rodar no Microsoft 365 e no FabricIQ.
