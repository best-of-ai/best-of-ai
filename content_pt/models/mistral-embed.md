O Mistral Embed é o modelo de embeddings de texto da Mistral AI. Disponível pela API desde o início de 2024, ele converte texto em vetores de 1.024 dimensões para busca semântica, agrupamento e geração aumentada por recuperação (RAG). Aceita entradas de até 8.192 tokens. A Mistral o apresenta como uma opção de embeddings de uso geral para equipes que já desenvolvem na plataforma da empresa, e não como um modelo especializado em código ou recuperação multilíngue.

O preço é de US$ 0,01 por milhão de tokens de entrada, o que o torna uma das opções hospedadas mais baratas para embeddings. O acesso é feito exclusivamente pela API da Mistral; não há pesos disponíveis para download. Mais tarde, a Mistral adicionou o Codestral Embed, modelo separado e ajustado especificamente para recuperação de código, mantendo o Mistral Embed como a opção geral para texto.
