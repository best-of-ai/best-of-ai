Granite Code é a família de modelos abertos para código da IBM, lançada em maio de 2024 em quatro tamanhos — 3B, 8B, 20B e 34B parâmetros — cada um disponível em versões base e ajustada para seguir instruções. A IBM Research treinou os modelos com cerca de 3 a 4 trilhões de tokens de 116 linguagens de programação, combinando código bruto com textos em linguagem natural sobre código para atender, em um mesmo sistema, a tarefas como geração de código, correção de bugs e explicação de código. Os modelos são distribuídos sob Apache 2.0, permitindo que empresas os ajustem e redistribuam sem entraves de licenciamento; a IBM os destinou diretamente a organizações cautelosas com assistentes de código fechados. No lançamento, benchmarks mostraram modelos Granite Code igualando ou superando outros modelos abertos de código de tamanho semelhante no HumanEval e em conjuntos relacionados. A linha está disponível no Hugging Face, pelo Ollama e na AWS via Bedrock e SageMaker; trabalhos posteriores de ampliação levaram algumas variantes a uma janela de contexto de 128K.
