MAI Code 2 FlashはMAI Code 2の小型版で、2026年11月17日にIgniteで発表されました。Microsoftは、コードの説明、的を絞った編集、定型的な修正のような大量の処理向けに作りました。GitHub Copilotで使えるほか、Microsoft Foundryでは限定アクセスのプレビューです。

Microsoftによると、ベンチマークの平均はGPT-6 LunaやClaude Haiku 5.5と同程度で、コストはその何分の一かです。トークンあたりの料金は公表していません。Code 2 Flashから作った派生モデルのMAI Work Flashは、Microsoft 365とFabricIQで動きます。
