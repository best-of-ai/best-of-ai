Microsoft AIは2026年11月17日にIgniteでMAI Code 2を公開しました。本番コード、デバッグ、複数ファイルにまたがる実装、リポジトリ全体の推論、UIの作業といった、企業の日常的なプログラミングを対象にしています。Microsoftによると、基礎科学の研究や、非常に長期にわたるエージェントタスクにはまだ調整されていません。GitHub Copilotで使えます。ページにはコストがパーセントでしか書かれておらず、50%の割引価格が表示されています。

DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas、FrontierCode v1.1の平均で、MAI Code 2はGPT-6.1 Solのスコアの98%に40%のコストで、Claude Opus 5.5のスコアの96%に5%のコストで届くとMicrosoftは説明しています。フロントエンドのブラインドテストでは、258人のアノテーターが64%の割合でGPT-6 Solよりこちらを選びました。いずれもMicrosoft自身による実行結果です。
