Visual Studio Code、通称VS Codeは、開発者のあいだで最も広く使われているコードエディタです。すばやく開ける軽さがありながら、構文のハイライト、デバッガー、統合ターミナル、Gitのサポート、言語、リンター、テーマ、ツールを加える巨大な拡張機能マーケットプレイスなど、ほとんどの人が必要とするものがそろっています。中核はオープンソースで、Windows、macOS、Linuxで動きます。ブラウザ版もあり、リモート開発機能を使えば、コンテナ内、SSH経由、クラウド環境で作業できます。

AIは今では組み込みの一部です。GitHub Copilotは、入力に合わせたインラインのコード提案、プロジェクトについての質問に答えるチャットパネル、タスクを計画し、複数のファイルを編集し、ターミナルコマンドを実行し、起きたエラーを直せるエージェントモードを備えています。VS CodeはModel Context Protocolにも対応しており、エージェントが外部のツールやデータソースに接続でき、さまざまなプロバイダーのモデルを使えます。CursorやWindsurfをはじめ、ほかの多くのAIコーディングツールは、VS Codeのフォークとして始まっており、エコシステムの多くがこれを土台にしていることの表れです。

エディタ自体は無料です。Copilotには、利用が限られた無料枠と、より多く使う人やチーム向けの有料プランがあります。Microsoftの公式ダウンロードにはテレメトリーと一部のプロプライエタリな部分が含まれているため、完全にオープンソースのバイナリがほしい人向けに、VSCodiumのようなコミュニティビルドがあります。IntelliJやVisual Studioのような本格的なIDEと比べると、VS Codeは初期状態でできることが少なく、拡張機能に頼ります。そのぶん設定の手間はかかりますが、より速く、柔軟なエディタになります。
