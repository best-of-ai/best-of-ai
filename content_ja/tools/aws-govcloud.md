AWS GovCloudは、厳しい規制要件のあるワークロード向けに作られた、独立したAWSリージョンの一群です。米国の政府機関、受託事業者、管理されたデータを扱うその他の組織が、FedRAMP High、国防総省のCloud Computing Security Requirements Guide、ITAR、CJIS、HIPAAなどの基準に従わなければならないシステムを置くために使います。これらのリージョンは通常のAWSリージョンから物理的にも論理的にも分離され、アクセスは審査を受けた米国市民に限られます。

多くのAWSサービスが使え、コンピュート、ストレージ、データベース、それに増えつつあるAIサービスが含まれます。顧客は機械学習と生成AIのワークロードを動かせます。Amazon Bedrockを通じたモデルの利用も含み、データはコンプライアンスの境界の中に留まります。アカウントは専用の手続きで作り、請求のために通常のAWSアカウントと結び付けます。

GovCloudの料金は他のAWSリージョンに近く、たいていやや高めです。そこで使えるサービスと最新機能は一部に限られます。コンプライアンスは責任を分担する形なので、顧客はワークロードを正しく設定し、運用する必要があります。競合にはMicrosoft Azure Government、Google CloudのAssured Workloads、Oracleの政府向けリージョンがあります。GovCloudは、規制されたデータを認定された米国の環境の中に置かなければならない組織に向いています。
