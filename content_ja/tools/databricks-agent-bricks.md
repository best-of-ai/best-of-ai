Agent Bricksは、自社のデータに基づくエージェントを求める企業向けです。すべてを手で書くのではなく、社内文書への質問への回答、フォームからの情報抽出、複数のエージェントの協調といった作業をチームが説明すると、プラットフォームが構築を手伝います。合成のテストデータを作り、ジャッジで品質を評価し、モデルと設定を変えて試しながらエージェントを調整して、精度とコストを改善します。

Databricksのプラットフォーム上にあるため、エージェントはUnity Catalogで管理されたデータを使い、アクセス制御は企業の既存の規則に従います。MLflow上に組まれた可観測性と評価のツールがエージェントの振る舞いを追跡し、開発者は自分のフレームワークを持ち込めます。Lakebaseは、状態とアプリケーションデータのためのトランザクション型データベースをエージェントに渡し、アプリケーションは分析用データのそばに記憶と結果を保存できます。

Agent BricksはDatabricksの従量課金の一部として販売され、費用は使うコンピュートとモデルによって変わります。すでにデータをDatabricksに置いている組織で、いちばん意味があります。代替にはSnowflake Cortex、Amazon Bedrock AgentCore、Google Vertex AI Agent Builder、Microsoft Copilot Studio、それにLangGraphのようなオープンソースのフレームワークがあります。エージェントを実際のワークフローに任せる前には、慎重な評価がなお必要です。
