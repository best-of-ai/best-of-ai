Replit Agent 4は、ソフトウェアを言葉で説明すればエージェントが作ってくれる、という考え方を引き継いでいます。Replitのワークスペースで作りたいものを説明すると、エージェントがコードを書き、環境とデータベースを整え、結果をテストして、デプロイします。進み具合を確認し、普通の言葉でフィードバックを返し、変更を頼めます。Replitによると、このバージョンは前のバージョンよりかなり速くなっています。アプリ作りには多くの手順があるので、これは大きな違いです。

新しいキャンバスで、エージェントが作れるものが広がりました。ウェブアプリやモバイルアプリに加えて、表計算、グラフ、簡単なゲームも作れ、複数の種類の成果物を1つの場所で扱えます。エージェントはモバイルでも使えるので、スマートフォンからプロジェクトを始めたり確認したりできます。ホスティングとデプロイが組み込まれているため、完成したアプリを同じ場所で公開できます。

Agent 4はReplitの有料プランに含まれ、利用量はクレジットで測られます。長い、または複雑なビルドはクレジットを多く使うことがあります。エージェントが作ったソフトウェア全般に言えることですが、実際のユーザー、支払い、機密データを扱う前にアプリのレビューが必要で、あいまいな依頼ではエージェントが堂々巡りになることもあります。アプリ作りではLovable、Bolt、v0、Base44が競合し、既存のコードベースで作業する開発者にはCursorとClaude Codeが向いています。プラットフォーム全体については、Replit本体の項目を見てください。
