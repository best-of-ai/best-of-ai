Agent HQは、コーディングエージェントを一人のアシスタントではなく、管理するチームとして扱うGitHubのやり方です。AIベンダーを一つに絞らず、開発者は、コード、issue、pull requestがすでに置いてある同じ場所から、OpenAIのCodexやAnthropicのClaude Codeのように、別々のプロバイダのエージェントへ作業を割り当てられます。各エージェントは自分のタスクに取り組み、いつものpull requestの流れで、レビュー用の変更を返します。

Mission Controlは、すべてのエージェントが何をしているかの中心の画面を出し、開発者は、どのタスクが動いているか、どれが終わったか、どれに注意が必要かを見られます。Plan Modeでは、エージェントがコードを書く前に手順を提案するので、開発者は早い段階で方針を直せます。GitHub、コマンドライン、VS Codeのどこでも動くので、作業に合う画面から同じタスクを始めて追えます。

組織は、チームが使ってよいエージェントとモデルを制御でき、指標のダッシュボードが利用状況と結果を示します。利用には有料のCopilotプランが必要で、一部のエージェントはプレミアムリクエストを課金することがあります。複数のエージェントを動かすとレビューするコードの量が増えるので、レビューのやり方は、軽くなるどころか、より重要になります。CursorとDevinは独自のエージェント管理を持ち、Claude CodeとCodexは直接動かせます。Agent HQが最も向いているのは、すでにGitHubを中心にしているチームです。
