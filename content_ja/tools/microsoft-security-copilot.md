Security Copilotは、人手の足りないセキュリティ運用チームの負担を軽くすることを目指しています。アナリストがインシデントで何が起きたかを自然言語で尋ねると、Copilotがセキュリティ製品からのシグナルを集め、攻撃の経路を要約し、アラートを説明して、次の手順を提案します。KQLなどの言語でクエリを書き、不審なスクリプトやファイルを分析し、インシデントレポートを作れるので、定型作業の時間が減ります。

製品はエージェントの方向に進んでいます。目的別のエージェントが、フィッシングのアラートのトリアージ、脆弱性の評価、注意が必要な状況の優先順位付けといった仕事を、人間の監督のもとでこなします。アナリストがすでに使っているポータルに組み込まれ、プラグインでMicrosoft以外のツールにもつながるので、ほかのシステムのデータも使えます。アクセスできる範囲と実行できる操作は、制御で管理されます。

Security Copilotは有料で、従量課金のユニット制です。詳細はMicrosoftが時期ごとに調整していて、上位のセキュリティライセンスに含まれる機能もあります。Microsoftのセキュリティスタックにすでに投資している組織に最も役立ちます。AIによる分析は間違うことがあるため、対応する前に確認が必要です。競合には、GoogleのGemini in Security、CrowdStrike Charlotte AI、SentinelOne Purple AI、Palo Alto Cortex、SplunkのAIツールがあります。
