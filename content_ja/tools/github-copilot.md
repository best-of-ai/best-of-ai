GitHub Copilotは、利用者数が最も多いAIコーディングツールで、コードの多くがすでに置いてある場所に組み込まれています。最初はインラインの自動補完で、開いているファイルをもとに行や関数を完成させ、今もVS Code、Visual Studio、JetBrainsのIDE、Neovim、Xcodeでそれをします。チャットパネルは、エディタを離れずに、コードの説明、テストの作成、エラーの修正、プロジェクトについての質問への回答をします。

新しい部分はエージェント型です。エディタのエージェントモードは、タスクを計画し、複数のファイルを編集し、ターミナルコマンドを実行し、失敗を見てやり直します。CopilotのコーディングエージェントはGitHub上で直接動きます。issueを割り当てると、バックグラウンドで作業し、レビュー用のpull requestを開きます。Copilotはpull requestのレビューやコマンドラインでの補助もでき、選択画面で選んだ複数プロバイダのモデルを使えます。チームはカスタム指示を足して、自分たちの決まりに従わせられます。

利用量に限りのある無料枠、個人向けの有料プラン、それに管理の制御、ポリシー設定、コードをモデルの学習から外す選択肢を備えたビジネスと企業向けのプランがあります。最も性能の高いモデルへのプレミアムリクエストは従量になることがあり、多用すると上限に達します。開発者がすでに使っているツールの中で動くので、導入は容易です。Cursor、Windsurf、Claude Codeは、よりエージェント中心の体験を出します。一方、Copilotの強みは、カバー範囲の広さ、GitHubとの連携、企業向けのサポートです。
