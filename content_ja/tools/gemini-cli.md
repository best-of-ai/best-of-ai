Gemini CLIは、コーディングと自動化のエージェントとしてGeminiをターミナルへ持ち込みます。プロジェクトのディレクトリで、コードベースの説明、失敗しているテストの修正、機能の追加のように、タスクをふつうの言葉で伝えます。エージェントはファイルを読み、変更を提案し、シェルのコマンドを実行し、それを繰り返します。Webを検索でき、コンテキスト用のファイルからプロジェクトの規約を学びます。Geminiのコンテキスト長が長いので、長い文脈も扱えます。

拡張できる作りです。Model Context Protocolへの対応で外部ツールにつながり、拡張は自前のコマンドと連携をひとまとめにします。設定で、チームは権限とサンドボックスを制御できます。Apache 2.0ライセンスのオープンソースで、自動化や継続的インテグレーションからスクリプトとして動かせます。エディタでは、Gemini Code Assistのエージェントモードの中でも動きます。

個人のGoogleアカウントなら、利用上限の範囲で無料です。有料プランやAPIキーで上限は上がります。ほかのコーディングエージェントと同じく間違えることがあるので、変更は確認し、ファイルを変更したり削除したりするコマンドには注意が必要です。代替にはClaude Code、OpenAI Codex CLI、Aider、Cline、GitHub CopilotのCLIがあります。無料でオープンソースのターミナルエージェントが欲しい開発者に向いています。
