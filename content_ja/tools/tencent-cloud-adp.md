Tencent Cloud ADPは、企業がエージェントを作るためのツールをそろえています。ナレッジベースをつないで検索に使い、ビジュアルエディタでワークフローを設計し、複数のエージェントを組み合わせて協調させます。モデルには、TencentのHunyuanシリーズなどがあります。

主な用途は、カスタマーサービス、社内アシスタント、業務プロセスの自動化です。テストと監視のツールを備え、WeChatや企業向けメッセージングなど、Tencentのエコシステムと連携します。

料金はTencent Cloud内の従量課金です。中国国外では利用できる範囲やサポートが限られ、データの保管場所も検討が必要です。代替には、Alibaba CloudのBailian、Baidu Qianfan、ByteDanceのVolcano Engine、Dify、AWS Bedrock Agentsがあります。Tencent Cloud ADPは、Tencent Cloud上でエージェントを作る企業に向いています。
