ワークフローはYAMLファイルで、マーケットプレイスにある再利用できるアクションを呼び出します。ホストされたランナーはLinux、Windows、macOSで動き、チームが自分のランナーを動かすこともできます。シークレットと環境がデプロイを制御します。

公開リポジトリでは無料で使え、非公開リポジトリには無料の利用枠があり、それを超えると有料です。

代替にはGitLab CIとCircleCIがあります。GitHub Actionsは、GitHub上で働くDevOpsエンジニアに向いています。
