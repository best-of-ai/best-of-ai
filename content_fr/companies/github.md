Le travail de GitHub sur l'IA tourne autour de Copilot, qui a commencé par la complétion de code dans l'éditeur et couvre maintenant le chat, la revue de code et un agent qui prend des issues et ouvre des pull requests. Copilot se vend dans un abonnement GitHub, avec des paliers plus élevés pour un usage plus intensif.

Agent HQ, annoncé à Universe en octobre 2025 et déployé plus largement début 2026, change l'argumentaire. Au lieu de proposer seulement l'agent de Microsoft, GitHub laisse les abonnés confier du travail à des agents de programmation d'Anthropic, OpenAI, Google, Cognition et xAI. Une vue Mission Control suit ce que fait chaque agent, et les administrateurs choisissent les agents et les modèles que leurs équipes peuvent utiliser. Codex, d'OpenAI, a été le premier agent externe à y figurer, suivi de Claude Code.

Plan Mode, un tableau de bord de métriques et une étape de revue intégrée, qui vérifie le code de l'agent avant qu'un développeur ne le voie, complètent l'ensemble. Le pari de GitHub, c'est qu'il n'a pas besoin de construire le meilleur agent s'il contrôle l'endroit où tous travaillent.
