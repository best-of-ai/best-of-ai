Les produits d'IA de HubSpot portent le nom Breeze. L'entreprise a vendu des agents Breeze pour le contenu, les réseaux sociaux, la prospection et le support client. En avril 2026, elle est passée à une tarification au résultat pour ses agents : les clients paient quand un agent termine la tâche. Les actions des agents sont facturées en HubSpot Credits, à part des licences par siège.

Le 23 juillet 2026, selon un blog, HubSpot a annoncé Agent Hub comme lieu pour ses agents, a renommé Breeze Studio en Agent Builder et a retiré cinq agents en bêta. Les comptes rendus divergent sur le modèle derrière les agents : l'un cite un changelog développeur selon lequel le modèle par défaut est passé à GPT-5, l'autre parle de GPT-4.x.

Les sorties du printemps 2026 couvraient aussi l'Answer Engine Optimization, qui suit la façon dont une marque apparaît dans les réponses des IA. La plupart de ces détails viennent de blogs tiers : mieux vaut vérifier le changelog de HubSpot avant de s'appuyer sur les dates.
