Character.AI entraîne ses propres modèles de langage conversationnels en interne, plutôt que de s'appuyer seulement sur des API tierces, et le c2 model fait partie de cette lignée de systèmes propriétaires faits pour le chat avec ses personnages. Les mises à jour publiques précédentes s'appelaient C1, C1.1 et C1.2, chacune pour des réponses plus dans le personnage, plus cohérentes sur de longues conversations et plus réactives. Sa famille de modèles interne (connue sous le nom de Kaiju) couvre plusieurs tailles, pour que les différentes fonctions puissent arbitrer entre latence et qualité. Character.AI n'a publié ni le nombre de paramètres, ni les données d'entraînement, ni les détails d'architecture de ses modèles de chat, et les traite comme des secrets commerciaux, comme le font la plupart des produits grand public de compagnons d'IA.

Le modèle n'est pas disponible en dehors de l'application et du site web de Character.AI : pas d'API publique, pas de poids à télécharger, pas d'hébergement chez un tiers. Il est réglé pour le jeu de rôle et la conversation façon compagnon, pas pour des tâches d'assistant général comme le code ou l'analyse de documents. Les choix de produit de Character.AI, comme la longueur des réponses, le filtrage et la mémoire, comptent autant dans l'usage que le modèle lui-même.
