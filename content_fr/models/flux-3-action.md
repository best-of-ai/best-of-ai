Black Forest Labs a publié FLUX 3 Action le 23 septembre 2026, un modèle à poids ouverts de 7 milliards de paramètres qui prédit des actions de robot à partir de vidéo. Il a obtenu 42,2 % sur le benchmark RoboLab-120 de NVIDIA, contre 36,8 % pour Cosmos 3 Nano, le modèle de NVIDIA, avec moins de la moitié des paramètres. Les poids sont publiés sur Hugging Face sous une nouvelle FLUX Kommunity License.
