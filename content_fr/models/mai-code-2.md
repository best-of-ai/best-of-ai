Microsoft AI a sorti MAI Code 2 le 17 novembre 2026 à Ignite. Il vise la programmation d'entreprise au quotidien : code de production, débogage, implémentation sur plusieurs fichiers, raisonnement à l'échelle d'un dépôt et travail sur l'interface. Microsoft dit qu'il n'est pas encore réglé pour la recherche scientifique fondamentale ni pour les tâches agentiques à très long horizon. Il est disponible dans GitHub Copilot, et la page ne donne les coûts qu'en pourcentages, avec un prix promotionnel de 50 % affiché.

En moyenne sur DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas et FrontierCode v1.1, Microsoft dit que MAI Code 2 atteint 98 % du score de GPT-6.1 Sol pour 40 % du coût, et 96 % du score de Claude Opus 5.5 pour 5 % du coût. Dans un test à l'aveugle sur le frontend, 258 annotateurs l'ont préféré à GPT-6 Sol dans 64 % des cas. Ce sont les propres essais de Microsoft.
