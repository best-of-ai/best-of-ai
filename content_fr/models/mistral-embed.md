Mistral Embed est le modèle d'embeddings texte de Mistral AI, disponible via son API depuis début 2024. Il transforme le texte en vecteurs de 1 024 dimensions pour la recherche sémantique, le clustering et la génération augmentée par la recherche. Il accepte des entrées jusqu'à 8 192 tokens, et Mistral le présente comme une option d'embeddings généraliste pour les équipes qui construisent déjà sur la plateforme Mistral, plutôt que comme un modèle spécialisé pour le code ou la recherche multilingue.

Il est tarifé à 0,01 $ par million de tokens d'entrée, ce qui en fait l'une des options d'embeddings hébergées les moins chères, et on n'y accède que par l'API de Mistral, pas sous forme de poids téléchargeables. Mistral a ensuite ajouté Codestral Embed, un modèle à part réglé pour la recherche de code, et Mistral Embed reste l'option pour le texte général dans la gamme.
