MAI Code 2 Flash est le petit frère de MAI Code 2, annoncé le 17 novembre 2026 à Ignite. Microsoft l'a conçu pour les tâches en grand volume comme les explications de code, les modifications ciblées et les corrections courantes. Il est dans GitHub Copilot et en préversion à accès limité dans Microsoft Foundry.

Microsoft dit que sa moyenne sur les benchmarks est comparable à celle de GPT-6 Luna et de Claude Haiku 5.5 pour une fraction de leur coût, et ne donne aucun prix par token. Un modèle dérivé, MAI Work Flash, est construit à partir de Code 2 Flash pour tourner dans Microsoft 365 et FabricIQ.
