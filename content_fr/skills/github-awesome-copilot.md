Ce dépôt regroupe les skills suivants :

- **acquire-codebase-knowledge** : Aide un agent à comprendre une base de code existante.
- **azure-well-architected-review** : Lance une évaluation selon le Well-Architected Framework d'Azure.
- **aws-cost-optimize** : Cherche comment réduire les dépenses cloud sur AWS.
- **codeql** : Applique une analyse de sécurité statique fondée sur CodeQL.
- **architecture-blueprint-generator** : Produit une documentation d'architecture système.
- **conventional-commit** : Impose le format de message Conventional Commits.
- **agent-owasp-compliance** : Vérifie le comportement de l'agent face aux consignes de sécurité OWASP.
- **copilot-pr-autopilot** : Automatise des parties du flux de pull request.
- **anti-ui-slop** : Signale une interface de mauvaise qualité ou d'allure trop générique.
