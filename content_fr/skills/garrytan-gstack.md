Ce dépôt regroupe les skills suivants :

- **office-hours** : Pose des questions directes sur une idée de produit avant d'écrire du code.
- **plan-ceo-review** : Revoit le périmètre du projet et reformule le problème de fond.
- **plan-eng-review** : Revoit l'architecture, le flux de données et les plans de tests.
- **review** : Fait une revue de code tournée vers la production et applique les correctifs tout seul.
- **qa** : Teste l'app dans un navigateur réel et génère des tests de régression.
- **ship** : Ouvre un pull request et met en place un framework de tests s'il en manque un.
- **design-consultation** : Génère un système de design complet pour le projet.
- **design-shotgun** : Produit plusieurs maquettes visuelles pour explorer des pistes de design.
- **cso** : Fait un audit de sécurité basé sur OWASP et STRIDE.
- **document-release** : Met à jour la documentation du projet automatiquement.
