Ce dépôt regroupe les skills suivants :

- **stitch::code-to-design** : Convertit du code existant en design Stitch.
- **stitch::generate-design** : Génère un nouveau design à partir d'un prompt.
- **stitch::manage-design-system** : Gère le design system d'un projet dans Stitch.
- **stitch::react-components** : Génère des composants React à partir d'un design Stitch.
- **stitch::react-native** : Génère du code React Native à partir d'un design Stitch.
- **remotion** : Génère du code vidéo Remotion à partir d'un design Stitch.
- **shadcn-ui** : Génère des composants basés sur shadcn/ui à partir d'un design Stitch.
- **enhance-prompt** : Skill utilitaire qui affine un prompt de design avant la génération.
- **taste-design** : Skill utilitaire pour évaluer la qualité d'un design.
