Ce dépôt regroupe les skills suivants :

- **coupling-analysis** : Analyse le couplage entre modules, selon la force, la distance et la volatilité.
- **domain-analysis** : Cartographie les domaines métier et propose des frontières de services, avec le design stratégique DDD.
- **component-identification-sizing** : Cartographie les composants d'architecture et mesure leur taille.
- **component-common-domain-detection** : Trouve de la logique métier dupliquée, dispersée entre les composants.
- **component-flattening-analysis** : Trouve les classes mal placées et corrige les problèmes de hiérarchie des composants.
- **decomposition-planning-roadmap** : Planifie des migrations pas à pas pour découper un monolithe.
- **evolutionary-modular-architecture** : Guide le design de monolithes modulaires avec le DDD.
