Ce dépôt regroupe les skills suivants :

- **skill-creator** : Outils pour écrire de nouveaux Agent Skills.
- **frontend-design** : Consignes pour construire une interface distincte et volontaire.
- **code-review** : Relit un diff ou une pull request sur la justesse et les problèmes de qualité.
- **code-simplifier** : Simplifie et nettoie du code existant.
- **claude-security** : Plugin centré sur la sécurité pour l'usage de Claude Code.
- **pr-review-toolkit** : Une boîte à outils pour relire des pull requests.
- **hookify** : Aide à configurer les hooks de Claude Code.
- **mcp-server-dev** : Aide pour développer des serveurs MCP.
- **agent-sdk-dev** : Aide pour construire avec le Claude Agent SDK.
