Ce dépôt regroupe les skills suivants :

- **camerax** : Guide les fonctions caméra construites avec CameraX.
- **android-cli** : Explique comment installer et utiliser l'outil en ligne de commande android.
- **appfunctions** : Trouve des flux de l'app à exposer comme AppFunctions, par exemple créer une note.
- **ml-kit-genai-prompt-api** : Ajoute la ML Kit GenAI Prompt API à une base de code Android.
- **mlkit-agent-api** : Construit des flux d'agent sur l'appareil avec la ML Kit GenAI Agent API.
- **restore-credentials** : Implémente Restore Credentials avec la bibliothèque Credential Manager.
- **verified-email** : Implémente la récupération d'e-mail vérifié via Credential Manager.
- **android-for-cars-parked-apps** : Adapte des apps de vidéo, de jeu et de navigateur pour qu'elles tournent comme apps en stationnement sur Android Auto.
