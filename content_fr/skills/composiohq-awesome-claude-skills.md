Ce dépôt regroupe les skills suivants :

- **Connect**: Permet à Claude d'agir pour de vrai sur plus de 1 000 apps, e-mail et Slack compris.
- **MCP Builder**: Guide la création d'un serveur Model Context Protocol pour une API externe.
- **Changelog Generator**: Construit automatiquement un changelog pour les utilisateurs, à partir de l'historique des commits git.
- **Brand Guidelines**: Applique l'identité officielle d'Anthropic aux artifacts générés.
- **Skill Creator**: Donne des indications pour écrire de nouveaux Claude Skills efficaces.
- **File Organizer**: Classe les fichiers par contexte et signale les doublons.
- **Content Research Writer**: Documente un sujet et rédige des sections de contenu citées et relues.
- **Image Enhancer**: Améliore la résolution et la netteté d'une image.
- **GitHub Automation**: Automatise les issues GitHub, les pull requests et les flux de travail.
- **Slack Automation**: Automatise les messages Slack et la gestion des canaux.
