Ce dépôt réunit les skills suivants :

- **interview-me** : Fait émerger les exigences par des questions ciblées.
- **spec-driven-development** : Écrit un PRD avant d'écrire le moindre code.
- **constraint-driven-development** : Pose et impose les standards de qualité d'un projet.
- **planning-and-task-breakdown** : Découpe une spécification en tâches que l'on peut vérifier une par une.
- **incremental-implementation** : Livre le travail en tranches verticales fines et testées.
- **test-driven-development** : Applique le cycle red-green-refactor.
- **context-engineering** : Décide quelle information arrive à l'agent, et quand.
- **doubt-driven-development** : Fait une passe de revue de code en mode adversaire.
- **frontend-ui-engineering** : Guide les choix de design des composants et de l'interface.
- **api-and-interface-design** : Applique un design contrat d'abord aux API et aux interfaces.
- **browser-testing-with-devtools** : Utilise Chrome DevTools pour inspecter une app pendant l'exécution.
- **code-review-and-quality** : Relit le code selon cinq contrôles de qualité distincts.
- **security-and-hardening** : Contrôle le code par rapport à l'OWASP Top 10.
- **git-workflow-and-versioning** : Impose un flux git trunk-based.
- **shipping-and-launch** : Lance un déploiement par étapes au moment de publier un changement.
