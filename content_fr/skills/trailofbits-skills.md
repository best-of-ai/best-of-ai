Ce dépôt regroupe les skills suivants :

- **building-secure-contracts** : Boîte à outils de sécurité des smart contracts, avec des scanners de vulnérabilités.
- **c-review** : Revue de sécurité du code C et C++.
- **differential-review** : Revue de code différentielle, centrée sur la sécurité.
- **rust-review** : Revue de sécurité Rust, sur la sûreté mémoire et la concurrence.
- **semgrep-rule-creator** : Rédaction de règles sur mesure pour détecter des vulnérabilités.
- **property-based-testing** : Écriture et revue de tests fondés sur des propriétés.
- **supply-chain-risk-auditor** : Analyse des vulnérabilités de dépendances et des éditeurs.
