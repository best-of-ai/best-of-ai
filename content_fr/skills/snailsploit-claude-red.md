Ce dépôt regroupe les skills suivants :

- **offensive-active-directory** : Couvre la reconnaissance Active Directory et la méthode d'attaque pour des missions red team internes.
- **offensive-netexec** : Couvre l'usage de NetExec pour l'énumération réseau et la post-exploitation.
- **offensive-api-security** : Méthode pour tester des API REST, gRPC et WebSocket.
- **offensive-api-abuse** : Couvre l'abus de logique métier et des schémas d'attaque d'API plus avancés.
- **offensive-jwt** : Couvre les attaques JWT, comme la confusion d'algorithme et les secrets HMAC faibles.
- **offensive-cicd-pipeline** : Couvre les faiblesses des pipelines CI/CD, dont l'injection dans GitHub Actions.
