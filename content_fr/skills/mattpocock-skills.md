Ce dépôt regroupe les skills suivants :

- **grill-with-docs** : Mène une session de planification qui construit un modèle de domaine et met à jour la doc du projet.
- **triage** : Fait avancer les issues dans un workflow défini, en machine à états.
- **improve-codebase-architecture** : Parcourt une base de code et signale où son architecture pourrait être approfondie.
- **to-spec** : Transforme une conversation en spécification écrite, pour un suivi d'issues.
- **to-tickets** : Découpe un plan en petits tickets ordonnés, avec les dépendances notées.
- **implement** : Construit une fonctionnalité à partir d'une spec, en développement piloté par les tests.
- **wayfinder** : Planifie un gros travail comme un ensemble de tickets de décision liés.
- **prototype** : Construit un prototype jetable pour répondre à une question de design.
- **diagnosing-bugs** : Lance une boucle structurée pour retrouver les bugs difficiles.
- **research** : Examine une question à partir de sources primaires.
- **domain-modeling** : Construit et affine le modèle de domaine d'un projet.
- **code-review** : Relit le code au regard des standards de code et de la spec d'origine.
