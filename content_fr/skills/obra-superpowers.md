Ce dépôt regroupe les skills suivants :

- **test-driven-development** : Applique le cycle red-green-refactor et liste les anti-patterns de test courants.
- **systematic-debugging** : Mène une analyse de cause racine en quatre phases.
- **verification-before-completion** : Confirme qu'un correctif marche vraiment avant de marquer la tâche comme finie.
- **brainstorming** : Affine une idée brute par un questionnement socratique.
- **writing-plans** : Crée un plan d'implémentation découpé en petites tâches.
- **executing-plans** : Exécute un plan par lots, avec des points de contrôle pour une revue humaine.
- **dispatching-parallel-agents** : Coordonne plusieurs sous-agents qui travaillent en même temps.
- **requesting-code-review** : Passe une checklist avant de demander une revue de code.
- **receiving-code-review** : Traite les retours d'une revue de code et y répond.
- **using-git-worktrees** : Gère du travail en parallèle sur plusieurs git worktrees.
- **finishing-a-development-branch** : Décide comment clore une branche, par merge ou par pull request.
- **subagent-driven-development** : Lance une revue en deux temps : conformité à la spec, puis qualité.
- **writing-skills** : Un méta-skill, avec un cadre pour écrire de nouveaux skills.
