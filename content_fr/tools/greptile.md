Greptile est un relecteur de code par IA centré sur le contexte du code source. Au lieu de lire seulement le diff, il construit une compréhension de tout le dépôt, y compris comment les fonctions et les modules se relient, pour que les commentaires puissent pointer des impacts dans des fichiers que la pull request n'a pas touchés.

Il poste des commentaires de revue et des résumés sur les pull requests GitHub et GitLab. Les équipes peuvent fixer des règles en langage clair, et le système apprend des pouces levés et baissés sur ses commentaires pour réduire le bruit. Une API permet aux développeurs de poser des questions sur le code source.

Greptile est payant, au prix par développeur, avec un essai. Une revue automatisée peut rater des problèmes de conception et produit parfois de fausses alertes, donc la revue humaine reste importante. Les alternatives incluent CodeRabbit, Graphite, la revue de code de GitHub Copilot, Qodo et Sourcery. Greptile convient aux équipes avec de grandes bases de code qui veulent plus de contexte dans les revues.
