Qodo a commencé sous le nom CodiumAI, centré sur les tests, puis s'est élargi à la qualité sur tout le développement. Dans l'IDE, il analyse une fonction, comprend son comportement et génère des tests unitaires qui couvrent les cas normaux, les cas limites et les modes d'échec, ce qui aide à monter la couverture sans tout écrire à la main. Il propose aussi un chat et des suggestions de code qui tiennent compte du contexte du projet.

Le volet revue est une part importante. Qodo Merge, construit sur un outil open source appelé PR-Agent, commente les pull requests avec des résumés, des bugs potentiels, des problèmes de sécurité et des correctifs suggérés, et peut apprendre les standards d'une équipe pour que les revues reflètent les règles internes. Des systèmes de revue multi-agents et un moteur de contexte visent à comprendre de grandes bases de code, ce qui compte pour les équipes d'entreprise avec beaucoup de dépôts. Les intégrations couvrent GitHub, GitLab, Bitbucket et les principaux IDE.

Qodo a une offre gratuite pour les particuliers et l'open source, et des offres payantes pour les équipes et les entreprises, avec une option de déploiement sur site. Les tests générés et les commentaires de revue demandent du jugement, parce que certains tests ne font que confirmer le comportement actuel, bugs compris. Les concurrents incluent CodeRabbit, Greptile, la revue de GitHub Copilot, Bito et Sourcery pour les revues, et Diffblue pour les tests unitaires Java. Qodo convient aux équipes qui veulent améliorer la qualité du code à mesure que le code généré par IA augmente.
