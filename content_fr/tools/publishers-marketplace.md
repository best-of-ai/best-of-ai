Les agents littéraires s'en servent pour voir quels éditeurs achètent quels types de livres, et pour publier leurs propres deals. Les auteurs l'utilisent pour chercher des agents. Une newsletter quotidienne liste les nouveaux deals de livres.

Les données sont surtout déclarées par les membres, donc ce n'est pas un inventaire complet.

Query Tracker aide les auteurs à suivre leurs envois. Publishers Marketplace convient aux agents littéraires.
