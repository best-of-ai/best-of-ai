Kimi Code est un agent en ligne de commande, de la même famille que Claude Code et Codex CLI. Tu le lances dans un dossier de projet, tu décris une tâche, et il lit les fichiers, modifie le code, lance des commandes et vérifie les résultats, en décidant de la suite selon ce qui se passe. Des permissions te laissent approuver les actions risquées.

Par défaut, il utilise les modèles Kimi de Moonshot AI, connus pour la programmation et le long contexte, et il peut aussi se connecter à d'autres fournisseurs compatibles. Les fonctions incluent des sous-agents intégrés pour coder, explorer et planifier, la prise en charge du Model Context Protocol pour connecter des outils, des hooks de cycle de vie pour l'automatisation et les contrôles de sécurité, et un mode ACP pour que des éditeurs comme Zed et JetBrains le pilotent.

L'outil est open source sous licence MIT. L'accès aux modèles demande un compte ou une clé API, et les offres ont des limites. Plusieurs projets non officiels portent le même nom, donc utilise le dépôt officiel de Moonshot AI. Les alternatives incluent Claude Code, OpenAI Codex CLI, Gemini CLI, OpenCode et Aider. Kimi Code convient aux développeurs qui veulent un agent de terminal construit autour des modèles Kimi.
