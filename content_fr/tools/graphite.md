Graphite est construit autour d'un flux où les gros changements sont découpés en petites pull requests dépendantes. Cette approche empilée, courante dans les grandes entreprises tech, permet aux ingénieurs de continuer sur le morceau suivant sans attendre que le précédent soit relu et mergé. Graphite fournit un outil en ligne de commande et une interface web qui rendent la gestion des piles simple, ce que GitHub seul gère maladroitement.

Il ajoute des fonctions autour de la revue. Une file de merge garde la branche principale saine en testant et en mergeant les changements dans l'ordre, une boîte de réception aide les relecteurs à voir ce qui demande de l'attention, et des insights montrent combien de temps les revues prennent. Un relecteur IA commente les pull requests pour attraper des bugs et des problèmes de style, ce qui compte alors que plus de code est écrit par des assistants d'IA.

Cursor a racheté Graphite pour rapprocher la revue de l'éditeur, et le produit continue de marcher avec les dépôts GitHub. Il a une offre gratuite pour les particuliers et des offres payantes pour les équipes. Adopter les pull requests empilées change les habitudes, donc les équipes ont besoin d'adhésion. Les alternatives incluent les outils natifs de GitHub, CodeRabbit, Greptile, Reviewable, et les flux de style Phabricator. Graphite convient aux équipes qui veulent une revue de code plus rapide et plus propre.
