Kilo Code fonctionne comme extension pour VS Code et JetBrains, comme outil en ligne de commande et comme app de bureau. Il propose des agents pour coder, planifier, poser des questions et déboguer, et tu peux définir les tiens. Les agents peuvent confier du travail à des sous-agents et tourner en parallèle, et les agents cloud peuvent continuer à travailler depuis le navigateur, Slack ou une app mobile. Le code est sous licence MIT, et l'outil en ligne de commande est un fork d'OpenCode.

Tu choisis comment payer les modèles. La Kilo Gateway route vers plus de 500 modèles et répercute les prix des fournisseurs sans majoration, tu peux apporter tes propres clés, ou faire tourner des modèles locaux avec Ollama ou LM Studio. Un Code Reviewer vérifie automatiquement les pull requests, et une marketplace référence des agents, des skills et des serveurs MCP.

L'extension est gratuite. Les offres Teams coûtent 15 dollars par utilisateur et par mois, et le calcul cloud est facturé à l'heure en plus de l'usage des modèles. Anaconda a annoncé en juillet 2026 avoir racheté Kilo Code, sans en révéler les conditions. Les agents peuvent modifier beaucoup de fichiers à la fois : relis les diffs avant de les accepter. Parmi les alternatives, il y a Cline, OpenCode, Claude Code et Cursor. Kilo Code convient aux développeurs qui veulent un agent open source compatible avec n'importe quel modèle.
