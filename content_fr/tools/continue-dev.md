Continue est construit autour du choix et du contrôle. Au lieu de verrouiller les utilisateurs chez un seul fournisseur, il laisse brancher le modèle préféré, des API cloud aux modèles qui tournent en local avec Ollama, et régler son comportement avec des règles, des prompts et du contexte tiré du code et de la documentation.

L'extension propose l'autocomplétion, un chat qui peut citer des fichiers et des docs, et un mode d'édition qui réécrit le code sélectionné. Les équipes peuvent partager des configurations et utiliser le hub de Continue pour partager des assistants. Le projet s'est étendu à des contrôles automatiques qui tournent sur les pull requests. Comme le code est ouvert, les entreprises peuvent l'auditer et l'adapter.

Continue est gratuit et open source, avec des options payantes pour les équipes. La mise en place est plus lourde que pour les produits commerciaux, et la qualité dépend des modèles choisis. Les alternatives incluent GitHub Copilot, Cursor, Cline, Roo Code et Sourcegraph Cody. Continue convient aux développeurs qui veulent un assistant ouvert et personnalisable.
