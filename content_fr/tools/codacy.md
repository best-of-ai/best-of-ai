Codacy se connecte aux dépôts sur GitHub, GitLab et Bitbucket et analyse le code à mesure qu'il change. Il lance de l'analyse statique sur de nombreux langages, cherche les problèmes de style, les bugs, les questions de sécurité et la complexité, et publie les résultats en commentaires sur les pull requests. Les équipes peuvent fixer des quality gates qui bloquent les fusions quand le code ne respecte pas les standards convenus.

Des tableaux de bord montrent les tendances dans le temps, dont la couverture de code, la duplication et le nombre de problèmes par dépôt, ce qui aide les responsables d'ingénierie à voir si la qualité s'améliore. Des fonctions de sécurité scannent les dépendances et les secrets, et des fonctions d'IA récentes suggèrent des corrections et aident à relire le code produit par des assistants d'IA. Il s'intègre aux systèmes de CI et aux IDE.

Codacy a une offre gratuite pour l'open source et les petites équipes, et des offres payantes par développeur. Comme toute analyse statique, il produit des faux positifs et a besoin de règles réglées pour l'équipe. Parmi les alternatives : SonarQube, Code Climate, DeepSource, Snyk Code et le scan de code intégré de GitHub. Codacy convient aux équipes qui veulent des contrôles de qualité automatiques dans leur flux de pull requests.
