Codiga proposait une analyse de code en temps réel dans l'éditeur. Ses plugins pour VS Code, les IDE JetBrains et d'autres outils scannaient le code pendant la frappe pour les vulnérabilités de sécurité, les bugs et les écarts aux standards de code, et un moteur de règles permettait aux équipes d'écrire leurs propres contrôles. Il fournissait aussi un assistant d'extraits de code et, plus tard, des suggestions basées sur l'IA, et s'intégrait aux plateformes Git pour relire les pull requests automatiquement.

L'entreprise a été rachetée par Datadog, qui voulait amener l'analyse de code dans sa plateforme d'observabilité et de sécurité. Les produits autonomes de Codiga ont été fermés peu après, avec des remboursements pour les abonnés payants, et l'équipe a rejoint Datadog. Le moteur d'analyse statique et ses règles portent maintenant Datadog Code Security, et l'analyseur est disponible en open source.

Pour des outils proches, SonarQube, Semgrep, Snyk Code et CodeQL fournissent de l'analyse statique, tandis que des outils de revue par IA comme CodeRabbit et Qodo gèrent les pull requests. Les équipes qui utilisent Datadog peuvent se servir de ses fonctions de sécurité du code intégrées.
