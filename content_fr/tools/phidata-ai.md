Phidata a commencé comme un framework Python pour transformer des modèles de langage en agents. Les développeurs définissent un agent avec des instructions, des outils, une mémoire et une base de connaissances, et le framework s'occupe de l'exécuter, de stocker l'historique et de retrouver des documents. Il prend aussi en charge des équipes d'agents qui travaillent ensemble.

Le projet a été renommé Agno, et la même équipe et la même base de code continuent sous le nouveau nom : la documentation et les paquets parlent désormais d'Agno. Les versions récentes mettent l'accent sur la vitesse, une conception légère et des fonctions de production, comme un runtime pour servir les agents.

Le framework est gratuit et open source. Consulte la documentation actuelle d'Agno pour l'installation et la licence, car les détails ont changé avec le renommage. Parmi les alternatives : LangGraph, CrewAI, Mastra, l'Agents SDK d'OpenAI et Haystack. Cette fiche couvre l'ancien nom. Phidata convient aux développeurs qui cherchent l'ancien projet et qui voudront la doc actuelle d'Agno.
