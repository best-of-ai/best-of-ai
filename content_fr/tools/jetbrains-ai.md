JetBrains AI Assistant travaille dans les IDE que beaucoup de développeurs professionnels utilisent déjà. Dans IntelliJ IDEA, PyCharm, WebStorm, GoLand, Rider et le reste de la famille, il fournit une complétion en ligne, un panneau de chat qui comprend le projet, et des actions pour expliquer le code, générer des tests, écrire des messages de commit et suggérer des correctifs d'erreurs. Comme il est intégré à l'IDE, il peut utiliser la connaissance profonde que l'IDE a de la structure du code, comme les types, les références et les configurations d'exécution.

Junie est l'agent de code de JetBrains, qui peut prendre une tâche, planifier le travail, modifier des fichiers, lancer des tests et itérer. L'assistant permet de choisir parmi des modèles de fournisseurs comme OpenAI, Anthropic et Google, et prend en charge des modèles locaux pour ceux qui ont besoin que les données restent sur leur machine. JetBrains développe aussi son propre modèle de complétion de code pour des suggestions rapides, et s'intègre à d'autres agents via ses protocoles.

AI Assistant se vend comme un module d'abonnement aux IDE JetBrains, par paliers, avec une offre gratuite à usage limité et des paliers payants qui relèvent les quotas. Il marche le mieux pour les développeurs qui préfèrent les IDE JetBrains à VS Code. GitHub Copilot tourne aussi dans les IDE JetBrains, Cursor et Windsurf sont des éditeurs IA séparés, et Claude Code et d'autres agents peuvent travailler à côté de l'IDE. Les développeurs doivent vérifier comment le code est envoyé aux fournisseurs de modèles, selon la politique de l'organisation.
