Cline est un assistant de code autonome qui vit dans ton éditeur. Tu décris une tâche, et il la mène : lecture des fichiers pertinents, propositions de modifications, commandes lancées, et vérification du résultat. Il a un mode Plan, où il explore le projet et convient d'une approche avec toi, et un mode Act, où il exécute le plan. Chaque changement de fichier et chaque commande de terminal s'affiche pour ton accord, donc tu gardes la main, même si tu peux activer l'approbation automatique pour les actions à moindre risque.

Il peut faire bien plus que modifier du texte. Avec un outil navigateur, il peut lancer l'app qu'il construit, cliquer dedans et regarder des captures pour trouver des problèmes. Il prend en charge le Model Context Protocol, donc tu peux ajouter des outils comme l'accès à une base de données ou des API sur mesure. Des checkpoints permettent de revenir à un état antérieur du projet si une exécution tourne mal. Cline est aussi disponible comme outil en ligne de commande et comme SDK.

L'extension est gratuite et open source sous licence Apache 2.0, et tu apportes ton propre modèle. Elle fonctionne avec Anthropic, OpenAI, Google, AWS Bedrock, OpenRouter, et des modèles locaux via Ollama ou LM Studio. Tu paies le fournisseur pour les tokens, et les sessions agentiques peuvent en utiliser beaucoup, donc les coûts varient. Roo Code et Kilo Code sont des forks qui s'appuient sur la même idée. Cursor et Claude Code sont les alternatives commerciales les plus proches.
