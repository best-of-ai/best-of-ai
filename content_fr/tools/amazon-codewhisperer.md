CodeWhisperer a été le premier assistant de code d'Amazon, un pendant de GitHub Copilot qui suggérait des lignes et des fonctions entières au fil de la frappe, dans des éditeurs comme VS Code et les IDE JetBrains. Il était entraîné avec un accent particulier sur les API AWS, donc il était particulièrement bon sur du code qui appelait S3, Lambda, DynamoDB et d'autres services AWS. Il prenait aussi en charge beaucoup de langages courants.

Deux fonctions le distinguaient des premiers rivaux. Un suivi de références signalait les suggestions qui ressemblaient à du code open source et montrait la licence, et un scan de sécurité vérifiait le code pour des vulnérabilités comme des identifiants exposés et des failles d'injection. Un palier individuel était gratuit, et un palier professionnel ajoutait des contrôles d'admin et des limites plus hautes.

AWS a depuis fusionné CodeWhisperer dans Amazon Q Developer, un assistant plus large qui ajoute le chat, des agents qui mènent des tâches en plusieurs étapes, la transformation de code, et de l'aide dans la console AWS. Si tu cherches le produit aujourd'hui, Q Developer est celui à évaluer, et le nom d'origine survit surtout dans d'anciennes docs et des billets de blog. Les alternatives incluent GitHub Copilot, Cursor et JetBrains AI Assistant.
