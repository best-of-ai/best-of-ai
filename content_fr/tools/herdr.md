Herdr gère le tas croissant de sessions d'agents que les développeurs lancent. Au lieu de beaucoup de fenêtres de terminal, il présente les agents dans une interface à onglets et montre si chacun travaille, a fini, ou attend une saisie, quand l'agent rapporte un statut. Il prend en charge tout agent qui tourne dans un terminal.

Le choix de conception clé est le runtime herdr-core, un petit serveur sur ta machine qui fait tourner les sessions. L'app n'est qu'un front-end, donc la quitter ou la mettre à jour n'arrête pas les agents. Une version terminal de Herdr, l'originale, existe encore comme programme séparé avec son propre serveur.

Herdr est gratuit et open source sous licence Apache 2.0, et tourne sur macOS, Linux et Windows. L'app de bureau est nouvelle, donc attends-toi à des changements. Si la machine redémarre ou si le core s'arrête, les programmes en cours se terminent. Les alternatives incluent tmux, Zellij, Warp, Conductor, et les multiplexeurs de terminal intégrés aux outils d'agent. Herdr convient aux développeurs qui font tourner beaucoup d'agents de code à la fois.
