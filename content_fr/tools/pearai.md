PearAI est un éditeur autonome forké de VS Code, avec des fonctions d'IA intégrées. Les développeurs ont la complétion de code, un panneau de chat qui comprend le projet, et l'édition en ligne, et peuvent connecter leurs modèles préférés. Comme c'est un fork, les extensions et les réglages familiers suivent.

Il se positionne comme une alternative ouverte à Cursor et Windsurf. La couche d'IA s'appuie sur Continue, un assistant open source. Le projet a eu tôt une controverse de licence sur son usage de code existant, qu'il a depuis traitée.

PearAI propose un usage gratuit avec un abonnement payant optionnel pour des modèles hébergés. Les forks de VS Code ont un travail de maintenance pour suivre l'amont, et le projet est plus petit que ses rivaux. Parmi les alternatives : Cursor, Windsurf, Cline, Continue et Void. PearAI convient aux développeurs qui veulent un éditeur d'IA open source.
