Refact.ai donne aux développeurs un assistant qu'ils peuvent contrôler. Il propose l'autocomplétion, un chat qui comprend la base de code, et un agent qui peut mener des tâches comme corriger des bugs, lancer des tests et refactorer. Il se branche sur les éditeurs courants.

La confidentialité est un avantage clé : les entreprises peuvent le faire tourner sur leurs propres serveurs avec des modèles ouverts, pour que le code ne quitte pas leur environnement, ou utiliser des modèles cloud. Le fine-tuning sur une base de code est disponible dans certaines configurations.

Refact.ai est open source, avec des fonctions entreprise payantes et des offres hébergées. L'auto-hébergement demande des GPU et de la maintenance. Parmi les alternatives : Continue, Tabnine, Cline, GitHub Copilot et Sourcegraph Cody. Refact.ai convient aux équipes qui veulent un assistant de code auto-hébergeable.
