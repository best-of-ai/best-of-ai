GitLens enrichit VS Code avec l'historique Git. Il affiche des annotations de blame en ligne qui disent qui a changé une ligne en dernier, quand, et dans quel commit, et il permet de parcourir l'historique d'un fichier, d'une ligne ou d'une branche sans quitter l'éditeur. Les fonctions incluent un graphe de commits, des comparaisons entre branches, et un Launchpad qui rassemble pull requests et issues. C'est l'une des extensions les plus téléchargées pour VS Code.

Les fonctions d'IA aident pour les corvées Git courantes. GitLens peut écrire des messages de commit à partir des changements stagés, résumer en langage clair ce qu'un commit ou une branche a modifié, et aider à rédiger des descriptions de pull request, ce qui fait gagner du temps sur la documentation. Il prend en charge plusieurs fournisseurs et modèles d'IA, avec des options sur la façon dont les données sont envoyées.

GitLens a une offre gratuite avec beaucoup de fonctions, et des offres payantes pour des capacités avancées comme Launchpad et les espaces de travail, dans l'écosystème GitKraken. Les résumés d'IA doivent être vérifiés contre le diff réel. Les alternatives incluent les fonctions Git intégrées à VS Code, la génération de messages de commit de GitHub Copilot, GitKraken Client, Sourcetree, et Lazygit pour le terminal. GitLens convient aux développeurs qui travaillent dans VS Code et veulent mieux voir l'historique de leur code.
