Poolside se concentre sur un seul domaine : le code. L'entreprise entraîne de grands modèles depuis zéro, avec de l'apprentissage par renforcement où le modèle écrit du code, l'exécute et apprend selon qu'il fonctionne ou non. Le but est des modèles qui traitent de vraies tâches logicielles de façon fiable.

Elle vise des clients aux exigences de sécurité strictes, comme la défense et les grandes entreprises, et propose un déploiement dans leurs propres environnements. Les produits comprennent un assistant de code et un agent construits sur ses modèles, et l'entreprise a beaucoup investi dans l'infrastructure de calcul.

Poolside se vend sur des conditions entreprise sur mesure, et moins de choses sont publiques à son sujet que pour les outils grand public. Parmi les alternatives : Claude Code d'Anthropic, OpenAI Codex, GitHub Copilot, Codestral de Mistral et Cursor. Poolside convient aux organisations qui veulent des modèles de code privés.
