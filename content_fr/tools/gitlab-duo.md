GitLab Duo intègre l'IA aux endroits où les développeurs travaillent déjà dans GitLab. Dans l'éditeur, il suggère du code et génère des tests, dans les merge requests il résume les changements et aide à la revue de code, et un assistant de chat répond aux questions sur le code, les issues et GitLab lui-même. Côté DevSecOps, il peut expliquer des vulnérabilités de sécurité et proposer des correctifs, et aider à trouver la cause racine quand un pipeline de CI/CD échoue.

L'entreprise a aussi introduit des capacités d'agent qui peuvent prendre des tâches sur le cycle de vie logiciel, comme la planification, le code et la revue, avec une supervision humaine. Comme il travaille dans GitLab, il a accès au contexte des dépôts, des issues et des pipelines, ce qui manque aux assistants généralistes. Les clients auto-hébergés peuvent l'utiliser avec leur propre déploiement, et les organisations contrôlent quels modèles et quelles fonctions sont disponibles.

GitLab Duo se vend comme un add-on aux offres GitLab payantes, ou est inclus dans les offres supérieures, et le détail change avec le temps. Il est surtout utile aux équipes qui utilisent déjà GitLab comme plateforme centrale. Les alternatives incluent GitHub Copilot pour les utilisateurs de GitHub, Sourcegraph, Amazon Q Developer, et Cursor ou Claude Code pour le travail dans l'éditeur. Comme pour toutes les fonctions de code par IA, relis le code généré et les suggestions de sécurité avec soin.
