Les workflows sont des fichiers YAML qui appellent des actions réutilisables depuis une marketplace. Les runners hébergés tournent sous Linux, Windows et macOS, ou les équipes peuvent faire tourner les leurs. Les secrets et les environnements encadrent les déploiements.

Les dépôts publics l'utilisent gratuitement, et les dépôts privés ont un quota gratuit, puis un usage payant.

GitLab CI et CircleCI sont des alternatives. GitHub Actions convient aux ingénieurs DevOps qui travaillent sur GitHub.
