GitHub Copilot est l'outil de code par IA avec la plus grande base d'utilisateurs, et il est intégré à l'endroit où la plupart du code vit déjà. Il a commencé comme autocomplétion en ligne, qui termine des lignes et des fonctions d'après le fichier ouvert, et il le fait toujours dans VS Code, Visual Studio, les IDE JetBrains, Neovim et Xcode. Un panneau de chat explique le code, écrit des tests, corrige des erreurs et répond aux questions sur le projet sans quitter l'éditeur.

Les parties plus récentes sont agentiques. Le mode agent dans l'éditeur planifie une tâche, édite plusieurs fichiers, lance des commandes dans le terminal et itère sur les échecs. L'agent de code Copilot travaille directement sur GitHub : tu lui assignes une issue, il travaille en arrière-plan et ouvre une pull request à relire. Copilot peut aussi relire des pull requests, aider en ligne de commande, et utiliser des modèles de plusieurs fournisseurs, que tu choisis dans un sélecteur. Les équipes peuvent ajouter des instructions personnalisées pour qu'il suive leurs conventions.

Il y a une offre gratuite à usage limité, des offres individuelles payantes, et des offres business et entreprise avec contrôles d'admin, réglages de politique, et des options pour exclure le code de l'entraînement des modèles. Les requêtes premium vers les modèles les plus forts peuvent être mesurées, donc un usage intensif peut toucher des limites. Comme il vit dans les outils que les développeurs utilisent déjà, l'adoption est simple. Cursor, Windsurf et Claude Code offrent des expériences plus centrées sur l'agent, alors que la force de Copilot est l'étendue, l'intégration à GitHub et le support entreprise.
