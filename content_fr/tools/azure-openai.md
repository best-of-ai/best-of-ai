Azure OpenAI est la gamme de modèles d'OpenAI livrée via le cloud de Microsoft. Les entreprises s'en servent pour obtenir les mêmes familles de modèles de langage, de raisonnement, d'image et d'audio, mais sous les conditions, la facturation et les contrôles de sécurité d'Azure. Pour les secteurs réglementés et les grandes entreprises, ça compte : les données sont traitées dans Azure, peuvent être isolées sur un réseau privé, et sont couvertes par les certifications de conformité et l'accord de niveau de service de Microsoft.

Le développement se fait dans Microsoft Foundry, où tu déploies un modèle, le testes dans un playground et le relies à tes propres données et outils. Les fonctions disponibles comprennent le fine-tuning, le filtrage de contenu, l'appel d'outils et de fonctions, la recherche sur les documents de l'entreprise, et le tracing. Les déploiements existent en plusieurs types, comme le paiement à l'usage standard, le traitement par lots, et le débit provisionné, qui réserve de la capacité pour des charges stables avec une latence prévisible. Foundry propose aussi des modèles hors OpenAI, pour que les équipes comparent les options au même endroit.

Les nouveaux modèles OpenAI arrivent parfois sur Azure un peu plus tard que sur l'API d'OpenAI, et l'accès aux plus récents peut demander une demande. Le tarif suit le modèle à base de tokens d'OpenAI, avec la facturation Azure, et les remises d'entreprise sont courantes. C'est surtout pour les entreprises déjà standardisées sur Microsoft, ses principales alternatives étant AWS Bedrock et Google Vertex AI. Les particuliers et les petits projets trouvent en général l'API d'OpenAI plus simple.
