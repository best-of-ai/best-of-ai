Amazon Q Developer est le successeur de CodeWhisperer, et il est bâti autour de la connaissance AWS. Dans VS Code, JetBrains et d'autres IDE, il offre des suggestions de code en ligne et un panneau de chat qui explique le code, écrit des tests et optimise des fonctions. Dans le terminal, il ajoute l'autocomplétion et un chat qui peut traduire du langage clair en commandes shell. Dans la console AWS et sur des plateformes de chat comme Slack, il aide à dépanner des services et explique pourquoi une ressource se comporte mal.

Ses fonctions agentiques prennent des travaux plus grands. Un agent peut lire ton projet, planifier le travail, éditer plusieurs fichiers et lancer des commandes pour finir une fonction, écrire de la documentation ou relire du code. Des agents de transformation spécialisés montent des versions de Java et portent des applications .NET pour tourner sous Linux, un travail fastidieux sur de grandes bases. Un scan intégré trouve des problèmes de sécurité dans le code et suggère des correctifs.

Une offre gratuite donne un usage mensuel limité, et une offre Pro payante monte les limites et ajoute des contrôles d'admin, dont une promesse que ton contenu n'est pas utilisé pour améliorer le service. AWS a déplacé une partie de son travail agentique plus récent vers Kiro, son propre IDE pensé d'abord pour l'IA, donc les plugins Q Developer se voient mieux comme l'une de plusieurs options AWS. Ça a le plus de sens pour les équipes qui vivent sur AWS, tandis que GitHub Copilot et Cursor sont des rivaux généralistes plus larges.
