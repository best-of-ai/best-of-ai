Super-Agent explore à quoi pourrait ressembler un agent de code tourné vers une équipe. Construit sur le runtime Harness de DeepSeek, il est lié à un seul dépôt GitHub et écoute les demandes de collègues approuvés dans Feishu, une app de chat de travail. Un coéquipier peut lui demander d'enquêter ou de changer quelque chose, et il travaille sur le code puis rend compte.

Le prototype montre comment un labo pense les agents dans les outils de collaboration du quotidien, plutôt que seulement dans le terminal d'un développeur. Comme c'est un prototype, il se concentre sur la démonstration du design, pas sur un produit soigné avec de larges intégrations, et il demande une mise en place technique.

Le code est open source et gratuit, et les coûts viennent des modèles et de l'infrastructure que tu connectes. Comme projet précoce, attends-toi à des aspérités, des interfaces qui changent et une documentation limitée, et relis les changements de tout agent avant de fusionner. Les alternatives incluent Claude Code avec des intégrations GitHub, OpenAI Codex cloud, Devin, Factory et les agents en arrière-plan de Cursor. DeepSeek Super-Agent convient aux développeurs curieux des designs d'agents pour les équipes.
