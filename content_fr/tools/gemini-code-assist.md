Gemini Code Assist amène les modèles de Google dans l'éditeur du développeur. Dans VS Code et les IDE JetBrains, il suggère du code pendant que tu tapes, répond à des questions en chat, explique et refactorise le code, génère des tests, et aide à corriger des erreurs. Il peut prendre une tâche plus large et faire des changements coordonnés sur plusieurs fichiers en mode agent. Google propose aussi une version en ligne de commande, Gemini CLI, que beaucoup de développeurs utilisent directement dans le terminal.

Pour les organisations, les éditions entreprise ajoutent la personnalisation du code, qui permet à l'assistant de tenir compte des dépôts privés d'une entreprise pour que ses suggestions suivent les bibliothèques et styles internes, ainsi que des fonctions de sécurité et de conformité, une indemnisation, et des contrôles d'administration. Il fonctionne avec des outils Google Cloud comme Cloud Shell, Firebase et BigQuery, et il peut revoir des pull requests sur GitHub via une app compagnon.

Le palier individuel est gratuit avec des limites généreuses, ce qui le rend facile à essayer, et les offres entreprise sont facturées par utilisateur. Google change souvent les noms de ses produits d'IA, donc les détails peuvent bouger entre Gemini Code Assist, Gemini CLI, Jules et les produits liés. La qualité est compétitive avec les assistants de tête, et sa très grande fenêtre de contexte est un atout sur les grosses bases de code. GitHub Copilot, Cursor, Claude Code et Amazon Q Developer sont les principales alternatives.
