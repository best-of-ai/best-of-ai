Cody est né de la recherche de code de Sourcegraph, qui indexe des dépôts entiers et permet de trouver et de comprendre du code à travers de nombreux projets. Ce contexte était son principal avantage : au lieu de deviner à partir du fichier ouvert, Cody pouvait s'appuyer sur l'ensemble de la base pour répondre à des questions, écrire du code aligné sur les habitudes existantes et expliquer comment les parties d'un système s'emboîtent. Il fonctionnait dans VS Code, les IDE JetBrains et le web, avec le chat, l'autocomplétion et des commandes pour modifier et tester le code.

Le produit a changé. Sourcegraph a arrêté les offres Free et Pro de Cody pour les particuliers, et a aussi retiré Cody de l'offre Enterprise Starter. Cody Enterprise reste disponible pour les grandes organisations qui utilisent la plateforme Sourcegraph, là où la connaissance de la base de code est la plus utile. Pour la programmation plus récente, de type agent, Sourcegraph a lancé Amp, un outil séparé pensé pour des flux de travail agentiques.

Si tu compares des outils aujourd'hui, Cody a surtout du sens pour les entreprises qui font déjà tourner Sourcegraph et qui ont besoin d'intelligence sur de très grandes bases, réparties sur plusieurs dépôts, avec la possibilité d'utiliser des modèles de plusieurs fournisseurs. Les déploiements pour les entreprises peuvent tourner dans l'environnement du client. Les développeurs individuels devraient regarder GitHub Copilot, Cursor, Claude Code ou Amp. Les anciens avis qui parlent d'une offre Cody gratuite décrivent quelque chose qui n'existe plus.
