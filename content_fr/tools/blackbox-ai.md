Blackbox AI a été construit pour les programmeurs. Il propose la complétion de code, une interface de chat pour les questions de programmation, la recherche de code, et la possibilité de transformer une capture d'écran ou une image en code. Une extension VS Code et une app web l'ont rendu facile à essayer, et l'offre gratuite l'a aidé à toucher un grand nombre de développeurs. On lui demande d'expliquer du code inconnu, de convertir du code entre langages, d'écrire des fonctions et de corriger des erreurs.

L'entreprise a étendu son offre au-delà de l'assistant. Elle fournit maintenant un endpoint vers un large catalogue de modèles de nombreux fournisseurs, plus des fonctions comme l'accès chiffré, la rétention nulle des données pour les entreprises, des clés d'API à périmètre limité, des plafonds de dépense, la location de GPU et un support d'ingénierie pour les déploiements sur mesure. Des fonctions de programmation de type agent et des intégrations navigateur ou éditeur étendent ce que l'assistant peut faire.

Blackbox a une offre gratuite et des abonnements payants, avec des contrats entreprise via la vente. C'est l'un des nombreux assistants dans un domaine saturé, et des développeurs ont soulevé sur des forums des inquiétudes sur les pratiques de facturation et la qualité de son code par rapport aux leaders. Il faut vérifier les conditions de confidentialité avant de l'utiliser sur du code propriétaire. GitHub Copilot, Cursor, Windsurf et Claude Code sont des choix plus établis, et Cline propose une expérience d'agent open source.
