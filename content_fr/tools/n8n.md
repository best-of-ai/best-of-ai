n8n permet de construire des automatisations en reliant des nœuds sur une toile, un peu comme Zapier ou Make, mais avec plus de place pour le code. Chaque nœud est une étape : un déclencheur comme un webhook ou une planification, une action dans une app, ou un bloc qui transforme des données en JavaScript ou en Python. Des centaines d'intégrations sont incluses, et un nœud HTTP générique couvre le reste. Les flux peuvent se brancher, boucler et appeler d'autres flux, donc ça va des notifications simples aux pipelines de données élaborés.

L'IA est maintenant une grande partie du produit. n8n inclut des nœuds pour les modèles de langage, les outils, la mémoire et les bases vectorielles, pour que tu puisses construire des agents qui lisent les e-mails, cherchent dans des documents, appellent des API et décident de la suite. Tu peux voir chaque exécution étape par étape, ajouter une approbation humaine avant les actions sensibles, et changer de fournisseur de modèle. Ça en fait une façon courante de prototyper et d'exploiter des agents d'IA sans écrire une application complète.

Le code est disponible sur GitHub sous une licence fair-code, et tu peux le faire tourner toi-même sur un serveur ou dans Docker, ce qui garde les données dans ton environnement. n8n Cloud est l'option hébergée, avec des offres qui montent selon les exécutions, et des offres entreprise qui ajoutent l'authentification unique, les contrôles d'accès et les journaux d'audit. L'auto-hébergement coûte peu mais c'est à toi de gérer les mises à jour, la sécurité et la disponibilité. Zapier est plus simple pour les non-techniques, et Make est le rival visuel le plus proche.
