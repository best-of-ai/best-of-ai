Aide était un éditeur de code pensé d'abord pour l'IA, de la startup londonienne CodeStory. C'était un fork de VS Code, donc il était familier et pouvait utiliser des extensions, mais il ajoutait une couche d'IA qui comprenait le projet. Tu pouvais discuter de la base de code, demander des changements sur plusieurs fichiers, et obtenir des complétions informées par un contexte plus large. Il a été publié en open source sous licence AGPL, et le projet a beaucoup intéressé des développeurs qui cherchaient une alternative à Cursor.

CodeStory a aussi fait de la recherche sur le code de type agent, dont du travail sur des tâches de benchmark qui mesurent si un modèle peut corriger de vrais issues dans des dépôts open source. L'éditeur faisait partie de cet effort, et il permettait d'essayer le code agentique sur ses propres projets, avec un choix de modèles.

Le développement s'est arrêté, et l'éditeur n'est plus maintenu. Le code reste disponible sur GitHub pour qui veut le forker, mais les nouveaux utilisateurs sont mieux servis par des outils activement mis à jour. Cursor, Windsurf, Cline et GitHub Copilot sont les alternatives habituelles, et Void était un autre éditeur open source dans la même catégorie. Cette fiche reste pour référence, car d'anciens articles et pages de comparaison mentionnent encore Aide.
