Agent HQ est la façon dont GitHub traite les agents de code comme une équipe à piloter, plutôt que comme un seul assistant. Au lieu de choisir un seul fournisseur d'IA, un développeur peut confier du travail à des agents de différents fournisseurs, comme Codex d'OpenAI et Claude Code d'Anthropic, depuis l'endroit où le code, les issues et les pull requests sont déjà. Chaque agent avance sur sa tâche et renvoie les changements pour relecture, dans le flux habituel de pull request.

Mission Control donne une vue centrale de ce que fait chaque agent, pour voir quelles tâches tournent, lesquelles sont finies et lesquelles demandent de l'attention. Plan Mode laisse un agent proposer ses étapes avant d'écrire du code, pour corriger l'approche tôt. Comme ça marche dans GitHub, en ligne de commande et dans VS Code, les mêmes tâches peuvent être lancées et suivies depuis la surface qui convient.

Les organisations contrôlent quels agents et quels modèles leurs équipes peuvent utiliser, et un dashboard de métriques montre l'usage et les résultats. L'accès dépend d'une offre Copilot payante, et certains agents peuvent facturer des requêtes premium. Faire tourner plusieurs agents augmente le volume de code à relire, donc les habitudes de revue comptent plus, pas moins. Cursor et Devin ont leur propre gestion d'agents, et Claude Code et Codex peuvent tourner en direct. Agent HQ parle surtout aux équipes déjà centrées sur GitHub.
