cubic est un relecteur de code par IA qui regarde au-delà du diff. Il lit la base de code plus large pour juger si un changement risque de causer des problèmes, et il laisse des commentaires dans la pull request. Un score de confiance de fusion, de un à cinq, donne aux relecteurs un signal rapide sur l'attention qu'un changement demande.

D'autres fonctions allègent la revue. Les pull requests à faible risque peuvent être approuvées automatiquement, des scans nocturnes cherchent des bugs dans le dépôt, et les revues peuvent tourner depuis le terminal avant le push. Les équipes s'en servent pour réduire la file de pull requests qui attendent un humain.

C'est gratuit pour les dépôts publics, ce qui en fait une option pratique pour les mainteneurs open source, et des offres payantes couvrent les dépôts privés. CodeRabbit et Qodo sont les alternatives habituelles. Comme les relecteurs d'IA peuvent manquer du contexte ou signaler des faux positifs, prends-le comme une première passe qui réduit le temps de revue humaine, pas comme un remplacement.
