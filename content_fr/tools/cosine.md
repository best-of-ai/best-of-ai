Cosine vise à agir comme un coéquipier sur une base de code. Il indexe le dépôt, puis prend des tâches comme corriger un bug ou ajouter une fonction, planifie le travail, modifie plusieurs fichiers et lance des tests. Il explique son raisonnement en chemin, pour qu'un développeur puisse suivre et intervenir.

L'entreprise entraîne ses propres modèles, appelés Genie, spécialisés pour l'ingénierie logicielle à partir de données sur la façon dont les développeurs travaillent. Les outils incluent une interface en ligne de commande, une extension d'éditeur et une app web, et ça s'intègre à GitHub pour les pull requests. Il propose aussi des déploiements pour les organisations qui ont des exigences de sécurité.

Cosine a une offre gratuite et des offres payantes. Les scores de benchmark cités au lancement étaient auto-déclarés : teste-le sur ton propre code. Les alternatives incluent Claude Code, Cursor, Codex, Devin et l'agent de GitHub Copilot. Cosine convient aux développeurs qui veulent un agent de programmation spécialisé.
