Bito a commencé comme un assistant de chat et de complétion de code dans VS Code et les IDE JetBrains, et comme un outil en ligne de commande. On pouvait lui demander d'expliquer une fonction, d'écrire des tests unitaires, de trouver des bugs ou de générer de la documentation, et il utilisait un modèle au choix pour les réponses. Son attrait initial était une commodité pratique : des prompts réutilisables pour les tâches courantes et la prise en charge du contexte du projet.

Le produit s'est de plus en plus centré sur la revue de code. L'AI Code Review Agent examine les pull requests sur GitHub, GitLab et Bitbucket, laisse des commentaires sur des problèmes comme les bugs, les questions de sécurité et les écarts de style, et résume le changement pour les relecteurs. Il construit un modèle de la base de code pour que ses retours tiennent compte de la façon dont le code modifié s'insère dans le reste, ce qui aide à réduire les commentaires bruyants. Les équipes s'en servent pour accélérer les revues et attraper les problèmes plus tôt.

Bito a une offre gratuite et des offres payantes pour les particuliers et les équipes, avec des options entreprise qui incluent plus de contrôle sur les données. Les commentaires de revue automatisés ont besoin d'un humain pour décider lesquels valent d'être traités, et des outils trop bavards peuvent agacer les développeurs. Parmi les concurrents en revue de code IA : CodeRabbit, Qodo, Greptile, et les fonctions de revue de GitHub Copilot, tandis que des assistants généraux comme Cursor et Copilot couvrent le côté écriture. Bito est un acteur plus petit, mais ciblé.
