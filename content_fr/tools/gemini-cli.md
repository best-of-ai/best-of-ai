Gemini CLI amène Gemini dans le terminal comme agent de programmation et d'automatisation. Dans un répertoire de projet, tu décris une tâche en langage courant, comme expliquer une base de code, corriger un test qui échoue ou construire une fonction, et l'agent lit les fichiers, propose des changements, lance des commandes shell et itère. Il peut chercher sur le web, utiliser un fichier de contexte pour apprendre les conventions du projet, et travailler avec de longs contextes grâce à la grande fenêtre de contexte de Gemini.

Il est conçu pour être étendu. Le support du Model Context Protocol le relie à des outils externes, les extensions packagent des commandes et des intégrations sur mesure, et les réglages permettent aux équipes de contrôler les permissions et le sandboxing. Il est open source sous licence Apache 2.0, et il peut être scripté pour l'automatisation et l'intégration continue. Il tourne aussi dans le mode agent de Gemini Code Assist dans les éditeurs.

L'outil est gratuit avec un compte Google personnel dans des limites d'usage, et des offres payantes ou des clés d'API relèvent les limites. Comme tous les agents de code, il peut se tromper, donc relis les changements et fais attention aux commandes qui modifient ou suppriment des fichiers. Les alternatives incluent Claude Code, OpenAI Codex CLI, Aider, Cline et le CLI de GitHub Copilot. Gemini CLI convient aux développeurs qui veulent un agent de terminal gratuit et open source.
