Test Companion est un agent d'IA pour l'assurance qualité. Au lieu d'un dashboard séparé, il travaille dans l'éditeur du développeur, où il peut générer des scripts de test à partir d'une description ou du code, les lancer sur le cloud d'appareils et de navigateurs de BrowserStack, et enquêter sur les échecs.

La maintenance est un usage majeur. Les tests cassent quand les interfaces changent, et les corriger prend du temps. L'agent peut mettre à jour les sélecteurs, ajuster les étapes et relancer, ce qui réduit l'entretien qui rend les tests automatisés coûteux. Il fonctionne avec les frameworks courants et se connecte à l'infrastructure de test de BrowserStack.

Test Companion fait partie des offres payantes de BrowserStack. Les tests générés par IA ont encore besoin d'une revue, parce qu'un test qui passe ne prouve pas que la bonne chose est vérifiée. Parmi les alternatives : Testim, mabl, Katalon, Playwright avec des agents d'IA, et Applitools. Test Companion convient aux équipes qui testent déjà sur BrowserStack.
