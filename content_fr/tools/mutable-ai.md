Mutable AI était une startup qui construisait des outils d'IA pour les programmeurs. Son extension VS Code proposait la complétion de code, le refactoring et un chat capable de répondre à des questions sur un projet, et sa fonction AutoPilot visait à mener une fonctionnalité décrite à travers une base de code. L'équipe s'est ensuite fait connaître en transformant des dépôts en documentation lisible, de type wiki, ce qui aide les développeurs à comprendre un code inconnu.

Google a acquis l'entreprise, et le site d'origine de Mutable AI ne fonctionne plus. L'idée de générer un wiki vivant pour une base de code continue dans les produits de Google, où des outils de documentation bâtis sur ce concept sont apparus. Les utilisateurs de l'ancienne extension ont dû passer à d'autres assistants, le service autonome ayant disparu.

Pour des fonctions similaires aujourd'hui, il y a plusieurs choix. GitHub Copilot, Cursor et Claude Code gèrent la complétion, le refactoring et les changements agentiques, tandis que des outils comme DeepWiki et les efforts de documentation de code de Google génèrent des explications de dépôts. Sourcegraph et Greptile proposent la recherche et la compréhension de code pour les grands projets. Cette fiche reste pour référence, car d'anciens articles et listes de comparaison citent encore Mutable AI.
