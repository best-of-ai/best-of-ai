MultiOn a été l'une des premières entreprises à construire des agents qui utilisent un navigateur. Tu donnes une instruction en langage clair, et l'agent parcourt des sites, clique, saisit du texte et mène les étapes, en gardant une session à travers les pages. Les développeurs pouvaient l'appeler via une API pour construire leurs propres agents.

L'entreprise a parlé d'une nouvelle phase, et des annuaires décrivent un changement de nom et d'orientation, même si les récits diffèrent. Ça vaut le coup de vérifier le site officiel pour voir ce qui est disponible avant d'en dépendre.

Les agents web rencontrent des obstacles courants, dont les sites qui bloquent l'automatisation, la sécurité des connexions et des paiements, et les erreurs sur les tâches en plusieurs étapes. Les actions qui ont de vraies conséquences doivent être relues. Les alternatives incluent Browserbase avec des frameworks d'agents, le mode agent d'OpenAI, l'usage d'ordinateur d'Anthropic, Perplexity Comet et Skyvern. MultiOn convient aux développeurs qui expérimentent les agents de navigateur.
