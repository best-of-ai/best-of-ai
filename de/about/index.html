// Was das ist

Best of AI ist ein kuratiertes Verzeichnis für KI-Tools, betrieben von der Organisation best-of-ai auf GitHub. Dahinter steht kein Unternehmen, es gibt keine VC-Finanzierung und nichts ist kostenpflichtig. Die Tools sind so geordnet, dass du findest, was du brauchst, ohne dich durch gesponserte Ranglisten oder kostenpflichtige Testberichte zu arbeiten.

Die Daten liegen in einfachen Markdown-Dateien – eine Datei pro Tool, gespeichert in einem öffentlichen Repository. Alle können sie lesen, durchsuchen und weiterverwenden.

// Offene Daten, frei nutzbar

Der vollständige Index ist unter /index.json verfügbar. Du kannst ihn abrufen, forken oder darauf aufbauen. Für die Nutzung brauchst du weder ein Konto noch einen API-Schlüssel.

Jeder Tool-Eintrag ist eine Markdown-Datei mit einem einheitlichen Frontmatter-Schema: Name, Beschreibung, Website, Kategorie, Preis und Schlagwörter. Wenn du ein Projekt mit einer strukturierten Liste von KI-Tools baust, kannst du diese Daten frei nutzen.

Die meisten KI-Tool-Verzeichnisse verstecken sich hinter einem Login oder verlangen Geld für den Datenzugriff. Dieses nicht. Wir wollen die passenden Tools für alle zugänglich machen, nicht nur für Menschen, die sich ein Abo leisten können.

// Mitwirken

Das wird bei Pull Requests geprüft. Fehlt ein Tool, stimmt eine Beschreibung nicht oder passt eine Kategorie nicht? Öffne ein Issue oder sende eine Korrektur auf GitHub. Du brauchst niemandes Erlaubnis, um die Daten zu verbessern.

Im Repository findest du Vorlagen, um ein neues Tool einzureichen oder ein Problem zu melden. Korrekturen werden meist schnell übernommen. Ein Grund für einfache Dateien ist, dass Beiträge leicht geprüft und zusammengeführt werden können.
