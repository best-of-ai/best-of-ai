Microsoft AI publicó MAI Code 2 el 17 de noviembre de 2026 en Ignite. Está dirigido a la programación empresarial del día a día: código de producción, depuración, implementaciones de varios archivos, razonamiento sobre todo el repositorio y trabajo de interfaz. Microsoft dice que todavía no está ajustado para investigación científica fundamental ni para tareas de agentes de muy largo recorrido. Está disponible en GitHub Copilot, y la página da los costes solo en porcentajes, con un precio promocional del 50 % a la vista.

Con la media de DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas y FrontierCode v1.1, Microsoft dice que MAI Code 2 alcanza el 98 % de la puntuación de GPT-6.1 Sol al 40 % del coste, y el 96 % de la de Claude Opus 5.5 al 5 % del coste. En una prueba ciega de frontend, 258 anotadores lo prefirieron a GPT-6 Sol el 64 % de las veces. Son pruebas propias de Microsoft.
