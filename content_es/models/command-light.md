Command Light es el modelo más pequeño y rápido de Cohere de la familia Command original, publicado junto a Embed v3 en noviembre de 2023. Tiene alrededor de 6000 millones de parámetros y una ventana de contexto de 4096 tokens, y Cohere lo diseñó para aplicaciones que necesitan baja latencia y menor coste, y no un razonamiento de primer nivel. El precio era de 0,30 $ por millón de tokens de entrada y 0,60 $ por millón de tokens de salida a través de la API de Cohere. Cohere dejó en desuso Command Light en septiembre de 2025, junto con varios otros modelos Command tempranos, y ahora orienta hacia Command R, Command R+ o Command A, y llama a Command A el de mejor rendimiento en conjunto.
