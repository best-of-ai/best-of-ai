MAI Code 2 Flash es el hermano pequeño de MAI Code 2, anunciado el 17 de noviembre de 2026 en Ignite. Microsoft lo creó para trabajos de gran volumen como explicaciones de código, ediciones puntuales y correcciones rutinarias. Está en GitHub Copilot y en vista previa de acceso limitado en Microsoft Foundry.

Microsoft dice que su media en benchmarks es comparable a la de GPT-6 Luna y Claude Haiku 5.5 a una fracción de su coste, y no da precios por token. De Code 2 Flash sale un modelo derivado, MAI Work Flash, pensado para funcionar en Microsoft 365 y FabricIQ.
