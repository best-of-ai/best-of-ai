Codex funciona como un agente de ingeniería de software. Un desarrollador describe una tarea, como corregir un error o añadir una función, y Codex explora el código, hace un plan, edita archivos y ejecuta pruebas o linters para verificar el resultado. Después informa con un resumen de lo que cambió y por qué.

Viene en varias formas. Una herramienta de línea de comandos funciona en la máquina del desarrollador, una app de escritorio gestiona varias tareas, las extensiones se integran con editores como VS Code y una versión en la nube dentro de ChatGPT ejecuta tareas en sandboxes aislados, a menudo en paralelo, y puede proponer pull requests en GitHub. Los archivos de configuración permiten a los equipos darle al agente instrucciones del proyecto.

Codex se incluye en los planes de ChatGPT, con límites de uso que dependen del nivel, y hay acceso por API para quienes construyen productos. Los agentes se equivocan, así que los cambios necesitan revisión y pruebas. Entre las alternativas están Claude Code, Cursor, el agente de GitHub Copilot, Gemini CLI y Devin. Codex es para desarrolladores que quieren el agente de OpenAI en su flujo de trabajo.
