Describes qué probar en lenguaje natural, o apuntas TestSprite a un PRD o a un ticket, y su agente escribe y ejecuta pruebas de extremo a extremo contra tu aplicación en marcha, tanto del frontend como del backend. Cuando una prueba falla recibes un paquete con capturas de pantalla, instantáneas del DOM, una hipótesis de causa raíz y una corrección sugerida.

Las pruebas se reparan solas cuando cambia la interfaz, así que los retoques de diseño no rompen el conjunto. Se ejecuta como una comprobación de GitHub en cada pull request o de forma programada, y avisa en Slack, Jira y Linear. Una CLI de código abierto (Apache 2.0) y un servidor MCP permiten que agentes de programación como Claude Code, Cursor y Codex lo usen mientras escriben código.

El nivel gratuito ofrece una asignación mensual de créditos para un entorno y un repositorio. Los niveles de pago funcionan con créditos y se facturan por mes o por año, y el plan para empresas añade SSO. Resulta más útil en equipos donde los agentes de IA escriben buena parte del código y las pruebas tienen que seguir el ritmo.
