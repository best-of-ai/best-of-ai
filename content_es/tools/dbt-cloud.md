dbt, siglas de data build tool, se convirtió en la forma habitual de transformar datos en bruto dentro de un almacén como Snowflake, BigQuery o Databricks. Los analistas escriben sentencias SQL select, definen las dependencias entre ellas y dbt construye tablas y vistas en el orden correcto, con control de versiones, pruebas y documentación. Así lleva a la analítica prácticas de la ingeniería de software como la revisión de código y la integración continua.

dbt Cloud es el producto alojado de dbt Labs. Incluye un IDE en el navegador, programación de tareas, CI que prueba los cambios antes de que lleguen a producción, un catálogo de datos con linaje y una capa semántica que define las métricas una sola vez para usarlas en distintas herramientas de BI. Las funciones de IA ayudan a generar modelos, pruebas y documentación, y responden preguntas sobre el proyecto, lo que acelera las tareas repetitivas.

dbt Core, el motor de código abierto, es gratuito, y dbt Cloud tiene un plan gratuito para desarrolladores y planes de pago para equipos y empresas. Ejecutar dbt por tu cuenta requiere infraestructura y orquestación, que es justo lo que elimina el producto en la nube. Entre las alternativas están SQLMesh, Dataform en BigQuery, Coalesce y las funciones propias de cada almacén de datos. dbt encaja con ingenieros de analítica que quieren una capa de transformación estructurada y comprobable.
