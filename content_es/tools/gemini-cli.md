Gemini CLI lleva Gemini a la terminal como agente de programación y automatización. En el directorio de un proyecto describes una tarea en lenguaje natural, como explicar una base de código, arreglar una prueba que falla o construir una función, y el agente lee archivos, propone cambios, ejecuta comandos de shell e itera. Puede buscar en la web, usar un archivo de contexto para aprender las convenciones del proyecto y trabajar con contextos largos gracias a la gran ventana de contexto de Gemini.

Está pensado para ampliarse. La compatibilidad con Model Context Protocol lo conecta con herramientas externas, las extensiones empaquetan comandos personalizados e integraciones, y los ajustes permiten a los equipos controlar los permisos y el sandboxing. Es de código abierto con licencia Apache 2.0 y se puede automatizar con scripts para usarlo en automatizaciones e integración continua. También funciona dentro del modo agente de Gemini Code Assist en los editores.

La herramienta es gratuita con una cuenta personal de Google dentro de unos límites de uso, y los planes de pago o las claves de API amplían los límites. Como todos los agentes de programación, puede cometer errores, así que conviene revisar los cambios y tener cuidado con los comandos que modifican o borran archivos. Entre las alternativas están Claude Code, OpenAI Codex CLI, Aider, Cline y la CLI de GitHub Copilot. Gemini CLI sirve a desarrolladores que quieren un agente de terminal gratuito y de código abierto.
