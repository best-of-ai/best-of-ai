Bob es el asistente agéntico de IBM para el desarrollo de software. En lugar de limitarse a autocompletar código, participa en todo el ciclo de vida: entender una base de código, planificar cambios, escribir y revisar código, generar pruebas y ayudar con el despliegue. Distintos agentes asumen roles, como arquitecto o revisor, y trabajan dentro del editor del desarrollador.

El foco está en el uso empresarial. IBM insiste en la seguridad y la gobernanza, con protección contra fugas de datos sensibles, aplicación de políticas y pruebas de vulnerabilidades de la IA. Reparte las tareas entre varios modelos de lenguaje, entre ellos la familia Granite de IBM y modelos de otros proveedores, y se plantea para trabajos de modernización, como migrar aplicaciones antiguas de Java o COBOL.

IBM dice que primero desplegó la herramienta entre decenas de miles de sus propios empleados antes de lanzarla de forma general, y afirma haber obtenido grandes mejoras de productividad, que son cifras declaradas por la propia empresa. Bob es un producto de pago con pruebas y licencias para empresas. Entre las alternativas están GitHub Copilot, Cursor, Claude Code, Amazon Q Developer y Gemini Code Assist de Google. IBM Bob encaja con grandes organizaciones con entornos regulados y código heredado.
