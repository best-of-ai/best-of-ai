Claude Code funciona como un agente sobre tu proyecto real, no como un motor de sugerencias dentro de un editor. Lo inicias en un repositorio desde la terminal y describes la tarea, por ejemplo arreglar una prueba que falla, añadir un endpoint o actualizar una dependencia. Lee los archivos relevantes, hace un plan, edita código en todo el proyecto, ejecuta pruebas y otros comandos e itera sobre los errores. Pide permiso para las acciones que podrían ser arriesgadas, y puedes revisar los cambios como diffs o con git antes de hacer commit.

Es muy personalizable. Un archivo CLAUDE.md en el proyecto contiene las instrucciones y convenciones que el agente sigue siempre, y los skills empaquetan procedimientos repetibles. Los hooks ejecutan tus propios scripts en puntos del flujo de trabajo, los subagentes reparten el trabajo en contextos paralelos y el Model Context Protocol lo conecta con bases de datos, gestores de incidencias y otras herramientas. También funciona en editores como VS Code y JetBrains, en una app de escritorio y en el navegador, y se puede ejecutar en scripts y CI para tareas automatizadas.

Claude Code viene incluido en los planes de pago de Claude y también puede usarse con una clave de API que se factura según el uso, así que el coste depende de cuánto lo ejecutes. Las sesiones autónomas largas pueden consumir muchos tokens. Su resultado sigue necesitando revisión, sobre todo en código sensible para la seguridad. Codex de OpenAI, Gemini CLI de Google, Cursor, el agente de GitHub Copilot y Cline son las principales alternativas.
