AgentGPT fue una de las primeras herramientas que hizo fácil probar agentes autónomos. Abres una página web, pones nombre a un agente, describes un objetivo, como planificar un viaje o investigar un mercado, y pulsas desplegar. El agente escribe entonces su propia lista de tareas, las ejecuta una a una con un modelo de lenguaje y la revisa a medida que aprende. Verlo razonar sobre un objetivo en tiempo real fue una demostración muy gráfica de la idea que hay detrás de los agentes.

Surgió de Reworkd y se publicó como código abierto, así que los desarrolladores pueden ejecutarlo por su cuenta. El sitio alojado ofrece unos cuantos agentes de ejemplo y un número limitado de ejecuciones, y puedes aportar tu propia clave de API de un modelo para tener más. El proyecto ayudó a popularizar el ciclo de planificar, actuar y revisar que luego desarrollaron con mucho más cuidado otras herramientas.

AgentGPT se entiende mejor como una demostración del concepto. Sus agentes pueden divagar, repetirse o atascarse en tareas que requieren un uso fiable de herramientas, y carece de las salvaguardas, las integraciones y la calidad de los productos más recientes. Hoy, el modo agente de ChatGPT, Claude, Manus y frameworks como LangGraph y CrewAI resuelven el trabajo real con mucha más fiabilidad. AgentGPT sigue siendo útil para aprender cómo se estructuran los agentes autónomos y para hacer experimentos rápidos.
