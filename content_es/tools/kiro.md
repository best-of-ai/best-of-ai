Kiro se basa en el desarrollo guiado por especificaciones. Quien desarrolla describe una funcionalidad, y Kiro genera un documento de requisitos, un diseño técnico y una lista de tareas. Se revisan y editan, y después el agente recorre las tareas escribiendo código y pruebas. La idea es mantener al agente alineado con la intención en trabajos grandes en lugar de improvisar a partir del chat.

El editor se basa en Code OSS, así que las extensiones y la configuración de VS Code se trasladan. Los hooks activan acciones del agente ante eventos como guardar un archivo, los steering files dan orientación persistente sobre un proyecto, y la compatibilidad con Model Context Protocol conecta herramientas externas. Usa modelos de Claude a través de AWS.

Kiro tiene un nivel gratuito y planes de pago según el uso. Las especificaciones aportan estructura y algo de carga extra, que convienen más a funcionalidades grandes que a arreglos pequeños. Entre las alternativas están Cursor, Claude Code, Windsurf, GitHub Copilot y GitHub Spec Kit. Kiro encaja con desarrolladores que quieren disciplina de planificación con agentes.
