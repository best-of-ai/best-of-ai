Kilo Code funciona como extensión de VS Code y JetBrains, como herramienta de línea de comandos y como app de escritorio. Tiene agentes para programar, planificar, hacer preguntas y depurar, y puedes definir los tuyos. Los agentes pueden pasar trabajo a subagentes y ejecutarse en paralelo, y los agentes en la nube pueden seguir trabajando desde el navegador, Slack o una app móvil. El código tiene licencia MIT, y la herramienta de línea de comandos es una bifurcación de OpenCode.

Tú eliges cómo pagar los modelos. Kilo Gateway enruta a más de 500 modelos y traslada los precios de los proveedores sin recargo, puedes traer tus propias claves o ejecutar modelos locales con Ollama o LM Studio. Un Code Reviewer revisa los pull requests automáticamente, y un marketplace lista agentes, skills y servidores MCP.

La extensión es gratuita. Los planes Teams cuestan 15 dólares por usuario al mes, y el cómputo en la nube se factura por horas además del uso de modelos. Anaconda anunció en julio de 2026 que había adquirido Kilo Code, y no reveló las condiciones. Los agentes pueden cambiar muchos archivos a la vez, así que revisa los diffs antes de aceptarlos. Entre las alternativas están Cline, OpenCode, Claude Code y Cursor. Kilo Code encaja con desarrolladores que quieren un agente de código abierto que funcione con cualquier modelo.
