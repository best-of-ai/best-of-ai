AnythingLLM te da un lugar privado para hablar con tus archivos. Añades documentos, páginas web u otro contenido a un espacio de trabajo, y la app los indexa en una base de datos vectorial. Cuando haces una pregunta, recupera los pasajes relevantes y se los envía a un modelo de lenguaje, que responde con referencias.

Lo que más atrae es la flexibilidad. Puedes elegir un modelo local mediante Ollama o LM Studio, o un modelo en la nube de proveedores como OpenAI y Anthropic, y cambiarlos sin rehacer tu espacio de trabajo. Tiene agentes que pueden navegar por la web o ejecutar herramientas, admite varios usuarios y permisos en la versión de servidor, y ofrece una API y un widget de chat que se puede incrustar.

La versión de escritorio es gratuita y de código abierto, y hay una opción alojada y otra para empresas. Los modelos locales son menos capaces que los mayores modelos en la nube, y el rendimiento depende de tu hardware. Entre las alternativas están Open WebUI, GPT4All, Msty, LibreChat y Khoj. AnythingLLM es adecuado para personas y equipos que quieren chatear con documentos de forma privada.
