Sweep empezó como un desarrollador junior de IA en GitHub. El usuario describía una tarea en una incidencia, y el bot leía el código, planificaba los cambios y abría un pull request. Al equipo le resultó difícil alcanzar la fiabilidad que buscaba y observó que la mayor parte de la atención a la programación con IA se centraba en VS Code.

Pasaron a ofrecer un plugin para IntelliJ, PyCharm y otros IDE de JetBrains, con chat que tiene en cuenta el contexto, aplicación de cambios en varios archivos y revisión automática de código. El plugin puede ejecutarse en instalaciones locales, lo que conviene a empresas con requisitos de seguridad.

Sweep tiene un nivel gratuito y planes de pago. El flujo original de incidencia a pull request sigue en el proyecto de código abierto, aunque su soporte es incierto. Entre las alternativas están JetBrains AI Assistant, GitHub Copilot, Cline, Continue y Cursor. Sweep AI es útil para desarrolladores que usan herramientas de JetBrains.
