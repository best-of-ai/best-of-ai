Greptile es un revisor de código con IA centrado en el contexto del código. En lugar de leer solo el diff, construye una comprensión de todo el repositorio, incluida la relación entre funciones y módulos, de modo que sus comentarios pueden señalar efectos en archivos que el pull request no tocó.

Publica comentarios y resúmenes de revisión en pull requests de GitHub y GitLab. Los equipos pueden definir reglas en lenguaje natural, y el sistema aprende de los pulgares arriba y abajo en sus comentarios para reducir el ruido. Una API permite a los desarrolladores hacer preguntas sobre el código.

Greptile es de pago, con precio por desarrollador y prueba gratuita. La revisión automática puede pasar por alto problemas de diseño y a veces genera falsas alarmas, así que la revisión humana sigue siendo importante. Entre las alternativas están CodeRabbit, Graphite, la revisión de código de GitHub Copilot, Qodo y Sourcery. Greptile sirve para equipos con bases de código grandes que quieren más contexto en las revisiones.
