Volcano es una plataforma para crear y alojar agentes y las apps que los rodean, creada por Kong. La CLI es la interfaz principal, así que agentes de programación como Claude Code, Codex, Cursor y OpenCode pueden desplegar y ejecutar cosas directamente.

Los componentes incluyen funciones duraderas con puntos de control, aprobaciones, entornos aislados (sandboxes), bloqueos distribuidos, Postgres gestionado con pgvector, autenticación, almacenamiento de archivos, tiempo real y alojamiento de Next.js. La página de inicio también presenta LavaFlow como su función para apps que se reparan solas.

Un plan Hobby gratuito no pide tarjeta. El plan de pago Superagent incluye una asignación mensual de créditos y cuesta menos con facturación anual, y el plan para empresas es a medida. Desarrolladores que crean con agentes de programación son el público. Supabase, Vercel y Temporal cubren cada uno parte del mismo terreno.
