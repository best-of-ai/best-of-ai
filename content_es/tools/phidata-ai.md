Phidata comenzó como un framework de Python para convertir modelos de lenguaje en agentes. Los desarrolladores definen un agente con instrucciones, herramientas, memoria y una base de conocimiento; el framework se encarga de ejecutarlo, guardar el historial y recuperar documentos. También admite equipos de agentes que trabajan juntos.

El proyecto pasó a llamarse Agno, y el mismo equipo y código continúan con el nuevo nombre, por lo que la documentación y los paquetes ahora se refieren a Agno. Las versiones más recientes se centran en la velocidad, un diseño ligero y funciones de producción como un entorno de ejecución para servir agentes.

El framework es gratuito y de código abierto. Conviene consultar la documentación actual de Agno para la instalación y la licencia, ya que los detalles cambiaron con el cambio de nombre. Entre sus alternativas están LangGraph, CrewAI, Mastra, OpenAI Agents SDK y Haystack. Esta ficha recoge el nombre anterior. Phidata sirve a desarrolladores que buscan el proyecto antiguo y necesitan la documentación actual de Agno.
