Google AI Studio es donde los desarrolladores van a probar los modelos de Google sin configurar nada. Inicias sesión con una cuenta de Google, eliges un modelo Gemini y empiezas a escribir prompts en un espacio de pruebas donde puedes ajustar parámetros como la temperatura, añadir instrucciones de sistema y adjuntar imágenes, audio, vídeo o documentos. Cuando un prompt funciona, con un clic obtienes el código para ejecutarlo con la API de Gemini en Python, JavaScript y otros lenguajes.

Ha crecido hasta ser más que un espacio de pruebas. Un modo de construcción puede crear una pequeña app web funcional a partir de una descripción, que puedes previsualizar, editar y desplegar. El modo Live permite probar conversaciones de voz y vídeo en tiempo real con un modelo, y otras herramientas cubren la generación de imágenes y de vídeo y las salidas estructuradas. También es donde creas y gestionas las claves de la API de Gemini y consultas el uso.

El uso es gratuito dentro de los límites de frecuencia, lo que lo hace popular para prototipar y aprender. Para producción se paga por uso en la API de Gemini o se pasa a Vertex AI en Google Cloud, que añade funciones para empresas como la gobernanza de datos y los acuerdos de nivel de servicio. En el nivel gratuito, Google puede usar tus prompts para mejorar sus productos, así que no conviene introducir datos sensibles. Entre las alternativas están el Playground de OpenAI, la Console de Anthropic y el espacio de pruebas de AWS Bedrock.
