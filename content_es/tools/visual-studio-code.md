Visual Studio Code, al que casi todos llaman VS Code, es el editor de código más usado entre los desarrolladores. Es lo bastante ligero para abrirse rápido y trae lo que la mayoría necesita: resaltado de sintaxis, depurador, terminal integrada, soporte de Git y un enorme mercado de extensiones que añade lenguajes, linters, temas y herramientas. El núcleo es de código abierto y funciona en Windows, macOS y Linux. También tiene versión para el navegador, y las funciones de desarrollo remoto permiten trabajar dentro de contenedores, por SSH o en entornos en la nube.

La IA ya forma parte de su base. GitHub Copilot ofrece sugerencias de código en línea mientras escribes, un panel de chat que responde preguntas sobre tu proyecto y un modo agente que puede planificar una tarea, editar varios archivos, ejecutar comandos en la terminal y corregir los errores que encuentra. VS Code también es compatible con el Model Context Protocol, de modo que los agentes pueden conectarse a herramientas y fuentes de datos externas, y puedes usar modelos de distintos proveedores. Muchas otras herramientas de programación con IA, como Cursor y Windsurf, nacieron como forks de VS Code, una muestra de cuánto del ecosistema se apoya en él.

El editor en sí no cuesta nada. Copilot tiene un nivel gratuito con uso limitado y planes de pago para un uso más intenso y para equipos. Las descargas oficiales de Microsoft incluyen telemetría y algunas partes propietarias, y por eso existen compilaciones de la comunidad como VSCodium para quien quiere un binario totalmente de código abierto. Frente a IDE completos como IntelliJ o Visual Studio, VS Code hace menos de serie y depende de las extensiones, lo que puede suponer más configuración pero un editor más rápido y flexible.
