PearAI es un editor independiente derivado de VS Code con funciones de IA integradas. Los desarrolladores cuentan con autocompletado de código, un panel de chat que entiende el proyecto y edición dentro del código, y pueden conectar sus modelos preferidos. Al ser una bifurcación, conserva extensiones y ajustes conocidos.

Se presenta como una alternativa abierta a Cursor y Windsurf. La capa de IA se basa en Continue, un asistente de código abierto. El proyecto tuvo al principio una polémica sobre la licencia por el uso de código existente, que después resolvió.

PearAI ofrece uso gratuito con una suscripción de pago opcional para modelos alojados. Las bifurcaciones de VS Code requieren mantenimiento para seguir los cambios del proyecto original, y este proyecto es más pequeño que sus rivales. Entre las alternativas están Cursor, Windsurf, Cline, Continue y Void. PearAI sirve a desarrolladores que quieren un editor de IA de código abierto.
