Insomnia es una aplicación de escritorio que permite a los desarrolladores enviar solicitudes a APIs e inspeccionar las respuestas. Construyes solicitudes con cabeceras, autenticación y cuerpos, las organizas en colecciones y usas variables de entorno para cambiar entre desarrollo y producción. Admite REST, GraphQL, gRPC, WebSocket y Server-Sent Events, y puede importar definiciones desde especificaciones OpenAPI.

Además de las pruebas manuales, sirve para diseño y automatización. Un editor de diseño de APIs ayuda a escribir especificaciones, las suites de pruebas ejecutan colecciones de solicitudes con aserciones y las herramientas de línea de comandos corren las pruebas en CI. Los plugins amplían las funciones, la sincronización con Git guarda las colecciones junto al código y las funciones de IA ayudan a generar solicitudes, pruebas y documentación. Insomnia puede guardar los datos en local o en la nube, una elección que importa a los equipos preocupados por la privacidad.

Insomnia es de código abierto, con un nivel gratuito y planes de pago para colaboración en equipo y funciones para empresas. Compite en un espacio donde los usuarios han ido cambiando de herramienta a medida que los proveedores modificaban su enfoque sobre las cuentas en la nube. Entre las alternativas están Postman, que lidera el mercado, Bruno, un cliente de código abierto que funciona sin conexión, Hoppscotch, Thunder Client para VS Code y curl. Insomnia encaja con desarrolladores que quieren un cliente de API limpio y pensado para el uso local.
