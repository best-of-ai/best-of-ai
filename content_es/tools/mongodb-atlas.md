MongoDB guarda los datos como documentos flexibles parecidos a JSON en lugar de filas y columnas, lo que encaja con aplicaciones cuya estructura de datos cambia a menudo. Atlas lo ofrece como servicio gestionado: se encarga del aprovisionamiento, las copias de seguridad, el escalado y la seguridad, y funciona en las principales nubes. Los desarrolladores se conectan con controladores para casi todos los lenguajes, y funciones como la replicación y el sharding permiten alta disponibilidad y conjuntos de datos grandes. Un nivel gratuito sirve para proyectos pequeños y para aprender.

Para IA, Atlas ofrece búsqueda vectorial junto a la base de datos habitual, de modo que las aplicaciones pueden guardar embeddings y hacer consultas de similitud sin mover los datos a una base de datos vectorial aparte. Esto sirve para la generación aumentada por recuperación, las recomendaciones y la búsqueda semántica. MongoDB también ha adquirido una empresa que crea modelos de embeddings y de reordenación, y se integra con marcos de IA habituales como LangChain y LlamaIndex. La búsqueda de texto completo, las series temporales y las funciones de analítica están en la misma plataforma.

Atlas se factura por uso: nivel de cómputo, almacenamiento y transferencia de datos, con un nivel gratuito y planes dedicados para producción. Los costes pueden subir en clústeres grandes. Un modelo de documentos encaja mejor con unas aplicaciones que con otras, y los equipos con datos muy relacionales suelen preferir Postgres. Entre las alternativas están PostgreSQL con pgvector en servicios como Neon y Supabase, Amazon DynamoDB y DocumentDB, Couchbase y bases de datos vectoriales dedicadas como Pinecone. Atlas es una opción habitual para apps con esquemas que evolucionan.
