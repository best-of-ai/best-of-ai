Kimi Code es un agente de línea de comandos de la misma familia que Claude Code y Codex CLI. Se inicia en la carpeta de un proyecto, se describe una tarea y el agente lee archivos, edita código, ejecuta comandos y comprueba los resultados, decidiendo qué hacer a continuación según lo que ocurra. Los permisos permiten aprobar las acciones arriesgadas.

Usa por defecto los modelos Kimi de Moonshot AI, conocidos por su buena programación y su contexto largo, y también puede conectarse a otros proveedores compatibles. Entre sus funciones hay subagentes integrados para programar, explorar y planificar, compatibilidad con el Model Context Protocol para conectar herramientas, hooks de ciclo de vida para automatización y comprobaciones de seguridad, y un modo ACP para que editores como Zed y JetBrains puedan manejarlo.

La herramienta es de código abierto con licencia MIT. Acceder a los modelos requiere una cuenta o una clave de API, y los planes tienen límites. Varios proyectos no oficiales comparten el nombre, así que conviene usar el repositorio oficial de Moonshot AI. Entre las alternativas están Claude Code, OpenAI Codex CLI, Gemini CLI, OpenCode y Aider. Kimi Code encaja con desarrolladores que quieren un agente de terminal construido en torno a los modelos Kimi.
