Aide era un editor de código pensado desde el principio para la IA, creado por la startup londinense CodeStory. Era un fork de VS Code, así que resultaba familiar y admitía extensiones, pero añadía una capa de IA que entendía el proyecto. Se podía conversar sobre el código base, pedir cambios en varios archivos y recibir autocompletados con un contexto más amplio. Se publicó como código abierto con licencia AGPL, y el proyecto despertó un interés considerable entre desarrolladores que buscaban una alternativa a Cursor.

CodeStory también investigó la programación con agentes, incluido el trabajo sobre tareas de benchmark que miden si un modelo es capaz de resolver issues reales en repositorios de código abierto. El editor formaba parte de ese esfuerzo y permitía probar la programación con agentes en proyectos propios, con la posibilidad de elegir modelo.

El desarrollo se detuvo y el editor ya no se mantiene. El código sigue disponible en GitHub para quien quiera hacer un fork, pero los usuarios nuevos están mejor atendidos con herramientas que se actualicen. Cursor, Windsurf, Cline y GitHub Copilot son las alternativas habituales, y Void era otro editor de código abierto de la misma categoría. Esta ficha se mantiene como referencia, porque artículos antiguos y páginas de comparación todavía mencionan Aide.
