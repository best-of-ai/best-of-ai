Azure OpenAI es la gama de modelos de OpenAI servida desde la nube de Microsoft. Las empresas lo usan para acceder a las mismas familias de modelos de lenguaje, razonamiento, imagen y audio, pero bajo las condiciones, la facturación y los controles de seguridad de Azure. Para sectores regulados y grandes empresas eso importa: los datos se procesan dentro de Azure, pueden aislarse en una red privada y quedan cubiertos por las certificaciones de cumplimiento y el acuerdo de nivel de servicio de Microsoft.

El desarrollo se hace en Microsoft Foundry, donde se despliega un modelo, se prueba en un playground y se conecta con tus propios datos y herramientas. Entre las funciones disponibles están el fine-tuning, el filtrado de contenido, la llamada a herramientas y funciones, la recuperación sobre documentos de la empresa y el trazado. Los despliegues son de varios tipos, como el estándar de pago por uso, por lotes y de rendimiento aprovisionado, que reserva capacidad para cargas estables con latencia predecible. Foundry también ofrece modelos que no son de OpenAI, así que los equipos pueden comparar opciones en un solo lugar.

Los modelos nuevos de OpenAI a veces llegan a Azure algo más tarde que a la API de OpenAI, y acceder a los más recientes puede requerir una solicitud. Los precios siguen el modelo por tokens de OpenAI con facturación de Azure, y los descuentos para empresas son habituales. Es sobre todo para compañías que ya han estandarizado su trabajo en Microsoft, ya que sus principales alternativas son AWS Bedrock y Google Vertex AI. Para particulares y proyectos pequeños suele resultar más sencilla la API de OpenAI.
