Firebase permite desarrollar apps sin gestionar servidores propios. Sus servicios principales son Cloud Firestore y Realtime Database para almacenar y sincronizar datos, Authentication para iniciar sesión con correo, teléfono o cuentas sociales, Cloud Storage para archivos, Hosting para sitios web y Cloud Functions para código de servidor. Analytics, Crashlytics y Cloud Messaging para notificaciones push completan las herramientas del ciclo de vida de la app, y los SDK admiten iOS, Android, web, Flutter y Unity.

La IA ya forma parte de la plataforma. Gemini in Firebase ayuda a escribir código, depurar y entender los proyectos, y Firebase AI Logic ofrece a las apps una forma segura de llamar a Gemini y a otros modelos directamente desde el cliente. Genkit es un framework de código abierto para crear funciones y agentes de IA, y Firebase Studio es un entorno en el navegador para prototipar apps con ayuda de IA.

Firebase tiene un plan gratuito con cuotas generosas para proyectos pequeños y un plan de pago por uso para producción. Los costes pueden sorprender cuando crece el uso, sobre todo por las lecturas de la base de datos, así que conviene fijar presupuestos y estructurar bien las consultas. La plataforma te ata a los servicios de Google y sacar los datos de allí cuesta trabajo. Supabase es una alternativa de código abierto basada en Postgres, AWS Amplify y Appwrite también compiten, y Convex propone un backend en tiempo real distinto. Firebase es una elección habitual para apps móviles y prototipos.
