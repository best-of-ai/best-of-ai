Label Studio es una plataforma de anotación flexible. Los equipos la usan para etiquetar datos de machine learning, por ejemplo dibujando cuadros sobre imágenes, marcando entidades en texto, transcribiendo audio y valorando las respuestas de modelos de lenguaje. Su sistema de configuración permite definir interfaces de etiquetado personalizadas con un marcado sencillo, de modo que una sola herramienta sirve para proyectos muy distintos, y funciona en local o en un servidor.

El etiquetado asistido por modelos acelera el trabajo. Un backend de machine learning puede preetiquetar los datos para que las personas los corrijan, y el aprendizaje activo ayuda a priorizar los ejemplos más informativos. La plataforma admite la evaluación de modelos de lenguaje, con plantillas para tareas como ordenar respuestas y detectar errores factuales, un uso cada vez más común a medida que los equipos crean aplicaciones de IA. Una API y un SDK la conectan con los flujos de entrenamiento.

La edición comunitaria es gratuita y de código abierto, y HumanSignal vende Label Studio Enterprise con funciones como acceso por roles, flujos de trabajo, analítica y seguridad. Alojarla uno mismo requiere cierto trabajo técnico. Entre las alternativas están CVAT para visión artificial, Labelbox, Scale AI y Encord como plataformas comerciales, Prodigy para texto y Argilla para datos de modelos de lenguaje. Label Studio es adecuado para equipos que quieren una herramienta de anotación flexible y autoalojada.
