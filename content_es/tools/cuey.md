Cuey es una herramienta para comparar chatbots. Desde una barra lateral de Chrome, escribes un prompt una vez y se envía a servicios como ChatGPT, Claude y Gemini en los que ya tienes la sesión iniciada, con las respuestas mostradas juntas. Una vista resalta en qué coinciden y en qué difieren las respuestas, lo que sirve para verificar datos y elegir la mejor formulación.

Incluye una biblioteca de prompts guardados y una función de memoria para que el contexto te siga de un modelo a otro. Como trabaja con las interfaces de chat que ya usas, no necesita claves de API aparte. El desarrollador, Llama Valley Inc, afirma que los prompts y las respuestas no se almacenan en sus servidores.

Cuey es gratuito de instalar, con opciones de pago. Las afirmaciones sobre privacidad vienen del desarrollador, así que conviene revisar los permisos de la extensión antes de usarla. Entre las alternativas están ChatHub, Poe, ChatPlayground, LMArena y MultiGPT. Cuey sirve a quienes comparan con frecuencia respuestas entre chatbots.
