MultiOn fue una de las primeras empresas en desarrollar agentes capaces de usar un navegador. El usuario da una instrucción en lenguaje natural y el agente recorre sitios web, hace clic, escribe y completa los pasos, manteniendo la sesión entre páginas. Los desarrolladores podían usarlo mediante una API para crear sus propios agentes.

La empresa ha hablado de iniciar una nueva etapa, y algunos directorios describen un cambio de nombre y enfoque, aunque las versiones difieren. Por eso conviene consultar el sitio oficial para saber qué ofrece actualmente antes de depender de sus servicios.

Los agentes web afrontan obstáculos habituales: sitios que bloquean la automatización, seguridad de accesos y pagos, y errores en tareas de varios pasos. Conviene revisar las acciones con consecuencias reales. Entre las alternativas están Browserbase con marcos para agentes, el modo agente de OpenAI, computer use de Anthropic, Perplexity Comet y Skyvern. MultiOn puede servir a desarrolladores que experimentan con agentes de navegador.
