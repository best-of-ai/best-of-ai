GitHub Copilot es la herramienta de programación con IA con más usuarios, y está integrada en el lugar donde ya vive la mayor parte del código. Empezó como autocompletado en línea, terminando líneas y funciones a partir del archivo en el que estabas, y lo sigue haciendo en VS Code, Visual Studio, los IDE de JetBrains, Neovim y Xcode. Un panel de chat explica código, escribe pruebas, corrige errores y responde preguntas sobre tu proyecto sin salir del editor.

Las partes más nuevas son agénticas. El modo agente del editor planifica una tarea, edita varios archivos, ejecuta comandos de terminal y vuelve a intentarlo cuando algo falla. El agente de programación de Copilot trabaja directamente en GitHub: le asignas una issue, trabaja en segundo plano y abre un pull request para que lo revises. Copilot también puede revisar pull requests, ayudar en la línea de comandos y usar modelos de varios proveedores, que eliges en un selector. Los equipos pueden añadir instrucciones personalizadas para que siga sus convenciones.

Hay un nivel gratuito con uso limitado, planes de pago individuales y planes para empresas con controles de administración, ajustes de políticas y opciones para excluir el código del entrenamiento de modelos. Las solicitudes premium a los modelos más potentes pueden estar medidas, así que un uso intensivo puede llegar a los límites. Como funciona dentro de las herramientas que los desarrolladores ya usan, adoptarlo es fácil. Cursor, Windsurf y Claude Code ofrecen experiencias más centradas en el agente, mientras que la fortaleza de Copilot es su amplitud, la integración con GitHub y el soporte para empresas.
