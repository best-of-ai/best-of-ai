DataStax creció en torno a Apache Cassandra, una base de datos diseñada para aplicaciones grandes que no pueden parar nunca. Su servicio Astra DB ejecuta Cassandra en la nube sin servidores que gestionar y añade búsqueda vectorial, para que los desarrolladores guarden embeddings y encuentren elementos similares por significado. Eso la convierte en una base para la generación aumentada por recuperación (RAG), las recomendaciones y las funciones de chat.

La empresa también respalda las herramientas que rodean el desarrollo con IA. Langflow es un constructor visual de flujos de agentes y de recuperación, y sus API de datos permiten usar modelos de documentos o de tablas. Combinar una base de datos escalable con herramientas de IA ofrece a los equipos un camino del prototipo a cargas de producción grandes.

IBM anunció que planea adquirir DataStax para reforzar sus productos watsonx, así que los paquetes pueden cambiar con el tiempo. Astra DB tiene un nivel gratuito y precios según el uso, y Cassandra sigue siendo de código abierto. Entre las alternativas están Pinecone, Weaviate, Qdrant, MongoDB Atlas Vector Search y pgvector en Postgres. DataStax encaja con equipos que necesitan búsqueda vectorial a gran escala.
