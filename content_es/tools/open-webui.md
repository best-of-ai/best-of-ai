Open WebUI ofrece una interfaz de chat conocida para modelos que controlas tú. Lo ejecutas en tu propio servidor u ordenador, lo conectas a modelos locales mediante Ollama o a cualquier API compatible con OpenAI, y obtienes una app web cuidada con historial de conversaciones, cambio de modelo, bibliotecas de prompts y entrada de voz. Empezó como interfaz para Ollama y se ha convertido en una plataforma completa.

Sus funciones apuntan a equipos y usuarios avanzados. La generación aumentada por recuperación permite subir documentos y chatear con ellos, la búsqueda web puede aportar información actual, y las herramientas y funciones amplían lo que pueden hacer los modelos. Los administradores pueden gestionar varios usuarios, roles y permisos, lo que conviene a organizaciones que quieren un asistente de IA interno sin enviar datos a terceros. Admite plugins y pipelines para comportamientos a medida.

Open WebUI es gratuito para autoalojar, con una opción para empresas con soporte y marca propia. Su licencia cambió para incluir restricciones de marca en despliegues grandes, así que conviene revisar los términos si piensas redistribuirlo. La instalación exige cierta soltura técnica, y la calidad de las respuestas depende del modelo que haya detrás. Entre las alternativas están LibreChat, AnythingLLM, LobeChat, Jan y productos comerciales como ChatGPT Team. Open WebUI sirve para quienes quieren una interfaz autoalojada parecida a ChatGPT.
