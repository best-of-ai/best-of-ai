NocoDB convierte una base de datos en algo parecido a Airtable. Se conecta a una base SQL existente o permite crear una nueva, y los usuarios ven las tablas como hojas de cálculo que pueden filtrar, ordenar y editar, con vistas de tablero kanban, galería, calendario y formulario. Así, quienes no tienen conocimientos técnicos acceden a los datos sin aprender SQL.

Genera API REST y GraphQL para las tablas, admite permisos y webhooks, y ofrece automatización y un asistente de IA para ayudar con campos y consultas. Como es de código abierto, los equipos pueden alojarlo por su cuenta y mantener los datos en sus propios servidores.

NocoDB es gratuito si se aloja por cuenta propia, y tiene planes de pago en la nube y para empresas. Las instalaciones grandes requieren atención operativa. Entre las alternativas están Airtable, Baserow, Teable, Grist y las bases de datos de Notion. NocoDB encaja con equipos que quieren una capa similar a Airtable sobre su propia base de datos.
