Make, antes llamado Integromat, permite automatizar el trabajo entre apps dibujándolo. Colocas en un lienzo un módulo por cada app, como Gmail, Google Sheets, Slack o un CRM, y los unes con líneas que muestran cómo fluyen los datos. Puedes añadir routers que dividen el flujo en ramas, filtros que deciden qué elementos continúan, iteradores que procesan listas y funciones que modifican los datos por el camino. Este diseño visual hace que la lógica complicada sea más fácil de seguir que una larga lista lineal de pasos.

Admite una gran biblioteca de integraciones con apps, además de un módulo HTTP genérico y webhooks para todo lo que no tenga un conector listo. Los módulos de IA incorporan modelos de OpenAI, Anthropic, Google y otros para tareas como clasificar mensajes, resumir documentos o extraer datos de un texto. Make también ofrece agentes de IA que pueden decidir qué herramientas usar para lograr un objetivo, y los escenarios pueden ejecutarse según un horario, por webhook o cuando llegan datos nuevos.

Make tiene un plan gratuito con una asignación mensual de operaciones, y los planes de pago crecen según el número de operaciones. Como cada ejecución de un módulo cuenta como una operación, un escenario complejo que procese muchos elementos puede agotar un plan enseguida. Suele costar menos que Zapier para el mismo trabajo, pero tiene una curva de aprendizaje más pronunciada. n8n es la principal alternativa que puedes alojar tú mismo. Quienes no son técnicos y quieren la configuración más sencilla suelen preferir Zapier.
