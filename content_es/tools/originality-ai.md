Originality.ai se creó para quienes encargan o publican contenido escrito y quieren saber si lo ha escrito una IA. Pegas un texto o analizas una URL, y devuelve una puntuación que estima la probabilidad de que el texto lo hayan generado modelos como ChatGPT, Claude y Gemini, junto con una comprobación de plagio frente a fuentes web. Equipos de contenido, agencias de SEO y compradores de sitios web lo usan para revisar el trabajo de sus colaboradores.

Entre las herramientas adicionales hay una ayuda para verificar datos, un análisis de legibilidad y una función que muestra el historial de escritura de un Google Doc para demostrar cómo se redactó. Una extensión de Chrome y una API permiten integrarlo en flujos de publicación, y las cuentas de equipo permiten revisar muchas piezas. La empresa publica estudios de precisión, aunque otros discuten sus resultados.

Originality.ai es de pago, con créditos por análisis o suscripción. Ningún detector de IA es del todo fiable: los falsos positivos pueden etiquetar injustamente como IA un texto escrito por una persona, en particular si no es nativa de inglés, y hay falsos negativos cuando se edita el texto. Las puntuaciones deben servir para abrir una conversación y no como prueba. Entre las alternativas están GPTZero, Copyleaks, Turnitin para educación y Winston AI. Originality.ai sirve para editoriales que quieren un paso de filtrado.
