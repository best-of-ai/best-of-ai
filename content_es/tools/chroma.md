Chroma es una base de datos vectorial que apuesta por la sencillez para el desarrollador. Almacena embeddings, que son representaciones numéricas de texto, imágenes u otros datos, junto con metadatos y los documentos originales. Las aplicaciones la consultan para encontrar elementos de significado similar a una entrada dada, que es la base de la búsqueda semántica y de la generación aumentada por recuperación.

Es fácil empezar: unas pocas líneas de Python o JavaScript crean una colección, añaden documentos y ejecutan consultas, y puede funcionar en memoria dentro de un programa, como servidor local o en un servicio en la nube alojado. Se integra con LangChain, LlamaIndex y otros frameworks, lo que la convirtió en una opción habitual para prototipos.

Chroma es gratuita y de código abierto, con Chroma Cloud como servicio gestionado para producción. Los despliegues a gran escala exigen atención al rendimiento y a las operaciones, y algunos equipos migran a otras bases de datos para cargas pesadas. Entre las alternativas están Pinecone, Weaviate, Qdrant, Milvus y pgvector en Postgres. Chroma encaja en desarrolladores que prototipan aplicaciones de recuperación.
