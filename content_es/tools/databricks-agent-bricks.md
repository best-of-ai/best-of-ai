Agent Bricks está pensado para empresas que quieren agentes basados en sus propios datos. En lugar de escribirlo todo a mano, un equipo describe la tarea, por ejemplo responder preguntas sobre documentos internos, extraer información de formularios o coordinar varios agentes, y la plataforma ayuda a construirla. Genera datos de prueba sintéticos, evalúa la calidad con jueces y ajusta el agente probando distintos modelos y configuraciones para mejorar la precisión y el coste.

Como funciona sobre la plataforma de Databricks, los agentes usan datos gobernados mediante Unity Catalog, de modo que los controles de acceso siguen las reglas que la empresa ya tiene. Las herramientas de observabilidad y evaluación basadas en MLflow registran cómo se comportan los agentes, y los desarrolladores pueden traer sus propios frameworks. Lakebase ofrece a los agentes una base de datos transaccional para el estado y los datos de la aplicación, así que las aplicaciones pueden guardar memoria y resultados junto a los datos analíticos.

Agent Bricks se vende dentro del modelo de precios por uso de Databricks, por lo que el coste depende del cómputo y de los modelos que se usen. Tiene más sentido para organizaciones que ya guardan sus datos en Databricks. Entre las alternativas están Snowflake Cortex, Amazon Bedrock AgentCore, Google Vertex AI Agent Builder y Microsoft Copilot Studio, además de frameworks de código abierto como LangGraph. Los agentes siguen necesitando una evaluación cuidadosa antes de confiarles flujos de trabajo reales.
