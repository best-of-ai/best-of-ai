Cody surgió de la búsqueda de código de Sourcegraph, que indexa repositorios enteros y permite a los desarrolladores encontrar y entender código en muchos proyectos. Ese contexto era su principal ventaja: en lugar de adivinar a partir del archivo abierto, Cody podía apoyarse en toda la base de código para responder preguntas, escribir código acorde con los patrones existentes y explicar cómo encajan las partes de un sistema. Funcionaba en VS Code, en los IDE de JetBrains y en la web, con chat, autocompletado y comandos para editar y probar código.

El producto ha cambiado. Sourcegraph dejó de ofrecer los planes Free y Pro de Cody para particulares, y también lo retiró del plan Enterprise Starter. Cody Enterprise sigue disponible para grandes organizaciones que usan la plataforma de Sourcegraph, donde su conocimiento de la base de código resulta más útil. Para la programación más reciente basada en agentes, Sourcegraph presentó Amp, una herramienta aparte creada para flujos de trabajo con agentes.

Si hoy estás evaluando herramientas, Cody tiene sentido sobre todo para empresas que ya usan Sourcegraph y necesitan inteligencia de código sobre bases de código muy grandes con varios repositorios, con la opción de usar modelos de varios proveedores. Los despliegues empresariales pueden ejecutarse en el propio entorno del cliente. Los desarrolladores a título individual deberían mirar GitHub Copilot, Cursor, Claude Code o Amp. Las reseñas antiguas que mencionan un plan gratuito de Cody describen algo que ya no se ofrece.
