AWS GovCloud es un conjunto aparte de regiones de AWS creado para cargas de trabajo con requisitos normativos estrictos. Las agencias del Gobierno de EE. UU., los contratistas y otras organizaciones que manejan datos controlados lo usan para alojar sistemas que deben cumplir estándares como FedRAMP High, la Guía de requisitos de seguridad de la computación en la nube del Departamento de Defensa, ITAR, CJIS y HIPAA. Las regiones están aisladas física y lógicamente de las regiones estándar de AWS, y el acceso se limita a ciudadanos estadounidenses verificados.

Hay muchos servicios de AWS disponibles, entre ellos cómputo, almacenamiento, bases de datos y un conjunto creciente de servicios de IA. Los clientes pueden ejecutar cargas de aprendizaje automático e IA generativa, con acceso a modelos mediante Amazon Bedrock, sin sacar los datos del perímetro de cumplimiento. Las cuentas se crean mediante un proceso específico y se vinculan a una cuenta estándar de AWS para la facturación.

GovCloud tiene precios parecidos a los de otras regiones de AWS, normalmente algo más altos, y solo algunos servicios y las funciones más recientes están disponibles allí. El cumplimiento es una responsabilidad compartida, por lo que los clientes deben configurar y operar bien sus cargas de trabajo. Entre los competidores están Microsoft Azure Government, Assured Workloads de Google Cloud y las regiones para gobiernos de Oracle. GovCloud encaja en organizaciones que deben mantener datos regulados dentro de un entorno estadounidense certificado.
