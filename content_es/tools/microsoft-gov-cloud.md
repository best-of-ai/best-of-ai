Azure Government es un conjunto de regiones en la nube separado para organismos federales, estatales y locales de EE. UU. y sus socios. Funciona en centros de datos atendidos por personal estadounidense sometido a controles y está aislado de Azure comercial, lo que le permite cumplir normas aplicables a datos gubernamentales sensibles.

Las agencias lo usan para las tareas habituales en la nube, como alojar aplicaciones, analizar datos y utilizar IA. Servicios como Azure OpenAI y Copilot están disponibles en versiones que cumplen los requisitos gubernamentales, lo que permite a las agencias usar IA generativa con protecciones para sus datos.

Los precios siguen el modelo de pago por uso de Azure, con ofertas específicas para gobiernos. Los nuevos servicios suelen llegar a las regiones gubernamentales después que a las comerciales. Entre sus alternativas están AWS GovCloud, Google Public Sector, Oracle Government Cloud y las ofertas de IBM para gobiernos. Microsoft Azure Government conviene a agencias y contratistas que necesitan una nube conforme a la normativa.
