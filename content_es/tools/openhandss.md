OpenHands ofrece una alternativa abierta a los agentes comerciales de programación. El usuario le asigna una tarea y el agente trabaja en un entorno aislado con terminal, editor y navegador. Da los pasos necesarios para completarla y muestra lo que hace. Puede resolver issues de GitHub y abrir pull requests.

El proyecto comenzó como OpenDevin, una respuesta de código abierto a la demostración de Devin, y creció hasta convertirse en una plataforma comunitaria dirigida por All Hands AI. Admite modelos de muchos proveedores, tiene una herramienta de línea de comandos y una interfaz web, y se usa en investigación y benchmarks de agentes de programación.

OpenHands es gratuito y de código abierto, con una opción alojada en la nube. Los resultados del agente varían y necesitan revisión. Para ejecutarlo hace falta Docker y una clave de API. Entre las alternativas están Devin, Claude Code, OpenAI Codex, SWE-agent y Cline. OpenHands sirve a desarrolladores e investigadores que quieren un agente de programación abierto.
