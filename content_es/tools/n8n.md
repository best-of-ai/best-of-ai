n8n permite crear automatizaciones conectando nodos en un lienzo, como Zapier o Make, pero con más margen para el código. Cada nodo es un paso: un disparador como un webhook o un horario, una acción en una app o un bloque que transforma datos con JavaScript o Python. Incluye cientos de integraciones, y un nodo HTTP genérico cubre el resto. Los flujos pueden ramificarse, hacer bucles y llamar a otros flujos, así que sirve para cualquier cosa, desde notificaciones sencillas hasta elaborados flujos de datos.

La IA es ahora una parte importante del producto. n8n incluye nodos para modelos de lenguaje, herramientas, memoria y bases de datos vectoriales, con los que puedes crear agentes que leen correo, buscan en documentos, llaman a API y deciden qué hacer a continuación. Puedes ver cada ejecución paso a paso, añadir aprobación humana antes de acciones sensibles y cambiar de proveedor de modelos. Por eso es una forma popular de prototipar y operar agentes de IA sin escribir una aplicación completa.

El código está disponible en GitHub con una licencia fair-code, y puedes ejecutarlo tú mismo en un servidor o en Docker, lo que mantiene los datos en tu propio entorno. n8n Cloud es la opción alojada, con planes que escalan por ejecuciones, y los planes para empresas añaden inicio de sesión único, controles de acceso y registros de auditoría. Alojarlo uno mismo sale barato, pero implica encargarse de las actualizaciones, la seguridad y la disponibilidad. Zapier es más fácil para quienes no son técnicos, y Make es el rival visual más cercano.
