Cosine quiere comportarse como un compañero de equipo en un código base. Indexa el repositorio y luego asume tareas como corregir un error o añadir una función: planifica el trabajo, edita varios archivos y ejecuta pruebas. Explica su razonamiento por el camino para que el desarrollador pueda seguirlo e intervenir.

La empresa entrena sus propios modelos, llamados Genie, especializados en ingeniería de software a partir de datos sobre cómo trabajan los desarrolladores. Incluye una interfaz de línea de comandos, una extensión para el editor y una app web, y se integra con GitHub para los pull requests. También ofrece despliegues para organizaciones con requisitos de seguridad.

Cosine tiene un nivel gratuito y planes de pago. Las puntuaciones de benchmark citadas en el lanzamiento eran declaradas por la propia empresa, así que conviene probarlo con tu código. Entre las alternativas están Claude Code, Cursor, Codex, Devin y el agente de GitHub Copilot. Cosine sirve a desarrolladores que quieren un agente de programación especializado.
