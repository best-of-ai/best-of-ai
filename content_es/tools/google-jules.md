Jules está pensado para el estilo de programación asistida por IA en el que se delega. Enlazas un repositorio de GitHub, describes una tarea y Jules elabora un plan, trabaja en una máquina virtual segura en la nube y propone cambios mientras tú haces otra cosa. Clona el repositorio, instala dependencias, escribe código, ejecuta pruebas y te presenta el plan y los resultados para que los revises. Cuando lo apruebas, abre una pull request.

Se ocupa de trabajos rutinarios y bien definidos, como corregir errores, añadir pruebas, actualizar dependencias, mejorar la documentación e implementar funciones pequeñas. Puedes ejecutar varias tareas en paralelo, revisar el plan antes de que empiece y dar comentarios mientras trabaja. Funciona con los modelos Gemini de Google y se integra con los issues de GitHub y con la línea de comandos.

Jules tiene un nivel gratuito con un número limitado de tareas al día y niveles de pago con límites más altos, dentro de los planes de IA de Google. Como otros agentes, rinde mejor con tareas concretas y en repositorios que tienen pruebas, y puede tener dificultades con cambios ambiguos o muy grandes. Es imprescindible que una persona revise el resultado. OpenAI Codex, el agente de programación de GitHub Copilot, Devin y Claude Code son comparables, y los agentes en segundo plano de Cursor ofrecen un estilo parecido dentro de un editor. Google también ofrece Gemini CLI y Gemini Code Assist para ayuda interactiva.
