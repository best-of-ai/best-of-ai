Graphite se basa en un flujo de trabajo en el que los cambios grandes se dividen en pull requests pequeños y dependientes. Este enfoque de pull requests apilados, popular en las grandes tecnológicas, permite seguir con la siguiente pieza sin esperar a que se revise y se fusione la anterior. Graphite ofrece una herramienta de línea de comandos y una interfaz web que facilitan la gestión de las pilas, algo que GitHub por sí solo resuelve con torpeza.

Añade funciones alrededor de la revisión. Una cola de fusión mantiene sana la rama principal al probar y fusionar los cambios en orden, una bandeja de entrada ayuda a los revisores a ver qué requiere su atención y las métricas muestran cuánto tardan las revisiones. Un revisor de IA comenta los pull requests para detectar errores y problemas de estilo, algo que importa cada vez más a medida que los asistentes de IA escriben más código.

Cursor adquirió Graphite para acercar la revisión al editor, y el producto sigue funcionando con repositorios de GitHub. Tiene un nivel gratuito para particulares y planes de pago para equipos. Adoptar los pull requests apilados cambia hábitos, así que el equipo tiene que estar convencido. Entre las alternativas están las herramientas nativas de GitHub, CodeRabbit, Greptile, Reviewable y los flujos al estilo Phabricator. Graphite encaja con equipos que quieren una revisión de código más rápida y limpia.
