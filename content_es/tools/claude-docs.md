Claude Docs lleva la redacción de documentos al chat. En lugar de copiar una respuesta de la conversación a otra app, le pides a Claude que redacte un informe, un memorando o un plan, y aparece como un documento que puedes editar junto a la conversación. Puedes revisarlo escribiendo los cambios directamente o pidiéndole a Claude que reescriba secciones.

Los documentos se guardan en la pestaña Artifacts, así que es fácil encontrarlos más tarde y actualizarlos entre sesiones. Cuando el borrador está listo, se puede exportar a formatos habituales como Word, PDF, Google Docs o Markdown. La herramienta maneja títulos, listas y tablas, y trabaja con los archivos y el contexto compartidos en la conversación.

Claude Docs forma parte de Claude y está disponible en los planes de pago. Se ha ido lanzando en beta, así que las funciones pueden cambiar. Como con cualquier borrador de IA, hay que comprobar los datos y las cifras antes de compartirlo. Entre las alternativas están Google Docs con Gemini, Microsoft Word con Copilot, Notion AI y el canvas de ChatGPT. Claude Docs encaja con quienes redactan en Claude y quieren un documento terminado.
