Factory vende agentes de IA para equipos de ingeniería. Los Droids reciben tareas desde tickets o chat, exploran un código base, hacen cambios, ejecutan pruebas y abren pull requests para su revisión. Hay Droids especializados en trabajos distintos, como la revisión de código, la respuesta a incidentes o las migraciones.

El producto funciona con una herramienta de línea de comandos, integraciones con IDE y una interfaz web, y se conecta con GitHub, Jira, Slack y otras herramientas para que los agentes encajen en los flujos de trabajo existentes. Las funciones para empresas abordan la seguridad, los permisos y la elección de modelo, con soporte para varios proveedores de modelos.

Factory es de pago, con planes por uso, y se dirige a equipos de ingeniería profesionales. Lo que producen los agentes necesita revisión y buenas pruebas. Entre las alternativas están Claude Code, OpenAI Codex, Devin, Cursor y el agente de GitHub Copilot. Factory encaja con organizaciones de ingeniería que automatizan tareas rutinarias de desarrollo.
