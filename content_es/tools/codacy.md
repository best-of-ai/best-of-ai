Codacy se conecta a repositorios de GitHub, GitLab y Bitbucket y analiza el código a medida que cambia. Ejecuta análisis estático en muchos lenguajes, comprueba problemas de estilo, errores, fallos de seguridad y complejidad, y publica los resultados como comentarios en los pull requests. Los equipos pueden fijar quality gates que bloquean las fusiones cuando el código no cumple los estándares acordados.

Los paneles muestran tendencias a lo largo del tiempo, como la cobertura de código, la duplicación y el número de problemas por repositorio, lo que ayuda a los responsables de ingeniería a ver si la calidad mejora. Las funciones de seguridad analizan dependencias y secretos, y las funciones de IA más recientes sugieren correcciones y ayudan a revisar el código que producen los asistentes de IA. Se integra con sistemas de CI y con IDE.

Codacy tiene un nivel gratuito para código abierto y equipos pequeños, y planes de pago por desarrollador. Como todo análisis estático, produce falsos positivos y necesita que las reglas se ajusten al equipo. Entre las alternativas están SonarQube, Code Climate, DeepSource, Snyk Code y el escaneo de código integrado de GitHub. Codacy es adecuado para equipos que quieren revisiones de calidad automáticas en su flujo de pull requests.
