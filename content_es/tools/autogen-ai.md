AutoGen hizo accesibles las aplicaciones multiagente. Los desarrolladores definen agentes con roles, como un programador, un revisor y un proxy de usuario, y los dejan conversar para resolver un problema. Los agentes pueden escribir y ejecutar código, llamar a herramientas y pedir información a las personas, y el framework gestiona el paso de mensajes entre ellos.

El proyecto nació en Microsoft Research y atrajo a una gran comunidad. Una herramienta visual, AutoGen Studio, permitía prototipar equipos de agentes sin código. Con el tiempo, Microsoft consolidó sus esfuerzos: dirigió los proyectos nuevos a Microsoft Agent Framework, que combina ideas de AutoGen y Semantic Kernel, y describió AutoGen como en modo de mantenimiento.

AutoGen sigue siendo gratuito y de código abierto, y un fork de la comunidad llamado AG2 continúa el desarrollo con sus creadores originales. Para trabajo nuevo, conviene evaluar Microsoft Agent Framework o alternativas como LangGraph, CrewAI, OpenAI Agents SDK y el Agent SDK de Claude. Los proyectos existentes de AutoGen siguen funcionando, y AutoGen sirve para quienes mantienen sistemas antiguos o estudian patrones multiagente.
