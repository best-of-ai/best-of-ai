Codiga ofrecía análisis de código en tiempo real dentro del editor. Sus plugins para VS Code, los IDE de JetBrains y otras herramientas analizaban el código mientras se escribía en busca de vulnerabilidades de seguridad, errores e incumplimientos de estándares de programación, y un motor de reglas permitía a los equipos escribir sus propias comprobaciones. También ofrecía un asistente de fragmentos de código y, más tarde, sugerencias basadas en IA, y se integraba con plataformas Git para revisar pull requests automáticamente.

La empresa fue adquirida por Datadog, que quería llevar el análisis de código a su plataforma de observabilidad y seguridad. Los productos independientes de Codiga se cerraron poco después, con reembolsos para los suscriptores de pago, y el equipo se incorporó a Datadog. El motor de análisis estático y sus reglas sustentan ahora Datadog Code Security, y el analizador está disponible como código abierto.

Entre las herramientas similares, SonarQube, Semgrep, Snyk Code y CodeQL ofrecen análisis estático, mientras que herramientas de revisión con IA como CodeRabbit y Qodo se ocupan de los pull requests. Los equipos que usan Datadog pueden recurrir a sus funciones de seguridad de código integradas. Esta ficha se mantiene como referencia porque listas y tutoriales antiguos aún mencionan Codiga.
