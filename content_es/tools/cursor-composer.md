Composer fue la respuesta de Cursor a un límite básico de las primeras herramientas de programación con IA, que podían sugerir una línea o editar un archivo, pero fallaban con cambios que afectaban a varios. Describes una función o una refactorización, y Composer decide qué archivos hay que cambiar, escribe las ediciones y las muestra como diferencias para que las aceptes o rechaces. Puede crear archivos nuevos, actualizar importaciones y mantener coherente el código relacionado. Más tarde la función evolucionó hasta convertirse en el agente de Cursor, que además ejecuta comandos y corrige sus propios errores.

Composer es también el nombre que Cursor dio a sus propios modelos, entrenados para programar de forma ágil como agentes dentro del editor. Están pensados para ser lo bastante rápidos como para no sacar a quien programa de su ritmo mientras resuelven trabajo de varios pasos, y se ofrecen junto a modelos de proveedores como Anthropic, OpenAI y Google. Qué modelos hay disponibles y cuánto cuestan cambia a menudo.

Composer forma parte de Cursor, así que usarlo implica trabajar en el editor de Cursor, una bifurcación de VS Code, con un nivel gratuito y planes de pago que incluyen una cuota de uso. Los cambios grandes siguen necesitando una revisión cuidadosa, porque un modelo puede editar muchos archivos de forma que compile pero se le escape la intención. Entre las alternativas para editar varios archivos con IA están Cascade de Windsurf, el modo agente de GitHub Copilot, Cline y Claude Code.
