Bito empezó como un asistente de chat y autocompletado de código dentro de los IDE VS Code y JetBrains, y como herramienta de línea de comandos. Podías pedirle que explicara una función, escribiera pruebas unitarias, encontrara errores o generara documentación, y usaba el modelo que tú eligieras para las respuestas. Su atractivo inicial era práctico: prompts reutilizables para tareas comunes y compatibilidad con el contexto de tu proyecto.

El producto se ha centrado cada vez más en la revisión de código. El AI Code Review Agent examina pull requests en GitHub, GitLab y Bitbucket, deja comentarios sobre problemas como errores, fallos de seguridad e incumplimientos de estilo, y resume el cambio para quienes revisan. Construye un modelo de la base de código para que sus comentarios tengan en cuenta cómo encaja el código modificado con el resto, lo que ayuda a reducir el ruido. Los equipos lo usan para acelerar las revisiones y detectar problemas antes.

Bito tiene un nivel gratuito y planes de pago para particulares y equipos, con opciones para empresas que ofrecen más control sobre los datos. Los comentarios automáticos de revisión necesitan que una persona decida cuáles merecen atención, y las herramientas demasiado habladoras pueden molestar a los desarrolladores. Entre los competidores en revisión de código con IA están CodeRabbit, Qodo, Greptile y las funciones de revisión de GitHub Copilot, mientras que asistentes generales como Cursor y Copilot cubren la parte de escritura. Bito es un actor pequeño, pero enfocado.
