Gradio facilita enseñar un modelo a otras personas. Con unas pocas líneas de Python envuelves una función, por ejemplo una que recibe una imagen y devuelve un pie de foto, y Gradio genera una interfaz web con los componentes de entrada y salida adecuados: cuadros de texto, cargadores de imágenes, grabadoras de audio, deslizadores y más. Al ejecutar el script obtienes una app web local, y una opción para compartir crea un enlace público temporal, útil para demos y para recibir comentarios.

Ha crecido más allá de las demos sencillas. La API Blocks de Gradio permite crear interfaces más complejas y de varios pasos con diseños personalizados, y una clase de interfaz de chat crea chatbots con muy poco código. Cada app de Gradio expone además una API, y se puede usar desde código mediante bibliotecas cliente. Es compatible con el Model Context Protocol, así que una función de Gradio puede ofrecerse como herramienta a agentes de IA. Muchos artículos de aprendizaje automático y modelos abiertos enlazan a una demo de Gradio.

Gradio es gratuito y de código abierto con licencia Apache 2.0, y el alojamiento en Hugging Face Spaces es gratis para un uso básico, con hardware de pago para demos más pesadas. Está pensado para demos, herramientas internas y prototipos, así que las aplicaciones grandes en producción suelen necesitar un framework web propiamente dicho. Streamlit es la alternativa más cercana y es popular para apps de datos, Panel y Dash sirven para dashboards, y Chainlit se centra en aplicaciones de chat. Gradio es la opción por defecto para demos de modelos.
