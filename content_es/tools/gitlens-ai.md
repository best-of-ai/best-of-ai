GitLens enriquece VS Code con el historial de Git. Muestra anotaciones de blame en línea que indican quién cambió una línea por última vez, cuándo y en qué commit, y permite explorar el historial de un archivo, una línea o una rama sin salir del editor. Entre sus funciones hay un gráfico de commits, comparaciones entre ramas y un Launchpad que reúne pull requests e issues. Es una de las extensiones más descargadas de VS Code.

Las funciones de IA ayudan con las tareas habituales de Git. GitLens puede escribir mensajes de commit a partir de los cambios preparados, resumir en lenguaje llano lo que cambió un commit o una rama y ayudar a redactar descripciones de pull requests, con lo que se ahorra tiempo en documentación. Admite varios proveedores y modelos de IA, con opciones sobre cómo se envían los datos.

GitLens tiene un nivel gratuito con muchas funciones y planes de pago para capacidades avanzadas como Launchpad y los espacios de trabajo, dentro del ecosistema de GitKraken. Los resúmenes de la IA deben contrastarse con el diff real. Entre las alternativas están las funciones de Git integradas en VS Code, la generación de mensajes de commit de GitHub Copilot, GitKraken Client, Sourcetree y Lazygit para la terminal. GitLens sirve a desarrolladores que trabajan en VS Code y quieren conocer mejor el historial de su código.
