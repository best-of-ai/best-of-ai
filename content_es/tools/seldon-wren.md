Wren es el producto de control de calidad de software de Seldon, un laboratorio de investigación aplicada que crea modelos de cómo razonan y deciden las personas. Defines las pruebas en lenguaje natural y los agentes exploran los caminos de tu app, incluidos algunos que una prueba con guion nunca recorrería. Cada hallazgo incluye un recorrido grabado para que veas lo que ocurrió.

Detecta diseños rotos, llamadas a API fallidas y totales incorrectos. Los otros productos de Seldon son Finch, para investigación de usabilidad y UX, y Rook, que es solo para trabajos de gobierno y defensa. El pie de página menciona SOC 2, RGPD, HIPAA e ISO 27001.

Wren cobra por cada prueba completada, después de una prueba gratuita de 14 días. No hay tarifas por puesto, y el uso de modelos y la ejecución del navegador están incluidos. Hay precios por volumen para empresas. Encaja con equipos de ingeniería y de control de calidad que quieren cobertura exploratoria además de las pruebas con guion.
