Neon rehízo Postgres para la nube separando el almacenamiento del cómputo. Ese diseño permite que una base de datos escale hacia arriba bajo carga y hacia abajo hasta cero cuando está inactiva, así que se paga por el uso en vez de mantener un servidor encendido. Los desarrolladores obtienen Postgres estándar, lo que significa que funcionan las herramientas, controladores y extensiones existentes, incluido pgvector para guardar embeddings en aplicaciones de IA.

Su función más destacada es la ramificación. Como el almacenamiento es de copia en escritura, se puede crear una copia completa de una base de datos en segundos, como una rama de Git, para probar una migración, montar un entorno de previsualización por cada pull request o dar a cada desarrollador una copia aislada. Esa misma capacidad hace que Neon resulte atractivo para agentes de programación con IA y plataformas que levantan muchas bases de datos de corta vida. Hay agrupación de conexiones, réplicas de lectura e integraciones con Vercel y otras plataformas.

Neon tiene un nivel gratuito adecuado para proyectos pequeños, con planes de pago según el uso. Databricks adquirió Neon para dar soporte a bases de datos para agentes de IA y dijo que el servicio seguiría. Los arranques en frío tras escalar a cero pueden añadir un pequeño retraso, y los costes dependen del tiempo de cómputo y del almacenamiento. Supabase ofrece Postgres con un conjunto de herramientas de backend más amplio, PlanetScale y AWS Aurora Serverless compiten con él y CockroachDB atiende necesidades distribuidas. Neon es una opción popular para aplicaciones web modernas.
