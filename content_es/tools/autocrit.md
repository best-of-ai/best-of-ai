AutoCrit es una herramienta de edición para novelistas. El escritor pega un capítulo o sube un manuscrito, y el software informa sobre lo que buscan los editores: palabras y frases repetidas, adverbios, palabras de filtro, clichés, variedad de frases y diálogos. Los informes resaltan el texto para que veas dónde revisar.

Su rasgo distintivo es la comparación con ficción publicada. Mide un manuscrito frente a patrones de libros de éxito del mismo género, como el ritmo y el equilibrio entre diálogo y descripción, para que el escritor vea en qué se diferencia su borrador. Las funciones generativas ofrecen sugerencias para revisar y para generar ideas, y una biblioteca de guías ayuda con el oficio.

AutoCrit tiene un nivel gratuito y planes de pago. Los comentarios automáticos aplican reglas y promedios, y la buena escritura a menudo los rompe, así que conviene usar los informes como pistas para pensar y no como órdenes. Entre las alternativas están ProWritingAid, Grammarly, Hemingway Editor, Sudowrite y un editor humano. AutoCrit sirve para escritores de ficción que revisan borradores.
