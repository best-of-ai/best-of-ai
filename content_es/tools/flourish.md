Flourish hace accesible la narración con datos. Los usuarios suben una hoja de cálculo, eligen una plantilla como una carrera de barras, un diagrama de dispersión, una jerarquía, un mapa o una historia con desplazamiento, y personalizan colores, etiquetas y animaciones. El resultado es un gráfico interactivo que se puede insertar en un sitio web o artículo, o exportar como imagen o vídeo.

Su mayor atractivo es la biblioteca de plantillas, que incluye formatos difíciles de construir a mano, como las carreras de gráficos animadas y las historias de datos que cambian a medida que el lector se desplaza. Los equipos pueden configurar temas de marca, colaborar en proyectos y actualizar los gráficos cuando cambian los datos. Redacciones y organizaciones lo usan para publicar gráficos claros con rapidez.

Canva adquirió Flourish, que sigue como producto independiente. Tiene un plan gratuito para proyectos públicos y planes de pago para proyectos privados y funciones de equipo. No es una herramienta completa de inteligencia empresarial y funciona mejor para presentar que para un análisis profundo. Entre las alternativas están Datawrapper, Tableau Public, Infogram y Observable. Flourish sirve para quienes quieren elementos visuales interactivos llamativos.
