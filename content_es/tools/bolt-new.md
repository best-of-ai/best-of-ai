Bolt.new convierte una conversación en una aplicación que funciona. Escribes lo que quieres, por ejemplo un sitio de reservas, un dashboard o un prototipo pequeño de SaaS, y Bolt escribe el código, instala las dependencias y ejecuta el resultado en una vista previa en vivo dentro del navegador. Puedes seguir pidiendo cambios y él edita el proyecto sobre la marcha. Está construido sobre el entorno de desarrollo en el navegador de StackBlitz, así que no hay que instalar nada en el ordenador.

Además de generar código, cubre el trabajo que rodea al despliegue. Bolt Cloud ofrece alojamiento, dominios propios, bases de datos, autenticación de usuarios y analítica, de modo que un proyecto puede salir en producción desde la misma pantalla. Puedes empezar desde un prompt, un diseño de Figma, un repositorio de GitHub o una plantilla de equipo. La IA elige un modelo adecuado para la tarea y prueba y revisa su propio trabajo para reducir errores. También puedes descargar el código o abrirlo en un editor para seguir a mano.

Bolt tiene una forma gratuita de empezar, con planes de pago que añaden uso, modelos de gama alta y funciones para equipos. Cada prompt consume tokens, así que las iteraciones largas en un proyecto grande pueden agotar la cuota rápido, y las apps complicadas quizá necesiten a un desarrollador para terminarlas. Lovable, v0 y Replit son las alternativas habituales. Bolt funciona mejor para prototipos, herramientas internas y páginas de aterrizaje.
