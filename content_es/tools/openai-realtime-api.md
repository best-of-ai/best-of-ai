La Realtime API cambia la forma de crear aplicaciones de voz. Los sistemas anteriores encadenaban reconocimiento de voz, un modelo de lenguaje y síntesis de voz, lo que añadía retrasos en cada paso. La Realtime API procesa directamente la entrada y la salida de audio en un solo modelo, de modo que las respuestas empiezan antes y pueden incluir tonos, pausas e interrupciones más naturales.

Los desarrolladores se conectan mediante WebRTC o WebSockets para transmitir audio y recibir voz, texto y llamadas a herramientas. Admite llamadas a funciones, así que un agente de voz puede consultar datos o ejecutar acciones. Sirve para agentes telefónicos, asistentes integrados en apps y práctica de idiomas.

La API se factura según el uso y cuesta más que las llamadas de solo texto. Los agentes de voz requieren atención a la latencia, las interrupciones y la seguridad. Entre las alternativas están Gemini Live API de Google, los agentes conversacionales de ElevenLabs, Vapi, Retell AI y Twilio ConversationRelay. OpenAI Realtime API sirve a desarrolladores que crean experiencias de voz.
