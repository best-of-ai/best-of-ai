Qodo nació como CodiumAI con el foco en las pruebas y se ha ampliado a la calidad en todo el proceso de desarrollo. En el IDE analiza una función, entiende su comportamiento y genera pruebas unitarias que cubren los casos normales, los casos límite y los modos de fallo, lo que ayuda a subir la cobertura sin escribirlo todo a mano. También ofrece chat y sugerencias de código que tienen en cuenta el contexto del proyecto.

La parte de revisión es muy importante. Qodo Merge, basado en una herramienta de código abierto llamada PR-Agent, comenta las pull requests con resúmenes, posibles errores, problemas de seguridad y correcciones sugeridas, y puede aprender los estándares de un equipo para que las revisiones reflejen sus reglas internas. Los sistemas de revisión con varios agentes y un motor de contexto buscan entender grandes bases de código, algo que importa a los equipos de empresa con muchos repositorios. Las integraciones cubren GitHub, GitLab, Bitbucket y los principales IDE.

Qodo tiene un nivel gratuito para uso individual y de código abierto, y planes de pago para equipos y empresas, con opciones de despliegue en local. Las pruebas generadas y los comentarios de revisión requieren criterio, porque algunas pruebas solo confirman el comportamiento actual, errores incluidos. Entre los competidores están CodeRabbit, Greptile, la revisión de GitHub Copilot, Bito y Sourcery para revisiones, y Diffblue para pruebas unitarias en Java. Qodo encaja con equipos que quieren mejorar la calidad del código a medida que crece el código generado por IA.
