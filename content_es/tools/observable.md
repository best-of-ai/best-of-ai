Los usuarios escriben código en cuadernos y los gráficos se actualizan a medida que cambian los datos. Observable Plot ofrece una API concisa para gráficos, y Observable Framework genera apps de datos estáticas. Los equipos comparten cuadernos y paneles.

Requiere algo de conocimiento de JavaScript, lo que supone una barrera para quienes no programan.

Datawrapper y Flourish son alternativas no-code. Observable es para especialistas en visualización de datos que programan.
