Sonar permite a los desarrolladores crear aplicaciones que responden preguntas con información actual de la web. En lugar de depender solo de los datos de entrenamiento de un modelo, una petición a Sonar busca en la web, lee las páginas relevantes y devuelve una respuesta con citas. Ese anclaje en fuentes es útil para asistentes, herramientas de investigación, resúmenes de noticias y cualquier producto donde importen la actualidad y las fuentes.

Hay varias variantes. Los modelos Sonar estándar son rápidos y baratos, Sonar Pro maneja consultas más complejas con más fuentes, Sonar Reasoning añade análisis paso a paso y Sonar Deep Research ejecuta trabajos de investigación de varios pasos y redacta informes más largos. Una Search API ofrece resultados web ordenados para desarrolladores que quieren pasar contenido a sus propios modelos. La API sigue un formato conocido para quienes usan la de OpenAI, así que adoptarla es sencillo, y hay opciones para controlar qué dominios consultar y cuán recientes deben ser los resultados.

Sonar se factura por tokens más un cargo por cada búsqueda, con tarifas distintas según el modelo y la profundidad de búsqueda, y no tiene un nivel gratuito significativo. Los costes se acumulan en aplicaciones de mucho volumen, y las respuestas aún pueden contener errores o apoyarse en fuentes débiles. Entre las alternativas están los modelos con búsqueda integrada de OpenAI y Google, Exa y Tavily para APIs de búsqueda, la API de Brave Search y la herramienta de búsqueda web de Anthropic para Claude. Sonar encaja en equipos que quieren un servicio listo de búsqueda más LLM.
