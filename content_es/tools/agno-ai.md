Agno, antes llamado Phidata, busca que crear agentes sea sencillo y rápido. Un desarrollador define un agente en pocas líneas: elige un modelo, le da instrucciones y herramientas, y opcionalmente le añade memoria y una base de conocimiento. Los agentes pueden buscar en la web, consultar bases de datos, llamar a API y trabajar con texto, imágenes y audio. Se pueden combinar varios agentes en equipos que colaboran en tareas complejas.

El framework da prioridad al rendimiento y al uso en producción. Está diseñado para iniciar agentes rápidamente y usar poca memoria, lo que ayuda cuando se ejecutan muchos a la vez, e incluye funciones como el almacenamiento de sesiones, la recuperación desde bases de datos vectoriales, las salidas estructuradas y los pasos de razonamiento. AgentOS, una capa de runtime, permite a los equipos servir agentes mediante una API con una interfaz de control, y las herramientas de monitorización muestran las ejecuciones y el rendimiento.

Agno es gratuito y de código abierto, con funciones de pago opcionales en la nube para el despliegue y la gestión. Como otros frameworks de agentes, avanza deprisa, así que las API y las buenas prácticas cambian. LangGraph da un control de más bajo nivel, CrewAI pone el acento en equipos basados en roles, y el OpenAI Agents SDK y el ADK de Google son opciones respaldadas por proveedores. Agno encaja con desarrolladores de Python que quieren una forma limpia y rápida de crear agentes.
