Windsurf lo creó el equipo de Codeium como un editor diseñado en torno a la IA desde el principio, en contraste con añadir asistentes a un IDE existente. Su agente Cascade entiende el proyecto, edita varios archivos, ejecuta comandos de terminal y razona sobre los cambios mientras tú lo ves. Una función rápida de completado con Tab predice lo que vas a escribir, y las vistas previas permiten ver una app web en ejecución dentro del editor y pedir cambios de forma visual. Partió de VS Code, así que las extensiones y los ajustes se conservan.

La propiedad ha cambiado. Cognition, creadora del agente de software Devin, adquirió Windsurf, y el producto se presenta ahora como Devin Desktop. Funciona como un centro de mando para ejecutar agentes locales y en la nube en paralelo, con una vista estilo kanban, traspaso de sesiones de local a la nube, revisión de código integrada y compatibilidad con distintos agentes y modelos. El IDE completo sigue disponible, y Cognition asegura que los planes y ajustes actuales se mantienen.

Hay un plan gratuito y niveles de pago para particulares, equipos y empresas, y los detalles de los límites de uso han cambiado a medida que el producto ha pasado de manos. Quien lea reseñas antiguas debe tener en cuenta que describen el producto con su nombre y propietario anteriores. Cursor es el competidor más cercano, y GitHub Copilot, Cline y Claude Code también cubren la programación agéntica. Los equipos que valoran el autoalojamiento y unos controles de datos estrictos deberían revisar las opciones actuales para empresas.
