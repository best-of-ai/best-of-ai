CodeWhisperer fue el primer asistente de programación de Amazon, un equivalente de GitHub Copilot que sugería líneas y funciones completas mientras escribías en editores como VS Code y los IDE de JetBrains. Se entrenó con especial atención a las APIs de AWS, por lo que era especialmente bueno con código que llamaba a S3, Lambda, DynamoDB y otros servicios de AWS. También admitía muchos lenguajes de programación populares.

Dos funciones lo distinguían de los primeros rivales. Un rastreador de referencias señalaba las sugerencias que se parecían a código de código abierto y mostraba la licencia, y un análisis de seguridad revisaba tu código en busca de vulnerabilidades como credenciales expuestas y fallos de inyección. Un nivel individual era gratuito, y un nivel profesional añadía controles de administración y límites más altos.

AWS ha fusionado desde entonces CodeWhisperer en Amazon Q Developer, un asistente más amplio que añade chat, agentes que resuelven tareas de varios pasos, transformación de código y ayuda dentro de la consola de AWS. Si buscas el producto hoy, Q Developer es el que conviene evaluar, y el nombre original sobrevive sobre todo en documentación y entradas de blog antiguas. Entre las alternativas están GitHub Copilot, Cursor y JetBrains AI Assistant.
