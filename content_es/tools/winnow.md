Winnow apunta a un coste concreto de las cocinas profesionales: comida que se cocina y se tira. Su producto Vision se coloca sobre un cubo y registra cada descarte. La cámara identifica la comida, una báscula la pesa, y el sistema pone hora y foto al evento, así que el personal no tiene que anotarlo a mano.

Esos datos alimentan informes que muestran qué se desperdicia, cuándo y por qué. Un producto de previsión, Winnow Foresight, usa el historial para sugerir cuánto producir en cada servicio. Los planes van desde un seguimiento más simple con tableta hasta el sistema Vision, con cámara.

Entre los clientes hay operadores de restauración, hoteles, resorts, universidades y líneas de cruceros. Winnow no publica precios, pero ofrece una calculadora de ROI para estimar el ahorro. Está hecho para cocinas con volumen suficiente como para que el desperdicio sea una partida real, y resulta menos relevante para un café pequeño.
