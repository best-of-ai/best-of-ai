Hunchly es una extensión de navegador para investigaciones. Mientras la persona investigadora navega, guarda cada página tal como se veía, con capturas de pantalla, marcas de tiempo y valores hash que ayudan a demostrar que el contenido no se ha alterado. Las páginas se organizan en casos, de modo que las pruebas de una investigación larga se mantienen juntas.

La herramienta añade notas, etiquetas y una forma de buscar en el contenido capturado. Se pueden generar informes para compartirlos o para uso legal. Es popular entre investigadores de inteligencia de fuentes abiertas, periodistas y analistas de fraude y de las fuerzas del orden que necesitan conservar contenido que puede desaparecer.

Hunchly es una herramienta de pago, con licencia por usuario. Captura lo que ves, así que siguen aplicándose las normas de privacidad y legales sobre la recopilación de datos. Entre las alternativas están Webrecorder, Archive.today, Page Vault y Maltego para el análisis de vínculos. Hunchly es para investigadores que necesitan documentar de forma fiable su investigación en la web.
