Cline es un asistente de programación autónomo que vive en tu editor. Describes una tarea y la va resolviendo: lee los archivos relevantes, propone cambios, ejecuta comandos y comprueba el resultado. Tiene un modo Plan, en el que explora el proyecto y acuerda contigo un enfoque, y un modo Act, en el que lleva el plan a la práctica. Cada cambio de archivo y cada comando de terminal se te muestra para que lo apruebes, así que mantienes el control, aunque puedes activar la aprobación automática para acciones de menor riesgo.

Puede hacer bastante más que editar texto. Con una herramienta de navegador, puede lanzar la app que está construyendo, navegar por ella y mirar capturas de pantalla para detectar problemas. Admite el Model Context Protocol, de modo que puedes añadir herramientas como acceso a bases de datos o APIs propias. Los puntos de control (checkpoints) permiten devolver un proyecto a un estado anterior si una ejecución sale mal. Cline también está disponible como herramienta de línea de comandos y como SDK.

La extensión es gratuita y de código abierto bajo la licencia Apache 2.0, y tú aportas el modelo. Funciona con Anthropic, OpenAI, Google, AWS Bedrock, OpenRouter y modelos locales mediante Ollama o LM Studio. Pagas al proveedor por los tokens, y las sesiones con agentes pueden consumir muchos, así que el coste es variable. Roo Code y Kilo Code son forks que desarrollan la misma idea. Cursor y Claude Code son las alternativas comerciales más cercanas.
