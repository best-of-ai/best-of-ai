Se añaden botellas a una bodega virtual, se lleva el control de qué beber y cuándo, y se ven las notas agregadas de otros miembros. Los sumilleres usan las notas de la comunidad para juzgar cómo envejece un vino.

El servicio es gratuito con funciones de pago opcionales, y las notas las envían los usuarios.

Vivino tiene una base de usuarios ocasionales más grande. CellarTracker es adecuada para sumilleres y coleccionistas serios.
