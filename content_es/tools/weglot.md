Weglot permite que un sitio añada idiomas sin rehacerlo. Instalas un plugin o añades un fragmento de código, Weglot encuentra el texto de tus páginas, lo traduce con traducción automática y crea versiones del sitio en los idiomas que elijas. También añade un selector de idioma y se ocupa de las partes técnicas del SEO internacional, como las etiquetas hreflang y las URL traducidas.

El control de calidad se hace en un panel. Puedes editar cualquier traducción, usar un glosario para mantener igual los términos de marca y encargar traducciones profesionales a socios para las páginas clave. Las traducciones se guardan y se reutilizan, y la edición visual permite corregir el texto dentro del contexto de la página. Las funciones de IA mejoran la coherencia, y funciona con muchas plataformas populares.

Weglot es de pago, con planes según el número de palabras y de idiomas, y tiene un nivel gratuito para sitios muy pequeños. Como el contenido se guarda en el sistema de Weglot, dejarlo más adelante implica exportarlo. Entre las alternativas están Linguise, TranslatePress, WPML para WordPress, Localize y Smartling para grandes empresas. Weglot es adecuado para sitios pequeños y medianos que quieren una vía rápida para ofrecer varios idiomas.
