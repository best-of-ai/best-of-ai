Bruno forma parte del grupo de herramientas para enviar peticiones a APIs, junto a Postman e Insomnia. Su enfoque es distinto: las colecciones se guardan en un lenguaje de marcado de texto plano, como archivos en una carpeta, y no en la nube de un proveedor. Los equipos las suben a git, revisan los cambios en pull requests y mantienen las pruebas de la API junto al código que prueban.

Se pueden crear peticiones con variables, scripts y aserciones, ejecutar colecciones para hacer pruebas y usarlo desde una interfaz de línea de comandos en pipelines de CI. Admite REST, GraphQL y otros protocolos. Como funciona sin conexión y no exige cuenta, atrae a desarrolladores a quienes no gustan los inicios de sesión obligatorios ni la sincronización en la nube tras los cambios de otras herramientas.

Bruno es gratuito y de código abierto, con ediciones de pago que añaden funciones para equipos. Es más joven que Postman y tiene menos integraciones y funciones de colaboración. Entre las alternativas están Postman, Insomnia, Hoppscotch, Thunder Client y, para la línea de comandos, curl o HTTPie. Bruno es adecuado para desarrolladores que quieren herramientas de API que encajen con git.
