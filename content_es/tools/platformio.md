Los ingenieros configuran proyectos con un archivo de configuración y luego compilan, cargan y depuran el firmware. Funciona como extensión de VS Code. Incluye gestión de bibliotecas y pruebas unitarias.

El núcleo es de código abierto, con funciones de pago para equipos.

Arduino IDE y las herramientas de Zephyr son alternativas. PlatformIO es para ingenieros de sistemas embebidos que trabajan con muchas placas.
