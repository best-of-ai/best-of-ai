Muse Code es la propuesta de Meta para la programación con agentes. Un desarrollador lo inicia en la carpeta de un proyecto, describe una tarea y el agente explora el código, planifica cambios, edita archivos y ejecuta pruebas en todo el repositorio, en vez de trabajar en archivos sueltos. Utiliza un modelo de Meta ajustado para programar.

Meta lo presenta como una opción de menor coste frente a las herramientas de Anthropic y OpenAI, y se ejecuta desde la línea de comandos en macOS y Linux. Funciones como la ejecución paralela de subagentes están dirigidas a tareas más grandes. La herramienta se lanzó en beta, por lo que cabe esperar cambios.

El acceso se realiza mediante la API de modelos de Meta, y los precios y límites pueden cambiar. Las afirmaciones sobre benchmarks proceden de Meta y de informes secundarios, así que conviene probarlo con tu propio código. Entre sus alternativas están Claude Code, OpenAI Codex, Gemini CLI, Cursor y Kimi Code. Conviene a desarrolladores que quieren probar otro agente de terminal.
