Agent HQ es la forma que tiene GitHub de tratar a los agentes de programación como un equipo que se gestiona y no como un único asistente. En lugar de elegir un solo proveedor de IA, un desarrollador puede asignar trabajo a agentes de distintos proveedores, como Codex de OpenAI y Claude Code de Anthropic, desde el mismo lugar donde ya están el código, los issues y los pull requests. Cada agente trabaja en su tarea y devuelve los cambios para su revisión con el flujo habitual de pull requests.

Mission Control ofrece una vista central de lo que hace cada agente, de modo que el desarrollador ve qué tareas están en marcha, cuáles han terminado y cuáles necesitan atención. Plan Mode permite que un agente proponga sus pasos antes de escribir código, para que el desarrollador corrija el enfoque a tiempo. Como funciona en GitHub, la línea de comandos y VS Code, las mismas tareas pueden iniciarse y seguirse desde la superficie que mejor convenga.

Las organizaciones controlan qué agentes y modelos pueden usar sus equipos, y un dashboard de métricas muestra el uso y los resultados. El acceso depende de un plan de pago de Copilot, y algunos agentes pueden facturar solicitudes premium. Ejecutar varios agentes aumenta la cantidad de código que revisar, así que las prácticas de revisión importan más, no menos. Cursor y Devin ofrecen su propia gestión de agentes, y Claude Code y Codex pueden ejecutarse directamente. Agent HQ atrae sobre todo a los equipos que ya giran en torno a GitHub.
