v0 empezó como una herramienta para generar componentes de interfaz de usuario a partir de texto. Describías una tabla de precios o un dashboard y producía código React con estilos de Tailwind CSS y componentes de shadcn/ui que podías copiar en un proyecto. Desde entonces ha crecido hasta convertirse en un creador de apps completo: puedes pedirle páginas, formularios y lógica, subir un wireframe o una captura para recrearlos y ver cómo se actualiza una vista previa en vivo mientras afinas el resultado en la conversación.

Como lo hace Vercel, v0 funciona en estrecha relación con el ecosistema de Next.js. Puede conectarse a bases de datos y APIs, corregir sus propios errores, buscar información en la web y desplegar el proyecto terminado en Vercel con un clic. El código se puede sincronizar con GitHub o exportar, de modo que un desarrollador pueda seguir en un editor. Los equipos pueden compartir proyectos y usar sistemas de diseño, y una API permite que otras herramientas usen su generación.

v0 tiene un nivel gratuito con una asignación mensual de créditos y planes de pago con más créditos y funciones para equipos. El código generado suele ser limpio e idiomático, pero la lógica compleja, la autenticación y el manejo de datos siguen necesitando la revisión de un ingeniero. Rinde mejor en el desarrollo de front-end con React y Next.js y es menos adecuado para otros frameworks. Lovable, Bolt y Replit son competidores que crean apps más completas de principio a fin, y Cursor encaja mejor cuando trabajas sobre un código base ya existente.
