Los usuarios gratuitos pueden consultar el estado y el historial de los vuelos. Los productos para empresas incluyen API de datos de vuelo y herramientas que ayudan a los operadores con la planificación y las alertas. Sus datos combinan señales de radar, datos satelitales y receptores en tierra.

El personal de operaciones lo usa para vigilar retrasos y rastrear aeronaves. Como otros rastreadores públicos, es informativo y no sustituye a los sistemas oficiales de control de tráfico aéreo.

Flightradar24 es la principal alternativa. FlightAware sirve para despachadores, operadores y desarrolladores que necesitan datos de vuelo.
