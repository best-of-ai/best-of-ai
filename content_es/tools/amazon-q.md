Amazon Q Developer es el sucesor de CodeWhisperer y está construido en torno al conocimiento de AWS. En VS Code, JetBrains y otros IDE ofrece sugerencias de código en línea y un panel de chat que explica código, escribe pruebas y optimiza funciones. En la terminal añade autocompletado y un chat que traduce lenguaje natural a comandos de shell. En la consola de AWS y en plataformas de chat como Slack, ayuda a diagnosticar servicios y explica por qué un recurso falla.

Sus funciones de agente se ocupan de trabajos más grandes. Un agente puede leer tu proyecto, planificar el trabajo, editar varios archivos y ejecutar comandos para completar una función, escribir documentación o revisar código. Agentes de transformación especializados actualizan versiones de Java y portan aplicaciones .NET para que funcionen en Linux, un trabajo tedioso en bases de código grandes. Un análisis integrado encuentra problemas de seguridad en el código y sugiere correcciones.

Un nivel gratuito ofrece un uso mensual limitado, y un plan Pro de pago sube los límites y añade controles de administración, incluida la promesa de que tu contenido no se usa para mejorar el servicio. AWS está desplazando su trabajo agéntico más reciente hacia Kiro, su propio IDE pensado para la IA, así que los plugins de Q Developer conviene verlos como una de varias opciones de AWS. Tiene más sentido para equipos que viven en AWS, mientras que GitHub Copilot y Cursor son rivales más generalistas.
