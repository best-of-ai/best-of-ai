AWS IoT Core es la puerta de entrada de los dispositivos del Internet de las cosas a AWS. Los dispositivos se conectan mediante MQTT, HTTPS y otros protocolos, se autentican con certificados y publican y reciben mensajes, y el servicio escala a miles de millones de dispositivos y billones de mensajes. Un registro de dispositivos hace el seguimiento de cada uno, y los Device Shadows guardan una copia del estado del dispositivo para que las aplicaciones puedan interactuar con él aunque esté desconectado.

Un motor de reglas procesa los datos entrantes y los envía a otros servicios de AWS como Lambda, S3, DynamoDB, Kinesis y SageMaker, de modo que se pueden almacenar, analizar o usar para activar acciones. Servicios relacionados se ocupan de la gestión de dispositivos, la monitorización de flotas, las actualizaciones por aire y la computación en el borde con AWS IoT Greengrass, que ejecuta código y modelos de aprendizaje automático en el propio dispositivo. Las funciones de seguridad incluyen políticas detalladas y herramientas de registro y monitorización.

AWS IoT Core se cobra por mensaje, por tiempo de conexión y por acciones de reglas, con un nivel gratuito. Montar un sistema IoT implica decisiones de hardware, firmware y conectividad ajenas a la nube, y los costes pueden variar según el volumen de mensajes. Entre las alternativas están Azure IoT Hub, las opciones de IoT de Google Cloud, que han cambiado con el tiempo, y plataformas como ThingsBoard y HiveMQ. AWS IoT Core encaja en equipos que crean productos conectados sobre AWS.
