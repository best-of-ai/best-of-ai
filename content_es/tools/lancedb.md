LanceDB es una base de datos para datos de IA. Guarda los vectores junto con los datos originales, como texto, imágenes y referencias a vídeo, y admite búsqueda por similitud, filtrado y búsqueda de texto completo. Al ser embebida, se ejecuta dentro de la aplicación sin servidor, de forma parecida a como SQLite funciona con datos relacionales.

El formato Lance lo hace eficiente con conjuntos de datos grandes: mantiene los datos en disco, admite versionado y permite un acceso aleatorio rápido, de modo que puede manejar colecciones que no caben en memoria. Una oferta en la nube y para empresas añade escalabilidad y servicio gestionado. Se usa para la recuperación en aplicaciones de IA y para gestionar datos de entrenamiento.

LanceDB es gratuito y de código abierto, con planes de pago en la nube. Es más joven que algunas alternativas. Entre ellas están Chroma, Qdrant, Pinecone, Weaviate y pgvector. LanceDB sirve a desarrolladores que construyen sistemas de recuperación y flujos de datos multimodales.
