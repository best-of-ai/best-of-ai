Heroku popularizó la idea de que desplegar una app debería ser fácil. Un desarrollador sube código a un repositorio Git y Heroku lo compila, lo ejecuta en contenedores ligeros llamados dynos y se encarga del enrutamiento, el escalado y los registros. Los complementos aportan bases de datos, caché, monitorización y otros servicios con unos pocos clics, de modo que un equipo pequeño puede mantener una app en producción sin gestionar servidores. Muchas apps de Ruby, Python, Node y Java empezaron allí.

Heroku ha ido añadiendo funciones de IA para desarrolladores. La inferencia gestionada permite que las apps llamen a modelos alojados a través de la plataforma, y las funciones de agentes ayudan a crear y ejecutar aplicaciones con IA junto a la app y la base de datos habituales, con el objetivo de mantener sencilla la experiencia de desarrollo. Heroku Postgres sigue siendo un producto central, con compatibilidad con pgvector para embeddings.

Heroku es de pago, con precios según el tipo de dyno y el uso de complementos. Los planes gratuitos terminaron hace unos años y los planes más baratos cuestan unos pocos dólares al mes. A gran escala resulta más caro que ejecutar sobre infraestructura en la nube directamente. Entre las alternativas están Render, Railway, Fly.io, Vercel y Netlify para el front end, y Google Cloud Run o AWS App Runner. Heroku sirve a equipos que valoran la sencillez y un ecosistema maduro.
