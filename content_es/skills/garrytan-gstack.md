Este repositorio reúne los siguientes skills:

- **office-hours**: Hace preguntas directas sobre una idea de producto antes de escribir código.
- **plan-ceo-review**: Revisa el alcance del proyecto y replantea el problema de fondo.
- **plan-eng-review**: Revisa la arquitectura, el flujo de datos y los planes de tests.
- **review**: Hace una revisión de código centrada en producción y aplica correcciones automáticamente.
- **qa**: Prueba la app en un navegador en vivo y genera tests de regresión.
- **ship**: Abre un pull request y monta un framework de tests si falta.
- **design-consultation**: Genera un sistema de diseño completo para el proyecto.
- **design-shotgun**: Produce varios mockups visuales para explorar direcciones de diseño.
- **cso**: Hace una auditoría de seguridad basada en OWASP y STRIDE.
- **document-release**: Actualiza la documentación del proyecto automáticamente.
