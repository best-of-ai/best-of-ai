Este repositorio agrupa los siguientes skills:

- **Video to Super Prompt**: Convierte grabaciones de pantalla en prompts detallados para generar código.
- **HTML to Interaction Prompts**: Extrae prompts reutilizables de páginas HTML existentes.
- **Build Isometric ARPG**: Marco para el desarrollo de juegos de rol con Three.js.
- **Design Action Combat**: Arquitectura y ajuste de sistemas de juego de combate de acción.
- **Test Playable Web Games**: QA y validación de juegos en el navegador.
- **Landing Page**: Flujo de trabajo de diseño web y optimización de conversión.
- **Three.js**: Gráficos 3D y gestión de escenas WebGL.
- **Animation on Scroll**: Patrones de animación disparada por el scroll.
- **Shader Cursor Trail**: Efectos de interacción del cursor con WebGL.
- **Glass Dark Mode UI**: Sistema de diseño y lenguaje visual.
