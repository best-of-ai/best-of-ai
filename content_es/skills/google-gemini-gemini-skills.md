Este repositorio reúne los siguientes skills:

- **gemini-api-dev**: Cubre la generación de texto, el chat de varios turnos y el uso multimodal de la API de Gemini.
- **gemini-live-api-dev**: Cubre apps de streaming bidireccional en tiempo real sobre la Gemini Live API.
- **gemini-api-cli**: Llama a la API de Gemini desde la shell para generar medios y manejar archivos.
- **gemini-omni-flash-api**: Cubre la generación y la edición de vídeo a partir de referencias de texto, imagen y vídeo.
