Este repositorio reúne los siguientes skills:

- **motion-showreel**: Hace gráficos animados, títulos y movimiento de UI como vídeo MP4, con el código editable.
- **web-video-presentation**: Convierte un artículo o un guion en una presentación web 16:9 que se reproduce como un vídeo.
- **web-design-engineer**: Construye o rediseña páginas y paneles cuidados en HTML, CSS y React.
- **gpt-image-2**: Genera y edita imágenes con GPT Image 2 y ayuda a escribir prompts.
- **beautiful-article**: Convierte URLs, PDF, archivos DOCX o texto pegado en un artículo HTML de un solo archivo, sin conexión.
- **kb-retriever**: Busca en una carpeta local de base de conocimiento, incluidos PDF y hojas de cálculo, y responde preguntas.
