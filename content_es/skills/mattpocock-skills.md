Este repositorio agrupa los siguientes skills:

- **grill-with-docs**: Hace una sesión de planificación que construye un modelo de dominio y actualiza la documentación del proyecto.
- **triage**: Mueve issues por un flujo de trabajo de máquina de estados definido.
- **improve-codebase-architecture**: Examina una base de código e informa dónde se podría profundizar su arquitectura.
- **to-spec**: Convierte una conversación en una especificación escrita para un gestor de issues.
- **to-tickets**: Parte un plan en tickets pequeños y ordenados, con las dependencias anotadas.
- **implement**: Construye una función a partir de una especificación usando desarrollo guiado por pruebas.
- **wayfinder**: Planifica un trabajo grande como un conjunto de tickets de decisión enlazados.
- **prototype**: Construye un prototipo desechable para responder a una pregunta de diseño.
- **diagnosing-bugs**: Ejecuta un bucle estructurado para localizar fallos difíciles.
- **research**: Investiga una pregunta contra fuentes primarias.
- **domain-modeling**: Construye y afina el modelo de dominio de un proyecto.
- **code-review**: Revisa el código contra los estándares de programación y contra la especificación original.
