Este repositorio agrupa los siguientes skills:

- **baseline-ui**: Limpia código de UI descuidado corrigiendo espaciado, jerarquía y tipografía.
- **improve-ui**: Audita una pantalla de producto contra su propia evidencia de diseño y redacta los problemas comprobados.
- **fixing-accessibility**: Audita y corrige etiquetas ARIA, navegación por teclado, foco y contraste.
- **fixing-metadata**: Corrige títulos de página, meta descriptions, URLs canónicas y etiquetas Open Graph.
- **fixing-motion-performance**: Encuentra layout thrashing y otros problemas de rendimiento de la animación.
- **create-design-md**: Crea o actualiza un DESIGN.md a partir de un repositorio existente o de un sitio público.
- **component-canvas**: Construye un lienzo con desplazamiento y zoom para explorar componentes de UI y variantes.
