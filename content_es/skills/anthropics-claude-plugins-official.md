Este repositorio reúne los siguientes skills:

- **skill-creator**: Herramientas para escribir Agent Skills nuevos.
- **frontend-design**: Guía para construir una UI con intención y con carácter propio.
- **code-review**: Revisa un diff o un PR en busca de fallos de corrección y de calidad.
- **code-simplifier**: Simplifica y limpia código existente.
- **claude-security**: Plugin de seguridad para el uso de Claude Code.
- **pr-review-toolkit**: Un conjunto de herramientas para revisar pull requests.
- **hookify**: Ayuda a configurar los hooks de Claude Code.
- **mcp-server-dev**: Apoyo para desarrollar servidores MCP.
- **agent-sdk-dev**: Apoyo para construir con el Claude Agent SDK.
