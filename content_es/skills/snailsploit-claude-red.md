Este repositorio agrupa los siguientes skills:

- **offensive-active-directory**: Cubre el reconocimiento de Active Directory y la metodología de ataque en encargos internos de red team.
- **offensive-netexec**: Cubre el uso de NetExec para enumeración de red y post-explotación.
- **offensive-api-security**: Metodología para probar APIs REST, gRPC y WebSocket.
- **offensive-api-abuse**: Cubre el abuso de lógica de negocio y patrones de ataque de API más avanzados.
- **offensive-jwt**: Cubre ataques a JWT, como la confusión de algoritmo y secretos HMAC débiles.
- **offensive-cicd-pipeline**: Cubre debilidades de pipelines de CI/CD, incluida la inyección en GitHub Actions.
