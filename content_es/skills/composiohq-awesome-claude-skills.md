Este repositorio reúne los siguientes skills:

- **Connect**: Permite que Claude haga acciones reales en más de 1.000 apps, incluido el correo y Slack.
- **MCP Builder**: Guía el desarrollo de un servidor Model Context Protocol para una API externa.
- **Changelog Generator**: Construye un changelog para quien usa el producto, a partir del historial de commits de git.
- **Brand Guidelines**: Aplica la marca oficial de Anthropic a los artifacts generados.
- **Skill Creator**: Da orientación para escribir Claude Skills nuevos y que sirvan.
- **File Organizer**: Ordena archivos por contexto y señala duplicados.
- **Content Research Writer**: Investiga un tema y redacta secciones de contenido citadas y editadas.
- **Image Enhancer**: Mejora la resolución y la claridad de una imagen.
- **GitHub Automation**: Automatiza issues, pull requests y flujos de trabajo de GitHub.
- **Slack Automation**: Automatiza la mensajería y la gestión de canales de Slack.
