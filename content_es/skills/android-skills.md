Este repositorio reúne los siguientes skills:

- **camerax**: Guía funciones de cámara hechas con CameraX.
- **android-cli**: Explica cómo instalar y usar la herramienta de línea de comandos android.
- **appfunctions**: Encuentra flujos de la app para exponerlos como AppFunctions, por ejemplo crear una nota.
- **ml-kit-genai-prompt-api**: Añade la ML Kit GenAI Prompt API a una base de código Android.
- **mlkit-agent-api**: Construye flujos de agente en el dispositivo con la ML Kit GenAI Agent API.
- **restore-credentials**: Implementa Restore Credentials con la biblioteca Credential Manager.
- **verified-email**: Implementa la recuperación de correo verificado a través de Credential Manager.
- **android-for-cars-parked-apps**: Adapta apps de vídeo, juegos y navegador para que funcionen como apps en parado en Android Auto.
