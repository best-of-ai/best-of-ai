Este repositorio reúne los siguientes skills:

- **stitch::code-to-design**: Convierte código existente en un diseño de Stitch.
- **stitch::generate-design**: Genera un diseño nuevo a partir de un prompt.
- **stitch::manage-design-system**: Gestiona el sistema de diseño de un proyecto en Stitch.
- **stitch::react-components**: Genera componentes de React a partir de un diseño de Stitch.
- **stitch::react-native**: Genera código de React Native a partir de un diseño de Stitch.
- **remotion**: Genera código de vídeo de Remotion a partir de un diseño de Stitch.
- **shadcn-ui**: Genera componentes basados en shadcn/ui a partir de un diseño de Stitch.
- **enhance-prompt**: Skill de utilidad que afina un prompt de diseño antes de generar.
- **taste-design**: Skill de utilidad para evaluar la calidad del diseño.
