Este repositorio agrupa los siguientes skills:

- **building-secure-contracts**: Kit de seguridad para contratos inteligentes, con escáneres de vulnerabilidades.
- **c-review**: Revisión de seguridad de código C/C++ de amplio alcance.
- **differential-review**: Revisión diferencial de código, centrada en la seguridad.
- **rust-review**: Revisión de seguridad en Rust que cubre la seguridad de memoria y la concurrencia.
- **semgrep-rule-creator**: Redacción de reglas propias para detectar vulnerabilidades.
- **property-based-testing**: Escritura y revisión de pruebas basadas en propiedades.
- **supply-chain-risk-auditor**: Análisis de vulnerabilidades en dependencias y de quien las publica.
