Este repositorio reúne los siguientes skills:

- **docx**: Crea y edita documentos de Word.
- **pdf**: Crea, lee y edita archivos PDF.
- **pptx**: Crea y edita presentaciones de PowerPoint.
- **xlsx**: Crea y edita hojas de Excel.
- **mcp-builder**: Guía la construcción de un servidor Model Context Protocol.
- **webapp-testing**: Ayuda a Claude a probar una aplicación web.
- **skill-creator**: Un meta skill para crear Agent Skills nuevos.
- **brand-guidelines**: Aplica las guías de marca de Anthropic al resultado generado.
- **canvas-design**: Apoya la construcción de maquetaciones visuales al estilo canvas.
- **frontend-design**: Da orientación sobre decisiones de diseño visual del frontend.
- **algorithmic-art**: Genera arte algorítmico o generativo.
- **slack-gif-creator**: Crea GIF para usar en Slack.
- **doc-coauthoring**: Apoya la escritura y la edición colaborativa de documentos.
- **internal-comms**: Redacta notas internas y avisos para el equipo.
