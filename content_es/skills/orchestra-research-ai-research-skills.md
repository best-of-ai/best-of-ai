Este repositorio agrupa los siguientes skills:

- **LitGPT**: Skill para entrenar y hacer fine-tuning de modelos con el framework LitGPT.
- **Mamba**: Skill para trabajar con la arquitectura de modelo de espacio de estados Mamba.
- **Axolotl**: Skill para hacer fine-tuning de modelos de lenguaje con Axolotl.
- **PEFT**: Skill para métodos de fine-tuning eficientes en parámetros.
- **Unsloth**: Skill para fine-tuning rápido y eficiente en memoria.
- **TRL**: Skill para post-training basado en aprendizaje por refuerzo.
- **vLLM**: Skill para servir modelos con eficiencia.
- **llama.cpp**: Skill para ejecutar inferencia con llama.cpp.
- **LangChain**: Skill para construir flujos de trabajo de agentes con LangChain.
