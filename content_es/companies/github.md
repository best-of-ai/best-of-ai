El trabajo de GitHub en IA gira en torno a Copilot, que empezó como completado de código en línea y ahora cubre el chat, la revisión de código y un agente que toma issues y abre pull requests. Copilot se vende dentro de una suscripción de GitHub, con niveles más altos para un uso más intenso.

Agent HQ, anunciado en Universe en octubre de 2025 y desplegado de forma más amplia a principios de 2026, cambia el planteamiento. En lugar de ofrecer solo el agente de Microsoft, GitHub deja que los suscriptores asignen trabajo a agentes de programación de Anthropic, OpenAI, Google, Cognition y xAI. Una vista de Mission Control sigue lo que hace cada agente, y los administradores eligen qué agentes y modelos pueden usar sus equipos. El Codex de OpenAI fue el primer agente externo en aparecer, seguido de Claude Code.

Plan Mode, un panel de métricas y un paso de revisión integrado que comprueba el código del agente antes de que lo vea un desarrollador completan el conjunto. La apuesta de GitHub es que no necesitará construir el mejor agente si controla el lugar donde trabajan todos.
