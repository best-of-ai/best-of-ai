## Niemand bezahlt für einen Eintrag

Tools zahlen weder für eine Platzierung noch für einen höheren Rang. Jedes Tool wird vor der Aufnahme nach denselben Kriterien geprüft. Seine Position auf der Website richtet sich nach Kategorie, Rang oder Rangliste – niemals nach Sponsoring.

## So funktioniert die Rangliste

Jedes Tool erhält eine Qualitätsbewertung von 1 bis 10. Eine 10 ist Tools vorbehalten, die in ihrer Kategorie wirklich herausragend sind; neue Tools starten standardmäßig mit 5. Die Bewertung bestimmt die Sortierung innerhalb einer Kategorie und welche Tools in den Top-Empfehlungen einer Berufsseite erscheinen. Die [Rangliste](/leaderboard/) funktioniert ähnlich, bewertet Tools aber nach ihrem praktischen Nutzen statt nach Marketingausgaben.

## Was „handverlesen“ wirklich bedeutet

Ein Tool muss funktionieren, halten, was es verspricht, und die Zeit wert sein, bevor es auf die Website kommt. Tote Links, kaputte Demos und einfache Wrapper um die API eines anderen Anbieters lehnen wir ab – auch wenn sie anderswo gerade im Trend liegen.

## Warum Open Source hier wichtig ist

Jede Kategorie, jedes Tool und jede Regel für die Rangliste liegt in einem öffentlichen Repository. Alle können die Daten prüfen, eine Platzierung hinterfragen oder mit einem Pull Request einen Fehler korrigieren. Das schafft eine andere Form von Rechenschaft als bei typischen Bestenlisten, deren Auswahlregeln meist nur in den Köpfen ihrer Betreiber existieren. Mehr über die Abläufe erfährst du unter [So funktioniert die Website](/help/how-the-site-works/).
