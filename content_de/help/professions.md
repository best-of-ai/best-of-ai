## Was die Berufsseiten bieten

Statt nach Kategorie kannst du nach Beruf suchen: zum Beispiel nach Fotografie, Jura oder Recruiting. Jede Berufsseite zeigt alle Tools aus den Kategorien, die für den jeweiligen Beruf relevant sind.

## Wie ein Tool dort erscheint

Tools werden Berufsseiten nicht einzeln von Hand zugeordnet. Die Zuordnung ergibt sich aus der Kategorie. Für jeden Beruf sind relevante Kategorien hinterlegt; jedes Tool in einer dieser Kategorien erscheint automatisch auf der entsprechenden Berufsseite. Füge ein Tool zur Kategorie „Videobearbeitung“ hinzu, und es erscheint ohne weitere Schritte auf allen Berufsseiten, die diese Kategorie enthalten.

## Der Tab „Top-Empfehlungen“

Oben auf den meisten Berufsseiten gibt es einen kurzen Tab mit Top-Empfehlungen: eine kleinere, sorgfältig zusammengestellte Auswahl für den jeweiligen Beruf. Sie kombiniert handverlesene Tools mit den bestbewerteten Tools aus den passenden Kategorien. Darunter findest du die Kategorien mit der vollständigen, ungefilterten Auswahl.

## Dein Beruf fehlt?

Öffne auf [GitHub](https://github.com/best-of-ai/best-of-ai) ein Issue oder einen Pull Request und nenne den Beruf sowie die Kategorien, die dazugehören sollten. So kommen neue Berufsseiten hinzu.
