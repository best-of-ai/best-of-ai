Dieses Repository bündelt folgende Skills:

- **skill-creator**: Werkzeuge zum Erstellen neuer Agent Skills.
- **frontend-design**: Anleitung für unverwechselbare, bewusst gestaltete Benutzeroberflächen.
- **code-review**: Prüft Diffs und Pull Requests auf Korrektheit und Qualitätsprobleme.
- **code-simplifier**: Vereinfacht und bereinigt vorhandenen Code.
- **claude-security**: Sicherheitsorientiertes Plugin für die Nutzung von Claude Code.
- **pr-review-toolkit**: Werkzeugkasten für die Prüfung von Pull Requests.
- **hookify**: Unterstützt die Konfiguration von Claude-Code-Hooks.
- **mcp-server-dev**: Hilft bei der Entwicklung von MCP-Servern.
- **agent-sdk-dev**: Unterstützt die Entwicklung mit dem Claude Agent SDK.
