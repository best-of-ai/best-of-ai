Dieses Repository bündelt folgende Skills:

- **agent-watchdog**: Beobachtet, prüft oder korrigiert die Arbeit eines anderen Agenten anhand einer Sitzungs-ID.
- **efficient-orchestrator**: Erledigt größere Aufgaben mit einem koordinierenden Agenten, jedoch nur bei ausdrücklicher Aktivierung.
- **factory-collect**: Sammelt und sortiert Feedback, Telemetrie, Fehler und Probleme.
- **factory-babysit-pr**: Begleitet einen autorisierten Pull Request durch Prüfungen und Review.
- **factory-review-prs**: Prüft eine Warteschlange von Pull Requests anhand getrennter Kriterien für Antwort, Freigabe und Merge.
- **factory-human-digest**: Fasst offene Aufgaben zusammen, die menschliches Urteilsvermögen erfordern, über konfigurierte Repositories hinweg.
