Dieses Repository bündelt folgende Skills:

- **stitch::code-to-design**: Wandelt vorhandenen Code in ein Stitch-Design um.
- **stitch::generate-design**: Erstellt anhand eines Prompts ein neues Design.
- **stitch::manage-design-system**: Verwaltet das Designsystem eines Projekts in Stitch.
- **stitch::react-components**: Erstellt React-Komponenten anhand eines Stitch-Designs.
- **stitch::react-native**: Generiert React-Native-Code aus einem Stitch-Design.
- **remotion**: Erstellt Remotion-Videocode aus einem Stitch-Design.
- **shadcn-ui**: Erstellt Komponenten auf Basis von shadcn/ui.
- **enhance-prompt**: Verfeinert einen Design-Prompt vor der Generierung.
- **taste-design**: Bewertet die Designqualität.
