Dieses Repository bündelt folgende Skills:

- **office-hours**: Stellt gezielte Fragen zu einer Produktidee, bevor Code geschrieben wird.
- **plan-ceo-review**: Prüft den Projektumfang und formuliert das zugrunde liegende Problem neu.
- **plan-eng-review**: Prüft Architektur, Datenfluss und Testpläne.
- **review**: Führt eine produktionsorientierte Codeprüfung durch und setzt Korrekturen automatisch um.
- **qa**: Testet die App in einem Live-Browser und erstellt Regressionstests.
- **ship**: Öffnet einen Pull Request und richtet ein Testframework ein, falls noch keines vorhanden ist.
- **design-consultation**: Erstellt ein vollständiges Designsystem für das Projekt.
- **design-shotgun**: Erstellt mehrere visuelle Mockups, um verschiedene Gestaltungsrichtungen zu erkunden.
- **cso**: Führt ein Sicherheitsaudit anhand von OWASP und STRIDE durch.
- **document-release**: Aktualisiert die Projektdokumentation automatisch.
