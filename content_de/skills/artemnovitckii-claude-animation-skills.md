Dieses Repository bündelt elf Skills, darunter:

- **zach-d-films**: Erstellt ein 3D-Cartoon-Erklärvideo im Stil von „Was wäre, wenn“, mit Zeitlupen-Einschlägen und Untertiteln, die auf einen Sprechertext abgestimmt sind.
- **stick-figure**: Erstellt ein Erklär-Reel mit Strichmännchen, schnellen Übergängen, kurzen Untertiteln und per Code erzeugtem Ton.
- **minimalistic-graphics**: Erstellt Schwarzweiß-Strichzeichnungen als Animation, mit feinen Stufen und einem hüpfenden weißen Punkt.
- **map-route**: Animiert eine Route auf einer Karte aus einer kurzen Textanfrage.
