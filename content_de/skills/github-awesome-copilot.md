Dieses Repository bündelt folgende Skills:

- **acquire-codebase-knowledge**: Hilft einem Agenten, eine bestehende Codebasis zu verstehen.
- **azure-well-architected-review**: Bewertet eine Architektur anhand des Azure Well-Architected Frameworks.
- **aws-cost-optimize**: Sucht nach Möglichkeiten, Cloudkosten von AWS zu senken.
- **codeql**: Führt statische Sicherheitsanalysen mit CodeQL durch.
- **architecture-blueprint-generator**: Erstellt Dokumentation zur Systemarchitektur.
- **conventional-commit**: Setzt das Format für Conventional-Commits-Nachrichten durch.
- **agent-owasp-compliance**: Prüft Agentenverhalten anhand der OWASP-Sicherheitsrichtlinien.
- **copilot-pr-autopilot**: Automatisiert Teile des Pull-Request-Ablaufs.
- **anti-ui-slop**: Erkennt minderwertige oder generisch wirkende Oberflächenergebnisse.
