Dieses Repository bündelt folgende Skills:

- **grill-with-docs**: Führt eine Planungssitzung durch, erstellt ein Domänenmodell und aktualisiert Projektdokumente.
- **triage**: Bewegt Issues durch einen festgelegten Zustandsablauf.
- **improve-codebase-architecture**: Durchsucht eine Codebasis und zeigt Bereiche auf, deren Architektur weiterentwickelt werden könnte.
- **to-spec**: Wandelt ein Gespräch in eine schriftliche Spezifikation für ein Issue-Tracking-System um.
- **to-tickets**: Zerlegt einen Plan in kleine, geordnete Tickets und vermerkt Abhängigkeiten.
- **implement**: Entwickelt anhand einer Spezifikation mit testgetriebener Entwicklung eine Funktion.
- **wayfinder**: Plant umfangreiche Arbeit als verknüpfte Entscheidungstickets.
- **prototype**: Erstellt einen Wegwerf-Prototyp, um eine Designfrage zu beantworten.
- **diagnosing-bugs**: Führt eine strukturierte Schleife zur Untersuchung schwieriger Fehler aus.
- **research**: Untersucht eine Frage anhand von Primärquellen.
- **domain-modeling**: Erstellt und verfeinert das Domänenmodell eines Projekts.
- **code-review**: Prüft Code anhand von Coding-Standards und ursprünglicher Spezifikation.
