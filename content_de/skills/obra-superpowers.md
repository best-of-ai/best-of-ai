Dieses Repository bündelt folgende Skills:

- **test-driven-development**: Wendet den Red-Green-Refactor-Zyklus an und nennt häufige Anti-Patterns beim Testen.
- **systematic-debugging**: Führt eine Ursachenanalyse in vier Phasen durch.
- **verification-before-completion**: Bestätigt vor Abschluss einer Aufgabe, dass eine Korrektur tatsächlich funktioniert.
- **brainstorming**: Entwickelt eine grobe Idee durch sokratisches Fragen weiter.
- **writing-plans**: Erstellt einen in kleine Aufgaben unterteilten Umsetzungsplan.
- **executing-plans**: Setzt einen Plan in Abschnitten mit Prüfpunkten zur menschlichen Kontrolle um.
- **dispatching-parallel-agents**: Koordiniert mehrere parallel arbeitende Subagenten.
- **requesting-code-review**: Führt vor der Anfrage eines Code-Reviews eine Checkliste durch.
- **receiving-code-review**: Verarbeitet Rückmeldungen aus einem Code-Review und beantwortet sie.
- **using-git-worktrees**: Verwaltet parallele Arbeit in mehreren Git-Worktrees.
- **finishing-a-development-branch**: Entscheidet, wie ein Branch per Merge oder Pull Request abgeschlossen wird.
- **subagent-driven-development**: Führt eine zweistufige Prüfung auf Spezifikationstreue und Qualität durch.
- **writing-skills**: Meta-Skill mit einem Framework zum Schreiben neuer Skills.
