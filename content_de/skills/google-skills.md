Dieses Repository bündelt folgende Skills:

- **google-ads-api-quickstart**: Führt durch Zugangsdaten, die Wahl einer von sechs Clientbibliotheken oder REST und den ersten API-Aufruf.
- **google-ads-api-account-diagnostics**: Diagnostiziert Kontoprobleme wie verlorene Conversions oder geringe Lead-Zahlen.
- **google-ads-api-mcp-setup**: Installiert und konfiguriert den offiziellen Open-Source-Google-Ads-MCP-Server.
- **data-manager-api-setup**: Richtet Clientbibliotheken und Authentifizierung für die Data Manager API ein.
- **data-manager-api-event-ingestion**: Implementiert den Import von Ereignissen und Conversions über die Data Manager API.
- **data-manager-api-audience-ingestion**: Fügt Zielgruppenmitglieder über die Data Manager API hinzu, entfernt sie oder löscht sie.
- **google-mobile-ads-banner**: Fügt Android- und anderen mobilen Apps Google-Mobile-Ads-Banneranzeigen hinzu.
- **google-mobile-ads-android-migrate-to-next-gen**: Migriert eine Android-App vom älteren Google Mobile Ads SDK zur nächsten Generation.
