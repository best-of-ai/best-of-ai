Dieses Repository bündelt folgende Skills:

- **interview-me**: Arbeitet Anforderungen mit gezielten Fragen heraus.
- **spec-driven-development**: Verfasst ein PRD, bevor Code geschrieben wird.
- **constraint-driven-development**: Legt Qualitätsstandards für ein Projekt fest und setzt sie durch.
- **planning-and-task-breakdown**: Teilt eine Spezifikation in Aufgaben auf, die einzeln überprüft werden können.
- **incremental-implementation**: Liefert Arbeit in kleinen, getesteten vertikalen Abschnitten.
- **test-driven-development**: Wendet den Red-Green-Refactor-Zyklus an.
- **context-engineering**: Steuert, welche Informationen wann den Agenten erreichen.
- **doubt-driven-development**: Führt eine adversariale Codeprüfung durch.
- **frontend-ui-engineering**: Unterstützt Entscheidungen zu Komponenten- und Oberflächendesign.
- **api-and-interface-design**: Entwirft APIs und Schnittstellen nach dem Contract-first-Prinzip.
- **browser-testing-with-devtools**: Untersucht eine App zur Laufzeit mit Chrome DevTools.
- **code-review-and-quality**: Prüft Code anhand von fünf getrennten Qualitätsstufen.
- **security-and-hardening**: Prüft Code anhand der OWASP Top 10.
- **git-workflow-and-versioning**: Setzt einen trunk-basierten Git-Workflow durch.
- **shipping-and-launch**: Führt bei einer Veröffentlichung einen gestuften Rollout durch.
