Codex ist OpenAIs erstes speziell für Codegenerierung entwickeltes Modell. Es wurde im August 2021 angekündigt und basiert auf GPT-3, feinabgestimmt mit Milliarden öffentlich zugänglicher GitHub-Quellcodezeilen. Die größte veröffentlichte Version hatte 12 Milliarden Parameter und ein Kontextfenster von 4.096 Tokens. Im HumanEval-Benchmark löste sie beim ersten Versuch 28,8 Prozent der Aufgaben; bei 100 Versuchen pro Aufgabe stieg der Wert auf 77,5 Prozent. Codex trieb das ursprüngliche GitHub Copilot an, das 2021 als technische Vorschau startete. Damit gehörte es zu den ersten großen Einsätzen eines Sprachmodells als Programmierassistent statt als Chat- oder Vervollständigungsdemo. OpenAI bot es einige Jahre über eine private Beta-API an und stellte die eigenständige API im März 2023 ein. Die Fähigkeiten flossen in Nachfolger der GPT-3.5- und GPT-4-Familie ein. Der Name lebt als Marke für neuere agentische Programmierprodukte weiter; das ursprüngliche Codex-Modell ist über die API nicht mehr verfügbar.
