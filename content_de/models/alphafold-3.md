AlphaFold 3 ist ein Modell zur Strukturvorhersage, das Google DeepMind und Isomorphic Labs im Mai 2024 veröffentlichten. Es erweitert das frühere, auf Proteine beschränkte AlphaFold 2 auf eine viel größere Bandbreite biologischer Moleküle. Statt nur Proteinfaltungen vorherzusagen, modelliert es gemeinsam Komplexe aus Proteinen, DNA, RNA, kleinen Ligandenmolekülen, Ionen und chemisch modifizierten Resten. Die überarbeitete Architektur basiert auf einer Komponente namens Pairformer. Damit können Forschende in einer einzigen Vorhersage untersuchen, wie ein möglicher Wirkstoff an ein Protein bindet oder wie ein Protein mit einem RNA-Strang interagiert, ohne mehrere separate Werkzeuge zusammenführen zu müssen.

DeepMind stellte das Modell über den kostenlosen AlphaFold Server für nichtkommerzielle Forschung bereit. Im November 2024 veröffentlichte das Unternehmen auch den zugrunde liegenden Code und die Gewichte zur akademischen Nutzung; kommerzielle Nutzung läuft weiterhin über Isomorphic Labs. AlphaFold 3 wird häufig in der Strukturbiologie und frühen Wirkstoffforschung eingesetzt. Es überträgt DeepMinds frühere, mit dem Nobelpreis ausgezeichnete Arbeit zur Proteinstrukturvorhersage auf molekulare Wechselwirkungen, die für einen Großteil der Wirkstoffentwicklung und Krankheitsforschung entscheidend sind.
