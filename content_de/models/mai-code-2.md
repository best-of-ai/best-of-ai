Microsoft AI hat MAI Code 2 am 17. November 2026 auf der Ignite veröffentlicht. Es zielt auf alltägliches Programmieren im Unternehmen: Produktionscode, Debugging, Implementierung über mehrere Dateien, Schlussfolgern über ganze Repositories und UI-Arbeit. Laut Microsoft ist es noch nicht für grundlegende wissenschaftliche Forschung oder sehr langfristige agentische Aufgaben abgestimmt. Es ist in GitHub Copilot verfügbar, und die Seite nennt Kosten nur als Prozentwerte, dazu einen Aktionspreis von 50 Prozent.

Im Durchschnitt über DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas und FrontierCode v1.1 erreicht MAI Code 2 laut Microsoft 98 Prozent des Werts von GPT-6.1 Sol bei 40 Prozent der Kosten und 96 Prozent des Werts von Claude Opus 5.5 bei 5 Prozent der Kosten. In einem Blindtest für Frontend bevorzugten es 258 Annotator:innen in 64 Prozent der Fälle gegenüber GPT-6 Sol. Das sind Microsofts eigene Läufe.
