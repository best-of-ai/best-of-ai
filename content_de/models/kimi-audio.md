Kimi-Audio ist ein offenes Audio-Grundlagenmodell von Moonshot AI. Vortrainierte und instruction-tuned Checkpoints mit 7B Parametern erschienen Ende April 2025. Ein einzelnes Modell deckt Spracherkennung, Audioverständnis und Sprachgenerierung ab: Es kann Audio transkribieren, Fragen zu einem Audioausschnitt beantworten und gesprochene Ausgaben erzeugen, ohne dafür mehrere Modelle miteinander zu verbinden. Moonshot veröffentlichte zusammen mit dem Modell ein Evaluierungs-Toolkit. Gewichte und Code stehen unter Apache 2.0 auf GitHub und Hugging Face. Kimi-Audio ergänzt Kimi-VL und die textbasierten Modelle der Kimi-K-Reihe im Bestreben von Moonshot, spezialisierte Komponenten offen bereitzustellen, statt sämtliche Fähigkeiten hinter einer geschlossenen API zu halten. Entwicklern bietet es eine kostenlose, selbst hostbare Alternative zu kommerziellen Sprachmodellen wie Whisper von OpenAI und den Audiomodellen von Google.
