MAI Code 2 Flash ist das kleinere Geschwistermodell von MAI Code 2 und wurde am 17. November 2026 auf der Ignite angekündigt. Microsoft hat es für Aufgaben mit hohem Volumen gebaut, etwa Code-Erklärungen, gezielte Änderungen und Routinekorrekturen. Es ist in GitHub Copilot und in einer Vorschau mit begrenztem Zugang in Microsoft Foundry verfügbar.

Laut Microsoft ist der Benchmark-Durchschnitt mit GPT-6 Luna und Claude Haiku 5.5 vergleichbar, bei einem Bruchteil der Kosten, und Preise pro Token nennt Microsoft nicht. Aus Code 2 Flash wird ein abgeleitetes Modell, MAI Work Flash, gebaut, das in Microsoft 365 und FabricIQ läuft.
