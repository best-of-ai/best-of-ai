Mistral Large 3 ist Mistral AIs Spitzenmodell und erschien am 2. Dezember 2025 als Teil der umfassenderen Mistral-3-Reihe. Das sparse Mixture-of-Experts-Modell umfasst 675 Milliarden Parameter insgesamt, davon rund 41 Milliarden aktiv pro Token. So benötigt es ungefähr so viel Rechenleistung wie ein deutlich kleineres dichtes Modell und kann zugleich auf einen größeren Pool gelernter Gewichte zurückgreifen. Es verarbeitet Text und Bilder und unterstützt ein Kontextfenster von 256.000 Tokens. Mistral veröffentlichte die Gewichte unter Apache 2.0 und kehrte damit die bei Mistral Large 2 verfolgte geschlossene Strategie um.

Bei der Veröffentlichung landete das Modell in der LMArena-Rangliste offener Gewichte nahe der Spitze. Es richtet sich an Entwickler:innen, die Spitzenleistungen bei Schlussfolgern, Programmierung und Mehrsprachigkeit wünschen, ohne an eine geschlossene API gebunden zu sein. Verfügbar ist es über Le Chat, Mistrals API und Azure AI sowie als herunterladbare Gewichte auf Hugging Face zum Selbsthosten oder Fine-Tuning. Die API-Preise liegen deutlich unter denen von Mistral Large 2.
