Vibe ist Mistrals Agent für Softwareaufgaben. Die Kommandozeilenversion läuft in einem Projektverzeichnis, liest und schreibt Dateien, durchsucht Code, führt Shell-Befehle aus und verfolgt Aufgaben. Mistrals Programmiermodelle übernehmen Aufträge wie Fehler beheben, Funktionen ergänzen und Code erklären. Das in Python geschriebene Werkzeug ist unter Apache 2.0 quelloffen, integriert sich in Editoren wie Zed und lässt sich mit weiteren Tools verbinden.

Das umfassendere Vibe-Angebot erweitert Agentenfunktionen auf Büroaufgaben und Teams. Es baut auf Mistrals Devstral-Programmiermodellen und großen allgemeinen Modellen auf. Diese sind über Mistrals API und teilweise als offene Gewichte verfügbar, die Unternehmen auf eigenen Servern ausführen können. Diese Flexibilität ist für Unternehmen und Behörden attraktiv, die Agenten ohne Abhängigkeit von US-Cloud-Anbietern möchten.

Vibe gibt es in einem kostenlosen Tarif und kostenpflichtigen Plänen; Details hängen vom genutzten Modell und der Plattform ab. Agentenergebnisse müssen geprüft werden. Das kleinere Ökosystem bietet weniger Integrationen als Claude Code oder Codex. Alternativen sind Claude Code, OpenAI Codex, Gemini CLI, Cline, Aider und Cursor. Vibe eignet sich für Entwickler:innen und Organisationen, die einen offenen europäischen Programmieragenten möchten.
