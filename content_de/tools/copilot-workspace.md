Copilot Workspace war der Versuch von GitHub Next, den Einsatz von KI bei der Behebung eines Issues neu zu denken. Ausgehend von einem GitHub-Issue oder Prompt beschrieb das System zunächst das aktuelle und gewünschte Verhalten, erstellte dann einen Plan mit den zu ändernden Dateien und schrieb schließlich den Code. In jeder Phase konntest du den Text bearbeiten und den Ablauf auf Deutsch oder Englisch steuern, bevor Code entstand. Die fertigen Änderungen ließen sich als Pull Request öffnen oder in einer Cloud-Umgebung ausführen.

Es handelte sich um eine technische Vorschau, nicht um ein fertiges Produkt. Sie zeigte, wie GitHub sich vorstellte, dass Agenten eines Tages Routine-Tickets bearbeiten könnten. Die Vorschau ist beendet; neue Workspaces lassen sich nicht mehr erstellen oder öffnen. GitHub nennt den Agent-Modus von Copilot in VS Code und den Copilot-Coding-Agenten als nächste Entsprechungen. Letzterer bearbeitet ein zugewiesenes Issue im Hintergrund. Beide sind jedoch kein exakter Ersatz.

Für einen ähnlichen Workflow ist heute der Coding-Agent in GitHub Copilot die naheliegendste Option. Weitere Alternativen sind Devin, OpenAI Codex, Google Jules und Claude Code. Sie übernehmen Aufgaben meist von Anfang bis Ende und geben einen Pull Request zur Prüfung zurück. Den besonderen Spezifikations- und Planungsschritt von Workspace gibt es inzwischen auch in den Planungsmodi anderer Tools.
