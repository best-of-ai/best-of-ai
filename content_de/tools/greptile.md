Greptile ist ein KI-Codeprüfer mit Schwerpunkt auf dem Kontext der Codebasis. Statt nur den Diff zu lesen, erfasst es das gesamte Repository einschließlich der Beziehungen zwischen Funktionen und Modulen. Kommentare können dadurch auch Auswirkungen in Dateien ansprechen, die der Pull Request nicht verändert.

Greptile veröffentlicht Kommentare und Zusammenfassungen in GitHub- und GitLab-Pull-Requests. Teams formulieren Regeln in einfacher Sprache; das System lernt aus positiven und negativen Bewertungen seiner Kommentare und soll so unnötige Hinweise reduzieren. Eine API ermöglicht Fragen zur Codebasis.

Greptile ist kostenpflichtig, wird pro Entwickler abgerechnet und bietet eine Testphase. Automatische Prüfungen können Entwurfsprobleme übersehen und Fehlalarme erzeugen, daher bleibt menschliche Prüfung wichtig. Alternativen sind CodeRabbit, Graphite, GitHub Copilot Code Review, Qodo und Sourcery. Greptile eignet sich für Teams mit großen Codebasen, die mehr Kontext bei Codeprüfungen möchten.
