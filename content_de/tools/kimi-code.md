Kimi Code ist ein Kommandozeilenagent aus derselben Produktfamilie wie Claude Code und Codex CLI. Nutzer starten ihn in einem Projektordner, beschreiben eine Aufgabe, und er liest Dateien, bearbeitet Code, führt Befehle aus und prüft Ergebnisse. Auf Grundlage des Verlaufs entscheidet er, was als Nächstes zu tun ist. Berechtigungen erlauben die Freigabe riskanter Aktionen.

Standardmäßig nutzt das Tool Kimi-Modelle von Moonshot AI, die für Programmierung und lange Kontexte bekannt sind; auch andere kompatible Anbieter lassen sich anbinden. Funktionen umfassen integrierte Subagenten für Programmierung, Erkundung und Planung, Unterstützung des Model Context Protocol für Werkzeugverbindungen, Lifecycle-Hooks für Automatisierung und Sicherheitsprüfungen sowie einen ACP-Modus, über den Editoren wie Zed und JetBrains den Agenten steuern können.

Das Werkzeug ist unter der MIT-Lizenz quelloffen. Für den Modellzugriff sind ein Konto oder API-Schlüssel erforderlich; Tarife haben Nutzungslimits. Mehrere inoffizielle Projekte verwenden denselben Namen – maßgeblich ist das offizielle Repository von Moonshot AI. Alternativen sind Claude Code, OpenAI Codex CLI, Gemini CLI, OpenCode und Aider. Kimi Code eignet sich für Entwickler, die einen Terminalagenten auf Basis von Kimi-Modellen möchten.
