GitHub Copilot ist das KI-Coding-Tool mit der größten Nutzerbasis und direkt dort eingebaut, wo der meiste Code bereits liegt. Es begann als Inline-Autovervollständigung, die Zeilen und Funktionen anhand der geöffneten Datei vervollständigt. Das kann Copilot weiterhin in VS Code, Visual Studio, JetBrains-IDEs, Neovim und Xcode. Ein Chatfenster erklärt Code, schreibt Tests, behebt Fehler und beantwortet Fragen zu deinem Projekt, ohne dass du den Editor verlassen musst.

Neuere Funktionen arbeiten agentisch. Der Agent-Modus im Editor plant eine Aufgabe, bearbeitet mehrere Dateien, führt Terminalbefehle aus und überarbeitet fehlgeschlagene Versuche. Der Coding-Agent von Copilot arbeitet direkt auf GitHub: Du weist ihm ein Issue zu. Er bearbeitet es im Hintergrund und öffnet einen Pull Request, den du prüfen kannst. Copilot kann außerdem Pull Requests begutachten, in der Kommandozeile helfen und Modelle verschiedener Anbieter verwenden, die du über eine Auswahlliste festlegst. Teams können eigene Anweisungen hinterlegen, damit Copilot ihre Konventionen befolgt.

Es gibt einen kostenlosen Tarif mit begrenzter Nutzung, kostenpflichtige Einzeltarife sowie Business- und Enterprise-Tarife mit Admin-Steuerungen, Richtlinien und Optionen, Code vom Modelltraining auszuschließen. Premium-Anfragen an die leistungsstärksten Modelle können separat gezählt werden. Intensive Nutzung kann daher an Grenzen stoßen. Da Copilot in den vorhandenen Entwicklerwerkzeugen funktioniert, fällt die Einführung leicht. Cursor, Windsurf und Claude Code bieten stärker auf Agenten ausgerichtete Erlebnisse. Copilots Stärken sind die breite Verfügbarkeit, die GitHub-Integration und der Enterprise-Support.
