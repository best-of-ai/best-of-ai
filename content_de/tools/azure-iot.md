Azure IoT Hub ist das Rückgrat für Nachrichten zwischen verbundenen Geräten in Azure. Geräte senden Telemetriedaten wie Sensorwerte an die Cloud; die Cloud kann Befehle und Konfigurationen zurückschicken. Jedes Gerät hat eine eigene Identität und Zugangsdaten, sodass die Plattform es authentifizieren kann. Verbindungen verwenden Standardprotokolle wie MQTT und AMQP. Der Hub lässt sich auf große Geräteflotten skalieren und leitet Nachrichten an Speicher-, Streamverarbeitungs- und Analysedienste weiter.

Verwaltungsfunktionen erleichtern den Betrieb großer Flotten. Device Twins speichern Eigenschaften und gewünschte Einstellungen jedes Geräts. Jobs aktualisieren viele Geräte gleichzeitig, und ein Bereitstellungsdienst automatisiert die Aufnahme neuer Geräte. Azure IoT Edge führt Container-Code einschließlich Machine-Learning-Modellen auf Geräten aus, damit sie auch ohne Cloudverbindung reagieren. Der Hub integriert sich mit Azure Stream Analytics, Event Hubs, Functions und Digital Twins.

Der Preis von IoT Hub richtet sich nach Tarif und täglicher Nachrichtenzahl. Microsoft hat sein IoT-Portfolio weiterentwickelt und einige höher angesiedelte Angebote eingestellt; prüfe deshalb die aktuell empfohlene Architektur. Alternativen sind AWS IoT Core, Partnerangebote von Google Cloud sowie ThingsBoard, HiveMQ und EMQX. Azure IoT Hub eignet sich für Organisationen, die industrielle oder Verbraucher-IoT-Lösungen in Microsofts Cloud entwickeln.
