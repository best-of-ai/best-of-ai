Gemini CLI bringt Gemini als Programmier- und Automatisierungsagent ins Terminal. In einem Projektverzeichnis beschreibst du eine Aufgabe in natürlicher Sprache – etwa eine Codebasis erklären, einen fehlschlagenden Test beheben oder eine Funktion entwickeln. Der Agent liest Dateien, schlägt Änderungen vor, führt Shell-Befehle aus und arbeitet iterativ weiter. Er kann im Web suchen, Projektkonventionen aus einer Kontextdatei lernen und dank des großen Gemini-Kontextfensters viel Material verarbeiten.

Der Agent lässt sich erweitern. Über das Model Context Protocol verbindest du externe Werkzeuge; Erweiterungen bündeln eigene Befehle und Integrationen. Einstellungen steuern Berechtigungen und Sandbox. Gemini CLI ist unter der Apache-2.0-Lizenz quelloffen und lässt sich in Automatisierung und kontinuierliche Integration einbinden. In Editoren läuft es außerdem im Agentenmodus von Gemini Code Assist.

Mit einem persönlichen Google-Konto ist das Tool innerhalb von Nutzungslimits kostenlos. Kostenpflichtige Tarife oder API-Schlüssel erhöhen die Limits. Wie alle Programmieragenten kann es Fehler machen. Prüfe Änderungen und gehe vorsichtig mit Befehlen um, die Dateien ändern oder löschen. Alternativen sind Claude Code, OpenAI Codex CLI, Aider, Cline und die CLI von GitHub Copilot. Gemini CLI eignet sich für Entwickler:innen, die einen kostenlosen Open-Source-Terminalagenten möchten.
