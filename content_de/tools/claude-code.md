Claude Code arbeitet als Agent direkt in deinem Projekt statt als Vorschlagswerkzeug im Editor. Du startest ihn im Terminal innerhalb eines Repositorys und beschreibst eine Aufgabe, etwa einen fehlgeschlagenen Test zu beheben, einen Endpunkt hinzuzufügen oder eine Abhängigkeit zu aktualisieren. Claude Code liest die relevanten Dateien, erstellt einen Plan, bearbeitet projektweit den Code, führt Tests und andere Befehle aus und behebt dabei auftretende Fehler. Bei möglicherweise riskanten Aktionen fragt er um Erlaubnis. Änderungen kannst du als Diff oder in Git prüfen, bevor du sie übernimmst.

Das Werkzeug lässt sich stark anpassen. Eine CLAUDE.md-Datei im Projekt enthält Anweisungen und Konventionen, die der Agent bei jeder Ausführung befolgt. Skills bündeln wiederholbare Abläufe. Hooks führen an bestimmten Stellen des Workflows eigene Skripte aus. Subagenten teilen Aufgaben auf parallele Kontexte auf. Über das Model Context Protocol kannst du Datenbanken, Issue-Tracker und weitere Werkzeuge verbinden. Claude Code funktioniert außerdem in Editoren wie VS Code und JetBrains, in einer Desktop-App und im Browser. Für automatisierte Aufgaben lässt es sich in Skripten und CI ausführen.

Claude Code ist in kostenpflichtigen Claude-Tarifen enthalten. Du kannst es auch über einen API-Schlüssel nutzen und verbrauchsabhängig bezahlen. Die Kosten hängen davon ab, wie umfangreich du es einsetzt. Lange autonome Sitzungen können viele Tokens verbrauchen. Die Ausgabe muss weiterhin geprüft werden, besonders bei sicherheitskritischem Code. Die wichtigsten Alternativen sind Codex von OpenAI, Gemini CLI von Google, Cursor, der Agent von GitHub Copilot und Cline.
