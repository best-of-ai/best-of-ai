Test Companion ist ein KI-Agent für die Qualitätssicherung. Statt in einem separaten Dashboard arbeitet er im Editor der Entwickler:innen. Er erstellt aus einer Beschreibung oder dem Code Testskripte, führt sie in BrowserStacks Geräte- und Browser-Cloud aus und untersucht Fehler.

Ein wichtiger Anwendungsfall ist die Wartung. Tests brechen, wenn sich Oberflächen ändern, und ihre Reparatur kostet Zeit. Der Agent kann Selektoren aktualisieren, Schritte anpassen und Tests erneut ausführen. Er unterstützt gängige Frameworks und ist mit der Testinfrastruktur von BrowserStack verbunden.

Test Companion gehört zu den kostenpflichtigen Angeboten von BrowserStack. KI-generierte Tests müssen geprüft werden: Ein bestandener Test beweist nicht, dass tatsächlich das Richtige getestet wird. Alternativen sind Testim, mabl, Katalon, Playwright mit KI-Agenten und Applitools. Test Companion eignet sich für Teams, die bereits mit BrowserStack testen.
