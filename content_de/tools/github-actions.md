Arbeitsabläufe sind YAML-Dateien, die wiederverwendbare Aktionen aus einem Marktplatz aufrufen. Gehostete Runner laufen unter Linux, Windows und macOS. Teams können auch eigene Runner betreiben. Geheimnisse und Umgebungen steuern Bereitstellungen.

Öffentliche Repositorys können GitHub Actions kostenlos nutzen. Bei privaten Repositorys gibt es ein kostenloses Kontingent. Darüber hinaus wird die Nutzung kostenpflichtig.

GitLab CI und CircleCI sind Alternativen. GitHub Actions eignet sich für DevOps-Ingenieure, die GitHub verwenden.
