Label Studio ist eine flexible Plattform zur Datenannotation. Teams markieren damit Daten für maschinelles Lernen: Sie zeichnen Kästchen um Objekte in Bildern, kennzeichnen Entitäten in Text, transkribieren Audio und bewerten Ausgaben von Sprachmodellen. Mit einer Konfiguration aus einfacher Auszeichnungssprache können eigene Beschriftungsoberflächen erstellt werden. Das Werkzeug deckt viele Projekte ab und läuft lokal oder auf einem Server.

Modellgestützte Annotation beschleunigt die Arbeit. Ein ML-Backend kann Daten vorab beschriften, die anschließend von Menschen korrigiert werden; aktives Lernen priorisiert besonders informative Beispiele. Die Plattform unterstützt die Bewertung von Sprachmodellen mit Vorlagen für Aufgaben wie das Ordnen von Antworten und die Prüfung auf sachliche Fehler. Eine API und ein SDK verbinden sie mit Trainingsabläufen.

Die Community-Edition ist kostenlos und quelloffen. HumanSignal verkauft Label Studio Enterprise mit rollenbasiertem Zugriff, Arbeitsabläufen, Analysen und Sicherheitsfunktionen. Selbsthosting erfordert technischen Aufwand. Alternativen sind CVAT für Computer Vision, Labelbox, Scale AI und Encord als kommerzielle Plattformen, Prodigy für Text und Argilla für Sprachmodelldaten. Label Studio eignet sich für Teams, die ein flexibles, selbst gehostetes Annotationstool möchten.
