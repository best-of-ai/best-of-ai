Bolt.new verwandelt ein Gespräch in eine funktionierende Anwendung. Du beschreibst, was du bauen möchtest, etwa eine Buchungsseite, ein Dashboard oder einen kleinen SaaS-Prototyp. Bolt schreibt den Code, installiert Abhängigkeiten und zeigt das Ergebnis in einer Live-Vorschau im Browser. Du kannst weitere Änderungen anfragen, die Bolt direkt im Projekt umsetzt. Da die Entwicklungsumgebung von StackBlitz im Browser läuft, musst du nichts auf deinem Rechner installieren.

Bolt deckt neben der Codegenerierung auch die Bereitstellung ab. Bolt Cloud bietet Hosting, eigene Domains, Datenbanken, Nutzerauthentifizierung und Analysen. So kann ein Projekt direkt auf derselben Oberfläche live gehen. Du kannst mit einem Prompt, einem Figma-Design, einem GitHub-Repository oder einer Teamvorlage starten. Die KI wählt ein passendes Modell aus und testet und überarbeitet ihre Arbeit, um Fehler zu reduzieren. Du kannst den Code auch herunterladen oder in einem Editor öffnen und selbst weiterarbeiten.

Es gibt einen kostenlosen Einstieg und kostenpflichtige Tarife mit mehr Nutzung, leistungsstärkeren Modellen und Teamfunktionen. Jeder Prompt verbraucht Tokens. Lange Überarbeitungsschleifen bei großen Projekten können das Kontingent schnell aufbrauchen. Bei komplexen Apps muss eine Entwickler:in möglicherweise nacharbeiten. Übliche Alternativen sind Lovable, v0 und Replit. Bolt eignet sich besonders für Prototypen, interne Tools und Landingpages.
