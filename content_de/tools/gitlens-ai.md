GitLens erweitert VS Code um Git-Verlauf. Inline-Blame-Markierungen zeigen, wer eine Zeile zuletzt geändert hat, wann und in welchem Commit. Den Verlauf einer Datei, Zeile oder eines Branches kannst du ansehen, ohne den Editor zu verlassen. Zu den Funktionen gehören ein Commit-Graph, Vergleiche zwischen Branches und ein Launchpad für Pull Requests und Issues. GitLens zählt zu den meistgeladenen VS-Code-Erweiterungen.

KI hilft bei typischen Git-Aufgaben. GitLens verfasst Commit-Nachrichten anhand bereitgestellter Änderungen, fasst in natürlicher Sprache zusammen, was ein Commit oder Branch geändert hat, und entwirft Beschreibungen für Pull Requests. So sinkt der Dokumentationsaufwand. Mehrere KI-Anbieter und Modelle werden unterstützt; Einstellungen bestimmen, wie Daten übermittelt werden.

GitLens bietet einen kostenlosen Tarif mit vielen Funktionen sowie kostenpflichtige Pläne mit erweiterten Möglichkeiten wie Launchpad und Workspaces. Der Dienst gehört zum GitKraken-Ökosystem. KI-Zusammenfassungen solltest du mit dem tatsächlichen Diff vergleichen. Alternativen sind integrierte Git-Funktionen in VS Code, das Erstellen von Commit-Nachrichten durch GitHub Copilot, GitKraken Client, Sourcetree und Lazygit im Terminal. GitLens eignet sich für Entwickler:innen, die in VS Code arbeiten und den Verlauf ihres Codes besser verstehen möchten.
