Visual Studio Code, meist VS Code genannt, ist der am weitesten verbreitete Code-Editor unter Entwickler:innen. Er startet schnell und bietet die wichtigsten Funktionen: Syntaxhervorhebung, Debugger, integriertes Terminal, Git-Unterstützung und einen umfangreichen Erweiterungsmarktplatz für Sprachen, Linter, Themes und Tools. Der Kern ist Open Source. VS Code läuft unter Windows, macOS und Linux, hat auch eine Browser-Version und unterstützt die Remote-Entwicklung in Containern, über SSH und in Cloud-Umgebungen.

KI ist inzwischen direkt eingebaut. GitHub Copilot macht während des Tippens Inline-Codevorschläge. Ein Chatfenster beantwortet Fragen zum Projekt. Im Agent-Modus kann Copilot eine Aufgabe planen, mehrere Dateien bearbeiten, Terminalbefehle ausführen und auftretende Fehler beheben. VS Code unterstützt außerdem das Model Context Protocol. So können Agenten externe Tools und Datenquellen verbinden; außerdem lassen sich Modelle verschiedener Anbieter nutzen. Viele andere KI-Coding-Tools wie Cursor und Windsurf begannen als Forks von VS Code. Das zeigt, wie viel vom Ökosystem auf dem Editor aufbaut.

Der Editor selbst ist kostenlos. Copilot hat einen Gratis-Tarif mit begrenzter Nutzung sowie kostenpflichtige Tarife für intensive Nutzung und Teams. Die offiziellen Microsoft-Downloads enthalten Telemetrie und einige proprietäre Bestandteile. Deshalb gibt es Community-Versionen wie VSCodium für alle, die ein vollständig quelloffenes Programm möchten. Im Vergleich zu vollwertigen IDEs wie IntelliJ oder Visual Studio bietet VS Code weniger Funktionen von Haus aus und setzt auf Erweiterungen. Das bedeutet oft mehr Einrichtung, dafür bleibt der Editor schnell und flexibel.
