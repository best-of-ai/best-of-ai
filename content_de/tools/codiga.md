Codiga bot Codeanalyse in Echtzeit direkt im Editor. Plugins für VS Code, JetBrains-IDEs und weitere Werkzeuge prüften den Code während der Eingabe auf Sicherheitslücken, Fehler und Verstöße gegen Programmierstandards. Mit einer Regel-Engine konnten Teams eigene Prüfungen erstellen. Zudem gab es einen Assistenten für Code-Schnipsel und später KI-basierte Vorschläge. Integrationen mit Git-Plattformen prüften Pull Requests automatisch.

Datadog übernahm das Unternehmen, um Codeanalyse in seine Observability- und Sicherheitsplattform zu integrieren. Kurz darauf wurden die eigenständigen Codiga-Produkte eingestellt; zahlende Kunden erhielten Rückerstattungen und das Team wechselte zu Datadog. Die statische Analyse und die Regeln fließen heute in Datadog Code Security ein; der Analyzer ist als Open Source verfügbar.

Ähnliche Funktionen bieten SonarQube, Semgrep, Snyk Code und CodeQL für statische Analyse sowie CodeRabbit und Qodo für KI-gestützte Pull-Request-Prüfungen. Datadog-Kunden können die integrierten Sicherheitsfunktionen nutzen. Dieser Eintrag bleibt als Referenz erhalten, da ältere Toollisten und Anleitungen Codiga weiterhin erwähnen.
