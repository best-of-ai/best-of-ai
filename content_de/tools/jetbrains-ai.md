JetBrains AI Assistant arbeitet direkt in den IDEs, die viele professionelle Entwickler bereits verwenden. In IntelliJ IDEA, PyCharm, WebStorm, GoLand, Rider und der übrigen Produktfamilie bietet er Inline-Vervollständigung, ein Chatfenster mit Projektkontext sowie Aktionen zum Erklären von Code, Erzeugen von Tests, Verfassen von Commit-Nachrichten und Vorschlagen von Fehlerbehebungen. Da er in die IDE integriert ist, kann er deren umfassendes Wissen über die Codestruktur nutzen, etwa Typen, Referenzen und Ausführungskonfigurationen.

Junie ist der Coding-Agent von JetBrains. Er kann eine Aufgabe entgegennehmen, die Arbeit planen, Dateien bearbeiten, Tests ausführen und iterieren. Im Assistenten können Modelle von Anbietern wie OpenAI, Anthropic und Google ausgewählt werden. Für Fälle, in denen Daten auf dem eigenen Rechner bleiben müssen, werden lokale Modelle unterstützt. JetBrains entwickelt außerdem ein eigenes Codevervollständigungsmodell für schnelle Vorschläge und integriert über entsprechende Protokolle weitere Agenten.

AI Assistant wird als Abo-Erweiterung für JetBrains-IDEs in mehreren Stufen verkauft. Eine kostenlose Stufe ist in der Nutzung begrenzt; kostenpflichtige Tarife erhöhen die Kontingente. Der Assistent eignet sich besonders für Entwickler, die JetBrains-IDEs gegenüber VS Code bevorzugen. GitHub Copilot läuft ebenfalls in JetBrains-IDEs. Cursor und Windsurf sind eigenständige KI-Editoren; Claude Code und weitere Agenten lassen sich parallel zur IDE nutzen. Entwickler sollten prüfen, wie Code gemäß den Richtlinien ihrer Organisation an Modellanbieter übermittelt wird.
