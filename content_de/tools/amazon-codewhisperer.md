CodeWhisperer war Amazons erster Coding-Assistent und eine Alternative zu GitHub Copilot. In Editoren wie VS Code und JetBrains schlug er beim Tippen Zeilen und ganze Funktionen vor. Da das Modell besonders mit AWS-APIs trainiert wurde, eignete es sich gut für Code mit S3, Lambda, DynamoDB und anderen AWS-Diensten. Viele verbreitete Programmiersprachen wurden unterstützt.

Zwei Funktionen unterschieden CodeWhisperer von frühen Konkurrenten. Ein Quellen-Tracker markierte Vorschläge, die Open-Source-Code ähnelten, und zeigte dessen Lizenz. Ein Sicherheitsscan prüfte Code auf Schwachstellen wie offengelegte Zugangsdaten und Injection-Fehler. Für Einzelpersonen gab es einen kostenlosen Tarif. Eine Professional-Stufe ergänzte Admin-Steuerungen und höhere Nutzungsgrenzen.

Inzwischen hat AWS CodeWhisperer in Amazon Q Developer überführt. Der umfassendere Assistent ergänzt Chat, Agenten für mehrstufige Aufgaben, Code-Transformation und Hilfe direkt in der AWS-Konsole. Wenn du das Produkt heute suchst, solltest du Q Developer prüfen. Der ursprüngliche Name kommt hauptsächlich noch in älteren Dokumentationen und Blogbeiträgen vor. Alternativen sind GitHub Copilot, Cursor und JetBrains AI Assistant.
