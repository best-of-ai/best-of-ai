Muse Code ist Metas Einstieg in agentisches Programmieren. Entwickler:innen starten das Tool in einem Projektordner, beschreiben eine Aufgabe und lassen den Agenten den Code untersuchen, Änderungen planen, Dateien bearbeiten und Tests ausführen. Er arbeitet über ein ganzes Repository hinweg und nutzt ein für Programmierung angepasstes Meta-Modell.

Meta positioniert das Tool als günstigere Option neben Angeboten von Anthropic und OpenAI. Es läuft auf macOS und Linux über die Kommandozeile. Funktionen wie parallel ausgeführte Unteragenten sollen größere Aufgaben bewältigen. Das Werkzeug wurde als Beta veröffentlicht; Änderungen sind zu erwarten.

Der Zugriff erfolgt über Metas Modell-API; Preise und Limits können sich ändern. Benchmark-Angaben stammen von Meta und Sekundärberichten, daher solltest du mit eigenem Code testen. Alternativen sind Claude Code, OpenAI Codex, Gemini CLI, Cursor und Kimi Code. Muse Code eignet sich für Entwickler:innen, die einen weiteren Terminal-Agenten ausprobieren möchten.
