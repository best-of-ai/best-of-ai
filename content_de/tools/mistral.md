Mistral ist Europas bekanntestes KI-Labor für Spitzenmodelle. Aufmerksamkeit erhielt das Unternehmen zunächst durch kompakte Modelle mit offenen Gewichten, die mit größeren Modellen mithielten oder sie übertrafen. Seitdem veröffentlicht Mistral Modelle in mehreren Größen für Chat, Programmieren, Reasoning und Bildverarbeitung. Einige können unter freizügigen Lizenzen kostenlos heruntergeladen werden. Die leistungsstärksten Modelle gibt es über die API und Le Chat. Entwickler:innen schätzen, dass sie die Modelle auf eigener Hardware ausführen können.

Le Chat ist der Assistent für Privat- und Geschäftsnutzung. Er beantwortet alltägliche Fragen, hilft beim Schreiben, durchsucht das Web, analysiert Dateien und Bilder, erzeugt Bilder und führt Code aus. Dazu kommen Agenten und eine Arbeitsfläche für Dokumente. Die API umfasst Modelle für allgemeine Aufgaben, Codevervollständigung, Embeddings, OCR in Dokumenten und Moderation. Unternehmen können Mistral-Modelle mit Support und Anpassungen in der eigenen Cloud oder On-Premises bereitstellen.

Le Chat hat einen kostenlosen Tarif. Kostenpflichtige Einzel- und Teamtarife erhöhen Limits und ergänzen Funktionen. Die API wird pro Token abgerechnet. Mistral betont Datensouveränität und Hosting in Europa, was Behörden und Unternehmen anspricht, die auf den Speicherort ihrer Daten achten. Bei den schwierigsten Aufgaben sind die Modelle meist weniger leistungsfähig als die Spitzensysteme von OpenAI, Anthropic und Google. Gemessen an Größe und Kosten sind sie aber stark. Metas Llama, Cohere und DeepSeek sind vergleichbare Optionen für offene Modelle und den Unternehmenseinsatz.
