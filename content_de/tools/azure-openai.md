Azure OpenAI stellt OpenAIs Modellangebot über Microsofts Cloud bereit. Unternehmen erhalten dieselben Familien von Sprach-, Reasoning-, Bild- und Audiomodellen, nutzen dafür aber Azure-Verträge, Abrechnung und Sicherheitssteuerungen. Für regulierte Branchen und große Unternehmen ist das wichtig: Die Daten werden innerhalb von Azure verarbeitet, können in einem privaten Netzwerk isoliert werden und sind durch Microsofts Compliance-Zertifizierungen und Service-Level-Agreement abgedeckt.

Entwickelt wird in Microsoft Foundry. Dort stellst du ein Modell bereit, testest es in einer Playground-Umgebung und verbindest es mit eigenen Daten und Tools. Zu den Funktionen gehören Fine-Tuning, Inhaltsfilter, Tool- und Funktionsaufrufe, Retrieval über Unternehmensdokumente und Tracing. Es gibt verschiedene Bereitstellungstypen: Standard mit nutzungsabhängiger Abrechnung, Batch und bereitgestellten Durchsatz. Letzterer reserviert Kapazität für gleichmäßige Arbeitslasten mit planbarer Latenz. Foundry bietet auch Modelle anderer Anbieter als OpenAI, sodass Teams die Optionen an einem Ort vergleichen können.

Neue OpenAI-Modelle erscheinen auf Azure manchmal etwas später als in OpenAIs eigener API. Für den Zugriff auf die neuesten Modelle ist mitunter ein Antrag nötig. Die Preise folgen OpenAIs Token-Abrechnung und werden über Azure abgerechnet; Enterprise-Rabatte sind üblich. Azure OpenAI richtet sich vor allem an Unternehmen, die bereits auf Microsoft standardisiert sind. Die wichtigsten Alternativen sind AWS Bedrock und Google Vertex AI. Für Privatpersonen und kleine Projekte ist OpenAIs eigene API meist einfacher.
