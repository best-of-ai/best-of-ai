Amazon Q Developer ist der Nachfolger von CodeWhisperer und auf AWS spezialisiert. In VS Code, JetBrains und anderen IDEs bietet er Inline-Codevorschläge und einen Chat, der Code erklärt, Tests schreibt und Funktionen optimiert. Im Terminal ergänzt er Autovervollständigung und einen Chat, der Alltagssprache in Shell-Befehle übersetzt. In der AWS-Konsole und in Chatplattformen wie Slack hilft er beim Beheben von Dienstproblemen und erklärt, warum sich eine Ressource ungewöhnlich verhält.

Die Agentenfunktionen übernehmen umfangreichere Aufgaben. Ein Agent liest dein Projekt, plant die Arbeit, bearbeitet mehrere Dateien und führt Befehle aus, um eine Funktion zu vervollständigen, Dokumentation zu schreiben oder Code zu prüfen. Spezialisierte Transformationsagenten aktualisieren Java-Versionen und portieren .NET-Anwendungen für Linux – bei großen Codebasen eine mühsame Aufgabe. Ein integrierter Scan findet Sicherheitsprobleme im Code und schlägt Korrekturen vor.

Ein kostenloser Tarif bietet eine begrenzte monatliche Nutzung. Der kostenpflichtige Pro-Tarif erhöht die Limits und ergänzt Admin-Steuerungen. Dazu gehört die Zusage, dass deine Inhalte nicht zur Verbesserung des Dienstes verwendet werden. AWS verlagert neuere Agentenfunktionen zunehmend auf Kiro, seine eigene KI-IDE. Die Q-Developer-Plugins sind daher am besten als eine von mehreren AWS-Optionen zu betrachten. Q Developer eignet sich vor allem für Teams, die AWS intensiv nutzen. GitHub Copilot und Cursor sind breiter einsetzbare Konkurrenten.
