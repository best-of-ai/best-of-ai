Factory bietet KI-Agenten für Entwicklungsteams. Droids übernehmen Aufgaben aus Tickets oder Chats, untersuchen eine Codebasis, nehmen Änderungen vor, führen Tests aus und eröffnen Pull Requests zur Prüfung. Spezialisierte Agenten bearbeiten Codeprüfungen, Vorfälle oder Migrationen.

Das Produkt ist über Kommandozeile, IDE-Integrationen und Weboberfläche verfügbar. Verbindungen mit GitHub, Jira, Slack und weiteren Werkzeugen fügen Agenten in bestehende Abläufe ein. Unternehmensfunktionen befassen sich mit Sicherheit, Berechtigungen und Überwachung.

Factory wird Unternehmen im Abonnement angeboten. Agentenänderungen müssen überprüft werden, besonders bei Produktionssystemen. Alternativen sind Cognition Devin, OpenAI Codex, Claude Code und GitHub Copilot. Factory eignet sich für Engineering-Teams, die wiederkehrende Aufgaben automatisieren.
