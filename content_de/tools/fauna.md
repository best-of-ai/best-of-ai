Fauna wollte Entwicklern eine global skalierbare Datenbank ohne Serververwaltung bieten. Es kombinierte ein flexibles Dokumentmodell mit relationalen Funktionen, bot starke Konsistenz über Regionen und wurde über eine API mit eigener Abfragesprache FQL angesprochen; früher war auch GraphQL verfügbar. Web- und Mobile-Apps ließen sich ohne eigene Infrastruktur darauf aufbauen.

Das Unternehmen kündigte das Ende des gehosteten Dienstes an und schloss ihn; Konten wurden anschließend gelöscht. Fauna ist daher keine verfügbare Option für neue Projekte.

Für neue Anwendungen kommen PostgreSQL, PlanetScale, Neon, MongoDB Atlas oder Cloudflare D1 infrage. Fauna ist vor allem für bestehende Nutzer relevant, die eine Migration planen.
