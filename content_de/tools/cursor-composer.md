Composer war Cursors Antwort auf eine Grenze früher KI-Coding-Tools: Sie konnten eine Zeile vorschlagen oder eine Datei bearbeiten, hatten aber Schwierigkeiten mit Änderungen über mehrere Dateien hinweg. Du beschreibst eine Funktion oder ein Refactoring. Composer ermittelt, welche Dateien betroffen sind, nimmt die Änderungen vor und zeigt sie dir als Diffs, die du annehmen oder ablehnen kannst. Das Tool kann Dateien erstellen, Imports aktualisieren und zusammengehörigen Code konsistent halten. Später wurde die Funktion zum Cursor-Agenten ausgebaut, der auch Befehle ausführt und eigene Fehler korrigiert.

Composer ist außerdem der Name für die eigenen Modelle von Cursor, die auf schnelles agentisches Programmieren im Editor trainiert sind. Sie sollen schnell genug sein, damit Entwickler:innen im Arbeitsfluss bleiben, während sie mehrstufige Aufgaben erledigen. Neben diesen Modellen kannst du auch Modelle von Anbietern wie Anthropic, OpenAI und Google nutzen. Welche Modelle verfügbar sind und wie sie bepreist werden, ändert sich häufig.

Composer ist Teil von Cursor. Du arbeitest dafür im Cursor-Editor, einem Fork von VS Code. Es gibt einen kostenlosen Tarif und kostenpflichtige Pläne mit enthaltenem Nutzungskontingent. Umfangreiche Änderungen solltest du dennoch sorgfältig prüfen: Das Modell kann viele Dateien so bearbeiten, dass der Code zwar kompiliert, aber an deiner Absicht vorbeigeht. Alternativen für KI-Bearbeitung über mehrere Dateien sind Cascade von Windsurf, der Agent-Modus von GitHub Copilot, Cline und Claude Code.
