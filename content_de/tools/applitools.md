Applitools löst ein Problem, das herkömmliche automatisierte Tests übersehen: ob eine Seite richtig aussieht. Ein Funktionstest kann bestätigen, dass eine Schaltfläche vorhanden ist, obwohl das Layout kaputt ist, sich Elemente überlagern oder Inhalte außerhalb des Bildschirms liegen. Applitools Eyes erstellt Screenshots während der Tests und vergleicht sie mit freigegebenen Vorlagen. Dabei nutzt es visuelle KI, die Layout, Text und Farbe ähnlich wie ein Mensch versteht. So entstehen weniger Fehlalarme als bei pixelgenauen Vergleichen, bei denen schon kleine Darstellungsunterschiede jede Prüfung auslösen.

Über das Ultrafast Grid läuft die Plattform in vielen Browsern, Ansichtsgrößen und Geräten. Ein Test kann eine Website so schnell in Dutzenden Konfigurationen prüfen. Applitools Autonomous ergänzt KI, die Tests erstellt, ausführt und pflegt. Sie kann Schritte in einfacher Sprache formulieren und sich an Änderungen der Oberfläche anpassen. Dashboards gruppieren ähnliche Unterschiede, damit Prüfer viele davon gemeinsam freigeben oder ablehnen können. Die Ergebnisse fließen zurück in den Arbeitsablauf des Teams.

Applitools lässt sich mit über 60 Werkzeugen verbinden, darunter Selenium, Cypress, Playwright, CI/CD-Systeme wie Jenkins und GitHub Actions sowie Fehlerverfolgungsprogramme. Die gestaffelten Preise richten sich nach Nutzung. Es gibt einen kostenlosen Einstiegstarif und Angebote für Unternehmen. Besonders nützlich ist das Werkzeug für Teams mit stabilen automatisierten Testsuiten, da visuelle Prüfungen diese ergänzen. Alternativen sind Percy von BrowserStack, Chromatic für Komponenten und quelloffene Playwright-Screenshots.
