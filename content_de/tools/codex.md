Codex arbeitet als Softwareentwicklungs-Agent. Ein Entwickler beschreibt eine Aufgabe, etwa einen Fehler zu beheben oder eine Funktion hinzuzufügen. Codex untersucht den Code, erstellt einen Plan, bearbeitet Dateien und führt Tests oder Linter aus. Anschließend fasst er zusammen, was er geändert hat und warum.

Codex gibt es in mehreren Varianten: Ein Kommandozeilenwerkzeug läuft lokal, eine Desktop-App verwaltet mehrere Aufgaben, Erweiterungen binden ihn in Editoren wie VS Code ein und eine Cloudversion in ChatGPT erledigt Aufgaben in isolierten Sandboxes, oft parallel, und kann Pull Requests auf GitHub vorschlagen. Konfigurationsdateien ermöglichen projektspezifische Anweisungen.

Codex ist in ChatGPT-Tarifen mit je nach Stufe geltenden Nutzungslimits enthalten; für Entwickler gibt es außerdem API-Zugang. Agenten machen Fehler, daher müssen Änderungen geprüft und getestet werden. Alternativen sind Claude Code, Cursor, der Agent von GitHub Copilot, Gemini CLI und Devin. Codex eignet sich für Entwickler, die OpenAIs Agent in ihren Arbeitsablauf aufnehmen möchten.
