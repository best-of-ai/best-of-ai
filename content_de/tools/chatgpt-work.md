ChatGPT Work erweitert ChatGPT vom Beantworten von Fragen hin zum Erledigen von Aufgaben. Du beschreibst ein Ziel, zum Beispiel einen wöchentlichen Statusbericht zu erstellen, aus einem Ordner mit Notizen eine Präsentation zu bauen oder Zahlen zwischen zwei Tabellen abzugleichen. Der Agent arbeitet die Schritte nacheinander ab. Er sammelt Kontext aus verbundenen Werkzeugen, nutzt bei Bedarf einen Browser und Code und erstellt fertige Dateien. Aufgaben können längere Zeit im Hintergrund laufen. Du kannst später zurückkehren und das Ergebnis prüfen.

Verbindungen laufen über Erweiterungen für E-Mail, Kalender, Slack, Microsoft Teams, Google Drive, SharePoint, CRM-Systeme und Projektverfolgung. Geplante Aufgaben lassen den Agenten im Hintergrund weiterarbeiten. So kann er zum Beispiel jeden Morgen einen Kanal prüfen und ein Dokument aktualisieren. Die Technologie basiert auf Codex, dem Programmieragenten von OpenAI, und wird auf allgemeine Wissensarbeit angewendet. Administratoren von Business- und Enterprise-Tarifen können steuern, welche Erweiterungen und Browser der Agent verwendet, sensible Aktionen vorab freigeben oder blockieren und Nutzungslimits festlegen.

Verfügbarkeit und Limits hängen von deinem ChatGPT-Tarif ab und ändern sich während der Einführung. Prüfe daher die aktuelle Tarifseite. Wie jeder Agent kann das Ergebnis Fehler enthalten. Aktionen, die Nachrichten senden oder Datensätze ändern, solltest du vor der Freigabe prüfen. Claude Cowork, Agenten in Microsoft Copilot und Googles Gemini-Agenten sind die ähnlichsten Wettbewerber. ChatGPT Work ist besonders nützlich, wenn deine Dokumente und Gespräche bereits in Werkzeugen liegen, auf die der Agent zugreifen kann.
