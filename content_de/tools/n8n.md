Mit n8n erstellst du Automatisierungen, indem du Nodes auf einer Arbeitsfläche verbindest – ähnlich wie bei Zapier oder Make, aber mit mehr Möglichkeiten für Code. Jeder Node ist ein Schritt: ein Auslöser wie Webhook oder Zeitplan, eine Aktion in einer App oder ein Block, der Daten mit JavaScript oder Python umwandelt. Hunderte Integrationen sind enthalten. Für weitere Dienste gibt es einen allgemeinen HTTP-Node. Workflows können verzweigen, Schleifen durchlaufen und andere Workflows aufrufen. Damit lassen sich einfache Benachrichtigungen ebenso wie komplexe Datenpipelines umsetzen.

KI ist inzwischen ein großer Teil des Produkts. n8n enthält Nodes für Sprachmodelle, Werkzeuge, Speicher und Vektordatenbanken. Damit baust du Agenten, die E-Mails lesen, Dokumente durchsuchen, APIs aufrufen und ihre nächsten Schritte selbst wählen. Jeder Ablauf lässt sich Schritt für Schritt prüfen. Vor sensiblen Aktionen kannst du menschliche Freigaben einfügen und zwischen Modellanbietern wechseln. Dadurch ist n8n beliebt, um KI-Agenten zu prototypisieren und zu betreiben, ohne eine vollständige Anwendung zu schreiben.

Der Code steht auf GitHub unter einer Fair-Code-Lizenz. Du kannst n8n selbst auf einem Server oder mit Docker betreiben und die Daten in deiner Umgebung behalten. n8n Cloud ist die gehostete Option; die Tarife skalieren nach Ausführungen. Enterprise-Tarife ergänzen Single Sign-on, Zugriffskontrollen und Audit-Logs. Selbst-Hosting ist günstig, bedeutet aber, dass du Updates, Sicherheit und Verfügbarkeit selbst verantwortest. Zapier ist für Nicht-Techniker:innen einfacher. Make ist der ähnlichste visuelle Konkurrent.
