Aide war ein KI-orientierter Codeeditor des Londoner Start-ups CodeStory. Als Fork von VS Code sah er vertraut aus und unterstützte Erweiterungen, ergänzte aber eine KI-Ebene, die das Projekt verstand. Du konntest Fragen zur Codebasis stellen, Änderungen über mehrere Dateien hinweg anfordern und Vorschläge mit breiterem Kontext erhalten. Aide wurde unter der AGPL-Lizenz quelloffen veröffentlicht. Das Projekt stieß bei Entwicklern auf großes Interesse, die eine Alternative zu Cursor suchten.

CodeStory forschte auch an agentischem Programmieren. Dazu gehörten Benchmark-Aufgaben, die messen sollten, ob ein Modell echte Probleme in quelloffenen Repositorys beheben kann. Der Editor war Teil dieser Arbeit. Nutzer konnten damit agentisches Programmieren an eigenen Projekten und mit verschiedenen Modellen ausprobieren.

Die Entwicklung wurde eingestellt. Der Editor wird nicht mehr gepflegt. Der Code ist weiterhin auf GitHub verfügbar und kann geforkt werden. Neue Nutzer fahren mit aktiv gepflegten Werkzeugen besser. Übliche Alternativen sind Cursor, Windsurf, Cline und GitHub Copilot. Void war ein weiterer quelloffener Editor in derselben Kategorie. Dieser Eintrag bleibt als Referenz bestehen, weil ältere Artikel und Vergleichsseiten Aide weiterhin erwähnen.
