Jules ist für die Delegation von KI-gestützter Programmierarbeit konzipiert. Verknüpfe ein GitHub-Repository, beschreibe eine Aufgabe, und Jules erstellt einen Plan, arbeitet in einer sicheren virtuellen Cloud-Maschine und schlägt Änderungen vor, während du dich anderen Dingen widmest. Der Agent klont das Repository, installiert Abhängigkeiten, schreibt Code, führt Tests aus und zeigt Plan und Ergebnisse zur Prüfung. Nach deiner Freigabe erstellt er einen Pull Request.

Jules eignet sich für routinemäßige, klar umrissene Aufgaben wie Fehlerbehebungen, das Hinzufügen von Tests, Aktualisieren von Abhängigkeiten und Dokumentation sowie kleinere Funktionen. Mehrere Aufgaben können parallel laufen. Du kannst den Plan vor dem Start prüfen und während der Arbeit Feedback geben. Der Agent basiert auf Gemini-Modellen von Google und ist in GitHub-Issues und die Kommandozeile integriert.

Es gibt eine kostenlose Stufe mit einer begrenzten Zahl täglicher Aufgaben sowie kostenpflichtige Stufen mit höheren Limits im Rahmen der KI-Angebote von Google. Wie andere Agenten funktioniert Jules am besten mit konkreten Aufgaben und einem Repository mit Tests; mehrdeutige oder umfangreiche Änderungen können Schwierigkeiten bereiten. Die Ergebnisse müssen von Menschen geprüft werden. Vergleichbare Angebote sind OpenAI Codex, der Coding-Agent von GitHub Copilot, Devin und Claude Code. Cursors Hintergrundagenten bieten einen ähnlichen Ablauf innerhalb eines Editors. Google bietet außerdem Gemini CLI und Gemini Code Assist für interaktive Unterstützung.
