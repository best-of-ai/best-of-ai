Replit begann als Online-Codeeditor und Laufzeitumgebung, die Dutzende Programmiersprachen ohne Installation unterstützte. Du öffnest einen Browser-Tab, startest ein Projekt und dein Code läuft sofort auf den Servern von Replit. Das machte die Plattform in Schulen, Programmier-Bootcamps und bei Einsteigern beliebt. Dank gemeinsamem Bearbeiten können mehrere Personen gleichzeitig am selben Projekt arbeiten. Projekte werden gehostet, sodass du eine App mit einem Klick teilen oder bereitstellen kannst.

Heute liegt der Schwerpunkt auf Replit Agent, der Software anhand natürlicher Sprache erstellt. Du beschreibst eine App und der Agent schreibt den Code, richtet die Umgebung ein, installiert Pakete, erstellt eine Datenbank, testet das Ergebnis und stellt es bereit. Im Chat kannst du Funktionen verfeinern und Fehler beheben oder den Code direkt öffnen und bearbeiten. Ziel ist, Menschen ohne Programmiererfahrung funktionsfähige Apps erstellen zu lassen und Entwicklern schnelleres Arbeiten zu ermöglichen. Mit der mobilen App kannst du Apps auch am Smartphone erstellen und testen.

Ein kostenloser Einstiegstarif ist begrenzt. Bezahlte Tarife bieten mehr Agent-Nutzung, Rechenleistung und Bereitstellungskapazität; dazu kommen Team- und Unternehmenstarife. Die Nutzung des Agenten wird verbrauchsabhängig abgerechnet. Bei umfangreicher Entwicklung können daher zusätzliche Kosten zur Grundgebühr anfallen. Wie bei jedem KI-App-Builder solltest du generierten Code prüfen, bevor er echte Nutzer oder Zahlungen verarbeitet. Bei der Fehlerbehebung kann außerdem funktionierender Code beschädigt werden. Lovable, Bolt und v0 sind direkte Konkurrenten. Für eine klassische Entwicklungsumgebung kommen Cursor und GitHub Codespaces infrage.
