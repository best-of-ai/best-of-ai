Continue setzt auf Wahlfreiheit und Kontrolle. Statt Nutzer an einen Anbieter zu binden, können sie bevorzugte Modelle einbinden – von Cloud-APIs bis zu lokal mit Ollama betriebenen Modellen – und Verhalten, Prompts sowie Kontext aus Code und Dokumentation anpassen.

Die Erweiterung bietet Autovervollständigung, Chat mit Bezug auf Dateien und Dokumente sowie einen Bearbeitungsmodus zum Umschreiben ausgewählten Codes. Teams können Konfigurationen teilen und den Continue-Hub für Assistenten nutzen. Das Projekt wurde außerdem um automatische Prüfungen für Pull Requests erweitert. Da der Code offen ist, können Unternehmen ihn prüfen und anpassen.

Continue ist kostenlos und quelloffen; für Teams gibt es kostenpflichtige Optionen. Die Einrichtung ist aufwendiger als bei kommerziellen Produkten, und die Qualität hängt von den gewählten Modellen ab. Alternativen sind GitHub Copilot, Cursor, Cline, Roo Code und Sourcegraph Cody. Continue eignet sich für Entwickler, die einen offenen, anpassbaren Assistenten möchten.
