Nutzer:innen laden eine Datei hoch oder fügen einen Link ein und sehen Bewertungen dutzender Anbieter sowie Verhaltensberichte und Kommentare aus der Community. Eine API unterstützt Automatisierung. Kostenpflichtige Tarife ergänzen Suche und Threat Hunting. KI-Zusammenfassungen erläutern verdächtigen Code.

Hochgeladene Dateien werden für andere sichtbar. Reiche daher keine vertraulichen Dateien ein.

Hybrid Analysis und Any.Run sind verwandte Werkzeuge. VirusTotal eignet sich für Sicherheitsanalyst:innen, die erste Prüfungen durchführen.
