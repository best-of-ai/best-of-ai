Kilo Code läuft als Erweiterung für VS Code und JetBrains, als Kommandozeilen-Tool und als Desktop-App. Es hat Agenten zum Programmieren, Planen, Fragenstellen und Debuggen, und du kannst eigene definieren. Agenten können Arbeit an Subagenten übergeben und parallel laufen, und Cloud-Agenten können im Browser, in Slack oder in einer Handy-App weiterarbeiten. Der Code steht unter der MIT-Lizenz, und das Kommandozeilen-Tool ist ein Fork von OpenCode.

Wie du die Modelle bezahlst, entscheidest du selbst. Das Kilo Gateway leitet an mehr als 500 Modelle weiter und gibt die Preise der Anbieter ohne Aufschlag weiter, du kannst eigene Schlüssel mitbringen oder lokale Modelle über Ollama oder LM Studio laufen lassen. Ein Code Reviewer prüft Pull Requests automatisch, und ein Marketplace listet Agenten, Skills und MCP-Server.

Die Erweiterung ist kostenlos. Teams-Tarife kosten 15 Dollar pro Nutzer:in und Monat, und Cloud-Rechenzeit wird zusätzlich zur Modellnutzung stundenweise abgerechnet. Anaconda hat im Juli 2026 angekündigt, Kilo Code übernommen zu haben, und die Bedingungen nicht genannt. Agenten können viele Dateien auf einmal ändern, prüfe die Diffs also, bevor du sie übernimmst. Zu den Alternativen zählen Cline, OpenCode, Claude Code und Cursor. Kilo Code passt zu Entwickler:innen, die einen Open-Source-Agenten für beliebige Modelle wollen.
