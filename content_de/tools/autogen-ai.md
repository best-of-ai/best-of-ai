AutoGen machte Anwendungen mit mehreren Agenten zugänglich. Entwickler:innen definieren Agentenrollen, etwa Programmierer:in, Prüfer:in und Nutzervertretung, und lassen die Agenten gemeinsam ein Problem lösen. Sie können Code schreiben und ausführen, Werkzeuge aufrufen und Menschen um Eingaben bitten. Das Framework verwaltet den Nachrichtenaustausch.

Das Projekt begann bei Microsoft Research und gewann eine große Community. Mit AutoGen Studio konnten Interessierte Teams von Agenten ohne Code prototypisch aufbauen. Später bündelte Microsoft seine Arbeit und verwies neue Projekte auf das Microsoft Agent Framework, das Ansätze aus AutoGen und Semantic Kernel kombiniert. AutoGen befindet sich laut Microsoft im Wartungsmodus.

AutoGen bleibt kostenlos und Open Source. Ein Community-Fork namens AG2 wird von den ursprünglichen Entwickler:innen weiterentwickelt. Für neue Projekte solltest du Microsoft Agent Framework oder Alternativen wie LangGraph, CrewAI, OpenAI Agents SDK und Claude Agent SDK prüfen. Bestehende AutoGen-Projekte laufen weiterhin. AutoGen eignet sich für Teams, die ältere Systeme pflegen, und für alle, die Muster mit mehreren Agenten untersuchen.
