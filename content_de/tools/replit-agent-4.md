Replit Agent 4 führt die Idee fort, Software zu beschreiben und von einem Agenten erstellen zu lassen. Im Replit-Arbeitsbereich erklärst du, was du benötigst. Der Agent schreibt Code, richtet Umgebung und Datenbank ein, testet das Ergebnis und veröffentlicht es. Du prüfst den Fortschritt, gibst Feedback in natürlicher Sprache und bittest um Änderungen. Laut Replit ist diese Version deutlich schneller als ihr Vorgänger, was wichtig ist, weil die Entwicklung einer App viele Schritte umfasst.

Der neue Canvas erweitert, was der Agent erstellen kann. Neben Web- und Mobil-Apps kann er Tabellen, Diagramme und einfache Spiele erstellen und mehrere Arten von Ergebnissen in einem Arbeitsbereich bearbeiten. Der Agent ist auch mobil verfügbar, sodass Nutzer Projekte am Smartphone starten oder prüfen können. Integriertes Hosting und Deployment ermöglichen es, eine fertige App direkt dort zu veröffentlichen.

Agent 4 gehört zu den kostenpflichtigen Replit-Tarifen. Die Nutzung wird in Credits gemessen, die lange oder komplexe Entwicklungen verbrauchen können. Wie jede agentisch erstellte Software müssen Apps geprüft werden, bevor sie echte Nutzer, Zahlungen oder sensible Daten verarbeiten. Bei unklaren Anforderungen kann sich der Agent im Kreis drehen. Lovable, Bolt, v0 und Base44 konkurrieren beim App-Bau; Cursor und Claude Code eignen sich für Entwickler, die an bestehenden Codebasen arbeiten. Der Haupteintrag zu Replit beschreibt die gesamte Plattform.
