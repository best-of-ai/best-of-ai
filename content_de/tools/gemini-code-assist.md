Gemini Code Assist bringt die Modelle von Google in den Editor von Entwicklern. In VS Code und JetBrains-IDEs schlägt es beim Tippen Code vor, beantwortet Fragen im Chat, erklärt und überarbeitet Code, erstellt Tests und hilft, Fehler zu beheben. Im Agentenmodus kann es größere Aufgaben übernehmen und abgestimmte Änderungen über mehrere Dateien hinweg vornehmen. Google bietet auch eine Version für die Befehlszeile an: Gemini CLI, das viele Entwickler direkt im Terminal verwenden.

Unternehmenseditionen ergänzen Codeanpassung. Damit kann der Assistent private Repositorys eines Unternehmens berücksichtigen, sodass seine Vorschläge interne Bibliotheken und Schreibweisen verwenden. Hinzu kommen Sicherheits- und Compliance-Funktionen, Haftungsfreistellung und Verwaltungskontrollen. Gemini Code Assist funktioniert mit Google-Cloud-Werkzeugen wie Cloud Shell, Firebase und BigQuery. Über eine begleitende App kann es außerdem Pull Requests in GitHub prüfen.

Der Tarif für Einzelpersonen ist mit großzügigen Limits kostenlos und lässt sich daher leicht ausprobieren. Unternehmenstarife werden pro Nutzer abgerechnet. Google ändert häufig die Namen seiner KI-Produkte. Details können sich daher zwischen Gemini Code Assist, Gemini CLI, Jules und verwandten Produkten verschieben. Die Qualität konkurriert mit führenden Assistenten. Ein sehr großes Kontextfenster ist bei umfangreichen Codebasen ein Vorteil. Die wichtigsten Alternativen sind GitHub Copilot, Cursor, Claude Code und Amazon Q Developer.
