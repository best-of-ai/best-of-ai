Cursor begann als Fork von Visual Studio Code. Oberfläche, Erweiterungen und Tastenkürzel sind daher allen vertraut, die VS Code kennen. Der Unterschied: KI ist Teil des Editors und kein Zusatz. Cursor sagt nicht nur das nächste Token, sondern auch deine nächste Änderung voraus. Umbenennungen und wiederholte Änderungen lassen sich dadurch oft mit einem einzigen Tab-Tastendruck übernehmen. Du kannst Code auswählen und um eine Überarbeitung bitten oder mit einem Modell chatten, das das gesamte Repository indexiert hat und Fragen zu noch nicht geöffneten Dateien beantworten kann.

Der Agent-Modus ist das, worüber die meisten sprechen, wenn sie Cursor erwähnen. Bei einer Aufgabe wie dem Hinzufügen einer Einstellungsseite oder dem Beheben eines fehlschlagenden Tests plant der Agent die Schritte, bearbeitet Dateien im Projekt, führt Befehle aus, liest Fehlermeldungen und versucht es erneut. Vor der Übernahme prüfst du die Änderungen als Diffs. In Rules-Dateien kannst du Projektkonventionen festhalten, an die sich der Agent halten soll. Hintergrundagenten bearbeiten Aufgaben in der Cloud, während du etwas anderes machst. Cursor lässt dich Modelle mehrerer Anbieter auswählen und bietet auch eigene Modelle.

Cursor hat einen kostenlosen Tarif mit begrenzter Nutzung und kostenpflichtige Tarife für Einzelpersonen, Teams und Unternehmen. Intensive Nutzung des Agenten kann das enthaltene Kontingent schnell aufbrauchen. Die Kosten hängen also davon ab, wie du arbeitest und welche Modelle du auswählst. Da Cursor eine separate Anwendung ist, musst du den Editor wechseln; Einstellungen und Erweiterungen aus VS Code lassen sich importieren. Teams mit strengen Datenschutzanforderungen sollten die Optionen zur Datenverarbeitung prüfen: Ohne aktivierten Datenschutzmodus wird Code an Modellanbieter gesendet. Alternativen sind GitHub Copilot in VS Code, Windsurf und Claude Code.
