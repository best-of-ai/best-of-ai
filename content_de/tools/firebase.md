Mit Firebase entwickeln Entwickler Apps, ohne eigene Server betreiben zu müssen. Zu den Kerndiensten gehören Cloud Firestore und Realtime Database zum Speichern und Synchronisieren von Daten, Authentication für die Anmeldung per E-Mail, Telefon oder Social-Media-Konto, Cloud Storage für Dateien, Hosting für Websites und Cloud Functions für serverseitigen Code. Analytics, Crashlytics und Cloud Messaging für Push-Benachrichtigungen ergänzen die Werkzeuge für den gesamten App-Lebenszyklus. SDKs unterstützen iOS, Android, Web, Flutter und Unity.

KI ist inzwischen Teil der Plattform. Gemini in Firebase hilft Entwicklern beim Schreiben und Debuggen von Code und beim Verstehen ihrer Projekte. Firebase AI Logic ermöglicht Apps, Gemini und andere Modelle sicher direkt vom Client aus aufzurufen. Genkit ist ein quelloffenes Framework zum Entwickeln von KI-Funktionen und Agenten. Firebase Studio bietet eine browserbasierte Umgebung, um Apps mit KI-Unterstützung als Prototypen zu erstellen.

Firebase bietet einen kostenlosen Tarif mit großzügigen Kontingenten für kleine Projekte und einen nutzungsabhängigen Tarif für den Produktivbetrieb. Wenn die Nutzung wächst, können unerwartet hohe Kosten entstehen, besonders durch Datenbankabfragen. Deshalb solltest du Budgets festlegen und Abfragen sorgfältig strukturieren. Die Plattform bindet dich an Google-Dienste. Ein späterer Wechsel erfordert Aufwand. Supabase ist eine quelloffene Alternative auf Basis von Postgres. AWS Amplify und Appwrite konkurrieren ebenfalls. Convex bietet ein anderes Echtzeit-Backend. Firebase ist eine verbreitete Wahl für Mobil-Apps und Prototypen.
