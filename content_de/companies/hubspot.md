HubSpots KI-Produkte laufen unter dem Namen Breeze. Das Unternehmen bot Agenten für Inhalte, soziale Medien, Kundengewinnung und Support an. Im April 2026 wechselte es zu einer ergebnisbasierten Preisgestaltung: Kund:innen zahlen, wenn ein Agent eine Aufgabe abschließt. Aktionen der Agenten werden in HubSpot-Credits abgerechnet, getrennt von Nutzerlizenzen.

Einem Blog zufolge kündigte HubSpot am 23. Juli 2026 Agent Hub als zentrale Umgebung für Agenten an, benannte Breeze Studio in Agent Builder um und stellte fünf Beta-Agenten ein. Berichte unterscheiden sich darin, welches Modell den Agenten zugrunde liegt: Eine Quelle verweist auf ein Entwickler-Changelog, dem zufolge GPT-5 zum Standard wurde; eine andere nennt GPT-4.x.

Veröffentlichungen im Frühjahr 2026 umfassten auch Answer Engine Optimization, das verfolgt, wie eine Marke in KI-Antworten erscheint. Die meisten Details stammen aus Drittanbieter-Blogs. Prüfe daher HubSpots Changelog, bevor du dich auf Datumsangaben verlässt.
