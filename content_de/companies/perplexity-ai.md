Perplexity betreibt eine Antwortmaschine, die ihre Quellen nennt. Aus der Suche entwickelte das Unternehmen ein breiteres Angebot an Agenten. Comet ist der KI-Browser, kostenlos verfügbar und mit einer Mischung verschiedener Modelle einschließlich eigener Modelle von Perplexity. Perplexity Computer, im Februar 2026 gestartet, ist ein Cloud-Agent für längere Aufgaben. Labs und Research erzeugen Berichte und kleine Anwendungen.

Für Entwickler:innen wird die Sonar API durch eine neue Agent API ersetzt. Perplexity zufolge bleibt Sonar bis zum 27. September 2026 verfügbar. Neue Projekte sollen mit der Agent API beginnen, die neben eigenen Modellen auch Modelle anderer Anbieter ansteuern kann.
