We just shipped something new: [Skills](https://bestofai.io/skills), a section of the directory built for finding Agent Skills.

## What are Skills?

If you're working with Claude or another LLM agent, you've probably seen how a good "Skill" (a packaged set of instructions, scripts, and best practices) can turn a generic model into something that handles a specific job really well: editing Word docs, running test-driven development, reviewing a pull request, building a polished frontend.

The problem is these skills are scattered across dozens of repos, gists, and forum threads. There wasn't a single place to browse them, compare them, and grab the ones that fit your workflow.

Now there is.

## What's in it

We've curated 50 skills across 9 categories: Document Automation, Development & Engineering, Code Review & Quality, Testing & Debugging, Workflow & Productivity, Design & Creative, Communication & Writing, Business & Finance, and Browser & Agent Automation.

The popular, battle-tested ones are front and center:

- **DOCX / PDF / PPTX / XLSX**: Anthropic's document automation skills
- **Test-Driven Development** and **Systematic Debugging**: for a disciplined coding workflow
- **Code Review** and **Security Review**: for catching issues before they ship
- **Frontend Design** and **Artifacts Builder**: for building polished UI fast
- **Brainstorming** and **Writing Plans**: for shaping features before you build them

Every skill is organized by category and author, so you can find what's relevant to your stack instead of digging through GitHub search results.

## Something missing? Add it.

This is an open source project, and the Skills directory is only as good as what the community adds to it. If there's a skill you use and like that isn't listed yet, we'd like you to add it.

Go to the [Contribute page](https://bestofai.io/contribute/) and open a PR, or an issue if you're not sure how to format it, and we'll get it added.
