This repository bundles the following skills:

- **baseline-ui**: Cleans up sloppy UI code by fixing spacing, hierarchy and typography.
- **improve-ui**: Audits a product screen against its own design evidence and writes up verified problems.
- **fixing-accessibility**: Audits and fixes ARIA labels, keyboard navigation, focus and contrast.
- **fixing-metadata**: Fixes page titles, meta descriptions, canonical URLs and Open Graph tags.
- **fixing-motion-performance**: Finds layout thrashing and other animation performance problems.
- **create-design-md**: Creates or updates a DESIGN.md from an existing repo or public site.
- **component-canvas**: Builds a pan-and-zoom canvas for exploring UI components and variants.
