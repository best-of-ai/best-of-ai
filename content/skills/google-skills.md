This repository bundles the following skills:

- **google-ads-api-quickstart**: Walks through credentials, picking one of six client libraries or REST, and a first API call.
- **google-ads-api-account-diagnostics**: Diagnoses account problems such as lost conversions or low lead volume.
- **google-ads-api-mcp-setup**: Installs and configures the official open-source Google Ads MCP server.
- **data-manager-api-setup**: Sets up client libraries and authentication for the Data Manager API.
- **data-manager-api-event-ingestion**: Implements event and conversion ingestion with the Data Manager API.
- **data-manager-api-audience-ingestion**: Adds, removes and clears audience members through the Data Manager API.
- **google-mobile-ads-banner**: Adds Google Mobile Ads banner ads to Android and other mobile apps.
- **google-mobile-ads-android-migrate-to-next-gen**: Moves an Android app from the legacy Google Mobile Ads SDK to the next-generation one.
