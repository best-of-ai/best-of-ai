This repository bundles the following skills:

- **idea-evaluator**: Scores a rough research idea against a five-dimension framework.
- **deep-research**: Runs a survey-grade literature investigation on a topic.
- **benchmark-paper-template**: Structures benchmark and evaluation papers using a five-pillar framework.
- **intro-drafter**: Drafts a paper's introduction following a six-paragraph flowchart.
- **figure-designer**: Advises on the core figures in a technical paper.
- **paper-polish**: Fixes grammar and flow in academic prose while keeping the author's meaning.
- **drawio-reconstruction**: Rebuilds a reference image as an editable Draw.io file.
