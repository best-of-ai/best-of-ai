This repository bundles the following skills:

- **obsidian-markdown**: Creates and edits Obsidian Flavored Markdown files, including wikilinks and callouts.
- **obsidian-bases**: Creates and edits Obsidian Bases files with views, filters, and formulas.
- **json-canvas**: Creates and edits JSON Canvas files, including nodes, edges, and groups.
- **obsidian-cli**: Interacts with Obsidian vaults through the Obsidian CLI.
- **defuddle**: Extracts clean markdown from web pages using the Defuddle tool.
