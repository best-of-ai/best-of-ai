This repository bundles the following skills:

- **acquire-codebase-knowledge**: Helps an agent build understanding of an existing codebase.
- **azure-well-architected-review**: Runs an assessment against Azure's Well-Architected Framework.
- **aws-cost-optimize**: Looks for ways to reduce AWS cloud spend.
- **codeql**: Applies CodeQL-based static security analysis.
- **architecture-blueprint-generator**: Produces system architecture documentation.
- **conventional-commit**: Enforces the Conventional Commits message format.
- **agent-owasp-compliance**: Checks agent behavior against OWASP security guidance.
- **copilot-pr-autopilot**: Automates parts of the pull request workflow.
- **anti-ui-slop**: Flags low-quality or generic-looking UI output.
