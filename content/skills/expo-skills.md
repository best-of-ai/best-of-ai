This repository bundles the following skills:

- **expo-overview**: Router setup and shared configuration entry point.
- **expo-router**: File-based navigation with modals, sheets, and native tabs.
- **expo-animation**: Reanimated and gesture-based motion effects.
- **expo-native-ui**: Platform-native styling and visual controls.
- **expo-data-fetching**: API calls, caching, and offline support.
- **expo-upgrade**: SDK version migrations and dependency management.
- **eas-app-stores**: Production builds and app store deployment.
- **eas-workflows**: CI/CD automation configuration.
- **eas-update**: Over-the-air publishing and rollout management.
