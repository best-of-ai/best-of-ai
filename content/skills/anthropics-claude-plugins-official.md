This repository bundles the following skills:

- **skill-creator**: Tooling for authoring new Agent Skills.
- **frontend-design**: Guidance for building distinctive, intentional UI.
- **code-review**: Reviews a diff or PR for correctness and quality issues.
- **code-simplifier**: Simplifies and cleans up existing code.
- **claude-security**: Security-focused plugin for Claude Code usage.
- **pr-review-toolkit**: A toolkit for reviewing pull requests.
- **hookify**: Helps configure Claude Code hooks.
- **mcp-server-dev**: Support for developing MCP servers.
- **agent-sdk-dev**: Support for building with the Claude Agent SDK.
