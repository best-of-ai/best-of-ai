This repository bundles the following skills:

- **aav-vector-design-agent**: Designs adeno-associated virus vectors for gene therapy, including capsid engineering.
- **adaptyv**: Connects to a cloud lab platform for automated protein testing.
- **agentd-drug-discovery**: Mines evidence, designs molecules and ranks candidates using SAR and ADMET.
- **aeon**: Handles time series machine learning tasks such as classification and regression.
- **adhd-daily-planner**: Supports daily planning and structure for people with ADHD.
