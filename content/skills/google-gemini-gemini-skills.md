This repository bundles the following skills:

- **gemini-api-dev**: Covers text generation, multi-turn chat and multimodal use of the Gemini API.
- **gemini-live-api-dev**: Covers real-time, bidirectional streaming apps on the Gemini Live API.
- **gemini-api-cli**: Calls the Gemini API from the shell for media generation and files.
- **gemini-omni-flash-api**: Covers video generation and editing from text, image and video references.
