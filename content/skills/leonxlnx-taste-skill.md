This repository bundles the following skills:

- **design-taste-frontend**: Infers a design language from the brief and outputs GSAP code skeletons.
- **gpt-taste**: A stricter variant tuned for GPT and Codex, with higher layout variance.
- **image-to-code**: Generates a reference image first, then builds the frontend to match it.
- **redesign-existing-projects**: Audits an existing interface and fixes its layout and spacing.
- **high-end-visual-design**: Aims for a calmer look with softer contrast and premium fonts.
- **minimalist-ui**: Produces an editorial-style interface with a restrained color palette.
- **industrial-brutalist-ui**: Produces a high-contrast style based on Swiss type design.
- **imagegen-frontend-web**: Generates website mockup images with an emphasis on typography and spacing.
- **imagegen-frontend-mobile**: Generates mobile screen mockups for iOS, Android, and cross-platform apps.
- **brandkit**: Generates a brand identity board including logo, color palette, and type choices.
