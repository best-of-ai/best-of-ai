This repository bundles the following skills:

- **motion-showreel**: Makes animated graphics, titles and UI motion as MP4 video with editable source.
- **web-video-presentation**: Turns an article or script into a 16:9 web presentation that plays like a video.
- **web-design-engineer**: Builds or redesigns polished pages and dashboards in HTML, CSS and React.
- **gpt-image-2**: Generates and edits images with GPT Image 2 and helps write prompts.
- **beautiful-article**: Turns URLs, PDFs, DOCX files or pasted text into an offline single-file HTML article.
- **kb-retriever**: Searches a local knowledge base folder, including PDFs and spreadsheets, and answers questions.
