This repository bundles the following skills:

- **offensive-active-directory**: Covers Active Directory recon and attack methodology for internal red team engagements.
- **offensive-netexec**: Covers using NetExec for network enumeration and post-exploitation.
- **offensive-api-security**: Methodology for testing REST, gRPC and WebSocket APIs.
- **offensive-api-abuse**: Covers business logic abuse and more advanced API attack patterns.
- **offensive-jwt**: Covers JWT attacks such as algorithm confusion and weak HMAC secrets.
- **offensive-cicd-pipeline**: Covers CI/CD pipeline weaknesses, including GitHub Actions injection.
