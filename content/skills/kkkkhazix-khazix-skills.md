This repository bundles the following skills:

- **leader**: Turns vague ideas into clear, actionable goals an agent can execute independently.
- **storage-analyzer**: Scans system disk usage and flags files for safe deletion.
- **aihot**: Fetches daily AI news summaries and trends without requiring an API key.
- **neat-freak**: Aligns project documentation and CLAUDE.md files and audits rule execution.
- **hv-analysis**: Produces long research reports, roughly 10,000 to 30,000 words, analyzing products or companies.
- **khazix-writer**: Writes long-form content in the creator's specific style, tone, and voice.
