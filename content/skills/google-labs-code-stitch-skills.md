This repository bundles the following skills:

- **stitch::code-to-design**: Converts existing code into a Stitch design.
- **stitch::generate-design**: Generates a new design from a prompt.
- **stitch::manage-design-system**: Manages a project's design system in Stitch.
- **stitch::react-components**: Generates React components from a Stitch design.
- **stitch::react-native**: Generates React Native code from a Stitch design.
- **remotion**: Generates Remotion video code from a Stitch design.
- **shadcn-ui**: Generates shadcn/ui-based components from a Stitch design.
- **enhance-prompt**: Utility skill that refines a design prompt before generation.
- **taste-design**: Utility skill for evaluating design quality.
