This repository bundles the following skills:

- **camerax**: Guides camera features built with CameraX.
- **android-cli**: Explains how to install and use the android command-line tool.
- **appfunctions**: Finds app workflows to expose as AppFunctions, such as creating a note.
- **ml-kit-genai-prompt-api**: Adds the ML Kit GenAI Prompt API to an Android codebase.
- **mlkit-agent-api**: Builds on-device agent workflows with the ML Kit GenAI Agent API.
- **restore-credentials**: Implements Restore Credentials with the Credential Manager library.
- **verified-email**: Implements verified email retrieval through Credential Manager.
- **android-for-cars-parked-apps**: Adapts video, game and browser apps to run as parked apps on Android Auto.
