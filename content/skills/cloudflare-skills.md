This repository bundles the following skills:

- **agents-sdk**: Builds, debugs and reviews apps that use the Cloudflare Agents SDK.
- **cf-cli**: Uses Cloudflare's cf command-line tool for the API and Workers projects.
- **cloudflare-app-bootstrap**: Gets a Workers app serving a local request by wiring up bindings and secrets.
- **cloudflare-email-service**: Implements and troubleshoots Email Sending and Email Routing.
- **cloudflare-one**: Designs and reviews Zero Trust and SASE deployments.
- **cloudflare-one-migrations**: Plans migrations from existing VPN, SWG or SASE products to Cloudflare One.
- **basin**: Builds and troubleshoots analytics workflows with Basin Pipelines and Catalog.
