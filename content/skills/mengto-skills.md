This repository bundles the following skills:

- **Video to Super Prompt**: Converts screen recordings into detailed prompts for code generation.
- **HTML to Interaction Prompts**: Extracts reusable prompts from existing HTML pages.
- **Build Isometric ARPG**: Framework for Three.js role-playing game development.
- **Design Action Combat**: Gameplay system architecture and tuning.
- **Test Playable Web Games**: QA and validation for browser-based games.
- **Landing Page**: Web design and conversion optimization workflow.
- **Three.js**: 3D graphics and WebGL scene management.
- **Animation on Scroll**: Scroll-triggered animation patterns.
- **Shader Cursor Trail**: WebGL cursor interaction effects.
- **Glass Dark Mode UI**: Design system and visual language.
