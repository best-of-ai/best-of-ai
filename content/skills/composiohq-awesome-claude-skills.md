This repository bundles the following skills:

- **Connect**: Lets Claude take real actions across more than 1,000 apps, including email and Slack.
- **MCP Builder**: Guides the development of a Model Context Protocol server for an external API.
- **Changelog Generator**: Builds a user-facing changelog automatically from git commit history.
- **Brand Guidelines**: Applies Anthropic's official branding to generated artifacts.
- **Skill Creator**: Provides guidance for writing new, effective Claude Skills.
- **File Organizer**: Sorts files by context and flags duplicates.
- **Content Research Writer**: Researches a topic and drafts cited, edited sections of content.
- **Image Enhancer**: Improves image resolution and clarity.
- **GitHub Automation**: Automates GitHub issues, pull requests, and workflows.
- **Slack Automation**: Automates Slack messaging and channel management.
