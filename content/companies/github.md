GitHub's AI work centers on Copilot, which began as inline code completion and now covers chat, code review and an agent that takes issues and opens pull requests. Copilot is sold as part of a GitHub subscription, with higher tiers for heavier use.

Agent HQ, announced at Universe in October 2025 and rolled out more widely in early 2026, changes the pitch. Instead of only offering Microsoft's own agent, GitHub lets subscribers assign work to coding agents from Anthropic, OpenAI, Google, Cognition and xAI. A Mission Control view tracks what each agent is doing, and administrators choose which agents and models their teams can use. OpenAI's Codex was the first outside agent to appear in it, followed by Claude Code.

Plan Mode, a metrics dashboard and a built-in review step that checks the agent's code before a developer sees it round out the feature set. GitHub's bet is that it will not need to build the best agent if it controls the place where all of them work.
