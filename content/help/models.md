## What's covered

The models section catalogs AI models directly, language models, image models, and beyond, separate from the tools and products built using them. Models are grouped into their own categories, the same way tools are grouped by category.

## How it's different from the tools directory

A tool is something you use. A model is what powers it. ChatGPT the product is a tool; GPT is a model. Best of AI tracks both, but keeps them in separate sections because they answer different questions: what should I use, versus what's actually running underneath it.

## How it connects to companies and hardware

Models come from companies, so a model's page links back to the lab that built it. And since running a model takes hardware, the [Hardware](/help/hardware/) section sits right next to this one, for anyone deciding what to run a given model on.
