Microsoft announced Maia 300 on October 12, 2026. Each chip uses eight HBM4 stacks with up to 18 TB/s of memory bandwidth. Microsoft says a 96-accelerator configuration delivers up to seven times Maia 200's rack-scale token throughput. Production deployments start in 2027, with multi-gigawatt rollouts planned.
