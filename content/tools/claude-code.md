Claude Code works as an agent on your actual project instead of a suggestion engine in an editor. You start it in a repository from the terminal and describe the task, such as fixing a failing test, adding an endpoint, or upgrading a dependency. It reads the relevant files, makes a plan, edits code across the project, runs tests and other commands, and iterates on the errors. It asks permission for actions that could be risky, and you can review changes as diffs or through git before committing.

It is highly customizable. A CLAUDE.md file in a project holds instructions and conventions the agent follows every time, and skills package repeatable procedures. Hooks run your own scripts at points in the workflow, subagents split work across parallel contexts, and the Model Context Protocol connects it to databases, issue trackers, and other tools. It also works in editors like VS Code and JetBrains, in a desktop app, and in the browser, and it can be run in scripts and CI for automated tasks.

Claude Code is included with paid Claude plans and can also be used with an API key billed by usage, so costs depend on how much you run it. Large autonomous sessions can consume a lot of tokens. Its output still needs review, especially for security-sensitive code. OpenAI's Codex, Google's Gemini CLI, Cursor, GitHub Copilot's agent, and Cline are the main alternatives.
