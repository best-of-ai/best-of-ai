Codiga offered real-time code analysis inside the editor. Its plugins for VS Code, JetBrains IDEs, and other tools scanned code as you typed for security vulnerabilities, bugs, and violations of coding standards, and a rules engine let teams write their own checks. It also provided a code snippet assistant and, later, AI-based suggestions, and integrated with Git platforms to review pull requests automatically.

The company was acquired by Datadog, which wanted to bring code analysis into its observability and security platform. Codiga's standalone products were shut down shortly afterward, with refunds for paid subscribers, and the team joined Datadog. The static analysis engine and its rules now underpin Datadog Code Security, and the analyzer is available as open source.

For similar tools, SonarQube, Semgrep, Snyk Code, and CodeQL provide static analysis, while AI review tools such as CodeRabbit and Qodo handle pull requests. Teams that use Datadog can use its built-in code security features. This entry stays for reference because older tool lists and tutorials still mention Codiga.
