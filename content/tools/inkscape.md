Inkscape is a capable vector editor that costs nothing. Users draw with pens, shapes, and text, and the results are stored as scalable vector graphics, which remain sharp at any size. It includes tools for paths, boolean operations, gradients, patterns, and a trace feature that converts bitmaps to vectors. Designers use it for logos, icons, illustrations, laser cutting files, and web graphics.

As an open-source project, it has a community that builds extensions and shares resources. Its SVG-centered design makes it a good fit for web work, and it can export to PNG, PDF, and other formats, and import many common file types. The interface has improved significantly in recent versions, and it runs on Windows, macOS, and Linux. AI features are not built into the core, though plugins and external tools add some.

Inkscape is free and developed by volunteers, supported by donations. Compared with Illustrator, it lacks some advanced features, has a steeper learning curve for certain tasks, and can be slower with very complex files. Alternatives include Adobe Illustrator, Affinity Designer, Figma for interface work, and Vectorizer.ai for conversion. Inkscape suits designers, students, and hobbyists who want a powerful vector tool at no cost.
