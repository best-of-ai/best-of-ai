Engineers set up projects with a configuration file, then build, upload, and debug firmware. It runs as an extension for VS Code. Library management and unit testing are included.

The core is open source, with paid features for teams.

Arduino IDE and Zephyr tooling are alternatives. PlatformIO suits embedded engineers who work across many boards.
