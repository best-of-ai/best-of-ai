Microsoft uses the Copilot name for a family of assistants rather than one product. The consumer Copilot app and website work like other AI chatbots: you can ask questions, generate text and images, talk by voice, and have it look at your screen or camera for help with what you are doing. It is built into Windows and the Edge browser, where it can summarize pages, compare information across open tabs, and help with tasks as you browse.

The business version is Microsoft 365 Copilot, and it is the one with the most practical value for office work. It sits inside Word, Excel, PowerPoint, Outlook, and Teams, and it can use your own documents, emails, and meetings as context, within the permissions you already have. It drafts documents, builds slides from a file, analyzes spreadsheet data, writes replies, and recaps meetings. Researcher and Analyst agents handle longer jobs, and Copilot Studio lets companies build their own agents on top of company data.

Copilot has a free consumer tier and paid consumer plans with higher limits. Microsoft 365 Copilot is a per-user add-on to qualifying business plans, and Microsoft sells it separately from the base Microsoft 365 license, so the total cost adds up for large teams. The models behind it come from OpenAI and other providers, and Microsoft changes which ones it uses over time. The main advantage is that it works inside tools many companies already pay for, with enterprise security and compliance controls attached. The main weakness is that quality is uneven across apps, and it is only as useful as the files and permissions behind it.
