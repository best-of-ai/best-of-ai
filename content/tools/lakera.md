Lakera defends applications built on language models. Its Guard product sits between users and a model, scanning prompts for attempts to override instructions, extract secrets, or inject malicious content, and checking outputs for leaks and harmful material. Developers add it with an API call.

The company grew out of research on adversarial attacks and became known for Gandalf, a public game where players try to trick a model into revealing a password, which generated a large dataset of attacks. Red teaming tools test applications before launch.

Check Point, a cybersecurity firm, acquired Lakera to add AI security to its platform. Lakera has had a free tier and paid plans. No filter catches everything, so layered defenses and limited permissions remain important. Alternatives include Prompt Security, Protect AI, HiddenLayer, Giskard, and cloud provider guardrails. Lakera suits teams deploying LLM applications.
