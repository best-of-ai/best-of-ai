Plandex works in the terminal and aims at tasks that span many files. It plans a change, builds it up in a sandbox so edits can be reviewed before they touch your project, and supports long context windows to keep track of large repositories. Changes can be rolled back, and different models can be used for different steps.

The team behind it announced that Plandex Cloud would wind down, leaving the self-hosted open-source server and CLI. That means new users need to run it themselves, and development activity has slowed, so check the repository for current maintenance.

Plandex is free, with costs for the model APIs you use. Other agents have since advanced quickly. Alternatives include Claude Code, OpenAI Codex, Aider, OpenCode, and Cline. Plandex suits developers who want an open agent they can host themselves.
