PagerDuty is an incident management platform. Monitoring tools send alerts, and PagerDuty decides who should respond based on schedules and escalation rules, notifying them by phone, text, or app. It groups related alerts so one problem does not create a flood of pages.

During an incident, it supports coordination: a timeline, chat integrations, status pages, and runbooks for common fixes. AI features summarize the situation, suggest causes based on past incidents, and help write postmortems. Automation can run diagnostic or remediation steps.

PagerDuty has a free plan for small teams and paid tiers. It is widely used by engineering and IT teams. Alternatives include Opsgenie (being retired by Atlassian), incident.io, Better Stack, Grafana OnCall, and FireHydrant. PagerDuty suits teams that run on-call rotations.
