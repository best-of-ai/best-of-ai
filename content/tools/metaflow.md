Metaflow lets data scientists write workflows as plain Python classes. Steps are functions, and the framework tracks code, data, and parameters for each run, so any result can be reproduced. It scales steps out to cloud compute with a decorator, without making the scientist learn infrastructure.

Netflix built it to let data scientists move from a laptop experiment to production on their own. Features include versioned artifacts, scheduling through orchestrators such as Argo Workflows and AWS Step Functions, and a UI for inspecting runs. Outerbounds, a company founded by Metaflow's creators, offers a managed platform.

Metaflow is free and open source. It is geared to ML and data workflows, not general application orchestration. Alternatives include Kubeflow, Dagster, Prefect, Airflow, and ZenML. Metaflow suits data science teams that want simple, reproducible workflows.
