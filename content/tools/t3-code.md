T3 Code is a fully open-source desktop app built by Theo (t3.gg) and developer Julius, designed to be a better frontend for agentic AI coding workflows. Rather than replacing tools like Claude Code or Codex under the hood, it acts as a smarter UI layer on top of them — letting you run multiple AI agents in parallel across different git repos/worktrees simultaneously, all from one organized interface. Theo describes it as born out of a genuine love of coding, and says he hasn't opened Codex in weeks since building it. It's fully open source (github.com/pingdotgg/t3code), currently in alpha, and the community has been particularly excited about the worktree-based parallel project workflow as the standout killer feature.
