Users load a video, type lines, and set timing with audio waveforms. Styling uses the ASS format, which supports fonts, colors, and positioning. Scripts automate repetitive edits.

The interface is old but dependable, and development is community driven.

Subtitle Edit and Amara are alternatives. Aegisub suits subtitlers who need precise control.
