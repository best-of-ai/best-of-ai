Buddy runs pipelines that start on a push, a pull request, a schedule or a webhook, and are set up in the web UI or in YAML. Claude Code, Codex CLI, Cursor, Antigravity and Grok Build are built-in pipeline actions, and an agent action gets the same code, variables and integrations as any other step. Typical jobs are reviewing a pull request when it opens, writing the PR description, drafting release notes or looking into a new Sentry issue. The same pipelines deploy to cloud providers, Kubernetes, servers over SSH and static hosting.

Work that does not fit a pipeline step can run in a sandbox, an isolated Ubuntu machine with Node, Python, Go, Docker and Claude Code preinstalled. Buddy fetches the repository into the sandbox, so the agent works on that copy instead of a developer's laptop. Sandboxes are managed with the bdy CLI or a TypeScript SDK.

An agent running locally can control Buddy through a remote MCP server or an installable skill, and run pipelines, read build logs, deploy to environments and manage sandboxes on request. Buddy has no free plan. A 14-day trial with $5 of usage credit requires a credit card, and after it teams choose the Pro or Team plan, with usage billed on top. Alternatives include GitHub Actions with Copilot agents, GitLab Duo, CircleCI, and sandbox providers such as E2B and Daytona.
