beacon.sh addresses a limit of coding agents: they start each session knowing little about the project. Beacon watches what the agent does, such as commands that work, mistakes it makes, and conventions it discovers, and stores them as notes the agent can use next time.

It works with popular coding agents and keeps the memory in files and a local store the developer can inspect and edit. Over time, that cuts repeated explanations and failed attempts.

The tool is free and open source, and new, so expect change. Stored notes should be reviewed since wrong lessons can persist. Alternatives include project instruction files such as CLAUDE.md and AGENTS.md, Mem0, Letta, and built-in memory in agent tools. beacon.sh suits developers using coding agents heavily.
