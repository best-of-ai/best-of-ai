Poolside focuses on one domain: code. The company trains large models from scratch, using reinforcement learning where the model writes code, runs it, and learns from whether it works. The aim is models that handle real software tasks reliably.

It targets customers with strict security needs, such as defense and large enterprises, and offers deployment in their own environments. Products include a coding assistant and an agent built on its models, and the company has invested heavily in computing infrastructure.

Poolside is sold on custom enterprise terms, and less is public about it than about consumer tools. Alternatives include Anthropic's Claude Code, OpenAI Codex, GitHub Copilot, Mistral's Codestral, and Cursor. Poolside suits organizations wanting private coding models.
