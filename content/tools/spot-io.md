Spot started as Spotinst, a company that helped users run workloads on cheap but interruptible cloud capacity. Its Elastigroup service predicts when spot instances will be reclaimed and moves workloads to keep applications running, which can reduce compute costs sharply. Ocean applies the same ideas to Kubernetes clusters, scaling nodes and choosing instance types automatically, and Eco manages savings plans and reserved instances.

NetApp acquired Spot, branded it Spot by NetApp, and later sold the Spot FinOps portfolio to Flexera, which now develops it alongside its other cloud cost tools. The tools support AWS, Azure, and Google Cloud, with dashboards showing savings, and they are sold on a model tied to a percentage of savings or capacity. Customers have included engineering teams running large container and batch workloads.

Savings depend on how tolerant applications are to interruption, and automation needs careful setup and trust. Alternatives include CAST AI for Kubernetes cost optimization, Karpenter as an open-source autoscaler, native tools such as AWS Compute Optimizer, CloudHealth, Apptio Cloudability, and Vantage. Spot suits teams with large cloud bills and workloads that can handle flexible capacity.
