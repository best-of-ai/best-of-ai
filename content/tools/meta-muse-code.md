Muse Code is Meta's entry into agentic coding. A developer starts it in a project folder, describes a task, and the agent explores the code, plans changes, edits files, and runs tests, working across a repository rather than on single files. It is powered by a Meta model tuned for coding.

Meta presents it as a lower-cost option next to tools from Anthropic and OpenAI, and it runs from the command line on macOS and Linux. Features such as running sub-agents in parallel aim at larger tasks. The tool was released in beta, so expect changes.

Access runs through Meta's model API, and pricing and limits may change. Benchmark claims come from Meta and secondary reports, so test on your own code. Alternatives include Claude Code, OpenAI Codex, Gemini CLI, Cursor, and Kimi Code. Muse Code suits developers who want to try another terminal agent.
