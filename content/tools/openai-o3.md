o3 takes a fundamentally different approach than standard language models. Instead of generating a response immediately, it runs an internal reasoning process — working through the problem step by step, exploring approaches, catching its own errors — before producing a final answer. This thinking process can take seconds or minutes depending on the complexity of the task and the effort level configured. On tasks that require this depth of reasoning, o3's accuracy is considerably higher than GPT-4o, which prioritises speed.

The benchmarks that o3 excels at reflect what it's actually useful for. It achieved near-perfect scores on the AIME mathematics competition problems that consistently trip up standard LLMs. On ARC-AGI, a benchmark designed to test general reasoning rather than memorised patterns, o3 demonstrated significantly stronger performance than previous models. For competitive programming and complex multi-step analysis, the extended thinking pays off in fewer wrong answers and more reliable logic.

o3 is available through the ChatGPT interface for Pro subscribers ($200/month), and via the API with per-token pricing that's higher than GPT-4o but justified for applications where accuracy is more important than cost per query. An o3-mini model offers reasoning capabilities at lower cost for applications that need multi-step thinking but can't absorb the full model's latency and expense. Teams doing scientific research, financial modelling, advanced code generation, and complex data analysis are the primary use cases where the reasoning advantage translates into concrete value.
