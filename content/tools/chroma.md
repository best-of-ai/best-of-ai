Chroma is a vector database aimed at developer simplicity. It stores embeddings, which are numerical representations of text, images, or other data, along with metadata and the original documents. Applications query it to find items similar in meaning to a given input, which is the core of semantic search and retrieval-augmented generation.

It is easy to start: a few lines of Python or JavaScript create a collection, add documents, and run queries, and it can run in memory inside a program, as a local server, or in a hosted cloud service. It integrates with LangChain, LlamaIndex, and other frameworks, which made it a common choice for prototypes.

Chroma is free and open source, with a managed Chroma Cloud for production. Large-scale deployments need attention to performance and operations, and some teams migrate to other databases for heavy workloads. Alternatives include Pinecone, Weaviate, Qdrant, Milvus, and pgvector in Postgres. Chroma suits developers prototyping retrieval applications.
