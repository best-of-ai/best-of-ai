Kilo Code runs as an extension for VS Code and JetBrains, as a command line tool, and as a desktop app. It has agents for coding, planning, asking questions, and debugging, and you can define your own. Agents can hand work to sub-agents and run in parallel, and cloud agents can keep working from the browser, Slack, or a phone app. The code is MIT licensed, and the command line tool is a fork of OpenCode.

You choose how to pay for models. The Kilo Gateway routes to more than 500 models and passes through provider prices with no markup, you can bring your own keys, or you can run local models through Ollama or LM Studio. A Code Reviewer checks pull requests automatically, and a marketplace lists agents, skills, and MCP servers.

The extension is free. Teams plans cost $15 per user per month, and cloud compute is billed by the hour on top of model usage. Anaconda announced in July 2026 that it had acquired Kilo Code, and it did not disclose the terms. Agents can change many files at once, so review the diffs before you accept them. Alternatives include Cline, OpenCode, Claude Code, and Cursor. Kilo Code suits developers who want an open-source agent that works with any model.
