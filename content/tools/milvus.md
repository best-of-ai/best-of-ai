Milvus is built for scale. It stores high-dimensional vectors, which represent text, images, or other data, and finds the nearest neighbors quickly even among billions of items. It supports different index types, filtering with metadata, and hybrid search that combines vectors and keywords.

The architecture separates storage and compute so it can run across a cluster, and there are lighter modes for development. It is part of the Linux Foundation's AI & Data group, and Zilliz offers a managed cloud service with additional features.

Milvus is free and open source, and running large clusters takes operational skill. Alternatives include Pinecone, Qdrant, Weaviate, Chroma, and pgvector. Milvus suits teams that need scalable vector search.
