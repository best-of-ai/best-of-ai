Promptfoo helps developers test AI systems systematically. A user defines test cases and criteria in a configuration file, runs prompts across models, and compares outputs side by side, with assertions that check for expected content, format, or safety. It runs from the command line and in CI pipelines.

Red-teaming features generate adversarial inputs to probe for jailbreaks, prompt injection, data leaks, and other vulnerabilities, and report where an application fails. It supports many providers and local models and has been widely adopted.

OpenAI announced it was acquiring Promptfoo to build security testing into its agent platform, so its direction may evolve; check the project's current status. The core tool has been free and open source, with enterprise options. Alternatives include Braintrust, Patronus AI, Giskard, Garak, and LangSmith. Promptfoo suits developers testing AI applications.
