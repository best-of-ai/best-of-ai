Exa, formerly Metaphor, rethinks search for machines instead of people. Where a traditional engine matches keywords, Exa uses neural embeddings to find pages that are semantically similar to a query, even when they do not share words. You can search with natural-language descriptions, such as a list of startups building a specific kind of robot, and it returns results that match the idea. It can also take a link and find similar pages.

For developers, Exa is an API that delivers content in a form suited to language models. A search call can return full page text or highlights, so an agent can read results without scraping. Additional products include deep research that runs multi-step searches and compiles answers with citations, and Websets, which builds structured lists of companies, people, or papers with data gathered from the web. These features are used in AI assistants, sales research, and data collection.

Exa offers a free tier and pay-as-you-go pricing for API calls, with enterprise plans. Results are strong for research-style queries, though classic keyword searches for a specific known page may be handled better by Google. Competitors for AI-oriented search include Perplexity's API, Tavily, Brave Search API, Parallel, and Google's search grounding in Gemini. Developers often try several for their use case, since quality varies by query type.
