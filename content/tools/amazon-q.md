Amazon Q Developer is the successor to CodeWhisperer, and it is built around AWS knowledge. In VS Code, JetBrains, and other IDEs it offers inline code suggestions and a chat panel that explains code, writes tests, and optimizes functions. In the terminal, it adds autocomplete and a chat that can translate plain language into shell commands. In the AWS console and on chat platforms like Slack, it helps troubleshoot services and explains why a resource is misbehaving.

Its agentic features handle bigger jobs. An agent can read your project, plan the work, edit several files, and run commands to complete a feature, write documentation, or review code. Specialized transformation agents upgrade Java versions and port .NET applications to run on Linux, which is tedious work for large codebases. A built-in scan finds security problems in code and suggests fixes.

A free tier gives limited monthly use, and a paid Pro plan raises the limits and adds admin controls, including a promise that your content is not used to improve the service. AWS has been shifting its newer agentic work toward Kiro, its own AI-first IDE, so the Q Developer plugins are best seen as one of several AWS options. It makes the most sense for teams that live on AWS, while GitHub Copilot and Cursor are broader general-purpose rivals.
