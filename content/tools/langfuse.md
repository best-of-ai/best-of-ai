Langfuse gives developers visibility into LLM applications. By adding its SDK or an integration, each request is traced with its prompts, model responses, tool calls, latency, and cost, including nested steps in agent workflows. Engineers inspect failures in a web interface and see usage across users and sessions.

Beyond observability, it supports quality work. Prompt management lets teams version and deploy prompts without code changes, evaluation features score outputs through LLM judges, user feedback, or custom checks, and datasets let teams run experiments before release. The product can be self-hosted, which suits privacy-sensitive teams.

Langfuse has a free cloud tier, paid plans, and a free open-source version. ClickHouse acquired the company, and the project remains open. Alternatives include LangSmith, Braintrust, Arize Phoenix, Helicone, and Weights & Biases Weave. Langfuse suits teams building production LLM applications.
