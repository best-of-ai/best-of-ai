CephX automates cephalometric tracing. An orthodontist uploads a lateral ceph image, the AI places the landmarks, and a full set of measurements comes back within seconds instead of the manual tracing time.

It includes many standard analyses, so a practice can pick the one it already uses. For 3D work, it can build a 2D cephalometric view from CBCT scans and includes airway analysis.

CephX is a paid service. Landmark placement still needs a clinician's review, and the accuracy claims come mostly from the vendor. Alternatives include Owandy Ceph Analysis, Invivo, and Diagnocat. CephX suits orthodontic practices that want faster, more consistent ceph analysis.
