Agent skills tend to pile up in scattered folders. Skillbox keeps them in one library and syncs them to the directories that Claude Code and Cursor read from. You can import from your computer, GitHub or GitLab, switch skills on per project, and keep incoming updates apart from the version you are using.

Skillbox Trust scans skills for prompt injection, exfiltration and secrets using Cisco's Skill Scanner. Capture turns a successful agent session into a skill, and Trim shortens command output before the agent reads it. It also flags overlapping skills and pauses ones that go unused. There is a Mac desktop app.

The free plan covers a few devices and a set number of followed sources, with no card needed. Paid plans add Trim and the built-in AI after a trial, and a team plan adds shared workspaces. Developers who use several coding agents get the most from it.
