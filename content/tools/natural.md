Natural addresses a gap in agent infrastructure: how an AI agent pays for things. Through its API, developers create an account for an agent, fund it, set spending rules, and let it pay vendors, receive money, or issue virtual cards for purchases.

Controls matter, since a spending agent can cause damage. Limits, approvals, and logs let the owner decide what an agent may buy and see what it did. The company positions this as payments infrastructure for a future where agents transact with each other and with businesses.

Agent payments are early, with evolving rules and risk. Natural is a paid developer product, and independent information is limited. Alternatives include Stripe's agentic commerce tools, Visa and Mastercard agent programs, Coinbase's x402 and wallets, and Skyfire. Natural suits developers building agents that need to transact.
