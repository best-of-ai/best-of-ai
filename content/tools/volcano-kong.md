Volcano is a platform for building and hosting agents and the apps around them, created by Kong. The CLI is the main interface, so coding agents such as Claude Code, Codex, Cursor and OpenCode can deploy and run things directly.

The building blocks include durable functions with checkpoints, approvals, sandboxes, distributed locks, managed Postgres with pgvector, auth, file storage, realtime and Next.js hosting. The homepage also presents LavaFlow as its feature for self-healing apps.

A free hobby plan needs no card. The paid Superagent plan includes a monthly credit allotment and costs less when billed annually, and enterprise is custom. Developers who build with coding agents are the audience. Supabase, Vercel and Temporal each cover part of the same ground.
