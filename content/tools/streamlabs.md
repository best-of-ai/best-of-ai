Streamers use Streamlabs Desktop to build scenes, add overlays, and go live. Alerts show donations and follows. Extra tools help with clips and multistreaming, and an AI assistant can help with clips.

Some features need a paid plan.

OBS Studio is the open-source base. Streamlabs suits streamers who want ready-made overlays.
