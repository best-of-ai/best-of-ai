Custom Agents extend Notion AI from something you chat with into something that works on its own. A team sets up an agent with instructions and the content it can access, then chooses what should trigger it: a schedule, a comment on a page, a change to a database, an @mention, or messages in a public Slack channel. The agent then does the job, such as triaging incoming requests, compiling a weekly report, updating a tracker, or answering questions in a channel.

Control and transparency are built in. Each run is logged, so people can see what the agent did and revert changes, and agents only use content that they have been explicitly granted access to. Administrators decide who can create agents and which models they may use, and can monitor how many credits agents consume. Agents pause when credits run out, which prevents surprise charges.

Custom Agents are available on Business and Enterprise plans, and usage is metered through Notion credits that are bought as an add-on. Costs depend on how much content an agent reads and how often it runs, so it is worth starting with a few well-defined jobs. Notion has since added ways to connect external agents. Alternatives include Zapier Agents, Microsoft Copilot Studio, Slack's AI agents, and ChatGPT Work. Custom Agents suit teams that already live in Notion.
