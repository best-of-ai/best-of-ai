Comet makes the assistant part of the browser. Instead of copying content into a chatbot, users can ask questions about the page they are on, compare information across tabs, summarize a thread, or have the assistant search and collect results. Perplexity's answer engine is the default way to search.

An agent mode lets the assistant take actions, such as filling in forms, managing a calendar or inbox, or completing a purchase flow, while the user watches and can step in. This gives it the power and the risks of any browsing agent, including exposure to prompt injection from malicious web pages.

Comet is built on Chromium, so extensions and bookmarks carry over. Access has expanded over time, with some features tied to Perplexity plans. Alternatives include ChatGPT Atlas, Dia, Microsoft Edge with Copilot, Chrome with Gemini, and Brave. Comet suits people who want an AI-first browser.
