Google AI Studio is where developers go to try Google's models without setting anything up. You sign in with a Google account, pick a Gemini model, and start prompting in a playground that lets you adjust settings like temperature, add system instructions, and attach images, audio, video, or documents. Once a prompt works, one click gives you the code to run it through the Gemini API in Python, JavaScript, and other languages.

It has grown into more than a playground. A build mode can create a small working web app from a description, which you can preview, edit, and deploy. Live mode lets you test real-time voice and video conversations with a model, and other tools cover image generation, video generation, and structured outputs. It is also where you create and manage Gemini API keys and see usage.

Use is free within rate limits, which makes it popular for prototyping and learning. For production, you pay by usage on the Gemini API or move to Vertex AI on Google Cloud, which adds enterprise features such as data governance and service-level agreements. On the free tier, Google may use your prompts to improve its products, so sensitive data should not go in. Alternatives include OpenAI's Playground, Anthropic's Console, and AWS Bedrock's playground.
