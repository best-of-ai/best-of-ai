Make, formerly called Integromat, lets you automate work between apps by drawing it. You place modules on a canvas for each app, such as Gmail, Google Sheets, Slack, or a CRM, and connect them with lines that show how data flows. You can add routers that split the flow into branches, filters that decide which items continue, iterators that handle lists, and functions that change data on the way. This visual layout makes complicated logic easier to follow than a long linear list of steps.

It supports a large library of app integrations plus a generic HTTP module and webhooks for anything without a ready-made connector. AI modules bring in models from OpenAI, Anthropic, Google, and others for tasks like classifying messages, summarizing documents, or extracting details from text. Make also offers AI agents that can decide which tools to use for a goal, and scenarios can run on a schedule, by webhook, or when new data arrives.

Make has a free plan with a monthly operation allowance, and paid plans scale with the number of operations. Because each module run counts as an operation, a complex scenario that handles many items can use up a plan quickly. It tends to cost less than Zapier for the same work but has a steeper learning curve. n8n is the main self-hostable alternative. Non-technical users who want the simplest setup often prefer Zapier.
