Cuey is a tool for comparing chatbots. From a sidebar in Chrome, you type a prompt once and it goes to services such as ChatGPT, Claude, and Gemini that you are logged into, with the responses displayed together. A view highlights where the answers agree and differ, which is useful for fact-checking and choosing the best phrasing.

It includes a library of saved prompts and a memory feature so context can follow you from one model to another. Because it works with the chat interfaces you already use, it does not need separate API keys. The developer, Llama Valley Inc, states that prompts and responses are not stored on its servers.

Cuey is free to install, with paid options. Privacy claims come from the developer, so review the extension's permissions before use. Alternatives include ChatHub, Poe, ChatPlayground, LMArena, and MultiGPT. Cuey suits people who regularly compare answers across chatbots.
