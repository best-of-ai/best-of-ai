The free axe DevTools browser extension runs on a page and lists issues with the offending element and a suggested fix. The same engine, axe-core, plugs into test frameworks like Cypress, Playwright, and Jest, so teams can catch regressions in continuous integration. Deque's paid products add guided manual testing and reporting.

Automated checks find only part of all accessibility problems, since things like reading order and meaningful link text need a person. Auditors usually run axe first and then test with a screen reader and keyboard.

WAVE, Lighthouse, and Pa11y are common alternatives. axe suits accessibility specialists and developers who want checks built into their workflow.
