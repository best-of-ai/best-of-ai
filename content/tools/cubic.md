cubic is an AI code reviewer that looks beyond the diff. It reads the wider codebase to judge whether a change is likely to cause problems, and it leaves inline comments on the pull request. A merge confidence score from one to five gives reviewers a quick signal about how much attention a change needs.

Other features reduce review load. Low-risk pull requests can be auto-approved, nightly scans look for bugs across the repository, and reviews can run from the terminal before you push. Teams use it to cut the queue of pull requests waiting for a human.

It is free for public repositories, which makes it a practical option for open source maintainers, and paid plans cover private repos. CodeRabbit and Qodo are the usual alternatives. Because AI reviewers can miss context or flag false positives, treat it as a first pass that reduces human review time and not a replacement for it.
