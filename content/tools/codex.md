Codex works as a software engineering agent. A developer describes a task, such as fixing a bug or adding a feature, and Codex explores the code, makes a plan, edits files, and runs tests or linters to verify the result. It reports back with a summary of what it changed and why.

It comes in several forms. A command line tool runs on the developer's machine, a desktop app manages multiple tasks, extensions integrate with editors like VS Code, and a cloud version in ChatGPT runs tasks in isolated sandboxes, often in parallel, and can propose pull requests on GitHub. Configuration files let teams give the agent project instructions.

Codex is included with ChatGPT plans, with usage limits that depend on the tier, and API access is available for builders. Agents make mistakes, so changes need review and tests. Alternatives include Claude Code, Cursor, GitHub Copilot's agent, Gemini CLI, and Devin. Codex suits developers who want OpenAI's agent in their workflow.
