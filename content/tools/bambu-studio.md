Bambu Studio turns 3D model files into instructions a printer can follow. You load a model, arrange it on the virtual build plate, set options such as layer height, supports, and infill, and the slicer generates the toolpath, previewing how the print will be built. It supports multicolor and multimaterial printing through Bambu's automatic material system, with tools to assign colors and manage waste.

It is based on open-source slicer code and is itself open source. Features include automatic calibration, print profiles tuned for Bambu printers and common filaments, remote monitoring and control over the cloud, and integration with MakerWorld, Bambu's online library of models, where users share designs and print profiles. It runs on Windows, macOS, and Linux and also supports some other printers.

Bambu Studio is free. It is designed mainly for Bambu Lab hardware, and the company's closed cloud features and firmware approach have attracted debate among makers. OrcaSlicer is a popular community fork that supports many printer brands, PrusaSlicer and Cura are other well-known slicers, and Simplify3D is a paid alternative. Bambu Studio suits owners of Bambu printers who want a smooth, integrated workflow.
