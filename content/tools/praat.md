Users load recordings, view spectrograms, annotate segments, and run scripts for batch analysis. It also supports speech synthesis experiments. The interface is old-fashioned but very capable.

It is open source and runs on Windows, macOS, and Linux.

ELAN is useful for annotating video and audio. Praat suits linguists studying phonetics.
