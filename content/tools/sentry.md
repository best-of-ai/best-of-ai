Sentry tells developers when their code breaks and why. By adding an SDK to an app, errors are reported with stack traces, the environment, the user's actions leading up to the problem, and the release that introduced it. Sentry groups duplicate errors into single issues, sends alerts, and links to the relevant commit, so teams can fix a bug quickly rather than discovering it from user complaints.

Beyond error tracking, Sentry monitors performance with tracing that shows slow requests and database queries, and session replay records what the user saw. Cron monitoring watches scheduled jobs, and release health tracks crash-free sessions. Its AI assistant, Seer, analyzes issues to suggest root causes and can propose fixes, and tools for monitoring AI applications trace model calls. It supports most languages and frameworks, and integrates with GitHub, Slack, and Jira.

Sentry has a free developer plan and paid plans scaled by event volume, and it can be self-hosted. The source is available under a license that allows use but restricts competing hosted services. Costs rise with traffic unless you sample events. Competitors include Bugsnag, Datadog, New Relic, Rollbar, and Firebase Crashlytics for mobile. Sentry is one of the most popular choices for developers because of its focus on code-level detail.
