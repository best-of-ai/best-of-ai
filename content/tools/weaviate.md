Weaviate stores objects and their vector embeddings together. Applications query by meaning, filter by metadata, and combine vector similarity with keyword search. It can create embeddings itself through integrated modules or accept vectors from outside.

Generative search lets a query retrieve relevant objects and pass them to a language model in one step, which suits retrieval-augmented generation. Multi-tenancy, replication, and compression support production use at scale. Weaviate can be self-hosted or used as a managed cloud service.

Weaviate is open source with a free sandbox and paid cloud plans. Alternatives include Pinecone, Qdrant, Milvus, Chroma, and pgvector. Weaviate suits developers building search and RAG applications.
