Haystack helps developers assemble applications that answer questions over documents. A pipeline strings together components: converting files, splitting text, creating embeddings, retrieving relevant passages, and generating an answer with a language model. Each component is swappable, so teams can change a model or database without rewriting everything.

The framework supports many model providers and vector stores, hybrid search, evaluation tools, and agents that use tools. It also provides a way to serialize pipelines, which supports deployment and testing. deepset offers a commercial platform around it for companies that want managed hosting and collaboration.

Haystack is free and open source. It has a learning curve and competes with other orchestration frameworks. Alternatives include LangChain, LlamaIndex, DSPy, Semantic Kernel, and Vercel AI SDK. Haystack suits engineering teams building production search and RAG systems.
