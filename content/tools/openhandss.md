OpenHands provides an open alternative to commercial coding agents. A user gives it a task, and the agent works in a sandbox with a terminal, an editor, and a browser, taking steps to complete the job and showing its work. It can resolve GitHub issues and open pull requests.

The project started as OpenDevin, an open-source response to the Devin demo, and grew into a community-driven platform run by All Hands AI. It supports models from many providers, has a command line tool and a web interface, and is used in research and benchmarks for coding agents.

OpenHands is free and open source, with a hosted cloud option. Agent results vary and need review. Running it needs Docker and an API key. Alternatives include Devin, Claude Code, OpenAI Codex, SWE-agent, and Cline. OpenHands suits developers and researchers who want an open coding agent.
