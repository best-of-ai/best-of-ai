Azure OpenAI is OpenAI's model lineup delivered through Microsoft's cloud. Companies use it to get the same families of language, reasoning, image, and audio models, but under Azure's terms, billing, and security controls. For regulated industries and large enterprises, that matters: the data is processed inside Azure, can be isolated on a private network, and is covered by Microsoft's compliance certifications and service-level agreement.

Development happens in Microsoft Foundry, where you deploy a model, test it in a playground, and connect it to your own data and tools. Available features include fine-tuning, content filtering, tool and function calling, retrieval over company documents, and tracing. Deployments come in several types, such as standard pay-as-you-go, batch, and provisioned throughput, which reserves capacity for steady workloads with predictable latency. Foundry also offers non-OpenAI models, so teams can compare options in one place.

New OpenAI models sometimes arrive on Azure slightly later than on OpenAI's own API, and access to the newest ones may require an application. Pricing follows OpenAI's token-based model with Azure billing, and enterprise discounts are common. It is mainly for companies already standardized on Microsoft, as its main alternatives are AWS Bedrock and Google Vertex AI. Individuals and small projects usually find OpenAI's own API simpler.
