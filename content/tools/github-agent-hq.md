Agent HQ was announced at GitHub Universe in October 2025 and released more widely in early 2026. OpenAI's Codex was the first outside agent supported, followed by Claude Code. Admins choose which agents and models their teams may use, and a metrics dashboard shows usage. Plan Mode lets an agent propose steps before it writes code.
