You describe the game you want and Wanaka Studio produces a first playable version in the browser. From there you keep directing the AI in plain language, or you edit the world yourself. Characters, environments, animations, UI and visuals all live in one studio, so you don't need to code or juggle separate asset tools.

Behind the prompt is what the product calls an AI game team, with roles for planning, art, music, testing and promotion. When the game is ready you publish it to a browser link and share it. A community forum is where people post games, run playtests and collaborate, and creators can remix each other's projects.

There is a free way to start, and paid plans are billed monthly or yearly. It suits people with a game idea and no programming background. Developers who want full control over engine code will probably still prefer Unity or Godot.
