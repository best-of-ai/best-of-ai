Inngest lets developers define workflows in code that survive failures. A function is broken into steps, and Inngest stores the result of each step, retries failures, and resumes where it left off. This suits tasks like processing orders, sending sequences of emails, and running AI agent chains that take a long time.

It is designed for serverless platforms such as Vercel and AWS Lambda, where long-running processes are awkward. Features include event triggers, scheduled runs, rate limiting, concurrency control, and a dashboard to inspect runs and replay failures. It supports TypeScript, Python, and Go.

Inngest has a free tier and usage-based paid plans, and the server is open source. It competes with other workflow tools, and teams need to learn its model. Alternatives include Temporal, Trigger.dev, Restate, AWS Step Functions, and Hatchet. Inngest suits developers building durable workflows on serverless.
