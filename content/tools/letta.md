Letta grew out of the MemGPT research project, which proposed managing an agent's memory like an operating system manages memory. In Letta, an agent has a core memory it always sees and external stores it can read and write, so it can keep information across conversations that far exceed a model's context window.

Developers create agents through an API, define their tools and memory blocks, and let them run over long periods. This suits assistants that need to remember user preferences, companions, and agents that learn from experience. A hosted platform manages deployment, and tools let developers inspect and edit what an agent remembers.

Letta is open source with a cloud service that has free and paid tiers. Memory systems add complexity and cost, and what an agent stores needs privacy care. Alternatives include Mem0, Zep, LangGraph with memory, and memory features in OpenAI and Anthropic products. Letta suits developers building agents that remember.
