Kite is a collaborative interface design tool built so AI agents can work in the same file as people. Claude, ChatGPT, Cursor or Codex connect to Kite's hosted MCP server and create real, editable layers: frames, text, components and auto layout, rather than flat images or one-off code. Teammates see those changes appear live and can keep editing them by hand.

Finished frames can be copied into Figma, or copied out as HTML, React or Tailwind code. Kite runs in the browser and also ships Mac and Windows apps.

The free plan includes unlimited editors, 3 files and 200 agent actions a day, and agents use your own AI subscription rather than Kite credits. Pro costs $16 per editor per month billed yearly, or $20 monthly. Kite launched in 2026, so it is younger and has a smaller plugin ecosystem than Figma.
