Antigravity is Google's take on an AI-first coding environment. Instead of a chat panel beside the editor, agents have direct access to the editor, the terminal, and a browser, so they can write code, run it, test the result in a browser, and report back with artifacts such as plans, screenshots, and recordings that show what they did.

Developers can run several agents in parallel and manage them from a control view. Later versions added background tasks that run on a schedule and a standalone command line tool. The environment uses Google's Gemini models and can work with other models.

Antigravity has been offered free in preview, with usage limits, and terms may change. Agents with terminal and browser access need careful permissions. Alternatives include Cursor, Windsurf, Claude Code, OpenAI Codex, and GitHub Copilot's agent mode. Google Antigravity suits developers who want to try agent-first workflows.
