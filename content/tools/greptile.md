Greptile is an AI code reviewer with a focus on codebase context. Instead of reading only the diff, it builds an understanding of the whole repository, including how functions and modules relate, so comments can point to impacts in files the pull request did not touch.

It posts review comments and summaries on GitHub and GitLab pull requests. Teams can set rules in plain language, and the system learns from thumbs up and down on its comments to reduce noise. An API allows developers to ask questions about the codebase.

Greptile is paid, priced per developer, with a trial. Automated review can miss design problems and sometimes produces false alarms, so human review is still important. Alternatives include CodeRabbit, Graphite, GitHub Copilot code review, Qodo, and Sourcery. Greptile suits teams with large codebases that want deeper context in reviews.
