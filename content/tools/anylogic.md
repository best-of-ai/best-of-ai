Models can use discrete-event, agent-based, or system dynamics methods, alone or combined. Users run experiments, see animations, and analyze results. Java scripting allows custom logic.

A free version exists for learning, and professional licenses are paid.

Simul8 and Arena are alternatives. AnyLogic suits industrial engineers who run simulation studies.
