Phidata began as a Python framework for turning language models into agents. Developers define an agent with instructions, tools, memory, and a knowledge base, and the framework handles running it, storing history, and retrieving documents. It also supports teams of agents that work together.

The project was renamed Agno, and the same team and codebase continue under the new name, so documentation and packages now refer to Agno. Newer releases focus on speed, a lightweight design, and production features such as a runtime for serving agents.

The framework is free and open source. Check Agno's current documentation for installation and licensing, since details changed with the rename. Alternatives include LangGraph, CrewAI, Mastra, the OpenAI Agents SDK, and Haystack. This listing covers the earlier name. Phidata suits developers looking up the older project, who will want Agno's current docs.
