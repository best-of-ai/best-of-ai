PearAI is a standalone editor forked from VS Code, with AI features built in. Developers get code completion, a chat panel that understands the project, and inline editing, and can connect their preferred models. Because it is a fork, familiar extensions and settings carry over.

It positions itself as an open alternative to Cursor and Windsurf. The AI layer builds on Continue, an open-source assistant. The project had a licensing controversy early on regarding its use of existing code, which it has since addressed.

PearAI offers free use with an optional paid subscription for hosted models. Forks of VS Code face maintenance work to keep up with upstream, and the project is smaller than its rivals. Alternatives include Cursor, Windsurf, Cline, Continue, and Void. PearAI suits developers who want an open-source AI editor.
