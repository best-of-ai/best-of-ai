dbt, short for data build tool, became the standard way to transform raw data inside a warehouse such as Snowflake, BigQuery, or Databricks. Analysts write SQL select statements, define dependencies among them, and dbt builds tables and views in the right order, with version control, testing, and documentation. This brings software engineering practices like code review and continuous integration to analytics work.

dbt Cloud is the hosted product from dbt Labs. It provides a browser-based IDE, job scheduling, CI that tests changes before they reach production, a data catalog with lineage, and a semantic layer that defines metrics once for use across BI tools. AI features help generate models, tests, and documentation, and answer questions about the project, which speeds up repetitive tasks.

dbt Core, the open-source engine, is free, and dbt Cloud has a free developer plan and paid team and enterprise plans. Running dbt yourself needs infrastructure and orchestration, which is what the cloud product removes. Alternatives include SQLMesh, Dataform in BigQuery, Coalesce, and warehouse-native features. dbt suits analytics engineers who want a structured, testable transformation layer.
