GitHub Copilot is the AI coding tool with the largest user base, and it is built into the place where most code already lives. It started as inline autocomplete, finishing lines and functions based on the file you were in, and it still does that in VS Code, Visual Studio, JetBrains IDEs, Neovim, and Xcode. A chat panel explains code, writes tests, fixes errors, and answers questions about your project without leaving the editor.

The newer parts are agentic. Agent mode in the editor plans a task, edits several files, runs terminal commands, and iterates on failures. The Copilot coding agent works on GitHub directly: you assign it an issue, and it works in the background and opens a pull request for you to review. Copilot can also review pull requests, help in the command line, and use models from several providers, which you choose from a picker. Teams can add custom instructions so it follows their conventions.

There is a free tier with limited usage, paid individual plans, and business and enterprise plans with admin controls, policy settings, and options to exclude code from model training. Premium requests to the strongest models may be metered, so heavy use can reach limits. Because it works inside the tools developers already use, adoption is easy. Cursor, Windsurf, and Claude Code offer more agent-centered experiences, while Copilot's strength is breadth, integration with GitHub, and enterprise support.
