Factory sells AI agents for engineering teams. Droids take tasks from tickets or chat, explore a codebase, make changes, run tests, and open pull requests for review. Specialized droids handle different jobs, such as code review, incident response, or migrations.

The product works through a command line tool, IDE integrations, and a web interface, and connects to GitHub, Jira, Slack, and other tools so agents fit into existing workflows. Enterprise features address security, permissions, and model choice, with support for several model providers.

Factory is paid, with plans by usage, and targets professional engineering teams. Agent output needs review and good tests. Alternatives include Claude Code, OpenAI Codex, Devin, Cursor, and GitHub Copilot's agent. Factory suits engineering organizations automating routine development tasks.
