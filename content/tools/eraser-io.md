Eraser is built around engineers' diagrams. Users can write diagrams as code in a simple syntax, draw them visually, or describe them in plain language and let AI generate the first version. The result stays editable, with a clean style that looks good in documentation and design reviews.

The product also supports documents. Eraser has a docs editor where diagrams sit alongside text for design documents and runbooks, and integrations with GitHub allow diagrams to be generated from a repository and kept in sync. Teams share and comment on documents in real time.

Eraser has a free plan and paid tiers for teams. It is aimed at technical diagrams, so general whiteboarding needs other tools. Alternatives include Mermaid, Lucidchart, draw.io, Excalidraw, and Miro. Eraser suits engineering teams documenting systems.
