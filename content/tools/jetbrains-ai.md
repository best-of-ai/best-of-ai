JetBrains AI Assistant works inside the IDEs that many professional developers already use. In IntelliJ IDEA, PyCharm, WebStorm, GoLand, Rider, and the rest of the family, it provides inline completion, a chat panel that understands the project, and actions to explain code, generate tests, write commit messages, and suggest fixes for errors. Because it is built into the IDE, it can use the IDE's deep knowledge of code structure, such as types, references, and run configurations.

Junie is JetBrains' coding agent, which can take a task, plan the work, edit files, run tests, and iterate. The assistant lets you choose among models from providers such as OpenAI, Anthropic, and Google, and supports local models for those who need data to stay on their machine. JetBrains also develops its own code completion model for fast suggestions, and integrates with other agents through its protocols.

AI Assistant is sold as a subscription add-on to JetBrains IDEs in tiers, with a free tier that has limited usage and paid tiers that raise quotas. It works best for developers who prefer JetBrains IDEs over VS Code. GitHub Copilot also runs inside JetBrains IDEs, Cursor and Windsurf are separate AI editors, and Claude Code and other agents can work alongside the IDE. Developers should review how code is sent to model providers under the organization's policy.
