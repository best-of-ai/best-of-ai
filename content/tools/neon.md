Neon runs PostgreSQL in the cloud with a design that lets databases scale to zero when idle and start quickly when needed. Because storage and compute are separate, it can create copy-on-write branches of a database instantly, which suits testing, previews, and development workflows.

Branching has become useful for AI work, where agents and coding tools create databases on the fly. The pgvector extension supports embeddings and similarity search, so developers can store vectors next to ordinary data. The platform is used with frameworks like Next.js and with serverless hosts.

Neon has a free tier and usage-based plans. Databricks acquired the company to bring serverless Postgres into its data and AI platform. Alternatives include Supabase, PlanetScale, Amazon Aurora Serverless, CockroachDB, and Xata. Neon suits developers who want serverless Postgres with branching.
