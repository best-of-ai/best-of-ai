NIM, short for NVIDIA Inference Microservices, packages a model so it is easy to deploy. Each microservice includes the model, optimized inference engines such as TensorRT-LLM, and standard APIs, delivered as a container. A team can run it on a cloud, a data center, or a workstation with NVIDIA GPUs and get tuned performance.

A catalog covers language models, vision, speech, and biology models from NVIDIA and partners, with APIs compatible with common formats such as OpenAI's. Enterprises use NIM to keep models and data inside their environment while reaching production speed.

Free access exists for development, and production use in an enterprise typically requires an NVIDIA AI Enterprise license. NIM runs on NVIDIA hardware. Alternatives include vLLM, Ollama, Hugging Face TGI, Baseten, and Together AI. NVIDIA NIM suits organizations deploying models on NVIDIA infrastructure.
