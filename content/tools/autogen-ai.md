AutoGen made multi-agent applications approachable. Developers define agents with roles, such as a coder, a reviewer, and a user proxy, and let them converse to solve a problem. Agents can write and run code, call tools, and ask humans for input, and the framework manages the message passing between them.

The project began at Microsoft Research and attracted a large community. A visual tool, AutoGen Studio, let people prototype agent teams without code. Over time, Microsoft consolidated its efforts, pointing new projects to the Microsoft Agent Framework, which combines ideas from AutoGen and Semantic Kernel, and describing AutoGen as being in maintenance mode.

AutoGen remains free and open source, and a community fork called AG2 continues development under its original creators. For new work, evaluate Microsoft Agent Framework or alternatives such as LangGraph, CrewAI, OpenAI Agents SDK, and Claude's Agent SDK. Existing AutoGen projects still run, and AutoGen suits people maintaining older systems or studying multi-agent patterns.
