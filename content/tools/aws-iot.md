AWS IoT Core is the entry point for Internet of Things devices into AWS. Devices connect using MQTT, HTTPS, and other protocols, authenticate with certificates, and publish and receive messages, with the service scaling to billions of devices and trillions of messages. A device registry tracks each device, and Device Shadows keep a copy of the device's state so applications can interact with it even when it is offline.

A rules engine processes incoming data and routes it to other AWS services such as Lambda, S3, DynamoDB, Kinesis, and SageMaker, so data can be stored, analyzed, or used to trigger actions. Related services handle device management, fleet monitoring, over-the-air updates, and edge computing with AWS IoT Greengrass, which runs code and machine learning models on the device. Security features include fine-grained policies, and logging and monitoring tools.

AWS IoT Core is priced per message, connection time, and rules actions, with a free tier. Building an IoT system involves hardware, firmware, and connectivity choices outside the cloud, and costs can vary with message volume. Alternatives include Azure IoT Hub, Google Cloud's IoT options, which have changed over time, and platforms such as ThingsBoard and HiveMQ. AWS IoT Core suits teams building connected products on AWS.
