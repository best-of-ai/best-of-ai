CodeWhisperer was Amazon's first coding assistant, a counterpart to GitHub Copilot that suggested lines and whole functions as you typed in editors such as VS Code and the JetBrains IDEs. It was trained with a special focus on AWS APIs, so it was particularly good at code that called S3, Lambda, DynamoDB, and other AWS services. It also supported many popular programming languages.

Two features set it apart from early rivals. A reference tracker flagged suggestions that resembled open-source code and showed the license, and a security scan checked your code for vulnerabilities such as exposed credentials and injection flaws. An individual tier was free, and a professional tier added admin controls and higher limits.

AWS has since merged CodeWhisperer into Amazon Q Developer, a broader assistant that adds chat, agents that work through multi-step tasks, code transformation, and help inside the AWS console. If you are looking for the product today, Q Developer is the one to evaluate, and the original name mostly survives in older documentation and blog posts. Alternatives include GitHub Copilot, Cursor, and JetBrains AI Assistant.
