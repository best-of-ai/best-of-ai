Canvas changes how you work with ChatGPT on longer projects. When a request involves writing a document or code, ChatGPT can open a separate pane next to the conversation, where the text or code appears as an editable file. You can edit it directly, highlight a passage and ask ChatGPT to change just that part, and see changes without the whole response being regenerated.

For writing, shortcuts adjust the length, reading level, and tone, add polish or emojis, and suggest edits inline like a collaborator leaving comments. For coding, Canvas helps review code, add comments and logs, fix bugs, and port a project to another language, and it can run some code, such as Python, within the interface. Version history lets you go back to earlier drafts.

Canvas is available to ChatGPT users across plans, with features tied to the model and updates over time. It is a convenience feature, not a separate product, and it isn't as full-featured as a dedicated editor or IDE. Claude's Artifacts, Google Gemini's Canvas, and Microsoft Copilot's Pages offer similar side-by-side editing, and tools like Cursor and Notion AI serve deeper code and document needs. Canvas suits people who iterate on drafts with ChatGPT.
