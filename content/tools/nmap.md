Users run scans from the command line or a graphical front end such as Zenmap. The scripting engine adds checks for vulnerabilities and service details. Results export to several formats.

Scanning networks without permission is illegal in many places, so use it only on systems you are allowed to test.

Masscan is faster at scale. Nmap suits penetration testers and network engineers.
