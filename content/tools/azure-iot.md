Azure IoT Hub is the messaging backbone for connected devices on Azure. Devices send telemetry such as sensor readings to the cloud, and the cloud can send commands and configuration back. Each device has its own identity and credentials, so the platform can authenticate it, and connections use standard protocols like MQTT and AMQP. The hub scales to large fleets and can route messages to storage, stream processing, and analytics services.

Management features help operate fleets. Device twins keep a record of each device's properties and desired settings, jobs update many devices at once, and a device provisioning service automates onboarding. Azure IoT Edge runs containerized code, including machine learning models, on devices so they can act without a cloud connection. It integrates with Azure Stream Analytics, Event Hubs, Functions, and Digital Twins.

IoT Hub is priced by tier and number of messages per day. Microsoft has evolved its IoT portfolio over time, retiring some higher-level offerings, so check the current recommended architecture. Alternatives include AWS IoT Core, Google Cloud's partners, and platforms like ThingsBoard, HiveMQ, and EMQX. Azure IoT Hub suits organizations building industrial or consumer IoT solutions on Microsoft's cloud.
