Labs goes beyond answering a question. You describe a project, such as a market analysis, a financial model, or a small dashboard, and Labs works for several minutes, combining web research, code execution, and chart creation. It then returns finished assets: a written report, a spreadsheet, charts, or a simple web app that you can download or share. The tool uses a team of specialized steps behind the scenes, so the output is more like a deliverable than a chat reply.

Typical uses include building a competitive analysis with supporting data, creating a presentation outline with charts, cleaning and analyzing a dataset, and prototyping a small tool. Everything produced is saved with the project, so you can inspect files and sources and ask for revisions. It sits alongside Perplexity's Deep Research and Spaces features.

Labs is available to paid Perplexity subscribers, with higher tiers getting more usage. Like other agent-style tools, results can contain errors in data or logic, and complex analysis should be checked. The older labs.perplexity.ai site was used as a playground for new models, which is a different thing. Alternatives include ChatGPT Work, Manus, Claude with its file-creation tools, and Google's Gemini Deep Research. Labs suits people who want a finished first draft quickly.
