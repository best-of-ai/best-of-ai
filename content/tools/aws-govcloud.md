AWS GovCloud is a separate set of AWS regions built for workloads that carry strict regulatory requirements. US government agencies, contractors, and other organizations handling controlled data use it to host systems that must comply with standards such as FedRAMP High, the Department of Defense Cloud Computing Security Requirements Guide, ITAR, CJIS, and HIPAA. The regions are physically and logically isolated from the standard AWS regions, and access is restricted to vetted US citizens.

Many AWS services are available, including compute, storage, databases, and a growing set of AI services. Customers can run machine learning and generative AI workloads, including access to models through Amazon Bedrock, while keeping data within the compliance boundary. Accounts are created through a specific process and linked to a standard AWS account for billing.

GovCloud is priced similarly to other AWS regions, usually somewhat higher, and only some services and the newest features are available there. Compliance is a shared responsibility, so customers must configure and operate their workloads correctly. Competitors include Microsoft Azure Government, Google Cloud's Assured Workloads, and Oracle's government regions. GovCloud suits organizations that must keep regulated data within a certified US environment.
