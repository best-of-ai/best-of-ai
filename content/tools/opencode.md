OpenCode is a coding agent that works in a developer's terminal. It reads a repository, plans changes, edits files, and runs commands, with a text interface for conversation. The same engine also runs behind a desktop app, editor extension, and web client.

Provider freedom is the main appeal. Users connect models from Anthropic, OpenAI, Google, and others, or open models run locally, and can switch between them. Configuration files add project rules, custom agents, and Model Context Protocol tools, and sessions can be shared.

OpenCode is free and open source, and users pay for the model access they use, with an optional hosted service. Quality depends on the model chosen. Alternatives include Claude Code, OpenAI Codex, Gemini CLI, Aider, and Kimi Code. OpenCode suits developers who want an open agent that works with many models.
