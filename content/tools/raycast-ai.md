Raycast puts a command bar on your keyboard. Press a hotkey, type a few letters, and you can launch apps, search files, run calculations, manage windows, paste snippets, control music, and use hundreds of extensions that connect to tools such as GitHub, Linear, Notion, and Slack. Power users value how much it can cut mouse use and context switching.

Raycast AI adds chat and commands powered by leading language models. You can ask a question, rewrite selected text, summarize a page, translate, or run custom AI commands from any app, and switch among models from different providers. AI Extensions let the assistant act through extensions, such as creating an issue or checking a calendar, and Model Context Protocol support connects it to more tools. Chats and presets are synced across devices.

Raycast has a free tier that includes core features and extensions, and a Pro plan that adds AI and cloud sync. The Mac version is more mature than the Windows one. Alternatives include Alfred, Spotlight, and macOS Shortcuts, along with PowerToys Run on Windows and the built-in assistants of ChatGPT and Claude desktop apps. Raycast suits keyboard-driven people who want AI at their fingertips.
