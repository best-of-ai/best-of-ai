Semgrep scans code for patterns. Rules look like the code they match, which makes them easier to write than traditional analyzers' queries. Teams use community rules for common vulnerabilities and write custom ones for their own standards, running scans in CI and on developers' machines.

The commercial platform adds dependency scanning, secrets detection, and a triage assistant that uses AI to explain findings, suggest fixes, and filter likely false positives. It integrates with pull requests and issue trackers.

The open-source engine is free, with paid plans for the platform. Static analysis always produces some noise that needs tuning. Alternatives include Snyk Code, GitHub CodeQL, SonarQube, Checkmarx, and Veracode. Semgrep suits engineering and security teams building security into code review.
