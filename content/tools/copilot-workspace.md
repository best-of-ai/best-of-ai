Copilot Workspace starts from a GitHub Issue rather than a blank prompt. It reads the issue description, your codebase, and relevant context, then produces a natural language specification of what needs to change and an implementation plan listing the specific files and changes required. You review both the spec and the plan before any code is generated — editing them if the AI's interpretation of the issue doesn't match your intent. Only after you confirm does it generate the actual code changes.

This review-before-generation workflow is what makes Copilot Workspace different from other autonomous coding tools. Rather than optimising for speed at the cost of transparency, it gives developers control at each step: approve the spec, adjust the plan, review the code, run the tests. The whole process happens in a browser-based environment with a built-in terminal — you can run tests, check the output, and push to a branch without touching your local development setup.

Copilot Workspace is available to GitHub Copilot subscribers — individual ($10/month), Business ($19/seat/month), or Enterprise tiers. Access is currently through GitHub's experimental Copilot features; the interface is integrated with GitHub's repository and issue management so there's no separate tool to set up. The primary use case is handling well-defined, scoped GitHub Issues — bug fixes with clear reproduction steps, small feature additions with clear requirements — where the AI can plan the implementation from a written description and execute it with developer oversight at each step.
