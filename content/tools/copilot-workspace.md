Copilot Workspace was GitHub Next's attempt to rethink how AI fits into the work of fixing an issue. Starting from a GitHub issue or a prompt, it first wrote a specification of the current and desired behavior, then a plan listing the files to change, and finally the code. At each stage, you could edit the text, so you steered the work in plain English before any code appeared. The finished changes could be opened as a pull request or run in a cloud environment.

It was a technical preview rather than a finished product, and it showed how GitHub thought agents might one day handle routine tickets. The preview has ended, and users can no longer create or open workspaces. GitHub has said the closest replacements are Copilot's agent mode in VS Code and the Copilot coding agent, which takes an assigned issue and works on it in the background, but these are not a one-to-one match.

If you want that style of workflow today, the coding agent inside GitHub Copilot is the nearest option, along with tools such as Devin, OpenAI Codex, Google Jules, and Claude Code. Those handle tasks end to end, usually returning a pull request for review. The spec-and-plan step that made Workspace distinctive now shows up in other tools as planning modes. This entry stays for reference, since links, articles, and alternatives pages still refer to it.
