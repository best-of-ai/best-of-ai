Microsoft Translator covers the common translation needs. You can type or paste text, speak into a phone for conversation translation, translate images and documents, and use offline language packs when traveling. Multi-device conversation mode lets several people speak in different languages and see translations on their own screens, which suits meetings and travel.

It's integrated throughout Microsoft products. Teams offers live captions and translated meetings, Office apps can translate documents and text, and Edge translates web pages. For developers and businesses, Azure AI Translator provides APIs for text, document, and speech translation, with custom models and glossaries, and options to run in containers.

The consumer app is free, and the Azure service is billed per character with a free tier. Translation quality is good across major language pairs and weaker for smaller languages, and critical text should be reviewed by a human translator. Alternatives include Google Translate, which supports more languages, DeepL, known for natural output in European languages, Amazon Translate, and large language models. Microsoft Translator suits people already working in Microsoft 365.
