Replit Agent 4 continues the idea that you can describe software and have an agent build it. In the Replit workspace, you explain what you want, and the agent writes the code, sets up the environment and database, tests the result, and deploys it. You review progress, give feedback in plain language, and ask for changes. Replit says this version is substantially faster than its predecessor, which matters because building an app involves many steps.

The new canvas widens what the agent can produce. Besides web and mobile apps, it can create spreadsheets, charts, and simple games, and work on several kinds of artifacts in one space. The agent is also available on mobile, so users can start or check projects from a phone. Built-in hosting and deployment mean a finished app can go live from the same place.

Agent 4 is part of Replit's paid plans, with usage measured in credits that long or complex builds can consume. As with all agent-built software, apps need review before they handle real users, payments, or sensitive data, and the agent can go in circles on ambiguous requests. Lovable, Bolt, v0, and Base44 compete for app building, while Cursor and Claude Code suit developers working in existing codebases. See the main Replit entry for the broader platform.
