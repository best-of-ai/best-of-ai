Examiners add a disk image and run ingest modules that find deleted files, web history, and keyword hits. Timelines and hash databases help organize findings. Plug-ins extend it.

It is used by law enforcement, corporate investigators, and students. Reports must be validated before use in court.

Magnet AXIOM and Cellebrite are commercial alternatives. Autopsy suits forensic scientists with limited budgets.
