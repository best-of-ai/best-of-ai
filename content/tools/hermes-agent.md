Hermes Agent is built for work that stretches over days. It keeps memory across sessions, searches past conversations, and writes a skill after it finishes a complex task, then refines that skill as it gets used. A built-in scheduler runs recurring jobs described in plain language and sends the results to your chat apps. Subagents handle parallel work, and MCP servers add outside tools.

You can talk to it from a terminal interface, a desktop app, or a gateway that connects Telegram, Discord, Slack, WhatsApp, and Signal. It runs on a local machine, a small VPS, Docker, SSH hosts, or serverless platforms such as Modal and Daytona, and it works with models from Nous Portal, OpenRouter, OpenAI, or your own endpoint. It can import settings, memories, and skills from OpenClaw.

The software is free under the MIT license, and you pay for the models you use. Nous Portal adds optional hosted tools and cloud agents on plans from $20 a month. GitHub showed about 266,000 stars in late November 2026. An agent with shell access and your accounts needs careful permissions. Alternatives include OpenClaw, Claude Duet, OpenAI Dots, and Gemini Spark. Hermes Agent suits people who want a self-hosted agent that improves as they use it.
