The Realtime API changes how voice applications are built. Older systems chained speech recognition, a language model, and speech synthesis, adding delay at each step. The Realtime API handles audio in and audio out directly in one model, so responses start sooner and can include tone, pauses, and interruptions that sound natural.

Developers connect over WebRTC or WebSockets to stream audio and receive speech, text, and tool calls. It supports function calling, so a voice agent can look up data or take actions, and it can be used for phone agents, in-app assistants, and language practice.

The API is billed by usage and costs more than text-only calls. Voice agents need careful handling of latency, interruptions, and safety. Alternatives include Google's Gemini Live API, ElevenLabs conversational agents, Vapi, Retell AI, and Twilio ConversationRelay. OpenAI Realtime API suits developers building voice experiences.
