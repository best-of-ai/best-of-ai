Kimi Code is a command line agent in the same family as Claude Code and Codex CLI. You start it in a project folder, describe a task, and it reads files, edits code, runs commands, and checks results, deciding what to do next based on what happens. Permissions let you approve risky actions.

It defaults to Moonshot AI's Kimi models, which are known for strong coding and long context, and can also connect to other compatible providers. Features include built-in subagents for coding, exploring, and planning, support for the Model Context Protocol to connect tools, lifecycle hooks for automation and safety checks, and an ACP mode so editors like Zed and JetBrains can drive it.

The tool is open source under the MIT license. Access to the models needs an account or an API key, and plans have limits. Several unofficial projects share the name, so use the official repository from Moonshot AI. Alternatives include Claude Code, OpenAI Codex CLI, Gemini CLI, OpenCode, and Aider. Kimi Code suits developers who want a terminal agent built around Kimi models.
