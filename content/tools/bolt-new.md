Bolt.new turns a conversation into a working application. You type what you want, such as a booking site, a dashboard, or a small SaaS prototype, and Bolt writes the code, installs the dependencies, and runs the result in a live preview in your browser. You can keep asking for changes, and it edits the project as you go. It is built on StackBlitz's browser-based development environment, so nothing needs to be installed on your computer.

Beyond generating code, it covers the work around deployment. Bolt Cloud provides hosting, custom domains, databases, user authentication, and analytics, so a project can go live from the same screen. You can begin from a prompt, a Figma design, a GitHub repository, or a team template. The AI selects a model suited to the task, and it tests and revises its own work to reduce errors. You can also download the code or open it in an editor to take over by hand.

Bolt has a free way to start, with paid plans that add usage, higher-end models, and team features. Each prompt consumes tokens, so long iterations on a big project can burn through an allowance quickly, and complicated apps may need a developer to finish. Lovable, v0, and Replit are the usual alternatives. Bolt works best for prototypes, internal tools, and landing pages.
