Bolt.new runs a complete Node.js development environment inside your browser using WebContainers, a technology StackBlitz originally developed to make web development fully browser-based. When you describe an app — "a to-do app with user authentication and a SQLite database" — Bolt generates the file structure, installs npm packages, writes the code, and spins up a live preview, all without touching your local machine. It fixes its own errors iteratively rather than surfacing them for you to debug.

The full-stack capability is what makes Bolt different from simple code generation tools. It handles frontend UI (typically React or Svelte), backend logic (Express, Node.js), database connections, and deployment configuration as an integrated whole. You can then continue iterating conversationally: "add a search bar to the task list," "make the login form validate email format," or "add dark mode." Each change is applied and previewed immediately.

The free tier gives limited daily tokens; the Pro plan at $20/month provides substantially more for heavier use. Bolt integrates with Netlify and other deployment platforms for one-click publishing when the app is ready. It's become popular with non-technical founders prototyping MVPs, designers validating UX ideas, and developers who want to scaffold a project quickly before migrating it to their own local setup.
