Editors work with large bin structures, shared storage, and detailed timeline tools. Collaboration features let several editors work on one project. Newer versions add AI-based transcription and script search (PhraseFind and ScriptSync).

It is sold by subscription or as a perpetual license, and a free first version exists with limits. The interface has a longer learning curve than consumer editors.

Premiere Pro, DaVinci Resolve, and Final Cut Pro are alternatives. Media Composer suits film editors working on large productions.
