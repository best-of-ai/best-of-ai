GetYouTubeTranscript works from a pasted YouTube link. It reads the video's existing caption track, in any caption language the video has, and shows the full transcript with clickable timestamps. The transcript can be copied, downloaded as TXT, SRT or VTT, or translated into another language. On the same page, an AI summary gives the main points, and a chat box answers questions about what was said in the video.

For larger jobs it can collect the transcripts of a whole channel or playlist at once. The same features are available as a Chrome extension, a REST API for developers, and an MCP server for assistants such as Claude and ChatGPT. It relies on captions, so a video without any caption track cannot be transcribed.
