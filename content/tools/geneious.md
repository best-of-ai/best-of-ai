Geneious gives molecular biologists a graphical environment for work that would otherwise need command-line tools. Researchers import sequence data from sequencers or databases, then view, align, annotate, and compare it in a visual interface. It supports de novo assembly and mapping of reads to a reference, building phylogenetic trees, designing primers, and planning cloning experiments, so a lab can do many routine tasks in one program.

A plugin system extends it with additional algorithms and workflows, including tools for antibody discovery, metagenomics, and variant analysis. Results are shared through a collaboration feature, and a server product lets teams work with common databases. The software is part of Dotmatics, which also owns other scientific R&D tools. Machine learning appears in specific tools and plugins instead of as a general assistant.

Geneious is sold as a paid license in Prime and Biologics editions, with academic and individual pricing, and a free trial. It is easier for non-programmers than command-line pipelines but less flexible than scripting in Python or R, and very large datasets are better handled on a server or cloud workflow. Competitors include CLC Genomics Workbench from Qiagen, SnapGene for cloning, Benchling for cloud-based collaboration, and free tools like MEGA and UGENE. Geneious is popular in academic labs and biotech companies.
