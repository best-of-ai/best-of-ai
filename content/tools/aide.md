Aide was an AI-first code editor from the London startup CodeStory. It was a fork of VS Code, so it looked familiar and could use extensions, but it added a layer of AI that understood the project. You could chat about the codebase, ask for changes across several files, and get completions informed by wider context. It was released as open source under the AGPL license, and the project drew substantial interest from developers looking for an alternative to Cursor.

CodeStory also did research on agent-style coding, including work on benchmark tasks that measure whether a model can fix real issues in open-source repositories. The editor was part of that effort, and it let people try agentic coding on their own projects with a choice of models.

Development stopped, and the editor is no longer maintained. The code remains available on GitHub for anyone who wants to fork it, but new users are better served by tools that are actively updated. Cursor, Windsurf, Cline, and GitHub Copilot are the usual alternatives, and Void was another open-source editor in the same category. This entry stays for reference, since older articles and comparison pages still mention Aide.
