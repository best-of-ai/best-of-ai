Workflows are YAML files that call reusable actions from a marketplace. Hosted runners run on Linux, Windows, and macOS, or teams can run their own. Secrets and environments control deployments.

Public repositories use it free, and private ones get a free allowance with paid usage after.

GitLab CI and CircleCI are alternatives. GitHub Actions suits DevOps engineers on GitHub.
