Plausible keeps analytics simple. A tiny script collects page views, visitors, referrers, devices, and locations without using cookies or storing personal data, so most sites do not need a consent banner for it. The dashboard fits on a single page, which makes it quick to read for people who don't want to learn a complex tool.

It supports goals and events, so site owners can track signups or purchases, and funnels for conversion steps. Features like UTM tracking and a stats API round out the basics. The code is open source, and users can self-host a free community edition or pay for the hosted service, which is run from European servers.

Plausible is paid for the hosted version, priced by monthly pageviews, with a trial. It offers less depth than Google Analytics, with no user-level tracking, which is deliberate. Alternatives include Fathom, Umami, Matomo, Simple Analytics, and PostHog. Plausible suits site owners who want straightforward, privacy-respecting analytics.
