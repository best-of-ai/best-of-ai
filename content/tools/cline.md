Cline is an autonomous coding assistant that lives in your editor. You describe a task, and it works through it: reading the relevant files, proposing edits, running commands, and checking the result. It has a Plan mode, where it explores the project and agrees an approach with you, and an Act mode, where it carries the plan out. Each file change and terminal command is shown for your approval, so you stay in control, though you can switch on auto-approval for lower-risk actions.

It can do a lot more than edit text. With a browser tool, it can launch the app it is building, click through it, and look at screenshots to find problems. It supports the Model Context Protocol, so you can add tools such as database access or custom APIs. Checkpoints let you roll back a project to an earlier state if a run goes wrong. Cline is also available as a command-line tool and an SDK.

The extension is free and open source under the Apache 2.0 license, and you bring your own model. It works with Anthropic, OpenAI, Google, AWS Bedrock, OpenRouter, and local models through Ollama or LM Studio. You pay the provider for tokens, and agentic sessions can use many of them, so costs are variable. Roo Code and Kilo Code are forks that build on the same idea. Cursor and Claude Code are the closest commercial alternatives.
