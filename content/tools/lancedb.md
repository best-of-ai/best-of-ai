LanceDB is a database for AI data. It stores vectors alongside the original data, such as text, images, and video references, and supports similarity search, filtering, and full-text search. Because it is embedded, it runs inside an application with no server, similar to how SQLite works for relational data.

The Lance format makes it efficient for large datasets: it keeps data on disk, supports versioning, and allows fast random access, so it can handle collections that do not fit in memory. A cloud and enterprise offering adds scalability and managed service. It is used for retrieval in AI applications and for managing training data.

LanceDB is free and open source, with paid cloud plans. It is younger than some alternatives. Alternatives include Chroma, Qdrant, Pinecone, Weaviate, and pgvector. LanceDB suits developers building retrieval systems and multimodal data pipelines.
