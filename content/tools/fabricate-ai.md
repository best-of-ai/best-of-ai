Fabricate belongs to the group of prompt-to-app tools. A user describes the application, and the platform generates the interface, server logic, and data storage, then deploys it so it can be used right away. The user keeps refining by asking for changes in chat.

It is meant for prototypes, internal tools, and simple products. Getting from idea to something usable in minutes helps founders test concepts. Generated applications need testing, and authentication, payments, and security deserve a careful look before launch with real users.
