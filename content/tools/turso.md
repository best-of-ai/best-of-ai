Turso brings SQLite to the cloud. libSQL adds features to SQLite such as network access and replication, and Turso hosts databases and replicates them to regions near users for fast reads. It also supports embedded replicas that live inside an application.

The model suits products with a database per user or tenant, because creating a new database is cheap. Vector search support helps with AI features, and agents can use databases as disposable storage.

Turso has a free tier and usage-based plans. SQLite's design limits some heavy write workloads. Alternatives include Neon, PlanetScale, Cloudflare D1, Supabase, and Fly.io LiteFS. Turso suits developers building edge and multi-tenant apps.
