OpenClaw started as a personal project that let people message an AI agent through apps like WhatsApp and have it act on their computer. It went through a couple of names early on, including Clawdbot and Moltbot, before settling on OpenClaw, and grew quickly in popularity among developers and enthusiasts.

The agent can browse, run commands, manage files, and connect to services, with a memory that persists and skills that extend its abilities. Because it is self-hosted and MIT licensed, users run it themselves and choose which model to use, which appeals to people who want control.

That control comes with risk. An agent with access to a machine and accounts can be tricked by malicious content or make destructive mistakes, so run it in an isolated environment with limited permissions. It is free, with costs for the model APIs. Alternatives include ChatGPT agent mode, Claude with computer use, Manus, Lindy, and Hermes-based agents. OpenClaw suits technical users comfortable managing a self-hosted agent.
