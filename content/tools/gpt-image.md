GPT Image brings image generation into the same model family that handles text. A user describes an image or uploads one to edit, and the model generates or modifies it, following detailed instructions and rendering readable text, which earlier image models struggled with. It can edit photos, change styles, and keep a subject consistent across images.

The model is available inside ChatGPT, where conversation lets users refine results step by step, and through the API for developers building apps. It replaced the DALL-E models in OpenAI's lineup. Smaller and faster variants exist for cost-sensitive use.

GPT Image is included with ChatGPT plans with usage limits, and billed by usage in the API. Generated images carry provenance metadata, and policies restrict some content. Alternatives include Midjourney, Google's Imagen and Nano Banana, Adobe Firefly, Flux, and Stable Diffusion. GPT Image suits users who want conversational image creation and editing.
