Cowork takes the agent approach behind Claude Code and puts it in a regular app window. Instead of typing commands, you describe a job such as sorting a folder of receipts, turning notes into a report, or building a spreadsheet from several PDFs. Claude plans the steps, works on the files you have shared with it, and reports back when it is done.

It is aimed at office work more than software projects. You choose which folders it can see, so it only touches what you hand over. It suits repetitive jobs where you would otherwise copy and paste between documents all afternoon.
