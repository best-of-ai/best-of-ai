Super-Agent explores what a team-facing coding agent could look like. Built on DeepSeek's Harness runtime, it is tied to one GitHub repository and listens for requests from approved colleagues in Feishu, a workplace chat app. A teammate can ask it to investigate or change something, and it works on the code and reports back.

The prototype shows how a lab thinks about agents inside everyday collaboration tools instead of only in a developer's terminal. Because it is a prototype, it focuses on demonstrating the design, not on a polished product with broad integrations, and it requires technical setup.

The code is open source and free, and costs come from the models and infrastructure you connect. As an early project, expect rough edges, changing interfaces, and limited documentation, and review any agent's changes before merging. Alternatives include Claude Code with GitHub integrations, OpenAI Codex cloud, Devin, Factory, and Cursor background agents. DeepSeek Super-Agent suits developers curious about team-based agent designs.
