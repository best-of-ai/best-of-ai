Enlighten Animation Labs designs tools that merge artistic creativity with multimodal artificial intelligence. Its main product, Superpencil, is a digital sketchpad that allows realistic drawing, automated design generation, and plain-language workflow creation. It functions on both iPad and web platforms using Apple Pencil or touchpad. Users can start with sketches and then instruct the system in natural language to generate final artworks. Synthesizer, the engine behind Superpencil, provides scalable and stable AI inference, enabling consistent batch outputs and reusable templates. It includes version control for branching and restoring work. The system gives creators a sketch-first environment that combines automation and collaboration for all experience levels.
