Users write code in notebooks, and charts update as data changes. Observable Plot offers a concise chart API, and Observable Framework builds static data apps. Teams share notebooks and dashboards.

It requires some JavaScript knowledge, which is a barrier for non-coders.

Datawrapper and Flourish are no-code alternatives. Observable suits data visualization specialists who code.
