LM Studio makes running models on your own computer approachable. You open the app, search a catalog of models from Hugging Face, download one that fits your hardware, and start chatting, with no command line needed. Everything runs locally, so conversations stay on your machine, you can work offline, and there are no per-token fees. It supports popular open models such as Llama, Qwen, Gemma, and gpt-oss.

For developers, LM Studio can start a local server that mimics the OpenAI API, so existing tools and scripts can point at your own model. It supports multiple model formats, including GGUF and Apple's MLX for efficient performance on Mac, lets you tune settings such as context length and GPU offloading, and works with the Model Context Protocol to connect tools. A command-line version and SDKs support automation.

The app is free for personal and work use, and its code is not fully open source. Performance depends on your hardware, and smaller local models are less capable than frontier cloud models. Alternatives include Ollama, which is more command-line oriented, Jan, GPT4All, Open WebUI as an interface, and llama.cpp directly. LM Studio suits people who want a polished app to experiment with local AI.
