Penpot is built for collaboration between designers and developers. It uses open web standards, so designs map to real code, and supports flexible layouts based on CSS grid and flex. Teams create prototypes, design systems, and shared components in a browser.

Being open source matters to some teams. They can host Penpot themselves, keep control of their data, and avoid vendor lock-in, and developers can inspect designs and get code in a familiar form. AI features and plugins extend the tool.

Penpot is free, with a cloud service and paid plans for hosting and support. It has fewer plugins and a smaller community than Figma. Alternatives include Figma, Sketch, Framer, Lunacy, and Adobe XD, which is no longer developed. Penpot suits teams that want open, self-hostable design tools.
