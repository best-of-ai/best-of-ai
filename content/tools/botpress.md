Botpress started as an open-source tool for building chatbots with visual flows, and it grew into a platform around large language models. Developers and technical teams build agents that talk with customers on websites and messaging channels, connect to knowledge bases, and call APIs to do things like check an order or update an account. A visual builder and code options sit side by side, so non-engineers can adjust conversations while developers handle integrations.

The current focus is customer support. Botpress agents can work on top of an existing helpdesk or run in its own desk product. They answer questions, handle multi-step requests such as refunds or account changes, and escalate to people when needed. Teams can test agents, review conversations, and see analytics. Support for many languages and channels, including WhatsApp, Messenger, and web chat, is part of the platform.

Botpress has a free tier for building, with paid plans based on usage and enterprise options, and the company stresses that AI usage is included instead of charged per message. Building a dependable agent still takes work on knowledge content, testing, and guardrails. Competitors include Intercom's Fin, Zendesk AI, Voiceflow, Chatbase, and open-source options like Rasa. Botpress suits companies that want more control than a prebuilt support bot offers.
