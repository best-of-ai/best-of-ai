Vibe is Mistral's agent for software work. The command-line version runs in a project directory, reads and writes files, searches code, runs shell commands, and tracks tasks, using Mistral's coding models to carry out requests such as fixing bugs, adding features, and explaining code. It is open source under the Apache 2.0 license, written in Python, and integrates with editors such as Zed and with other tools.

The broader Vibe offering extends agent capabilities to office tasks and teams. It builds on Mistral's Devstral coding models and its large general models, which are available through Mistral's API and, for some, as open weights that organizations can run on their own servers. This flexibility is a selling point for companies and governments that want agents without relying on US cloud providers.

Vibe is available on a free tier and in paid plans, with details depending on the model and platform used. Agentic output requires review, and a smaller ecosystem than competitors like Claude Code or Codex means fewer integrations. Alternatives include Claude Code, OpenAI Codex, Gemini CLI, Cline, Aider, and Cursor. Vibe suits developers and organizations that want an open, European coding agent.
