Supabase provides what an application needs behind the scenes. It gives developers a hosted Postgres database with auto-generated APIs, user authentication, file storage, real-time updates, and serverless edge functions, all manageable from a web dashboard. It's often described as an open-source alternative to Firebase, with the advantage of using standard SQL and a portable database.

For AI, Supabase supports the pgvector extension, which stores embeddings in Postgres and enables similarity search, so developers can build semantic search and retrieval-augmented generation without a separate vector database. Edge functions can call language models, and an AI assistant in the dashboard helps write SQL and design schemas. It has become a popular backend for AI app builders such as Lovable and Bolt.

Supabase has a free tier suited to projects and prototypes and paid plans based on usage, and it can be self-hosted since the code is open source. Scaling a database still requires understanding of Postgres, and the free tier pauses inactive projects. Alternatives include Firebase, Neon and PlanetScale for databases, Appwrite and Convex as backends, and AWS Amplify. Supabase suits developers who want a flexible, SQL-based backend.
