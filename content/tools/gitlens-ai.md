GitLens enriches VS Code with Git history. It shows inline blame annotations that say who last changed a line, when, and in which commit, and lets you browse the history of a file, line, or branch without leaving the editor. Features include a commit graph, comparisons across branches, and a Launchpad that gathers pull requests and issues. It's one of the most downloaded extensions for VS Code.

AI features help with common Git chores. GitLens can write commit messages from staged changes, summarize what a commit or branch changed in plain language, and help draft pull request descriptions, saving time on documentation. It supports several AI providers and models, with options for how data is sent.

GitLens has a free tier with many features and paid plans for advanced capabilities such as Launchpad and workspaces, as part of the GitKraken ecosystem. AI summaries should be checked against the actual diff. Alternatives include built-in Git features in VS Code, GitHub Copilot's commit message generation, GitKraken Client, Sourcetree, and Lazygit for the terminal. GitLens suits developers who work in VS Code and want deeper insight into their code's history.
