Insomnia is a desktop application that lets developers send requests to APIs and inspect responses. You build requests with headers, authentication, and bodies, organize them into collections, and use environment variables to switch between development and production. It supports REST, GraphQL, gRPC, WebSocket, and Server-Sent Events, and can import definitions from OpenAPI specifications.

Beyond manual testing, it supports design and automation. An API design editor helps write specs, test suites run collections of requests with assertions, and command-line tools run tests in CI. Plugins extend functionality, Git sync stores collections with code, and AI features help generate requests, tests, and documentation. Insomnia can store data locally or in the cloud, a choice that matters to teams concerned about privacy.

Insomnia is open source, with a free tier, and paid plans for team collaboration and enterprise features. It competes in a space where users have moved among tools as vendors changed their approaches to cloud accounts. Alternatives include Postman, which is the market leader, Bruno, an open-source and offline-first client, Hoppscotch, Thunder Client for VS Code, and curl. Insomnia suits developers who want a clean, local-friendly API client.
