Sonar lets developers build apps that answer questions using current web information. Instead of relying only on a model's training data, a request to Sonar searches the web, reads relevant pages, and returns a response with citations. That grounding is useful for assistants, research tools, news summaries, and any product where freshness and sources matter.

There are several variants. The standard Sonar models are fast and low-cost, Sonar Pro handles more complex queries with more sources, Sonar Reasoning adds step-by-step analysis, and Sonar Deep Research runs multi-step research jobs and writes longer reports. A Search API offers ranked web results for developers who want to feed content to their own models. The API follows a format familiar to users of OpenAI's, so adoption is simple, and options control which domains to search and how recent results should be.

Sonar is billed by tokens plus a charge per search request, with different rates by model and search depth, and there is no meaningful free tier. Costs add up for high-volume apps, and answers can still contain errors or rely on weak sources. Alternatives include OpenAI's and Google's search-grounded models, Exa and Tavily for search APIs, Brave Search API, and Anthropic's web search tool for Claude. Sonar suits teams that want a ready-made search-plus-LLM service.
