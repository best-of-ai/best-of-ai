GitLab Duo integrates AI into the places where developers already work in GitLab. In the editor, it suggests code and generates tests, in merge requests it summarizes changes and helps with code review, and a chat assistant answers questions about code, issues, and GitLab itself. For DevSecOps, it can explain security vulnerabilities and propose fixes, and help find the root cause when a CI/CD pipeline fails.

The company has also introduced agent capabilities that can take on tasks across the software lifecycle, such as planning, coding, and review, with human oversight. Because it works within GitLab, it has access to context from repositories, issues, and pipelines, which general assistants lack. Self-managed customers can use it with their own deployment, and organizations control which models and features are available.

GitLab Duo is sold as an add-on to paid GitLab tiers or included in higher ones, with details changing over time. It's most valuable to teams that already use GitLab as their central platform. Alternatives include GitHub Copilot for GitHub users, Sourcegraph, Amazon Q Developer, and Cursor or Claude Code for editor-based work. As with all AI coding features, review generated code and security suggestions carefully.
