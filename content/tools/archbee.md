Archbee helps teams write and publish documentation. The editor supports rich text, code blocks, diagrams, and embedded content, and spaces organize material into sections with navigation and search. Teams can keep docs private for internal use or publish them as polished public sites with custom domains and branding, which makes it suitable for product help centers and developer portals.

Features for technical documentation include API reference generation from OpenAPI specs, Git integration to sync docs with repositories, version control, and review workflows. AI features provide smarter search and an assistant that answers questions from your documentation, plus writing help. Analytics show which pages are read and what readers search for but cannot find.

Archbee has a free plan and paid plans for teams with more spaces, collaborators, and features. It is smaller than some competitors in the market, so integrations and community resources are more limited. GitBook, Mintlify, ReadMe, Docusaurus, and Confluence cover similar needs, with Mintlify focusing on developer experience and Confluence on internal wikis. Archbee suits product and engineering teams that want a straightforward way to publish documentation.
