MLflow began at Databricks as a way to bring order to machine learning work. Teams log parameters, metrics, code versions, and artifacts for each run, compare results in a web interface, and package models in a standard format that can be deployed in many environments. A model registry manages versions and stages.

The project has extended to generative AI. It supports tracing of LLM applications, evaluation tools, and prompt management, making it useful for teams building with language models as well as classic models. It works with most ML libraries and cloud platforms.

MLflow is free and open source, and available as a managed service in Databricks and other clouds. Running it yourself requires infrastructure. Alternatives include Weights & Biases, Comet, Neptune, ClearML, and Langfuse for LLM tracing. MLflow suits teams wanting a vendor-neutral standard.
