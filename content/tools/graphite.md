Graphite is built around a workflow in which large changes are split into small, dependent pull requests. This stacked approach, popular at big tech companies, lets engineers keep working on the next piece without waiting for the previous one to be reviewed and merged. Graphite provides a command line tool and a web interface that make managing stacks simple, which plain GitHub handles awkwardly.

It adds features around review. A merge queue keeps the main branch healthy by testing and merging changes in order, an inbox helps reviewers see what needs attention, and insights show how long reviews take. An AI reviewer comments on pull requests to catch bugs and style problems, which matters as more code is written by AI assistants.

Cursor acquired Graphite to bring review closer to the editor, and the product continues to work with GitHub repositories. It has a free tier for individuals and paid plans for teams. Adopting stacked pull requests changes habits, so teams need buy-in. Alternatives include GitHub's native tools, CodeRabbit, Greptile, Reviewable, and Phabricator-style workflows. Graphite suits teams that want faster, cleaner code review.
