Developers define assets in Python and Dagster tracks lineage and freshness. A UI shows runs and dependencies, and tests run locally. Dagster Cloud offers a hosted service.

The open-source core is free. It differs from Airflow in structure, so teams moving over need to adjust.

Airflow and Prefect are alternatives. Dagster suits data engineers who want asset-based pipelines.
