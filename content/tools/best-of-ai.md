Best of AI is a directory for finding AI tools without wading through hype. It lists tools by what they do, across more than a hundred categories such as code assistants, image generation, and meeting assistants, and by who uses them, with profession pages for designers, developers, marketers, lawyers, teachers, and many others. Each tool has a page with a description, category, price tier, website, tags, and links to alternatives.

The site is built from files in a public repository. Every tool is a Markdown file with structured fields, so anyone can suggest a new listing or a correction through a pull request or an issue. The site is generated with Hugo as static pages, and search and filtering run in the browser with no server. Rankings reflect how well established a tool is, and lists are sorted so active products come before discontinued ones, which are kept visible but marked.

The directory is free to use. Because AI tools launch, merge, and shut down quickly, any listing can fall behind reality, so checking the official site before you pay is sensible. Other directories include There's an AI for That, Futurepedia, and Product Hunt, which lean toward volume and newness. Best of AI aims to be smaller and more selective, with pages that explain what each tool is rather than only listing it.
