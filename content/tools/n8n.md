n8n lets you build automations by connecting nodes on a canvas, similar to Zapier or Make, but with more room for code. Each node is a step: a trigger like a webhook or schedule, an action in an app, or a block that transforms data with JavaScript or Python. Hundreds of integrations are included, and a generic HTTP node covers the rest. Workflows can branch, loop, and call other workflows, so it handles anything from simple notifications to elaborate data pipelines.

AI is now a large part of the product. n8n includes nodes for language models, tools, memory, and vector stores, so you can build agents that read email, search documents, call APIs, and decide what to do next. You can see each run step by step, add human approval before sensitive actions, and swap in different model providers. This makes it a popular way to prototype and operate AI agents without writing a full application.

The code is available on GitHub under a fair-code license, and you can run it yourself on a server or in Docker, which keeps data in your own environment. n8n Cloud is the hosted option, with plans that scale by executions, and enterprise plans add single sign-on, access controls, and audit logs. Self-hosting is cheap but means you handle updates, security, and uptime. Zapier is easier for non-technical users, and Make is the closest visual rival.
