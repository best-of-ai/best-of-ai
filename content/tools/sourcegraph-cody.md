Cody grew out of Sourcegraph's code search, which indexes entire repositories and lets developers find and understand code across many projects. That context was its main advantage: instead of guessing from the open file, Cody could draw on the broader codebase to answer questions, write code that matched existing patterns, and explain how parts of a system fit together. It worked in VS Code, JetBrains IDEs, and the web, with chat, autocomplete, and commands to edit and test code.

The product has changed. Sourcegraph stopped Cody's Free and Pro plans for individuals, and it also removed Cody from the Enterprise Starter plan. Cody Enterprise remains available for large organizations that use Sourcegraph's platform, where its codebase awareness is most useful. For newer agent-style coding, Sourcegraph introduced Amp, a separate tool built for agentic workflows.

If you are evaluating tools today, Cody makes sense mainly for companies already running Sourcegraph and needing code intelligence over very large, multi-repository codebases, with the option to use models from several providers. Enterprise deployments can run in the customer's own environment. Individual developers should look at GitHub Copilot, Cursor, Claude Code, or Amp. Older reviews that mention a free Cody plan describe something that is no longer offered.
