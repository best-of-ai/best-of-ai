Forta provides security monitoring for blockchain applications. Independent developers write detection bots that scan transactions and state changes across networks, looking for patterns that signal attacks, such as sudden fund movements or unusual contract calls. Bots publish alerts to the network, which protocols and users can subscribe to.

Machine learning models are used for some detections, such as spotting scams or anomalies. Protocols use Forta alerts to trigger their own responses, such as pausing contracts. A marketplace of bots covers many threat types and chains, and its token supports staking and rewards for bot operators.

Forta has free access to some alerts and paid options for commercial use. Detection can produce false alarms, and speed matters because exploits happen in minutes. Alternatives include OpenZeppelin Defender, CertiK Skynet, Hypernative, Chainalysis, and Tenderly alerts. Forta suits blockchain projects that want real-time monitoring.
