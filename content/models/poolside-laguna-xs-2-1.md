Laguna XS 2.1 is Poolside's smallest open-weight coding model, launched July 2, 2026 as a free download on Hugging Face and OpenRouter ahead of the larger Laguna S 2.1 release later that month. It's a 33 billion parameter mixture-of-experts model small enough to run on a single GPU while still handling multi-step software engineering tasks, and it ships with DFlash speculator models to speed up inference. Like the rest of the Laguna line it's released under OpenMDW-1.1, a permissive license Poolside designed specifically for AI model weights, aimed at developers who want an agentic coding model they can self-host without a large hardware budget.
