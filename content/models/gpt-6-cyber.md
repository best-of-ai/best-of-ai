GPT-6 Cyber is OpenAI's security-testing model for investigating a vulnerability, reproducing it in an authorized test environment and checking a fix. An organization needs Daybreak Red access and approval to call it, and the account team confirms that access. Trackers date its availability to November 5, 2026.

It has a 1.05 million token context window with up to 128,000 output tokens. Prices are $20 per million input tokens and $100 per million output tokens for prompts up to 272,000 tokens. Longer prompts cost $40 and $150. It runs on Chat Completions and the Responses API, with function calling, code interpreter, hosted shell, computer use and MCP, but there is no Batch API.
