Claude Opus 4.5 is the Opus-tier model Anthropic released on November 24, 2025, and its headline change was price: input tokens dropped to $5 per million and output to $25 per million, a two-thirds cut from Opus 4.1's $15/$75 rate. It scored 80.9 percent on SWE-bench Verified at launch, ahead of Gemini 3 Pro's 76.2 percent and GPT-5.1 Codex Max's 77.9 percent on the same benchmark, and Anthropic added an "effort" parameter that lets developers dial reasoning depth up or down per request. It kept the 200,000 token context window and image input support from earlier Opus releases, and shipped alongside a round of Claude Code updates aimed at longer autonomous coding sessions. Anthropic followed it with Opus 4.6 in February 2026 and Opus 4.7 in April, each holding the same $5/$25 pricing while pushing coding scores further.
