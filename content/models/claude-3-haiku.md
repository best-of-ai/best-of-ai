Claude 3 Haiku is the smallest and fastest model in Anthropic's original Claude 3 family, launched in March 2024 alongside Sonnet and Opus. It was built for high-volume, latency-sensitive work such as customer support chat, content moderation, and data extraction, where a slower flagship model would be overkill. At $0.25 per million input tokens and $1.25 per million output tokens, it undercut most competing models on price while still reading images alongside text and handling a 200,000 token context window. Anthropic has since released faster, cheaper models in the Haiku line, so Claude 3 Haiku is now a legacy option kept available mainly for existing integrations built on it.
