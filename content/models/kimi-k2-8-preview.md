Moonshot AI rolled out Kimi K2.8 Preview on September 11, 2026, slotting it between the open-weight Kimi K2.7 Code and flagship Kimi K3. It landed inside Kimi Code and Kimi Work the same day with no configuration changes needed, added image and video input on top of text, and bumped every membership tier's context window from 262,144 to 1 million tokens. Adjustable thinking effort (low, high, or max) now matches the K3 series, with max as the default.

Unlike K2.7 Code and K3, both released as open weights, K2.8 Preview is closed and available only through Moonshot's own API and apps. The company hasn't fully explained the shift, though the timing lines up with a model Moonshot describes as performing close to K3 at a lower tier.
