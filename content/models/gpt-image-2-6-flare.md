GPT Image 2.6 Flare is one of two image models OpenAI added to its API on November 4, 2026. Flare is the variant that can return SVG vector graphics and animated GIFs alongside regular images, which makes it useful for logos, icons and short loops that need to stay editable.

OpenAI documented the release in its API changelog without a dedicated launch post. Trackers list image output at about $30 per million tokens. Its sibling, GPT Image 2.6 Sunburst, targets precise control over the result.
