Grok 4.5 is xAI's model released on July 8, 2026, built with a heavier emphasis on coding, agentic workflows, and knowledge work than earlier Grok releases. On the independent Artificial Analysis Intelligence Index it scored 54, placing fourth overall among frontier models while taking the top spot specifically on agentic tool use, and it posted 83.3 percent on Terminal-Bench 2.1 and 64.7 percent on SWE-Bench Pro, both benchmarks aimed at real coding and terminal tasks rather than multiple-choice knowledge tests. It carries a 1-million-token context window and handles text and image input, and xAI priced it at $2 per million input tokens and $6 per million output tokens, with a cheaper $0.50 rate for cached input tokens. It's reachable through the xAI API console, the Grok app, X, and a wide set of third-party integrations including Cursor, OpenRouter, Vercel, and Microsoft's Word, Excel, and PowerPoint add-ins. Some coverage framed it as xAI's answer to Anthropic's Opus-class models, given the shared focus on long agentic coding sessions.
