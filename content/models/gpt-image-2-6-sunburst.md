GPT Image 2.6 Sunburst arrived in the OpenAI API on November 4, 2026, together with Flare. Sunburst is the precision-control variant, meant for work where small, exact changes to an image matter more than a fresh generation each time.

OpenAI listed it in its API changelog and did not publish a separate announcement. Trackers put image output at about $30 per million tokens. Pick Flare instead when you need SVG or animated GIF output.
