Meta released Muse Glimmer on August 10, 2026, a 30 billion parameter model distilled from its larger Muse Spark 1.2 and built specifically to run always-on agentic tasks on a single consumer GPU rather than in the cloud. It pairs a causal language model with a dedicated perception encoder, folding multi-step reasoning, tool use, multimodal understanding, and failure recovery into one model that keeps working without network access. Meta says it beats similarly sized models from Google and Alibaba on agentic benchmarks and holds its own against models twice its size on reasoning tasks. Weights are open under the Apache 2.0 license, aimed at developers building privacy-sensitive coding assistants, document analysis tools, and personal agents that need to run locally.
