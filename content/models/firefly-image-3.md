Firefly Image 3 is Adobe's image generation model, introduced in April 2024 as an upgrade over the original Firefly model that launched in 2023. Adobe trained it to be commercially safe, meaning it draws only on licensed Adobe Stock content, public domain material, and other content Adobe has rights to use, which lets business customers generate images without the copyright uncertainty tied to models trained on scraped web data. It improved on its predecessor with better prompt understanding, sharper detail, and Structure Reference and Style Reference tools that let users guide output using an existing image's composition or visual style. Adobe built it into Photoshop, Illustrator, Adobe Express, and the standalone Firefly web app, with API access for enterprise integrations. Adobe has continued to ship newer Firefly image models since, and it retired Image 3 from its model picker in 2026 in favor of those successors.
