Firefly Vector is Adobe's generative model for producing editable vector graphics from text prompts, first shown at Adobe MAX in October 2023 as a beta feature inside Illustrator. Adobe describes it as the first generative AI model built specifically for vector output rather than raster images, which matters because vector graphics need to stay editable as paths and shapes rather than fixed pixels. It powers Illustrator features like Text to Vector Graphic, Generative Shape Fill, Generative Recolor, and Text to Pattern, letting designers generate logos, icons, and patterns they can still resize and edit like any other vector artwork. Like the rest of the Firefly line, it trains only on licensed and public domain content so outputs are safe for commercial use. Adobe has kept expanding the model's capabilities through Illustrator's regular feature updates rather than treating it as a single fixed release.
