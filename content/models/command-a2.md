Command A2 succeeds Command A as Cohere's flagship model, keeping the same enterprise-first pitch: strong retrieval-augmented generation, tool use, and multilingual support over chasing chatbot benchmarks. It's priced at $2.50 per million input tokens and $10 per million output tokens, and it's reachable through Cohere's own API as well as AWS Bedrock, Azure AI Foundry, and Oracle Cloud, the same multi-cloud distribution Cohere has relied on since Command R.

Cohere continues to sell mainly to enterprises building internal search and document-QA systems rather than consumer-facing products, and Command A2's improvements are aimed squarely at that audience: better grounding on retrieved documents and more reliable citation of sources, both areas where the company has staked its reputation against larger labs with flashier general-purpose models.
