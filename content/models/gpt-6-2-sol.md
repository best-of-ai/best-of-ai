GPT-6.2 Sol launched on November 17, 2026 next to Astra and is the one OpenAI staff use as their default model. It handles coding and agent workloads at $2 per million input tokens and $10 per million output tokens, the same rates as GPT-6.1 Sol. The context window is 1.05 million tokens, with up to 128,000 output tokens.

OpenAI says Sol gains 5.3 points over GPT-6.1 Sol on GDPval v2. On FrontierCode 2.0, with both models at max effort, it lands within 0.5 points of Astra at about a fifth of the cost. The API model ID is gpt-6.2-sol, and the model supports web search, computer use and the multi-agent beta in the Responses API.
