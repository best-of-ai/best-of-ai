Claude 3 Sonnet is the middle tier of Anthropic's original Claude 3 family, released in March 2024 alongside the smaller Haiku and the larger Opus. It was pitched as the balance point of the lineup: strong enough for most business tasks like summarization, coding help, and data analysis, but priced and sized to run more cheaply than Opus. At $3 per million input tokens and $15 per million output tokens, with a 200,000 token context window and support for image inputs, it became a common default for teams building on the Claude API in 2024. Anthropic replaced it a few months later with Claude 3.5 Sonnet, which outperformed it on most benchmarks at the same price, so Claude 3 Sonnet is now a legacy model.
