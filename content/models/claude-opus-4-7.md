Claude Opus 4.7, released April 16, 2026, is a direct upgrade to Opus 4.6 aimed at the hardest software engineering tasks, the ones where earlier Opus models still stumbled on large, unfamiliar codebases. Pricing held at $5 per million input tokens and $25 per million output tokens, and it kept the 1 million token context window with up to 128,000 tokens of output. It shipped with a new tokenizer that produces up to 35 percent more tokens for the same input text, a tradeoff Anthropic made to improve accuracy on code-heavy prompts. It's available through claude.ai, the API, Amazon Bedrock, Google Vertex AI, and Microsoft Foundry.
