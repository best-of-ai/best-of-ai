Laguna S 2.1, released July 21, 2026, is Poolside's open-weight foundation model for agentic coding, a 118 billion parameter mixture-of-experts system that activates 8 billion parameters per token and supports up to a 1,048,576 token context window. It scores 78.5 percent on SWE-Bench Multilingual, tops the published table among open models of disclosed size, and reaches 70.2 percent on Terminal-Bench 2.1 while staying competitive with rivals many times larger. Weights are available on Hugging Face under Poolside's own OpenMDW-1.1 license, and hosted access through OpenRouter runs free up to a 256K context window, with the full 1 million token context priced at $0.10 per million input tokens and $0.20 per million output tokens.
