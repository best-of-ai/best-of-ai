MAI Code 2 Flash is the smaller sibling of MAI Code 2, announced on November 17, 2026 at Ignite. Microsoft built it for high-volume jobs such as code explanations, targeted edits and routine fixes. It is in GitHub Copilot and in limited-access preview in Microsoft Foundry.

Microsoft says its benchmark average is comparable to GPT-6 Luna and Claude Haiku 5.5 at a fraction of their cost, and gives no per-token prices. A derived model, MAI Work Flash, is built from Code 2 Flash to run in Microsoft 365 and FabricIQ.
