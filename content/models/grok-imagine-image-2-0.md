xAI released Grok Imagine Image 2.0 on August 7, 2026 as the new Quality Mode inside Grok's image tool, on the web and in the iOS and Android apps. Instead of leading with raw generation quality, the update centers on editing: a magic wand tool that changes only the region a user points at, segmentation for selecting precise areas, background removal that exports a subject with transparency, multi-reference generation from up to five input images, Smart Resize across nine aspect ratios, and sharper text rendering for typography-heavy images. On the Arena leaderboards it landed at number two worldwide in both text-to-image and image editing, behind OpenAI's gpt-image-2 in both categories.

There's no public API yet. Access runs through Grok's paid subscription tiers, with xAI saying API access is coming later.
